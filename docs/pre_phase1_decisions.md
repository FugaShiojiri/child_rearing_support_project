## サマリー（最重要・最初に決めるべき5つ）

Phase 1 はインタビュー20件＋LP登録50件が卒業条件であり、**「LP公開」と「お金を受け取る前」**の2つのゲートを越えるために、以下5つを来週〜2週間以内に確定する必要がある。

1. **サービス名・LINE/note アカウント名・Gmail アドレスの確定**（LP公開・note執筆・LINE開設すべての前提）→ ブランディング案で詳述。独自ドメインは購入せず、Gmail＋無料サブドメインで運用。
2. **特定商取引法表記とプライバシーポリシーの整備**（LP公開＝有料予約金の徴収開始時点で必須。個人事業主は住所非公開特例を活用、CEO 自身のドラフトで対応）→ 法務案で詳述
3. **個人事業の開業届提出と事業用銀行口座の開設**（Stripe等の決済プロバイダ審査・領収書発行・青色申告のため）→ 事業基盤案で詳述
4. **Phase 1 終了時の Go/No-Go 判定基準と撤退ライン（時間・成果ベース）の数値化**（撤退ルールがないと「サンクコストで継続」する最大リスク回避）→ 数値目標案で詳述。**[補足: 金額キャップはユーザー決定により撤回済み]**
5. **CEO 自身の週次・月次の投下時間上限と本業との関係の明文化**（v0.1 で月40h想定だが、現実の可処分時間との突合がない）→ 自己経営案で詳述

## ユーザー確定事項（2026-05-13）

CEO（=ユーザー）から以下の方針が確定された。本ドキュメント内の関連項目は本セクションに従って更新済み。

### 確定事項1: Claude Code Max プランの範囲内で運用
- 有料SaaS・サブスクリプションは Claude Code（Max プラン）のみ
- **Claude API（従量課金）は不採用**
- 無料SaaS・無料枠で運用可能な代替案を採用
- 取引手数料（Stripe等の収益発生時の変動費）は別建てで許容
- **アーキテクチャ方針確定**: AI生成は Claude Code 上で CEO 自身がバッチ生成 → 目視確認 → 配信ライブラリ格納 → スケジュール配信、という運用に再設計する（LINE Bot からのリアルタイム API 呼び出しは設計しない）
- **独自ドメインは購入しない**: 連絡用はGmail、Web面は note URL ＋ 無料ホスティングのサブドメインで運用

### 確定事項2: 自己投資額の上限はなし
- 「総自己投資¥50万」のような数値キャップは設けない
- 撤退条件は **時間・成果ベース** に切り替える（金額ではなく「Phase 1 で X が達成できない場合は…」）

### 確定事項3: 販売・配信コンテンツは CEO が目視確認する
- 弁護士スポット相談（Phase 2 着手前 ¥3-5万）は不要
- AI生成コンテンツの責任担保は「5層ガードレール」のうち **Layer 4: CEO 月次セルフレビュー** を **配信前の都度目視確認** に強化することで対応
- 賠償責任保険（年¥1-3万）も Phase 2 着手前段階では不採用

## CEO推奨：来週着手すべき意思決定TOP3

来週1週間で **以下3つ** に CEO の時間を集中投下することを推奨。これらが確定しないと Phase 1 のすべてのアクションが止まる。

1. **数値ゲートの確定（6-1, 6-4）** ※ユーザー決定で 6-2, 6-3 は確定済み
   - Phase 1 終了時 Go/No-Go 基準、撤退条件（時間・成果ベース5項目）を**1ページにまとめて自分自身と契約する**。これがないと「もう少しやれば…」というサンクコスト罠に確実にハマる。所要時間: 60分。

2. **サービス名・屋号・SNS/noteハンドルの確定（3-1, 2-3, 3-4〜3-6）**
   - 候補3〜5案を出し、J-PlatPat で商標調査、SNS/note ハンドル・Gmail アドレスの空き確認を一気通貫で実施。屋号が決まれば開業届・銀行口座のすべての前提が揃う。所要時間: 3時間。

3. **CEO 自身の制約条件の明文化（7-1〜7-3）**
   - 週次投下時間上限、本業の副業規程確認、配偶者との事前合意の3点を文書化。これがないと、Phase 1 中盤で家庭・本業・健康のいずれかが崩れる。所要時間: 2時間（配偶者との会話含む）。

### 派生して必要となった追加タスク（ユーザー決定に伴い）

4. **プロダクト v0.2 への再設計（Claude API → Claude Code 運用への移行）**
   - LINE Bot からの API リアルタイム呼び出しを撤回し、「Claude Code 上で CEO がバッチ生成 → 目視確認 → 配信ライブラリ格納 → スケジュール配信」型のアーキテクチャに変更したプロダクト仕様 v0.2 を別途作成。所要時間: CEO への委譲で約2時間。
   - 影響範囲: コア体験（毎日のナッジ配信）の生成・配信ロジック、5層ガードレールの Layer 4 強化、月¥30万到達のコスト構造。

**TOP3 のうち1と3は CEO自身でしかできない意思決定**。2 は商標・ドメイン調査を SubAgent（後日 `legal-researcher` or `brand-strategist` 的なエージェントを立てる）に委譲可能。
