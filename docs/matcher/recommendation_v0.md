```
[軸プロファイル（6軸 × −2〜+2）]
        ↓
[各50理論の「理論プロファイル」と類似度計算]

        ↓

```

## ステップ 2: 類似度計算

### 距離関数: ユークリッド距離（重み付き）

親プロファイル P = (P_R, P_S, P_I, P_E, P_P, P_C)、理論プロファイル T = (T_R, T_S, T_I, T_E, T_P, T_C) のとき:

```
distance(P, T) = sqrt( w_R(P_R - T_R)² + w_S(P_S - T_S)² + w_I(P_I - T_I)² + w_E(P_E - T_E)² + w_P(P_P - T_P)² + w_C(P_C - T_C)² )
```

### 軸の重み（暫定）

```
w_R = 1.5  # 応答性: アタッチメント・敏感性は基盤的
w_S = 1.0
w_I = 1.2  # 主導権: 理論間の分化が大きい
w_E = 1.0
w_P = 1.0
w_C = 1.0
```

重みは Phase B 後にキャリブレーション。R を重くしているのは「応答性ゼロは愛着リスク」のため、応答性軸での近接性を優先的に評価したいから。

### 不確実性フラグ付き軸の処理

[[scoring_v0]] で「不確実性フラグ」が付いた軸は、その軸の重みを **50%** に減衰する:

```
if axis in uncertainty_flags:
    w_axis = w_axis * 0.5
```

## ステップ 3: 距離 → 類似度スコア

距離は値が小さいほど類似度が高い。ユーザー提示用に **0〜100% の類似度** に変換:

```
similarity(P, T) = max(0, 100 * (1 - distance(P, T) / max_distance))
```

`max_distance` は理論プロファイル空間で取り得る最大距離（軸数=6、各軸 ±2 なので最大 sqrt(6×16) = √96 ≈ 9.8、重み込みで再計算）。

## ステップ 4: トップ5 抽出

全50理論を similarity 降順でソートし、上位5理論を取得。

```
candidates = sorted(theories, key=similarity, reverse=True)[:5]
```

## ステップ 5: 偏り回避フィルタ

### フィルタ A: 流派の偏り回避

**ルール**: トップ3に類似系統が3つとも入らないようにする。

系統グループ（例）:
- アタッチメント系: `bowlby-attachment`, `ainsworth-strange-situation`, `polyvagal`, `harvard-cdc-framework`, `sasaki-masami`
- モンテッソーリ系: `montessori`, `pikler`, `rie-gerber`
- 自由保育系: `sudbury-democratic`, `forest-kindergarten`, `reggio-emilia`
- 賞賛・動機系: `adler`, `nvc`, `growth-mindset`, `self-determination-theory`
- 早期教育系: `yokomine-shiki`, `kumon`, `shichida-method`

**処理**: トップ3 のうち同じグループから3つ目を取ろうとしたら、次の候補に **降格** する。

### フィルタ B: × グループ（ヨコミネ式 / 七田式）の取扱い

**ルール**: × グループの理論（`yokomine-shiki`, `kumon`, `shichida-method`）が類似度1位に入った場合、 **「両論併記モード」** を発動する。

#### 両論併記モード
1. × 理論を「あなたが好むパターンに親和性が高い理論」として **3位以下** で紹介
2. 同時に「ただし長期効果は限定的というメタ分析（Duncan & Magnuson 2013）もあります。下記の論文と合わせて検討してください」と注釈
3. 1〜2位には **× グループ以外の代替案**（例: モンテッソーリ・Tools of the Mind・ハイスコープなど構造性 + 自律性のバランス系）を入れる

これにより「親バッシング」（あなたの選択は間違い、と言わない）と「無批判推奨」（科学的根拠の薄い理論を一位推奨しない）の両方を回避する。

### フィルタ C: 親の状態（CQ3）による調整

文脈質問 CQ3「いま一番のモヤモヤ」によって優先理論を加点:

| CQ3 | 加点理論 |
|---|---|
| 生活リズム・寝かしつけ | `polyvagal`, `conscious-discipline`, `harvard-cdc-framework` |
| 言うことを聞かない・かんしゃく | `conscious-discipline`, `nvc`, `adler`, `polyvagal` |
| 学び・知育・就学準備 | `vygotsky-zpd`, `highscope`, `montessori`, `tools-of-the-mind` |
| 子の気持ちが分からない | `theory-of-mind`, `nvc`, `bowlby-attachment` |
| 自分の余裕のなさ・しんどさ | `bronfenbrenner-ecological`, `harvard-cdc-framework`, `nobuta-sayoko`, `nelson-2014-pains-pleasures-parenting`（論文）|
| 周りと比べて不安 | `bronfenbrenner-ecological`, `sasaki-masami`, `keller-2018-attachment-universality-critique`（論文）|
| 特になし／全体的にしんどい | `harvard-cdc-framework`, `nobuta-sayoko`, `bronfenbrenner-ecological` |

加点幅は 類似度 +5% 程度（過剰加点して文脈質問が支配しないように）。

### フィルタ D: 年齢適合性

CQ1 子の年齢で **対象年齢から外れた理論** をフィルタアウト:
- 0-2歳の子なら `dolton-plan`, `ib-pyp`, `sudbury-democratic` などの学齢期理論を除外
- 3-6歳ならほとんどの理論が対象

## 偏り回避メカニズム（まとめ）

[[axes_v0]] の設計原則「両極を等しく尊重」を、推奨ロジックでも徹底するための4層防御:

### 層1: 軸設計レベル
- どの軸も両極とも価値があり、「正解側」を設定しない
- 質問は「正しい答え」を匂わせない（[[questions_v0]] 設計原則）

### 層2: 推奨計算レベル
- 流派の偏り回避フィルタ（フィルタ A）
- × グループ両論併記モード（フィルタ B）

### 層3: 出力レベル
- 「タイプ」ではなく「傾向」「型」と表現
- 「正しい育て方を提示」ではなく「親しみやすい教育観を紹介」
- 親の選んだ道を**肯定**する文言を必ず冒頭に置く
- 距離を置く点・批判リンクを必ず併置

### 層4: 文脈レベル
- 「3-6ヶ月後の再診断推奨」で固定タイプ感を回避
- CQ3 で親のしんどさをすくい、推奨に反映（「あなたが間違ってる」ではなく「いまのあなたを支える視点」を提供）
- 文化差を尊重（C軸 + Rothbaum 2000 / Keller 2018 論文）

## 出力前の最終チェック（運用時）

1. **トップ3に「× グループ」が1位に来ていないか**
2. **同じ系統の理論が3つとも入っていないか**
3. **「あなたは○○型です」など固定的タイプ表現になっていないか**
4. **論文リンクの全てが評価レベル moderate 以上か**
5. **「正解」「絶対」「必ず」など断定表現が混入していないか**

CEO 監修体制（[[CLAUDE.md]] 「販売コンテンツは CEO 目視確認」原則）に従い、最初の100ユーザー分は CEO が結果を全て目視確認する。

## 保留事項

1. **理論プロファイル値の妥当性**: 専門家3名以上に「この理論の軸スコアは妥当か」をレビューしてもらう（Phase B）
2. **類似度の見せ方**: パーセント表示 vs 順位だけ vs グラフ表示。UI 検証で決める
3. **論文選定の自動化**: 各理論カードに「最も親和性の高い論文」を自動選ぶロジック（matcher_axes タグと軸プロファイルのマッチング）
4. **推奨後の継続体験**: 「1位の理論についてもっと知りたい」「3位は不要、別の候補は？」など探索的UIを Phase 3 で
5. **複数親プロファイル**: 父母で異なるプロファイルを両方診断したとき、 **「2人の中間値」と「2人の差」** を両方提示する

## Phase B 検証計画との接続

[[matcher検証][Phase B 価値検証]] でマッチャーをテストする想定:

1. **100ペルソナでドライラン**: 50理論を体現する典型的親プロファイルを CEO + 育児支援者で作り、マッチャーがそれぞれの理論を上位推奨できるか
2. **専門家ブラインドテスト**: 30 ペルソナ × 専門家3名で「この親に勧める理論トップ3」を独立判定し、マッチャー推奨と一致率を計測
3. **実親パイロット**: 募集10〜20名で実際の親が診断 → 結果について「納得感」「驚き」「実行可能性」をアンケート
4. **解説の妥当性確認**: 結果カードの「あなたに合う理由」が実際に親に響く言葉になっているか、半構造化インタビューで検証

成功基準（暫定）:
- ドライラン: 50理論ペルソナで自分の理論がトップ3 に入る率 70%以上
- 専門家一致率: トップ3 のいずれかが専門家トップ3に含まれる率 60%以上
- 親納得感: 「結果に納得した」5段階で 3.5/5.0 以上
