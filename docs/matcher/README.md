# マッチャー設計（構想段階）

## ステータス

**構想段階** — MBTI式「親×教育理論」マッチャーの本体実装は、以下が揃ってから着手する：

1. 論文・書籍の情報収集の継続
2. 実親インタビュー（Google Form 経由）の実施と分析
3. 50理論×6軸スコアの妥当性レビュー

現時点の成果物（v0.1）は **将来実装のための叩き台** として保管。CEO エージェント主導で 2026-05-14 に Phase 2 軸設計として作成。

## 確定事項

- **6軸**: 応答性 R / 構造性 S / 主導権 I / 評価観 E / 早期化 P / 関係性 C
- **質問構成案**: コア12問 + 文脈3問 = 計15問
- **偏り回避**: × グループ（ヨコミネ式・七田式・公文式）は1位推奨禁止、3位以下降格、両論併記モード（ユーザー承認済 2026-05-14）

## 構想段階の理由

- **マッチャー本体実装はインタビュー後**: 実親のニーズ・モヤモヤを直接聞いてから推奨ロジックを確定する方が、誤った前提で作るより無駄が少ない
- **スコア妥当性は専門家レビュー待ち**: 50理論×6軸スコアは CEO 暫定値で、専門家3名以上のレビューが必要
- **情報収集の継続**: 論文 Phase A 完了（104本）後、書籍 Phase B0/B1 と並走で深める段階
