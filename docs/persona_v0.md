# ペルソナ v0

> ステータス: ドラフト（要検証）
> 対象: 日本人保護者 × 0〜6歳児（未就学児）
> 作成者: ceo SubAgent
> 作成日: 2026-05-13

## 年齢帯セグメント判断

**採用案: (b) 0〜2歳と3〜6歳の2ペルソナを併記**

### 理由

1. **困りごとの性質が根本的に異なる**
   - 0〜2歳: 生活リズム（61.5%）/ 食事（50.7%）/ しかり方（42.2%）といった「生存と日常運用」が中心（ミキハウス調査）。母親の最大の悩みは「仕事と私事の両立」、ワンオペ感41.8%。
   - 3〜6歳: 小学校就学への不安、ひらがな・数・英語などの「学びの先取り」、しつけ・社会性形成が中心。

2. **既存プレイヤーも年齢帯でコース分割している**
   - こどもちゃれんじ: baby（0〜1歳）/ ぷち/ぽけっと/ほっぷ/すてっぷ/じゃんぷ と1歳刻みで分離
   - スマイルゼミ: 幼児コースは年中・年長に集中。2024年から年少前まで拡張
   - ワンダーボックス: 4〜10歳（3歳未満は非対象）
   - → 単一ペルソナでは UX・コンテンツ設計が破綻する。

3. **検証段階の戦略的価値**
   - Phase 1（Discovery）の目的は「どの層が最も支払い意欲が高いか」の一次検証。
   - 2ペルソナを併記しておき、Phase 1 インタビュー20件のうち各10件で当てて、Phase 2 MVP では1つに絞る運用が合理的。
   - 単一ペルソナに早期コミットすると、機会損失が大きい（特に0〜2歳の親は「孤立・不安」の課題深度が高く、サブスク単価¥980を超える支払い意欲が見える可能性）。

### 暫定優先順位

**3〜6歳（ペルソナB）を主、0〜2歳（ペルソナA）を副**として並行検証。理由は、3〜6歳は既存市場（こどもちゃれんじ等）で「月額数千円を払う文化」が確立しており、CVR検証が早い。0〜2歳は競合が少なく単価を上げられる可能性があるが、行動データが少なく仮説リスクが高い。

## ペルソナA: 鈴木 美咲（0〜2歳児ママ）

### 1. 基本情報

| 項目 | 内容 |
|---|---|
| 名前 | 鈴木 美咲（みさき） |
| 年齢 | 31歳 |
| 職業 | 都内IT企業 マーケ職（育休中、子1歳2ヶ月、半年後復職予定） |
| 世帯年収 | 約820万円（夫:480万 / 本人復職後:340万想定） |
| 配偶者 | 33歳・SE・在宅勤務中心だが平日は子と関わる時間は朝夕30分ずつ程度 |
| 住居 | 東京都世田谷区 賃貸2LDK（10.5万円/月） |
| 子 | 第1子・男児・1歳2ヶ月 |

### 2. 解く瞬間（困りごとが顕在化するシーン）

- **平日朝 6:30〜7:30**: 子が早朝覚醒。離乳食を作りながら「これで栄養足りてる？」「同じメニューばかりで発達に影響ないか」と不安。SNSで他人の朝食を見て自己嫌悪。
- **平日昼 13:30〜15:00**: 子が昼寝の隙に、来週の予定（離乳食メニュー・予防接種・支援センター）を考えるが情報過多で決められない。育児書とInstagramで矛盾する情報に疲弊。
- **平日夜 22:00〜23:30**: 子の就寝後、SNSで「同じ月齢の子はもう歩いてる」を見て落ち込む。「うちの子、発達遅い？」を検索しまくる。誰にも相談できず孤独。

### 3. 解く不安（台詞レベル3つ）

1. 「この子の発達、本当にこれで大丈夫なのかな…相談する相手がいない」
2. 「離乳食、毎日同じようなのばっかりであげちゃってる。これで栄養足りてる？」
3. 「ネットの情報多すぎて、どれを信じればいいのか分からない。専門家にちょっとだけ聞きたい」

### 4. 提供価値の1文

**孤立しがちな0〜2歳児ママが、平日昼の隙間時間に、月齢に合わせた『今日やるべき1つ』と『発達の安心材料』を受け取れる**

### 5. 支払い意欲仮説

**¥1,480/月** で払う。理由: 「孤立解消＋専門家由来の判断材料」は心理的価値が高く、こどもちゃれんじbaby（¥2,000台）とSNS無料情報の中間に位置するなら割安感がある。0〜2歳の親は支援センター・小児科訪問のための交通費＋時間コストが¥3,000/月以上発生しており、その代替手段として成立する。

### 6. NOT-do リスト（あえて提供しないもの）

1. **物理玩具・絵本の配送**: 在庫・配送・選定の運用が個人開発と非互換。
2. **24時間チャット相談（人力）**: 工数青天井。AIサマリ＋週1回の専門家監修コンテンツで代替。
3. **発達評価・診断**: 医療領域に踏み込まない。「不安の安心材料提供」までに留め、明確な発達遅延の懸念は専門機関を推奨する。

## ペルソナB: 田中 さやか（3〜6歳児ママ）

### 1. 基本情報

| 項目 | 内容 |
|---|---|
| 名前 | 田中 さやか |
| 年齢 | 36歳 |
| 職業 | 地方都市の医療事務（時短勤務 9:00〜16:00） |
| 世帯年収 | 約680万円（夫:450万 / 本人:230万） |
| 配偶者 | 38歳・地方公務員・育児協力的だが教育方針は丸投げ |
| 住居 | 愛知県名古屋市 戸建（住宅ローン9万円/月） |
| 子 | 第1子・女児・5歳（年長、来年4月に小学校入学）／第2子・男児・2歳 |

### 2. 解く瞬間

- **平日夜 19:00〜20:00**: 夕食後、上の子に「ひらがな」を教えようとするが疲労困憊で続かない。下の子が騒ぐ。「ちゃんと教えてあげられてない」罪悪感。
- **平日朝 7:30〜8:00**: 登園前、上の子がぐずる。「最近"勉強"の話をすると嫌がる。小学校入って大丈夫？」とモヤモヤしながら保育園へ。
- **休日午前 9:00〜11:00**: 上の子と「何かやらせなきゃ」と思うが、こどもちゃれんじ¥3,000台は付録が増えて家が散らかる/スマイルゼミはタブレット代¥1万超で躊躇/結局YouTubeに頼って自己嫌悪。

### 3. 解く不安

1. 「小学校までに、ひらがな・数字・あいさつ、最低限身につけさせたい。でも何をどこまでやればいい？」
2. 「こどもちゃれんじ取ってたけど、付録ばかり溜まって続かなかった。もっと身軽なのがいい」
3. 「タブレット渡しっぱなしも嫌だし、親がつきっきりも無理。10分だけ親子で取り組めるやつが欲しい」

### 4. 提供価値の1文

**就学準備が気になる3〜6歳児ママが、平日夜・休日朝の10分で、親子で取り組める『今日のお題1つ』を受け取れる**

### 5. 支払い意欲仮説

**¥980/月** で払う。理由: こどもちゃれんじ・スマイルゼミ幼児コース（¥3,000台）の1/3価格でアンカリングし、「物が増えない・タブレット不要・10分で済む」を訴求すれば、既存サブスク解約者の受け皿として成立。ロードマップv0.1の収益モデルA案と整合（¥980×306人=¥30万）。

### 6. NOT-do リスト

1. **印刷教材の郵送**: 個人運営の物流コスト過大。LINE/Webで完結。
2. **専用タブレット販売**: 初期費用がCV阻害要因、スマイルゼミとの差別化点を消す。
3. **総合的な学習カリキュラム**: 「就学準備」に絞り、英語・プログラミング・運動には踏み込まない（NOT-do を明示してメッセージを尖らせる）。
