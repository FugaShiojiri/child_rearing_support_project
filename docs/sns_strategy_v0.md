# SNS 集客戦略 v0

> 作成日: 2026-05-13
> 作成者: ceo
> 対象: ひだまりこそだち Phase 1〜4
> ステータス: ドラフト（v0、Phase 1 検証後に v0.1 改訂）

---

## 結論（30秒で読める）

1. **主軸: X（旧Twitter）** — 育児層の本音流通量と拡散力が個人運営に最適、テキストのみで完結、note 導線と相性最良
2. **補助: Threads** — X と完全に同じテキスト資産を二次利用、+114% 成長中の上澄み取り
3. **note 自体のフォロー獲得** を並行（プラットフォーム内 SEO・回遊）

Instagram・TikTok・YouTube ショート・Pinterest は **Phase 1〜3 で不採用**。理由は画像/動画制作工数が個人運営の持続可能ラインを超えるため。

---

## 検討した制約

| 制約 | 影響 |
|---|---|
| Claude Code Max 以外課金不可 | 広告課金・予約投稿 SaaS（Buffer 等）・有料分析ツール（SocialDog 有料版等）すべて不採用 |
| 人手介入最小化（CEO 週 10-15h） | 1チャネルあたり週 2-3h 以内、合計 5-8h 以内が上限 |
| 配信主軸は note（毎日 90 本／月） | SNS は「note への流入導線」に徹する。SNS 自体で価値完結させる設計は不採用 |
| 販売コンテンツは CEO 目視確認 | SNS 投稿も CEO 目視。テンプレ化＋週次まとめ生成で工数吸収 |
| プロダクト v0.2: バッチ生成型 + 3 セグメント | SNS 投稿の素材は「バッチ生成済 90 本／月」から流用可能 → 制作コスト追加なし |

## 各 SNS の評価

| SNS | リーチ | 育児層親和性 | 運用工数 | コンテンツ要件 | 採用判断 |
|---|---|---|---|---|---|
| X (Twitter) | 中（20代78%・育児発信活発） | 高（本音・愚痴・共感の流通量） | 低（テキストのみ） | 140字テキスト | **主軸採用** |
| Threads | 小→中（+114% 成長中） | 中〜高（育児コミュニティ移住組） | 極低（X と同一素材転用） | 500字テキスト | **補助採用** |
| Instagram | 大（30-40代ママ 99%が情報源） | 極高（夜21時ピーク） | 高（画像/リール制作） | 画像・リール・フィード | 不採用（v0.1 で再評価） |
| TikTok | 大（若年層） | 中（未就学児ママ層は副次） | 極高（動画編集） | 縦動画 15-60s | 不採用 |
| YouTube ショート | 中（検索流入強） | 中 | 極高（撮影・編集） | 縦動画 | 不採用 |
| Pinterest | 小（国内育児層は薄い） | 低 | 中（画像作成） | 縦長画像 | 不採用 |
| note 内フォロー | 中（プラットフォーム回遊） | 高（読書習慣のあるママ） | 既存運用に内包 | テキスト記事 | 並行採用（SNS とは別扱い） |

### X (Twitter)（**採用・主軸**）

- 育児層の本音・愚痴・困りごとが最も濃く流通する場。共感ベースの拡散が起こりやすく、note 流入相性も最良（リンク貼付文化が定着）
- 140 字テキストのみで完結 → バッチ生成済お題から「親への声かけ台本」を 140 字に圧縮するだけで投稿素材化可能
- 競合（こどもちゃれんじ・スマイルゼミ）は Instagram 主軸で、X では公式存在感が薄い → 個人運営が入る余白がある

### Threads（**採用・補助／開始は Phase 2 から**）

- 日本国内で前年比 +114% 成長、絶対数は約 1,500 万人だが上澄みは育児・読書・自己啓発系コミュニティに移住中
- X 投稿の文字数を 500 字に拡張するだけで素材転用可能 → 追加工数ほぼゼロ
- アルゴリズムが新規参入者に優しい段階のうちに足場を作る
- **CEO決裁（2026-05-18）**: **Phase 1 では着手しない**（Phase 1 の検証目的は「X育児層→note」の1点。X/Threads並走は検証ノイズ＋手元作業倍増を招くため、まずXで仮説を1本に絞る。Threadsの新規参入アルゴ優位は Phase 2 でも十分残る）。**開始＝Phase 2**。`scripts/post_threads.py` を**自動化採用**（Threads APIは無料＝コスト制約に抵触せず）。運用形態＝「Xに出した投稿を500字拡張してThreadsへ自動転載」＝ユーザーのThreads作業は実質ゼロ（X目視承認に内包）。Xは手動コピペ継続（API有料化のため）。→ 下記「検証すべき仮説 S3」の Phase 1 並走比較は Phase 2 へ送り。

### Instagram（**不採用・v0.1 で再評価**）

- リーチと育児層親和性は最強（30-40代ママ 99%が情報源、夜 21 時帯ピーク）。本来は主軸候補
- **不採用理由**: 画像/リール制作が個人運営の持続可能工数を超える。Canva 無料版で代替できるが、競合のクオリティ（プロデザイナー在籍）と勝負にならない
- **再評価条件**: Phase 3 後半に有料会員 150 人到達 → 余剰工数が生まれた時点で、リール 1 本/週から再参入を検討
- ※オーナー要望（2026-05-15）: 「AI動画リールを自動でまわす」案あり。ただし高品質AI動画生成（Sora/Runway/Kling 等）は例外なく有料SaaSで「Claude Code Max 以外課金不可」と衝突。**再評価時も現実的上限は「静止画/カルーセルの半自動投稿（post_instagram.py + 無料ホスティング）」**。AI動画は Phase 4 以降の研究テーマ扱いを継続（CEO決裁・戦略変更なし）

### TikTok（**不採用**）

- 動画編集工数が週 5-10h 規模で持続不可
- 未就学児ママのコア時間帯（21時）はテキスト消費中心、TikTok 視聴は副次
- 顔出し前提のアルゴリズム → CEO の運営方針と非整合

### YouTube ショート（**不採用**）

- TikTok と同様の理由＋撮影機材ハードル
- ただし「note 記事の朗読音声を自動字幕化した縦動画」を Claude Code 経由で量産する案は **Phase 4 以降の研究テーマ** として保留

### Pinterest（**不採用**）

- 国内育児層の利用密度が低く、ROI が見込めない
- 画像中心 → Instagram 不採用と同じ工数問題

### note 内フォロー（**並行採用**）

- SNS ではないが集客チャネルとして並行運用
- 既に毎日 90 本記事を出すため、追加工数ゼロでフォロワーが積み上がる
- note 内のおすすめ・タグ・マガジンからの流入が CPA ゼロ

## 推奨チャネルミックス（Phase 別）

> **「能力 ≠ 運用値」原則（CEO決裁 2026-05-22・本書全体に適用）**: オーナー能力開示「週7h動ける／実質2日1本投稿可能（月15本）」は **天井として受け止め・運用値は段階解放**する設計（旧 sns_strategy「日次90本」の轍を踏まない）。連載ペース解放3段・燃え尽き検知ルールは `docs/note/series_plan_v0.md §10` 参照。週バジェット7h配分は [[project-content-capacity]] 参照。
>
> **CEO決裁 2026-05-28・本書末尾追補**: 旧 `project-operations-philosophy` 原則3「コミュニティはオフライン中心」を**撤回**（オーナー知人/地域ネットワーク不在が判明＝設計前提誤りはCEO責任として引き受け）。当面の web完結戦略は **`docs/web_only_strategy_v0.md`**（採用2本＝note他クリエイター接触＋タグ最適化／不採用5本＝X押し込み強化等）を**正**とする。本書のチャネル設計はPhase2再設計時に v0.1 改訂予定。

### Phase 1（Discovery、〜1 ヶ月）

- **採用**: X のみ 1 本
- **目的**: LP 登録 50 件のうち SNS 経由を 20 件以上獲得
- **投稿**: 1 日 1-2 ポスト（バッチ生成お題の切り出し）+ 週 1 本「立ち上げ日記」
- **工数**: 週 2-3h

> **CEO決裁（2026-05-18・Phase1運用の確定／上記の見積を上書き）**: 上記「X 1 日 1-2 ポスト＋週 1 日記／週 2-3h」は **日次 90 本 note 配信を前提とした旧プロダクト方針の見積** であり、現運用（連載 **隔週 1 本**・人手介入最小・Form 検証フェーズ）とは乖離する。**Phase1 の X は「note 公開連動の告知のみ・週 1-2 本・全文 Claude 下書き・オーナーはコピペのみ・週手作業 5 分以内」に縮小確定**。「投稿フォーマット 5 種ローテーション」は Phase1 では使わず **E パターン（note 新着告知）のみ** 採用。A-D（お題切り出し/共感/豆知識/日記）の本格運用と S1/S2 の検証は、5/28 中間レビューで **Form 回答 < 15 件** の場合に「第2波チャネル本格化」として再決裁する（Phase1 初期は X の集客性能を検証対象としない＝検証ノイズ回避）。根拠: 検証目的は note→Form 回収であって X 集客性能ではない／連載隔週で日次 X 素材は純粋な手間増／オーナー週 1h 手作業バジェット。

### Phase 2（β 構築、〜3 ヶ月）

- **採用**: X（主軸）+ Threads（X と同一素材を 500 字拡張版で転用）
- **目的**: β 10 名獲得、note メンバーシップ初月無料 → 課金転換の検証
- **投稿**: X 1 日 1-2 ポスト、Threads 1 日 1 ポスト（X の拡張版）
- **工数**: 週 3-4h（Threads は +30 分/週 のみ）

> **CEO決裁（2026-05-22・上書き）**: 本節「メンバーシップ初月無料→課金転換」は **旧プロダクト方針（日次90本配信）前提で凍結**。現運用と整合する収益化方針は `docs/monetization_roadmap_v0.md` を**正**とする：第一弾は**有料単品記事**（候補：1シーン×7理論の横断記事 ¥500）を Phase1 Go 後 1〜2 ヶ月の準備期間を経て投下。メンバーシップ／マガジンは Phase2 後半（9〜10月）で再判断。

### Phase 3（オーガニック獲得、〜6 ヶ月）

- **採用**: X（主軸）+ Threads（補助）+ note 内フォロー獲得施策
- **目的**: 有料 150 人、X フォロワー 3,000 / Threads 1,500
- **投稿**: X 1 日 2-3 ポスト、Threads 1 日 1-2 ポスト、note タグ最適化
- **工数**: 週 5-6h

> **CEO決裁（2026-05-22・上書き）**: 「有料 150 人」は **旧プロダクト方針（日次90本配信＋メンバーシップ）前提の試算で凍結**。現運用での収益化は単発有料記事の積み上げ＝詳細は `docs/monetization_roadmap_v0.md`。150人目標数値は現運用と非整合のため本決裁時点で参照しない。

### Phase 4（スケール、〜9 ヶ月）

- **採用**: 同上を継続。広告課金不可のためオーガニックで押し切る
- **追加検討**: Instagram 週 1 リール（Phase 3 後半に有料 150 人到達かつ余剰工数ありの場合のみ）
- **工数**: 週 6-8h

## 投稿フォーマット設計（主軸 X）

> ※ **Phase1 は E（note 新着告知）のみ**。A-D の本格運用は第2波本格化以降（上記「推奨チャネルミックス → Phase 1」の CEO決裁 2026-05-18 注記を参照）。

### 投稿パターン（5 種をローテーション）

| パターン | 頻度 | 文字数 | 素材源 | 例 |
|---|---|---|---|---|
| A. お題の切り出し | 週 5 本 | 140字 | バッチ生成「親への声かけ台本」 | 「5歳の『なんで？』が止まらない夜、答える前にこれだけ言ってみて: 『〇〇って思ったんだね』。脳科学的には〜（続きは note）」 |
| B. 育児あるある共感 | 週 3 本 | 140字 | CEO の観察・オフ会議事録 | 「保育園迎え後の30分が一番ハード問題」 |
| C. 出典付き豆知識 | 週 2 本 | 140字 | バッチ生成の `source_url` | 「文科省幼稚園教育要領にこう書いてある〜」 |
| D. 立ち上げ日記 | 週 1 本 | 140字 | CEO の内省 | 「個人で育児サブスク作ってます日記 #12」 |
| E. note 新着告知 | 毎日 1 本 | 140字 + URL | note 予約投稿スケジュール | 「今日の note: 〇〇」 |

### Threads への転用ルール

- A・B・C パターンを 500 字に拡張（背景・根拠・対話例を加える）
- D・E はそのまま転載

### 投稿時刻

- **平日 19:30-22:00**（未就学児ママのピーク時間帯、20-21 時がコア）
- 週末 9:30-11:00（休日午前の隙間時間）

## note との連携設計（集客ファネル）

```
[X / Threads]
  ・お題切り出し投稿に note URL
  ・拡散・共感獲得
   │
   ▼
[note 無料記事（30%）]
  ・SEO 流入記事 + 週末ふりかえり記事
  ・LP 代替（プロフィール・マガジンページ）
   │
   ▼
[note メンバーシップ ¥980/月（70%）]
  ・毎日のお題 90 本/月
  ・LINE Bot 月 1-2 回告知（任意）
   │
   ▼
[LINE Bot 友達追加（任意・補助）]
  ・無料枠 200 通/月の範囲で重要告知のみ
   │
   ▼
[Gmail（バックアップ）]
  ・障害時 / オフ会告知
```

**設計原則**:
- SNS で「価値の予告編」 → note で「本編」 → メンバーシップで「定期購読」
- SNS 投稿に毎回 note リンクは貼らない（5 投稿に 1 回程度）。過剰な誘導は共感を削ぐ

## やらないこと（NOT-do）

1. **広告課金（X Ads / Meta Ads / TikTok Ads）** — Claude Code Max 以外課金不可方針
2. **予約投稿 SaaS（Buffer / SocialDog 有料版 / Hootsuite）** — 同上。X / Threads の手動投稿 or 標準予約機能で代替
3. **全 SNS 同時運用** — 工数破綻、コンテンツ品質低下、CEO の継続不可能
4. **Instagram のリール・フィード制作（Phase 1-3）** — 画像/動画制作工数が持続不可能
5. **TikTok / YouTube ショートの動画投稿** — 同上、顔出し前提も非整合
6. **競合（こどもちゃれんじ等）の人気投稿の物まね** — 大手のリソース前提の戦術は個人で再現不可
7. **フォロワー購入・相互フォロー企画** — ブランド毀損
8. **DM 営業・コールドアウトリーチ** — 工数対効果が薄く、ブランド毀損リスク

## 競合の SNS 活用状況

| 競合 | Instagram | X | TikTok | 個人運営との差別化機会 |
|---|---|---|---|---|
| こどもちゃれんじ（しまじろう） | 主軸（複数アカウント、フォロワー数万） | 補助 | 公式不在 | X で「本音育児発信」の余白あり |
| こどもちゃれんじ My First English | Instagram（@shimajiro_myfirstenglish、約3,000） | 不明 | 不在 | 同上 |
| スマイルゼミ 幼児・小学生 | Instagram（@smilezemi_just、46,000+） | 補助 | 公式不在 | 同上 |
| ワンダーボックス | Instagram + X | X 活発 | 不在 | X は競合あり、差別化は「個人の本音発信」で勝負 |

**示唆**:
- 大手は Instagram に資源集中、X は手薄、TikTok は不在
- **X は個人運営が勝てる主戦場**。本音・愚痴・共感ベースの発信は大手ブランドアカウントには出来ない
- Instagram は「資源勝負」のため Phase 1-3 で参戦しても消耗戦になる
