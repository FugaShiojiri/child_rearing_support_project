```
  └─ 0〜6歳のいずれか ───────────────────────────────┐
  │                                                  ▼

  │
[S3 コンテンツ形態の選好（note / PDF / 診断 / オフライン ＋「理論に基づく」価値）]
  │
[S4 ガイドPDF への反応（既存成果物の需要・WTP・シリーズ期待）]
  │
[S5 マッチャー受容性（最重要・新規）]
  │
[S6 課金意向（形態別 WTP・サブスク前提を緩めた再設計）]
  │
[S7 NOT-do 選好（物送らない／アプリ不要）]
  │
[S8 自由記述・β案内メアド（任意）]
  │
[送信完了画面: お礼 ＋ β案内 ＋ note 誘導]
```

**Google Form 機能との整合（実装メモ）**:
- 条件分岐は「**セクションへの移動**」のみ使用。年齢による設問出し分けは行わない（S1 の対象外は Sd 対象外ライト動線へ移動・v1.2）。これにより v0 の 3A/3B 二重管理が不要になり、保守と離脱率が改善。
- 必須は **S1 の年齢1問** と **S6 の WTP 1問** のみ。他はすべて任意（離脱抑制）。
- 進捗バー表示 ON。
- 同一人物の重複は Google アカウント認証 ON もしくは「1回のみ回答」設定で抑制（個人情報は集めすぎない）。

## S1: スクリーニング

### 導入文（ドラフト・CEO目視確認対象）

> はじめまして。「ひだまりこそだち」は、子育ての「学びや関わり方の考え方」について、いろいろな見方をやさしく並べて、その方にあったものをそっとお渡しできないか、を考えている小さな試みです。
> このアンケートは、これからの形を決めるための声集めです（5分ほど・任意項目が中心です）。「正解はひとつではない」という前提で読んでいただけたらうれしいです。

### 質問

**Q1.1 [必須] いちばん下のお子さまの年齢を教えてください**
- 単一選択（ラジオ）
  - 妊娠中（出産予定）
  - 0歳
  - 1〜2歳
  - 3〜4歳
  - 5〜6歳
  - 小学生（7歳以上）
  - 子どもはいない（これから持ちたい・考え中） ← **v1.2 で分割・新設**
  - 子どもはいない・その他（いまは予定なし） ← **v1.2 で分割・新設**
- 分岐: 「0歳」「1〜2歳」「3〜4歳」「5〜6歳」 → S2 へ続行。それ以外（妊娠中／小学生／子なし2区分） → **Sd 対象外ライト動線**へ（v1.2：お礼のみ終了を廃止。後述）。
- 補足: 年代は **属性として集計に使う**（年代別クロス）。設問本体は年代で出し分けない。「子どもはいない」を意向で2分割し妊活・これから層を救う（CEO決裁 v1.2）。

**Q1.2 [任意] 回答者の立場**
- 単一選択: 母親 / 父親 / 祖父母 / その他養育者

**Q1.3 [任意] お子さまの人数**
- 単一選択: 1人 / 2人 / 3人以上

> 対象外の扱いは **Sd 対象外ライト動線**（下記）を参照。v1.2 で「お礼のみ終了」を廃止。

## Sd: 対象外ライト動線（v1.2・2026-05-15 オーナー提起→CEO決裁）

> Q1.1 で対象外（妊娠中／小学生以上／子なし2区分）を選んだ人の遷移先。**1ページ完結→送信**。本編（S2-S8）には1人も混ぜず**集計純度100%維持**。妊娠中＝6〜10ヶ月後に確実に0歳児保護者になる最有望リード、妊活・これから層も将来顧客。お礼で捨てず G2（待機リスト）獲得点に転換する。すべて任意・所要1〜2分。

**ページ冒頭メッセージ（ドラフト・CEO目視対象）:**
> ここまでお進みくださり、ありがとうございます。今回の声集めは0〜6歳のお子さまを育てている方を中心にお聞きしていますが、これから親になる方・なるかもしれない方の「いま気になっていること」も、私たちにとって大切なヒントです。よろしければ、あと少しだけ教えてください（任意・30秒ほど）。お急ぎの方はこのまま送信していただいて大丈夫です。

**Qd.1 [任意] いまのご状況に近いものは**（単一選択・セグメント識別タグ `segment_offtarget`）
- 妊娠中・出産を控えている / これから子どもを持ちたい・考えている（妊活中を含む）/ 子どもはもう大きい（小学生以上）/ 特に予定はない・関心があって見てみた / 答えたくない

**Qd.2 [任意・自由記述] いま、子育てや子どもとの関わりについて「気になっていること・知りたいこと」があれば一言**
- 補足: 「これからのことでも、ばくぜんとしたことでも大丈夫です。空欄でも構いません。」
- 集計: 将来顧客の生ニーズ語彙。本編 Q2.4 とは**別カラムでタグ分離**。

**Qd.3 [任意] これからの発信や活動のご案内を受け取れるメールアドレス**（メール形式）
- 説明: 「登録は任意です。これからの発信や活動のご案内を、ごくたまにお送りします。広告メールは送りません。」
- v1.2修正（CEO決裁 2026-05-15）: 「準備期…のお役立ち情報」を削除＝未確定（保留中）の準備期コンテンツを約束しない。抽象表現に統一しブランド「できないことを言わない」と整合。G2リード取得機能は不変。

**末尾 note 誘導（全セグメント共通）:** 「日々考えていることは note でゆるやかに発信しています。よろしければ覗いてみてください。」（v1.2修正で「準備期の方にも」を削除＝未確定語の露出を消しトーン統一。note URL は公開後にスクリプト `CONFIG.NOTE_URL` で挿入。未公開時はテキストのみ）

**集計ルール（CEO決裁）:**
- 本編 S2-S8 集計・既存マトリクス・副次クロスは**無改修・純度100%**（対象外者は本編に到達しない）。

- 5分制約・必須最小（Q1.1・Q6.1のみ）・ブランドトーンは不変。対象外者は本編スキップで実測1〜2分。

## S3: コンテンツ形態の選好（v0「ドリル vs 声かけ台本」の発展）

> note記事 / PDF資料 / 診断ツール / オフラインイベント のどれに魅力を感じるか、と「理論に基づくこと」の価値を測る。Google Form の「グリッド（複数選択肢の段階評価）」で1問に集約し設問数を抑える。

**Q3.1 [任意] 次のような「子育ての考え方の届け方」、それぞれどのくらい魅力を感じますか**（5段階グリッド: 1 魅力を感じない 〜 5 とても魅力を感じる）
- a. 短い読み物（note などの記事を、無理なく読めるペースで）
- b. まとまった資料（年代別の「関わり方ガイド」PDF を手元に置ける）
- c. 提案の仕組み（いくつかの質問に答えると、自分に合いそうな考え方を提案してくれる）
