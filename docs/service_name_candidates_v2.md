## ⚠️ 撤回された旧確定案（2026-05-13、後に v3 で再決定）

**旧採用案: Hagmii Garden（ハグミー・ガーデン）**

> ⚠️ 本案は採用後に「ハグミー」称呼が以下と衝突することが判明し、**撤回された**：
> - カトージ hugme ベビーカー
> - 一条工務店 HUGme 住宅
> - Gakken hugmo 保育ICT（直接競合）
> - はぐみ（HUGME）保育支援システム（直接競合）
>
> → v3 ブレストで「ひだまりこそだち」を最終確定。本セクションは検討記録として保持する。

- **語源**:
  - 「Hagmii」=「育む（はぐくむ）」から派生した造語
  - 「Garden」= 育む場所、植物（子）が自分のペースで育つ場
- **思想**: **「育む場所」を提供する** — 子はそれぞれのペースで育ち、親は環境を整える庭師の役割
- **採用理由**:
  - 「育む場所」感が強く、サービスの本質（毎日の声かけ・気づきが積み重なる場）と整合する
  - **0〜6歳の幅広い年齢帯と相性が良い**（庭の比喩は乳幼児から学齢前児まで自然に包含する）
  - 過去候補（こそだち他）は日本語ニュアンスに依存していたが、Hagmii Garden は英語＋カナ表記で **モダンで国際的な印象**、競合（こどもちゃれんじ等の和テイスト）との視覚差別化が明確
  - 「ハグ」のニュアンスが含まれ、温かさ・包み込む安心感も伝わる
  - ブランドメタファー（庭・育む・季節・芽吹き・実る・収穫）が豊富で、コンテンツ・ビジュアル展開がしやすい
- **採用プロセス**: CEO（ユーザー本人）の発案による

### 検討経緯（参考）

v1 5案（ことだち／こえかけ／そだちのたね／はじめのいっぽ／おやとこ）→ v2 6案（おやのおまもり／ねむまえ10分／きづきノート／ふぅ。／もうすぐいちねんせい便／tono.）→ 中間決定として「こそだち」が一時採用された → 最終的に CEO が「Hagmii Garden」を発案して採用。

以下、v2 ブレストの記録は **検討経緯としての参考情報** として保持する。

## 本ドキュメントの位置づけ

`docs/service_name_candidates.md` の5案（ことだち／こえかけ／そだちのたね／はじめのいっぽ／おやとこ）は、いずれも以下の切り口に偏っていた。

- 言葉・声かけ中心（ことだち、こえかけ）
- 育ち・成長中心（そだちのたね）
- 始まり中心（はじめのいっぽ）
- 親子関係の直接表現（おやとこ）

本v2ではこれらと**異なる方向性**を最低3軸以上カバーする新案を6つブレストし、最後に既存5案＋新規6案＝計11案の総合推奨ランキングTop3を提示する。

## 候補一覧（6案）

### 案A：おやのおまもり（oyanoomamori）

| 項目 | 内容 |
|---|---|
| 名称表記 | **おやのおまもり** / オヤノオマモリ / oyanoomamori |
| 由来・コンセプト | 「親が持つお守り」。子のためではなく、**親自身**が今日一日を乗り切るためのお守りとして毎日のお題が届く。「ちゃんと教えてあげられる自分になる」を親に主語を置いて表現 |
| 該当方向性 | (1) 親自身の自信・余裕 |
| ペルソナA訴求 | ◎（孤立・自己嫌悪に直接寄り添う） |
| ペルソナB訴求 | ○（罪悪感を抱えるさやかの台詞「ちゃんと教えてあげられてない」と直結） |
| 想起しやすさ | 4/5（7文字でやや長いが「お守り」の比喩が即理解可） |
| note適合 | ○ `note.com/oyanoomamori` 推定空き |
| 衝突調査（参考） | WebSearch で同名サービスのヒットなし。「親」「お守り」は普通名詞ゆえ商標性は弱いが、note ハンドル取得は競合少なめと推測 |
| 既存5案との差別化 | 既存5案はすべて「子」「親子の関係」が主語。本案は**親が主語**で唯一無二 |

### 案B：ねむまえ10分（nemumae10）

| 項目 | 内容 |
|---|---|
| 名称表記 | **ねむまえ10分** / ネムマエ10分 / nemumae10 |
| 由来・コンセプト | 「寝る前の10分、親子で一緒に1つだけ」というプロダクトv0.2のリズムを名前に固定。生活動線に直接埋め込む |
| 該当方向性 | (2) 毎日・習慣 |
| ペルソナA訴求 | ◎（夜泣き前の絵本タイム文化と接続） |
| ペルソナB訴求 | ◎（10分の親子取り組みコンセプトと完全一致） |
| 想起しやすさ | 5/5（数字込みで具体的、寝る前という生活時間を一発指定） |
| note適合 | ◎ `note.com/nemumae10` 取得しやすい |
| 衝突調査（参考） | WebSearch で「ねむまえ」名称の子育てサービス確認できず。寝かしつけアプリ「ぐっすリンベビー」は別領域。サービス名衝突リスクは低 |
| 既存5案との差別化 | 既存5案は「行為（声かけ・育ち・一歩）」を抽象的に表現。本案は**時間帯＋分数**で生活動線に固定する点で完全に異質 |

### 案C：きづきノート（kizuki-note）

| 項目 | 内容 |
|---|---|
| 名称表記 | **きづきノート** / キヅキノート / kizuki-note |
| 由来・コンセプト | 子の成長・個性・できた瞬間に **親が気づく** ためのノート。「うちの子、こんなことできるんだ」という発見を毎日積む |
| 該当方向性 | (3) 気づき・発見 |
| ペルソナA訴求 | ◎（発達不安に対し「比較ではなく我が子の発見」で安心材料を提供） |
| ペルソナB訴求 | ○（就学準備の文脈ではやや弱いが、子の得意発見と接続可） |
| 想起しやすさ | 4/5（「気づき」＋「ノート」で意味は即伝わる） |
| note適合 | ◎ note との親和性が極めて高い（noteそのものが「気づきを書く場」） |
| 衝突調査（参考） | 園と保護者の連絡アプリ「きっずノート」が存在（別領域・濁点違い）。「きづきノート」名称の子育てサービスはヒットなし。商用衝突リスク低〜中 |
| 既存5案との差別化 | 既存5案は「与える・育てる」発想。本案は**親の観察・受け取り**に主軸を置き、Phase 1 のフィードバック設計とも整合 |

### 案D：ふぅ。（fuu）

| 項目 | 内容 |
|---|---|
| 名称表記 | **ふぅ。** / フゥ / fuu |
| 由来・コンセプト | 完璧主義の親が「ふぅ」と肩の力を抜ける場所。v0.2 のNOT-do精神（物送らない・タブレット要らない・10分で済む）を擬音語1つに凝縮 |
| 該当方向性 | (4) 肩の力を抜く・楽になる |
| ペルソナA訴求 | ◎（22時の自己嫌悪タイムへの直接処方） |
| ペルソナB訴求 | ◎（罪悪感さやかへの「これで十分」メッセージ） |
| 想起しやすさ | 4/5（3文字で極短だが、句点込みのブランド表記がやや覚えにくい可能性） |
| note適合 | △ `note.com/fuu` は既取得の可能性大。`note.com/fuu-kosodate` 等のサブブランド必須 |
| 衝突調査（参考） | 「ふぅ」は一般擬音語ゆえ商標化困難。WebSearch では子育てサービスでの同名利用は確認できず、ただしハンドル取得競争は厳しい見込み |
| 既存5案との差別化 | 既存5案はすべて「行為・関係」を表現。本案は唯一**感情・体感**を直接表現し、トーン（ブランド人格）で差別化 |

### 案E：もうすぐいちねんせい便（mousugu-ichinensei-bin）

| 項目 | 内容 |

| 名称表記 | **もうすぐいちねんせい便** / モウスグイチネンセイビン / mousugu-ichinensei-bin |

| 想起しやすさ | 3/5（11文字で長い、ただし意味は瞬時に伝わる） |

## 既存5案＋新規6案＝計11案 総合推奨ランキング Top3

採用基準: (i) 両ペルソナ訴求、(ii) コンセプト整合、(iii) 想起性、(iv) 衝突リスク、(v) 既存5案にない切り口の魅力。

### Top1：ねむまえ10分（新案B）

- 両ペルソナ◎、想起性5/5、衝突リスク低、note適合◎
- プロダクトv0.2の「毎日10分」コアコンセプトを最も忠実に再現
- 既存5案が抽象的だったのに対し、**生活動線に固定する具体性**で差別化
- 唯一の懸念：将来「10分」枠を変更したい時に名前が足枷になる可能性 → 「ねむまえ」単独表記でも運用可

### Top2：ことだち（既存案1）

- 既存5案の中で総合点最高（v1 推奨1位）
- 親への声かけ台本コンセプトとの整合性は依然強い
- 新案と比べても両ペルソナ訴求◎・想起性◎・衝突リスク最小は維持
- v1分析の妥当性を再確認

### Top3：きづきノート（新案C）

- noteプラットフォームとの親和性が全11案中**最強**
- 「親の観察・気づき」というv0.2フィードバック設計（Layer 3）と直結
- ペルソナAの発達不安への処方として「比較ではなく我が子の発見」という新メッセージを打ち出せる
- 既存「そだちのたね」と方向性が近接するが、**親の主観に立つ**点で明確に異質

### Top3 圏外だが特筆すべき案

- **おやのおまもり**：親を主語にする視点は11案中唯一。Phase 1 インタビューで「親自身のしんどさ」が想定以上に深刻だった場合に昇格候補
- **もうすぐいちねんせい便**：Phase 1 で B 単独採用が確定した場合の有力候補。SEO集客で唯一優位
- **tono.**：長期商標性・海外展開を見据えるなら唯一の選択肢。ただしPhase 1段階では意味理解コストが課題
