## プロフィール本文（コピペ用）

```
ひだまりこそだち｜0〜6歳の子と過ごす方へ、毎日のお題と、その場で使える『親への声かけ』をnoteに1日ひとつそっと届けています。「こそだち」は子育ち＋子育てを重ねた合成造語。陽だまりのような場所で、親子それぞれのペースで日々を重ねていけたらうれしいです。よかったら覗いてください。
```

## ハッシュタグ案

### 常設候補（プロフィール下部・固定ポスト・通常ポストで使い回し）

- `#ひだまりこそだち`（ブランドタグ・最重要）
- `#子育て` `#育児`（汎用・到達優先）
- `#0歳 #1歳 #2歳 #3歳 #4歳 #5歳 #6歳`（年齢タグはポスト内容に合わせ1-2個）
- `#就学準備`（ペルソナB訴求）
- `#声かけ` `#親への声かけ`（プロダクト独自タグ）
- `#noteで毎日`（誘導タグ）

## 固定ツイート案（任意）

```
0〜6歳の子と過ごす方へ。

毎日のお題と、その場で使える『親への声かけ』を、noteに1日ひとつそっと並べています。

「何かをやらせなきゃ」の前に、声をかける側の私たちが、ひと呼吸おける場所になれたら。

▼note（ひだまりこそだち）
https://note.com/hidamari_sodachi

#ひだまりこそだち
```

> 補足: 固定ポストは「何ができるか・どこで読めるか」を補い、プロフィール本文では削った note リンクへの動線を担う。

## X 自己レビュー

| 観点 | 結果 |
|---|---|
| 「教える／育てる」動詞の回避 | OK（不使用） |
| 「育む／芽吹く／そっと寄り添う／日々を重ねる」の活用 | 「そっと届ける」「日々を重ねる」採用 |
| 子の個性・ペースを尊重 | 「親子それぞれのペースで」 |
| ターゲット明示（0〜6歳の保護者） | あり（冒頭） |
| 「こそだち」合成造語の説明 | あり（簡潔） |
| サービス価値（毎日のお題＋親への声かけ）明示 | あり |
| note 誘導の柔らかさ | 「よかったら覗いてください」 |
| メタファー使用回数 | 1回（陽だまり） |
| 媒体特性への適応 | 1秒で読める導線・固定ポストで補完 |
