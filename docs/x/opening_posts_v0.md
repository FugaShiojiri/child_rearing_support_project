## 投稿スケジュール案

Phase 1 の SNS 戦略（X 主軸・週 2-3h・平日 19:30-22:00 がコア）に沿って、3 日間に分散しつつ立ち上げ初週で 5 本を出し切る。

| 日 | 時刻 | 投稿 | 狙い |
|---|---|---|---|
| Day 1（水）| 20:00 | Post 1（初投稿・自己紹介）| ピーク時間帯にアカウント開設の挨拶。固定ツイート候補 |
| Day 2（木）| 20:00 | Post 2（WHY）| 共感ベースで一次拡散を狙う |
| Day 3（金）| 20:00 | Post 3（コンテンツ予告）| 「何が読めるか」を提示し、フォロー判断材料を渡す |
| Day 4（土）| 10:00 | Post 4（NOT-do 宣言）| 休日午前の隙間時間に、差別化メッセージを刺す |
| Day 5（日）| 20:00 | Post 5（フォロー誘導・note 連動）| 週末夜に note マニフェスト公開と接続 |

- Post 1 は数日間「固定ツイート」に設定し、後から訪れたユーザーがアカウントの素性を即座につかめるようにする。
- Post 5 公開のタイミングで、note 側のマニフェスト記事（バージョン C ベース）を同時公開できると流入導線が成立する。

## Post 1: 初投稿・自己紹介

```
はじめまして。ひだまりこそだち、というちいさなアカウントを始めました。

0〜6歳のお子さんと過ごす方へ、毎日のお題と、その場で使える「親への声かけ」を1日ひとつ、そっとお届けする場所です。

陽だまりのような場所で、親子それぞれのペースで日々を重ねていけたら。よろしくお願いします。

#こそだち #育児記録
```

【実測字数】改行除く **149字** / 改行込み **155字**
【意図】「誰が・誰に・何を・どんな姿勢で」を 1 投稿で完結させる。サービス名・対象（0〜6歳）・提供物（毎日のお題と親への声かけ）・思想（陽だまり／それぞれのペース）を最短距離で並べる。タイムラインで初見の人が 5 秒でアカウントを判別できる構成。
【補足】
- プロフィール画像／ヘッダーが整ってから投稿する。プロフィール文には note プロフィール v0 のバージョン A（86 字）を流用予定。
- 固定ツイートに設定する想定。
- ハッシュタグは 2 個に留め、本文の余白を優先。

## Post 2: WHY（なぜこのサービスを作るのか）

```
「ちゃんと教えなきゃ」と思うたび、私自身が一番こわばっていました。

子をどうにかする前に、声をかける側の私たちがひと呼吸おける言葉があってもいい。

そんな縁側のような場所を作りたくて、ひだまりこそだちを始めます。同じ気持ちの方と並んで座れたらうれしいです。

#育児記録 #ゆるい育児
```

【実測字数】改行除く **138字** / 改行込み **144字**
【意図】保護者の共感ポイント（教えなきゃ／こわばり）を最初の 1 行で開示し、運営者自身も同じ立場であることを示す。ペルソナ A・B 双方に通じる「親側のしんどさ」を起点にしつつ、ブランドメタファー（縁側・並んで座る）に着地。専門家ぶらない・寄り添う姿勢を体現する。
【補足】
- 自虐や卑下になりすぎないよう、文末は「同じ気持ちの方と並んで座れたらうれしい」と前向きに締める。
- 「教えなきゃ」は本文では否定文脈で使用しており、ブランドトーンの「教える／育てる動詞は控える」を逸脱しない。

## Post 3: コンテンツ予告（何を発信するか）

```
このアカウントで届けたいのは、1日ひとつの「親への声かけ台本」。

たとえば——
・「なんで？」が止まらない夜に
・着替えを嫌がる朝に
・うまく言葉が出てこない時に

子に何かをさせる前に、親が使える短い言葉を、午後の光のようにそっと置いていきます。日々のお題と合わせてどうぞ。

#こそだち #知育
```

【実測字数】改行除く **141字** / 改行込み **150字**
【意図】「フォローする価値があるか」を判断してもらうため、具体例 3 つを箇条書きで提示。ペルソナ B（3〜6歳の「なんで？」）とペルソナ A（着替え・発語）どちらにも引っかかる例を混ぜる。プロダクトの主役（親への声かけ）を明確化する。
【補足】
- 箇条書きで密度が上がるため、絵文字は使わず行頭「・」のみ。
- 「知育」タグは検索流入を意識して採用。ただし「知育＝先取り学習」と取られないよう、本文では「親が使える言葉」に軸を置く。

## Post 4: ブランドの姿勢宣言（NOT-do）

```
ひだまりこそだちで、しないと決めていること。

・物は送りません(教材も玩具も)
・「絶対」「必ず」「○歳までに」は使いません
・タブレットも要りません

うまく芽吹かない日もある、という余白を残したいから。読むのに10分かからない、ちいさな言葉だけをお届けします。

#ゆるい育児 #こそだち
```

【実測字数】改行除く **139字** / 改行込み **147字**
【意図】既存サブスク（こどもちゃれんじ・スマイルゼミ）に疲れた層への差別化メッセージ。ペルソナ B の NOT-do リスト（印刷教材なし・タブレットなし）と、ブランドの言語ルール（断言しない）を 3 点で並列化。NG ワードは「使わない」と引用する形でのみ登場。
【補足】
- 「うまく芽吹かない日もある」で押しつけがましさを中和し、宣言が説教調にならないようにする。
- 「絶対／必ず／○歳までに」は引用符付きで「使わない」対象として明示しているのみ。ブランドトーン上は OK。

## Post 5: フォロー誘導 + note 連動

```
近いうちに、note で「ひだまりこそだちをはじめます」というマニフェストを公開予定です。

なぜこの名前にしたのか、何を大切にしているのか、ゆっくり書きました。

このアカウントでは、毎日の声かけ台本を少しずつ。よかったらフォローして、気が向いた日にのぞいてください。

#こそだち #育児記録 #知育
```

【実測字数】改行除く **146字** / 改行込み **152字**
【意図】note マニフェスト記事（プロフィール v0 バージョン C ベース）への期待値を作り、X → note の動線を初期から確立する。フォロー導線は「強い CTA」ではなく「気が向いた日にのぞいてください」と低圧で閉じ、ブランドトーンを守る。
【補足】
- 投稿時点で note マニフェスト記事の URL が確定していれば、本文末（ハッシュタグの前）に短縮 URL ではなく素のリンクで貼る運用を推奨。URL を貼ると 23 字加算される想定（X の t.co 短縮）なので、最終的に改行込み 175 字程度に収まる。
- SNS 戦略 v0 の「SNS 投稿に毎回 note リンクは貼らない（5 投稿に 1 回程度）」原則に整合する位置取り。

## 共通の注意点

### ハッシュタグの一貫運用

- 主に使うタグ: `#こそだち`（ブランド固有・育てるべき自社タグ）／`#育児記録`（流入大）／`#ゆるい育児`（トーン一致）／`#知育`（広めの検索流入）。
- 1 投稿あたり **2〜3 個** に固定。Post 5 のみ 3 個、他は 2 個で運用負荷を抑える。
- 投稿末尾にまとめて配置し、本文中に混入させない（読みやすさ優先）。
- 「#子育て」は競合密度が極端に高いため、初期は外す。Phase 2 以降に再評価。

### メンション・引用は避ける（初期段階）

- フォロワー 0 の段階で他アカウントを引用・メンションすると、押し付けや営業色が出るリスクがある。Phase 1 は自己発信に集中。
- 公的資料（文部科学省・こども家庭庁）の URL を本文に貼るのも、Phase 1 の最初の 5 本では行わない。出典付き豆知識（パターン C）は 6 本目以降から開始。

### リプライへの返信方針

- 立ち上げ直後はリプライがほぼ来ない前提。返信が来た場合は **24 時間以内・1 件 1 リプ** で対応し、相互フォロー営業や DM 誘導は行わない。
- 反応がゼロでも、Post 1〜5 を予定通り順番に出し切る。途中で計画を曲げない。

### 絵文字の運用

- 今回の 5 本では絵文字を **0 個** で統一した。ブランドトーン（やさしく・断言しない・派手にしない）を最優先したため。
- Phase 1 の検証で「絵文字なし投稿のエンゲージメント」がベースラインとして測れるメリットもある。途中から絵文字を入れる場合は 1 ツイート 1〜2 個までを厳守。
