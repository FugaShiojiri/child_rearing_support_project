## 運用メモ（恒久）

- **Threads（🤖自動）**: 承認済み(`approved:true`)＆当日(JST)付けドラフトを main に push しておけば、毎日12:00 JSTに GitHub Actions が自動投稿（[[project-threads-autopost]]）。`scripts/threads_insights.py` で反応を測定。
- **note（✋手動）**: 自動投稿は未稼働（認証情報未設定）。記事＋サムネは在庫から、オーナーが手動公開。公開ボタンはオーナー。
- **Instagram（✋手動→来週🤖化予定）**: カルーセルは `instagram_carousel.py` で生成→OneDrive経由でオーナーが手動投稿。来週 GitHub raw URL 方式で自動化予定（無料・[[project-instagram-ops]]）。
- **承認ゲートは全チャネル不変**: 販売・配信コンテンツのオーナー目視（`approved:true`）は自動・手動問わず必須。
