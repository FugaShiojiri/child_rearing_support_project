## 4. 定性の兆候（粗く・結論にしない／n<20）

- **【オーナー一次情報・2026-06-04】「note他クリエイターへのコメント記載（T070）が、かなり効果的だったと思う」**。手を動かした本人の実感ベースの観察。ビュー36→113・スキ0→19の伸びの主ドライバーがT070だった可能性を示唆。
  - **位置づけ（慎重に）**: n小・要因分離は厳密にはできない（連載前倒し公開・口調刷新も同時進行）ため**「強い作業仮説」**として扱う（断定しない）。ただし**手を動かした本人の定性所見は重み大**。
  - **戦略的含意**: Phase2の **B（軽量定性＝コメント/DM起点の接点づくり）と C（チャネル再設計でリーチ母数を積む）を裏づける**。とくに「こちらからコメントで接点を作る→相手と読者がこちらへ来る」という導線が効くなら、T070は集客コストの低い再現可能レバーになりうる。
  - **T089(週次T070ヒアリング)・T087(学び文書)・T088(Phase2骨子)に反映する**。次に確認したい：どんなコメントに反応(プロフ訪問/フォロー/コメント返し)があったか、どのジャンルの記事が効いたか＝再現条件の特定。

- **【オーナー一次情報・2026-06-04 その2】他者のnoteマガジン「📖やさしさを繋ぐ図書館」(運営:ゆう｜ほどく会話のことば)にひだまり記事が収録された通知あり＝宣伝効果と実感**。
  - **位置づけ（慎重に）**: 当該マガジンは収録**1.4万本超**＝「厳選少数」でなく「フォロワー記事を広く収める」性格。**1本あたりの露出効果は控えめ**と見るのが妥当（過大評価しない）。
  - **戦略的含意（こちらが本質）**: 「他者のマガジンに収録される」＝**note内の発見性メカニズムの一つ**。かつ**T070(コメント接点)→相手が気づく→マガジン収録という再現可能ループ**を示唆＝上の「コメントが効いた」所見と整合。Phase2 C(note内発見性の深掘り)の具体レバー候補に「マガジン収録される/自前マガジン運営/相互収録」を加える。
  - 総合：**Form0だが"note内でコミュニティに認知され始めている"複数の弱い正信号**（スキ19・コメント接点・マガジン収録）。重いコミット(Form)前の浅い接点が動き出した段階＝CEOの「発見性は動く」判断を現場側からも追認。
