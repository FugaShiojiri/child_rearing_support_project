> 作成日: 2026-05-13
> 作成者: ceo SubAgent
> ステータス: 初版（CEO 最終選定待ち）
> 参照: `docs/product_v0_2.md`（親への声かけ台本 / 就学準備＋孤立解消） / `docs/persona_v0.md`（ペルソナA 0-2歳、ペルソナB 3-6歳）

---

## 命名の前提

`docs/product_v0_2.md` のコアコンセプトから抽出した3要素を名称に滲ませる：

1. **親への声かけ台本**（AI が "子の代わりに何かする" のではなく、"親が今日子にかける言葉" を渡す）
2. **就学準備 10 分**（ペルソナB の中核）
3. **孤立解消・発達の安心材料**（ペルソナA の中核）

5案すべて「親が読む note メンバーシップ」「やさしく・断言しない・公的根拠を添える」というブランドトーン（pre_phase1_decisions 3-3）に整合する命名を採用。

## 候補一覧（5案）

### 1. ことだち（kotodachi）

| 項目 | 内容 |
|---|---|
| 名称（カナ/平仮名/英字） | **ことだち** / コトダチ / kotodachi |
| 由来・コンセプト | 「ことば」＋「ともだち」の合成。親が子にかける**ことばの友** = 毎日 1 つの声かけ台本という贈り物。やさしい平仮名 4 文字で記憶しやすく、note ハンドルに収まる |
| ペルソナA（0-2歳）訴求度 | ○（「ことば」がまだ少ない時期の親の不安に寄り添う） |
| ペルソナB（3-6歳）訴求度 | ◎（ひらがな・就学準備の「ことば」とも自然に重なる） |
| 想起しやすさ・覚えやすさ | ◎ 平仮名 4 文字、語感が柔らかい、「ことばの友達」と一度説明すれば即定着 |
| note アカウント名としての適合 | ◎ `note.com/kotodachi` で運用可、サブブランド `kotodachi-baby` / `kotodachi-kindy` 展開可 |
| 商標・ハンドル空き（参考調査） | J-PlatPat 経由 WebSearch で同名の登録商標は確認できず（教育系第41類で明確ヒットなし、要 J-PlatPat 直接確認）。Instagram / X / Gmail は **未確認**（CEO の Week 1 で要 1 次確認） |
| 推奨順位 | **1 位** |
| 推奨理由 | 親への声かけ台本コンセプトと最も整合。両ペルソナを内包しつつ、平仮名の柔らかさが「断言しない」トーンに合致 |

### 2. こえかけ（koekake）

| 項目 | 内容 |
|---|---|
| 名称（カナ/平仮名/英字） | **こえかけ** / コエカケ / koekake |
| 由来・コンセプト | プロダクトの中核機能「親への声かけ台本」をそのまま名前にした直球案。「今日のこえかけ、届きました」という日常体験が名前に直結 |
| ペルソナA（0-2歳）訴求度 | ◎（言語発達期の親の「どう声をかければ」という悩みに直撃） |
| ペルソナB（3-6歳）訴求度 | ◎（就学準備の「ひらがなを教える声かけ」「ぐずる朝の声かけ」と直接結びつく） |
| 想起しやすさ・覚えやすさ | ◎ 平仮名 4 文字、機能名と一致するので説明不要、note タイトルに自然に入る |
| note アカウント名としての適合 | ◎ `note.com/koekake` で運用可。ただし「こえかけ」は普通名詞のため SEO で埋もれるリスクあり |
| 商標・ハンドル空き（参考調査） | WebSearch 検索ヒットなし（普通名詞すぎて検索性が低い）。普通名詞のため**商標登録は困難な可能性**、ただし note ハンドル取得は競合少なめと推測。Gmail / SNS は **未確認** |
| 推奨順位 | **2 位** |
| 推奨理由 | 機能訴求の明快さは最強。難点は商標性の弱さ（普通名詞）と SEO 不利。「やさしい命名」を最優先するなら 1 位候補 |

### 3. そだちのたね（sodachi-no-tane）

| 項目 | 内容 |
|---|---|
| 名称（カナ/平仮名/英字） | **そだちのたね** / ソダチノタネ / sodachi-no-tane |
| 由来・コンセプト | 「育ちの種」を平仮名表記。毎日のお題は **小さな種** で、親子で水をやることで子の育ちにつながる。発達観察の長期視点を込めた |
| ペルソナA（0-2歳）訴求度 | ◎（「うちの子の発達、大丈夫？」という不安に対する**長期視点の安心材料**として機能） |
| ペルソナB（3-6歳）訴求度 | ○（就学準備の文脈では「種まき」のメタファーがやや遠い） |
| 想起しやすさ・覚えやすさ | ○ 6 文字でやや長い。ただし「育ちの種」のメタファーは1度聞けば忘れにくい |
| note アカウント名としての適合 | ○ `note.com/sodachi-no-tane` 可。マガジン名としても自然 |
| 商標・ハンドル空き（参考調査） | WebSearch で同名サービスの明確ヒットなし。「育ちのたね」「そだちのたね」の競合プロダクトは未検出。Gmail / SNS は **未確認** |
| 推奨順位 | **3 位** |
| 推奨理由 | ペルソナA への訴求は最強だが、ペルソナB との両立がやや弱い。Phase 1 で「A 単独で行く」と決まった場合は 1 位昇格候補 |

### 4. はじめのいっぽ（hajime-no-ippo）

| 項目 | 内容 |
|---|---|
| 名称（カナ/平仮名/英字） | **はじめのいっぽ** / ハジメノイッポ / hajime-no-ippo |
| 由来・コンセプト | 子の「はじめてのできた」を親が一緒に踏みしめる **最初の一歩**。就学準備（小学校への一歩）と発達マイルストーン（歩く・話す）の両ペルソナに自然に橋を架ける |
| ペルソナA（0-2歳）訴求度 | ◎（初めての発達・初めての離乳食・初めての言葉） |
| ペルソナB（3-6歳）訴求度 | ◎（小学校への「はじめの一歩」＝就学準備の本質的メタファー） |
| 想起しやすさ・覚えやすさ | ○ 7 文字でやや長いが、慣用句として日本人に馴染みが深い。短縮形「いっぽ」も使える |
| note アカウント名としての適合 | △ `note.com/hajime-no-ippo` は取得可だが長い。サブブランド展開（`-baby` / `-kindy`）でさらに長くなる懸念 |
| 商標・ハンドル空き（参考調査） | **山口県の保幼小連携リーフレット「はじめのいっぽ」、絵本「はじめのいっぽ」（アスクミュージック）が存在**。商用商標としての登録状況は要 J-PlatPat 確認。一般慣用句のため類似サービスが乱立しやすい |
| 推奨順位 | **4 位** |
| 推奨理由 | コンセプト適合度は最強クラスだが、**同名の既存出版物・公的資料が複数**あり、SEO・ブランド差別化で不利。採用するなら早期の差別化要素（サブタイトル等）必須 |

### 5. おやとこ（oyatoko）

| 項目 | 内容 |
|---|---|
| 名称（カナ/平仮名/英字） | **おやとこ** / オヤトコ / oyatoko |
| 由来・コンセプト | 「親と子（おやとこ）」。親が読み、子と取り組む 10 分。**親が主役**の構造（プロダクト v0.2 の「親への声かけ台本」設計）を直接表現 |
| ペルソナA（0-2歳）訴求度 | ○（親子の関わりの最初期） |
| ペルソナB（3-6歳）訴求度 | ◎（10 分親子で取り組むコアコンセプトと直結） |
| 想起しやすさ・覚えやすさ | ◎ 平仮名 4 文字、語感も覚えやすい |
| note アカウント名としての適合 | ○ `note.com/oyatoko` 可だが、**競合濃厚** |
| 商標・ハンドル空き（参考調査） | **WebSearch で複数の既存サービスを確認**: (a) 大阪「おやとこらいぶねっと」(Instagram @oyatoko)、(b) 体験型親孝行サービス「オヤトコ」(oya-to-ko.com)、(c) Hahakala 社「OYA.NOTE」（旧 Wedoo）。**ハンドル `@oyatoko` は Instagram で取得済み**、ブランド衝突リスク高 |
| 推奨順位 | **5 位** |
| 推奨理由 | コンセプト適合は良いが、**同名サービスが複数存在し、note 流入で混同される確率が高い**。採用非推奨 |

## CEO 推奨順位サマリー

| 順位 | 名称 | 推奨理由（1文） |
|---|---|---|
| 1 | **ことだち** | コンセプト整合・両ペルソナ内包・商標衝突リスク最小 |
| 2 | こえかけ | 機能訴求最強、ただし普通名詞ゆえ商標性が弱い |
| 3 | そだちのたね | ペルソナA特化、B 単独採用ならアリ |
| 4 | はじめのいっぽ | コンセプト◎だが同名既存物多数で差別化困難 |
| 5 | おやとこ | 既存サービスとの衝突で採用非推奨 |

## CEO への意思決定の出し方

Week 1 で以下を確定してください：

1. **第1候補「ことだち」を採用するか**（推奨）
2. 採用する場合、Week 1 中に CEO 自身で以下を 30 分で確認：
   - J-PlatPat（特許情報プラットフォーム）で「ことだち」第41類（教育）の登録確認
   - Gmail `kotodachi@gmail.com` / `kotodachi.note@gmail.com` の取得可否
   - note `note.com/kotodachi` の空き確認
   - X / Instagram `@kotodachi` の空き確認
3. **完全空きでなくても採用判断は可能**（v0.2 新方針：参考情報扱い）。空きが取れない部分はサブブランド命名（`kotodachi-baby`、`kotodachi-kindy` 等）で回避可能

## 商標・ハンドル空き調査の限界（正直な記載）

本調査は WebSearch ベースの **参考情報** であり、以下の限界があります：

- J-PlatPat への直接アクセスは行っておらず、**法的な商標衝突の有無は確定していません**
- 各 SNS / Gmail / note のハンドル空き状況は WebSearch では正確に確定できず、**CEO 自身の Week 1 での 1 次確認が必須**
- v0.2 新方針により、これらは**採用の絶対条件ではなく参考情報**として扱います
- 商用展開段階で商標登録を本格検討する場合は、Phase 3-4 で弁理士相談を推奨（現時点では時期尚早）
