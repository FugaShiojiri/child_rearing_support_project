# IB-PYP（国際バカロレア初等プログラム／IB Primary Years Programme）

## 1. 一行サマリ
「なぜ？」を出発点に世界を学ぶ、3-12歳の探究型カリキュラム。

## 2. 中核思想

IB-PYPは、国際バカロレア機構（IBO、本部ジュネーブ）が1997年に開始した3-12歳向けの国際カリキュラム。中心にあるのは **「探究（inquiry）を通じて学ぶ」** という考え方で、教師が知識を一方的に与えるのではなく、子ども自身が問いを立て、調べ、表現し、振り返るプロセスを重視する。

学習は教科ごとに切り離されず、**6つのトランスディシプリナリー・テーマ**（Who we are／Where we are in place and time／How we express ourselves／How the world works／How we organize ourselves／Sharing the planet）の下で横断的に探究される。たとえば「私たちは誰か」というテーマで、自分の体・家族・文化・感情を、国語・理科・社会・芸術を行き来しながら学ぶ。

親の日常感覚に翻訳すると、「公園で見つけた虫の名前を一緒に図鑑で調べ、絵を描き、家族に発表する」──こうした **問い→調べる→表現する→振り返る** のサイクルこそがPYPの肝にあたる。

## 3. 子どもの捉え方

子どもは生まれながらの **探究者（inquirer）** であり、世界を理解しようとする能動的な学び手として捉える。「教えられる対象」ではなく「学びの主体」。IBが掲げる **Learner Profile（学習者像）** は10の人物像──探究する人、知識のある人、考える人、コミュニケーションができる人、信念のある人、心を開く人、思いやりのある人、挑戦する人、バランスのとれた人、振り返りができる人──で、3歳から大人までが生涯にわたって磨いていく資質として描かれる。

## 4. 大人（親・保育者）の役割

教師は「教える人」ではなく、子どもの問いを引き出し、深め、整える **ファシリテーター** として機能する。親に置き換えると：

- 答えを先回りせず、「あなたはどう思う？」と返す
- 子どもの「なぜ？」を流さず、一緒に調べる仲間になる
- 結果より、考えた過程・工夫・気づきを言葉にする

## 5. 環境・道具

学校では「探究の壁」（Wonder Wall）に子どもの問いを貼り出し、図書・実物・地域の人材・ICTを総動員する。家庭レベルでは、特別な教具は必須ではない。図鑑、観察ノート、地図、絵を描く道具、そして **「調べに行ける大人」** が最大の環境となる。

## 6. 0-6歳の実践イメージ

- **シーン1**：朝食で「卵ってどこから来るの？」と子。答えを言う前に「どこから来てると思う？」と返し、絵本やスーパーの卵パックを一緒に見に行く。
- **シーン2**：きょうだいゲンカが起きたとき。「どっちが悪い」を裁定せず、「Who we are（私たちは誰か）」のテーマよろしく、それぞれの気持ちを言葉にしてもらい、自分たちで解決策を出してもらう。
- **シーン3**：散歩中に落ち葉を集める。色・形・大きさで分類してみる。「How the world works（世界はどう動くか）」の入口として、季節の変化を一緒に観察する。

## 7. ひだまりこそだち との接点

**共感する点**
- 子どもを能動的な学び手として捉える前提
- 「教える」より「問いを返す」関わり方
- Learner Profile の「振り返ることができる人」「心を開く人」など、ジェンダー・国籍・能力を超えた人物像
- 教科や学問領域を越境して学ぶという発想は、生活そのものが学びである0-6歳期と相性がよい

**距離を置く点**
- IB認定校（特にインターナショナル幼稚園）は **年間100-300万円規模の学費** が珍しくなく、経済的アクセスが極端に偏る。「PYPに通わせられないと探究型教育は受けられない」というメッセージは誤りであり、ひだまりこそだち は採らない。
- 認定取得のための **大量の記録・ドキュメンテーション** は、家庭で完全再現すると親が疲弊する。海外実践理論共通の論点（README「家庭再現の距離感」参照）。

**取り入れたい要素**
- Learner Profile を **親自身のチェックリスト** として使う視点（「今日、自分は子どもに対して open-minded だったか？」）
- 6つのテーマの中から1つだけ、季節ごとに家庭の話題にしてみる
- 「どう思う？」「なぜそう思う？」「次はどうする？」の3問セットを日常会話に置く

## 8. 親が陥りがちな誤解

**誤解1：「IB-PYPに通わせないと探究型教育は受けられない」**
探究の本質は問い・観察・対話であり、これは家庭の食卓・散歩・絵本でも十分育てられる。高額な学費を払うかどうかと、子どもの探究心が育つかどうかは別の問題。

**誤解2：「Learner Profile の10属性を全部備えさせなきゃ」**
Learner Profile は到達目標ではなく、生涯磨いていく **方向性** として書かれている。3歳児に「あなたは Risk-taker か？」と問うものではない。親自身が指針として参考にする方が現実的。

**誤解3：「探究型＝放任して見守るだけ」**
PYPの探究は無計画な放任ではなく、教師の綿密なプランニングに支えられている。家庭でも「問いを返す」だけでなく、子どもが調べに行ける環境（本・人・場所）を用意する大人の準備が要る。
