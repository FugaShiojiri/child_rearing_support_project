# Tier S 7理論 × マッチャー6軸 マッピング

> 目的: マッチャー（親×理論診断）の 6 軸（R応答性 / S構造性 / I主導権 / E評価観 / P早期化 / C関係性）で Tier S 7 理論をスコア化し、推薦アルゴリズムの基礎データを整える。
> スコア範囲: **-2.0 〜 +2.0**（各軸の極性は [[docs/matcher/axes_v0]] を参照）
> 注意: スコアは「その理論が **どの軸でどちらの極に近い親に推奨されやすいか**」を示すものであり、**その軸でその理論が「正しい」とする評価ではない**。

## 1. 6 軸の極性（おさらい）

| 軸 | + 極 | - 極 |
|---|---|---|
| **R** 応答性 | R+ 高応答・察し | R− 自律探索を尊重 |
| **S** 構造性 | S+ 構造的・ルーティン | S− 流動的・自由 |
| **I** 主導権 | I+ 親主導・誘導 | I− 子主導・委ねる |
| **E** 評価観 | E+ 結果・能力 | E− 過程・工夫 |
| **P** 早期化 | P+ 早期投資・先取り | P− 発達待ち・ゆっくり |
| **C** 関係性 | C+ 共同体・つながり | C− 個別自立・境界 |

**読み方**: 太字は各軸でその理論の特徴的な極（|score| ≥ 1.5）。マッチャーで親プロファイルが {R+1.5, S-0.5, I-1.0, E-1.0, P-1.0, C+1.0} のような分布なら、Bowlby と 佐々木 が最も親和的、というふうに使う。

## 3. 各理論の軸別スコア + 理由

### 3.1 Bowlby アタッチメント理論

- **R 応答性: +2.0**（最強の R+）
  - 「敏感性 (sensitivity)」「応答性 (responsiveness)」が中核概念。
  - Madigan 2024 のメタ分析が敏感性 → 愛着安定の効果量を確定。
  - ただし「察し過剰」とは区別する（サインを読んで応える、サインがなくても先回りはしない）。
- **S 構造性: -0.5**（やや S−）
  - 「予測可能性」は子の安心に重要だが、Bowlby はルーティン化を推奨しない。
  - 「Serve and Return」は子のシグナル起点で発動するため、構造的でない。
- **I 主導権: -1.0**（I−寄り）
  - 子のシグナルに応答する関係性。親が学びの方向を提示することは中核ではない。
  - ただし「親が完全に降りる」のでなく「ニーズに応える主導性」は持つ。
- **E 評価観: -0.5**（やや E−）
  - 評価軸そのものに踏み込まない。
  - 「結果でなく関わりの過程」を重視するため、E− に寄せた。
- **P 早期化: -0.5**（やや P−）
  - 早期介入は重要だが「先取り教育」ではない。
  - 「世代間連鎖の介入は早いほど効果的」（Bakermans 2003）だが、これは knowledge 系の先取りとは別物。
- **C 関係性: 0.0**（中立）
  - 個と関係性のバランス。
  - Rothbaum 2000 は日米の文化差を指摘するが、Bowlby 理論自体は文化中立を志向。

### 3.2 アドラー心理学

- **R 応答性: +1.0**（R+寄り）
  - 共感的傾聴・勇気づけは応答的だが、Bowlby ほど「サインを読む」を強調しない。
  - 「相手の地平に降りる」共感が中核。
- **S 構造性: 0.0**（中立）
  - 「家族会議」など定例の場は構造的、日常の関わりは流動的。
- **I 主導権: -1.0**（I−寄り）
  - 「課題の分離」 ── 子の課題に親が踏み込まない。
  - ただし「対等」── 親が完全に降りるのでもない、独特の立ち位置。
- **E 評価観: -2.0**（最強の E−）
  - **アドラー心理学の最大の特徴**。「ほめる」（縦・評価）を否定し、「勇気づけ」（横・過程承認）を推奨。
  - 「えらいね」→「ありがとう、助かった」、「すごいね」→「やってみたんだね」。
- **P 早期化: -0.5**（やや P−）
  - 早期教育に踏み込まない。
  - 「子のペース」を尊重するが、Pikler/汐見 ほど明示的でない。
- **C 関係性: +1.0**（C+寄り）
  - **共同体感覚 (Gemeinschaftsgefühl) が中核**。
  - 「自分の意見を持つ自立」より「共同体への所属感・貢献感」を重視。
  - ただし「個と共同体の統合」── C+ 一辺倒でもない。

### 3.3 非暴力コミュニケーション (NVC)

- **R 応答性: +1.5**（R+寄り）
  - 「自己共感 → 相手への共感 → 表現」の循環。
  - 子の言葉の奥のニーズを推測する敏感性は高い。
- **S 構造性: -0.5**（やや S−）
  - 構造化された対話技法を持つが、日常リズム・ルーティンには言及しない。
- **I 主導権: -0.5**（やや I−）
  - 子のニーズを起点に対話する。
  - 親が方向を示すことは否定しない（「ニーズの表明」として）。
- **E 評価観: -1.5**（強い E−）
  - 「観察と評価を区別する」が原則。
  - 「いつも散らかしてる」（評価）を「さっき積み木をリビングに置いた」（観察）に翻訳。
  - 賞賛も評価とみなして警戒する。
- **P 早期化: 0.0**（中立）
  - 年齢論に言及しない。
  - 0 歳から使えるが、本領は 3 歳以降。
- **C 関係性: 0.0**（中立）
  - 「ニーズの普遍性」を主張、文化バイアスが軽い。
  - ただし日本の「察し文化」とは正面衝突しうる（C+ 文化との齟齬）。

### 3.4 モンテッソーリ教育

- **R 応答性: -0.5**（やや R−）
  - 「援助しすぎない援助者」── 子が求めるまで手を出さない。
  - 「集中している子に話しかけない」原則は R− の極。
- **S 構造性: +1.5**（強い S+）
  - **「整えられた環境 (prepared environment)」が中核**。
  - 子サイズの家具、決まった置き場所、本物の道具、自己訂正機能のある教具。
  - 物理環境の構造化は 7 理論で最強。
- **I 主導権: -1.5**（強い I−）
  - 子が活動を選び、好きなだけ繰り返す。
  - 教師 (directress) は環境の設計者であって指示者ではない。
  - 「Help me to do it myself」が標語。
- **E 評価観: -1.0**（E−寄り）
  - 教具に「自己訂正機能 (control of error)」── 大人が正解判定をしない。
  - 「すごい！」と声をかけることを集中の妨害とみなす。
- **P 早期化: +0.5**（やや P+）
  - **「敏感期」概念が早期投資的に解釈されやすい**。
  - 0-3 歳の言語・秩序・運動の敏感期は早期介入の根拠になる。
  - ただしモンテッソーリ自身は「先取り教育」と区別する。
- **C 関係性: -1.0**（C−寄り）
  - 「個の自己構築」を重視。
  - 集団活動・共同体感覚は副次的。
  - 西洋中産階級の「個と境界」を前提とする。

### 3.5 ピクラー・アプローチ

- **R 応答性: +0.5**（やや R+）
  - 世話の場面では応答的（一言ずつ声をかける）。
  - 遊びの場面では非介入（邪魔しない）── 両義的。
- **S 構造性: +0.5**（やや S+）
  - 世話のリズム・順序を大切にする。
  - 環境設計は Montessori より控えめ。
- **I 主導権: -2.0**（最強の I−）
  - **「促さない」が中核命題**。
  - 乳児に寝返り・座り・歩行を促さない、うつ伏せ強制・歩行器・座らせを避ける。
  - 7 理論で最も子主導。
- **E 評価観: -1.0**（E−寄り）
  - 「できた」を喜ぶよりも「自分でやれた」プロセスを尊重。
- **P 早期化: -1.5**（強い P−）
  - **「促さない」の身体版**。
  - 早期に立たせない・歩かせない。
  - 「自分のペース」を最も明示的に主張する。
- **C 関係性: -0.5**（やや C−）
  - 「乳児を一人の人として扱う」── 個の尊厳を重視。
  - 共同体・つながりへの言及は薄い。

### 3.6 汐見稔幸「子ども主体の保育」

- **R 応答性: +0.5**（やや R+）
  - 「子の内側にあるやってみたいに応える」関わり。
  - Bowlby ほど明示的でないが、敏感性は重要視。
- **S 構造性: -1.0**（S−寄り）
  - **「保育の本質は放牧」** ── 構造化を最小限に。
  - 倉橋惣三の流れを汲み、「自己充実 → 誘導」の順を重視。
- **I 主導権: -1.0**（I−寄り）
  - 「子どもファースト」── 子の興味を起点に。
  - ただし「放任」でない、誘導の余地を残す。
- **E 評価観: -1.0**（E−寄り）
  - 結果・能力評価を相対化する立場。
  - 「教えから学びへ」── 教育観の転換を説く。
- **P 早期化: -1.5**（強い P−）
  - **「焦らない」「先取りしない」が中核**。
  - 早期教育批判のスタンス。
- **C 関係性: +1.0**（C+寄り）
  - **「共育て」── 保護者と保育者がともに育てる**。
  - 「孤育て」批判、社会的関係性を強調。

### 3.7 佐々木正美「子どもへのまなざし」

- **R 応答性: +2.0**（最強の R+ ── Bowlby と並ぶ）
  - **「過保護はあってよい」── 子の要求に応える**。
  - Bowlby の応答性理論を日本語の温度感で語り直す。
- **S 構造性: -0.5**（やや S−）
  - 日常そのものを大切にする。
  - 構造化に踏み込まない。
- **I 主導権: -1.0**（I−寄り）
  - 「待つ・信じる・応える」── 親は方向を示さない。
- **E 評価観: -1.0**（E−寄り）
  - 「条件付きの愛情でない、存在そのものへの肯定」。
  - 結果評価を退ける。
- **P 早期化: -1.0**（P−寄り）
  - 早期教育に否定的。
  - エリクソンの発達段階を「待つ」根拠とする。
- **C 関係性: +1.5**（強い C+）
  - **日本文化の「甘え」を肯定する立場**。
  - 母子の情緒的つながりを重視。
  - Rothbaum 2000 の日米差の日本側をはっきり代表する。

## 4. 軸ごとの理論分布

各軸で、+ 極から - 極まで Tier S 7 理論を並べる。マッチャーが推薦するときの「軸 + 親プロファイル → 候補理論」の早見表。

### 4.1 R 軸（応答性）

```
R+ ←──────────────────────────────→ R−
[+2.0] Bowlby ━━━━ 佐々木 [+2.0]
[+1.5] NVC
[+1.0] アドラー
[+0.5] ピクラー ━━━━ 汐見 [+0.5]
[-0.5] モンテッソーリ
```

**R+ 強の親**（察し・先回り） → Bowlby / 佐々木 / NVC
**R− 強の親**（待つ・観察） → モンテッソーリ / ピクラー

### 4.2 S 軸（構造性）

```
S+ ←──────────────────────────────→ S−
[+1.5] モンテッソーリ
[+0.5] ピクラー
[0.0]  アドラー
[-0.5] Bowlby ━━━━ NVC ━━━━ 佐々木 [-0.5]
[-1.0] 汐見
```

**S+ 強の親**（ルーティン・予測可能性） → モンテッソーリ
**S− 強の親**（流動的・柔軟） → 汐見

### 4.3 I 軸（主導権）

```
I+ ←──────────────────────────────→ I−
（Tier S は全体的に I− 寄り。I+ 強の理論は Tier S には含まれない）
[-0.5] NVC
[-1.0] Bowlby ━━━━ アドラー ━━━━ 汐見 ━━━━ 佐々木 [-1.0]
[-1.5] モンテッソーリ
[-2.0] ピクラー
```

**I+ 強の親**（誘導・先取り） → Tier S からは弱い推薦（Tier C のヨコミネ式・公文式・七田式が両論併記で登場）
**I− 強の親**（委ねる） → ピクラー / モンテッソーリ

### 4.4 E 軸（評価観）

```
E+ ←──────────────────────────────→ E−
（Tier S は全体的に E− 寄り）
[-0.5] Bowlby
[-1.0] モンテッソーリ ━━━━ ピクラー ━━━━ 汐見 ━━━━ 佐々木 [-1.0]
[-1.5] NVC
[-2.0] アドラー
```

**E+ 強の親**（結果評価・賞賛） → Tier S からは Bowlby（中立寄り）、または成長マインドセット（Tier A）への入口提案
**E− 強の親**（過程評価） → アドラー / NVC

### 4.5 P 軸（早期化）

```
P+ ←──────────────────────────────→ P−
[+0.5] モンテッソーリ
[0.0]  NVC
[-0.5] Bowlby ━━━━ アドラー [-0.5]
[-1.0] 佐々木
[-1.5] ピクラー ━━━━ 汐見 [-1.5]
```

**P+ 強の親**（早期投資・先取り） → モンテッソーリ（敏感期は早期側、ただし「先取りでなく時宜にかなった環境」と区別する説明が必要）
**P− 強の親**（発達待ち） → ピクラー / 汐見 / 佐々木

### 4.6 C 軸（関係性）

```
C+ ←──────────────────────────────→ C−
[+1.5] 佐々木
[+1.0] アドラー ━━━━ 汐見 [+1.0]
[0.0]  Bowlby ━━━━ NVC [0.0]
[-0.5] ピクラー
[-1.0] モンテッソーリ
```

**C+ 強の親**（共同体・甘え肯定） → 佐々木 / アドラー / 汐見
**C− 強の親**（個別自立・境界） → モンテッソーリ / ピクラー

## 5. 軸の相関に基づく親プロファイル類型と推薦

[[docs/matcher/axes_v0]] §軸の独立性で示された **「軸間の中相関」** から、ありがちな親プロファイル類型と推薦理論を導く。

### 5.1 「察し・つながり」型（R+ / C+ / E− / I−）

- 典型: 共感的、子の気持ちに寄り添う、ルーティン化はあまりしない、結果より過程
- **主軸**: 佐々木 + Bowlby
- **副軸**: アドラー + NVC
- 注意: NVC は導入しても「形式」に走りやすいので、佐々木で温度感を担保する

### 5.2 「環境・構造」型（S+ / I− / R−）

- 典型: 整理整頓・スケジュール重視、子の自主性も尊重、過剰な察しはしない
- **主軸**: モンテッソーリ
- **副軸**: ピクラー（0-3 歳）+ Bowlby（応答性の補強）
- 注意: 「教具至上主義」「敏感期を逃すと取り戻せない」式の脅しに転びやすい

### 5.3 「自由・放牧」型（S− / I− / P−）

- 典型: 子に委ねる、ルーティン化しない、急がない
- **主軸**: 汐見
- **副軸**: ピクラー + 佐々木
- 注意: 「放任」と紙一重 ── Bowlby の応答性で歯止めをかける

### 5.4 「対等・勇気づけ」型（E− / I− / C 中立）

- 典型: 賞罰でなく対話、横の関係、結果より過程
- **主軸**: アドラー
- **副軸**: NVC + Bowlby
- 注意: 「すべて勇気の問題」式の単純化に陥らない

### 5.5 「先取り・成果」型（P+ / I+ / E+ / S+）

- 典型: 早期教育に積極的、習い事複数、結果評価
- **Tier S からの直接推薦は限定的**（モンテッソーリの敏感期解釈が唯一の接点）
- 推薦戦略: **両論併記** ── Tier C のヨコミネ式・公文式・七田式を紹介しつつ、Bowlby/Adler の「土台」記事に誘導する
- 注意: 親バッシングしない。「早期投資の長期効果は限定的というメタ分析」（Duncan & Magnuson 2013）と「質の高い早期投資は長期効果が出る」（Heckman 2013）を両方提示する

### 5.6 「ハイリスク・不安」型（R+ 強 / 親の自責が強い）

- 典型: 自分の生育歴に困難、親自身の精神的負荷が高い
- **主軸**: 佐々木 ──「育てたように子は育つ」を **励まし** として再翻訳
- **副軸**: Bowlby ── 世代間連鎖は「決定」でなく「リスク条件下では弱まる」（Verhage 2018）
- 専門家窓口の併記が必須

## 6. 推薦アルゴリズムへの接続

[[docs/matcher/recommendation_v0]] のスコアリング関数で、本マッピングをどう使うか。

### 6.1 単純な距離計算（v0）

親プロファイル（6 軸スコア）と各理論の 6 軸スコアの **ユークリッド距離** を計算し、距離の小さい順に推薦。

```
distance(parent, theory) = sqrt(
  (parent.R - theory.R)^2 +
  (parent.S - theory.S)^2 +
  (parent.I - theory.I)^2 +
  (parent.E - theory.E)^2 +
  (parent.P - theory.P)^2 +
  (parent.C - theory.C)^2
)
```

### 6.2 軸の重み付け（v0.5 で検討）

すべての軸を等重みにすると、Bowlby が R 軸で +2.0 と強いことで、R− 寄りの親に推薦されにくくなる問題がある。**Bowlby は土台理論なので、全プロファイルに最低限推薦すべき**。これを軸重み付けで反映する案:

- R 軸の重みを 0.5 倍に下げる（Bowlby が R− 親にも届きやすくなる）
- E 軸の重みを 1.5 倍に上げる（アドラー/NVC の E− 強さが活きる）

### 6.3 「土台理論」の優先推薦

Bowlby は **すべての親プロファイルに 1 位 or 2 位で推薦する** ルールを別途設ける。距離計算と独立した「土台層」を持つ設計。

### 6.4 偏り回避（× 流派の扱い）

P+/I+/E+/S+ がすべて強い親プロファイルには、Tier C のヨコミネ式・公文式・七田式が距離計算上「近い」となるが、Tier S 7 理論にこれらは含まれない。マッチャーは:
- Tier S からの推薦（Bowlby/Montessori 等）+ Tier C の両論併記、という構成にする
- 親バッシングしない、ただし「長期効果の限定性」エビデンスは明示する

## 7. 留意事項

1. **スコアは v0.1**：実データ（100 ペルソナでの軸スコア分布）が出てから再キャリブレーション必要。
2. **理論内の流派差を捨象している**：たとえばモンテッソーリ AMI と AMS で構造性は微妙に異なる。本表は中央値として扱う。
3. **文化差は別レイヤー**：Bowlby/Adler/NVC/Montessori/Pikler は西洋起源、佐々木/汐見 は日本起源。同じ R+ でも文化的含意が違う。マッチャーは結果画面で必ず文化差注釈を添える。
4. **年齢別の重み変動**：0-1 歳ではピクラー/Bowlby の重みが大きく、3-6 歳ではモンテッソーリ/アドラー/NVC が大きくなる。Phase B で年齢セグメント別に再計算予定。
5. **エビデンス強度の差**：本表はエビデンス強度を反映していない。マッチャーは推薦時に「エビデンス厚」（Bowlby/Montessori）と「実践知」（NVC/汐見/佐々木）を明示する。
