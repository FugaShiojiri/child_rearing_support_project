# Tier S 7理論 × 典型ペルソナ 推奨マトリクス

> 目的: ひだまりこそだち の典型ペルソナ 7 種に対し、Tier S 7 理論それぞれの推奨度を一覧化する。
> 推奨度: **◎ 強く推奨 / ○ 推奨 / △ 部分的に推奨 or 注意点あり / × 直接推奨しない（理由あり）**
> 用途: マッチャー結果の人手チェック基準、note 記事のターゲット設定、ペルソナインタビュー設計の参照点。

## 1. ペルソナ 7 種の定義

| **A** | 共働き・0-3歳・初産・忙しい | 復職直後の母、夫はあまり育児参加せず、保育園 0 歳児クラス利用、孤独感が強い | R+ / S+ / I 中立 / E 中立 / P+寄り（焦り） / C 中立 |

## 3. セル別の推奨理由（◎ / ○ / △ / ×）

### 3.1 ペルソナ A: 共働き・0-3歳・初産・忙しい

- **Bowlby ◎**：「保育園は愛着を壊さない」（Behrens 2016）が最重要メッセージ。3 歳児神話の解毒、複数愛着対象、修復可能性 ── すべて A の不安に直接効く。
- **佐々木 ◎**：「過保護はあってよい」が罪悪感を解毒。日本語の温度感で母性主義を再翻訳する力。
- **アドラー ○**：「ありがとう」「助かった」の声かけが共働き家庭の家事分担に効く。
- **NVC △**：技法習得に時間がかかる、忙しい A には負荷。「自己共感」の入口だけ提供する。
- **モンテッソーリ △**：教具・環境設計の時間が取れない。「日常生活の練習」（料理参加等）だけ部分採用。
- **ピクラー ○**：0-3 歳の身体発達（うつ伏せ強制・歩行器を避ける）は短時間で実装可能。世話の場面の一言の声かけは効率的。
- **汐見 ○**：「共育て」── 保育士との関係構築に効く。「孤育て」批判が孤独感に寄り添う。

### 3.2 ペルソナ B: 専業主婦・3-6歳・第二子妊娠中

- **Bowlby ◎**：「複数の愛着対象」── 上の子の愛着は薄まらない、父親・祖父母との関係を育てる時期。
- **佐々木 ◎**：「過保護はあってよい」が上の子退行への安心感に。エリクソンの自主性段階を待つ姿勢。
- **アドラー ◎**：「課題の分離」「勇気づけ」が上の子の自立を促す。下の子に手がかかる中で「お兄ちゃん／お姉ちゃん」役割を押し付けない関わり。
- **汐見 ◎**：「子どもファースト」── 兄弟比較せず一人ずつ見る視点。
- **NVC ○**：上の子の「ママ嫌い！」を「つながりのニーズ」と翻訳できる。
- **モンテッソーリ ○**：「自分でできる」を伸ばす環境設計が、第二子準備にも有効。
- **ピクラー △**：3-6 歳の上の子には適用しにくい。生まれてくる下の子向けには ◎。

### 3.3 ペルソナ C: ひとり親（シングルマザー）

- **Bowlby ◎**：「母親一人で抱え込まない、複数の大人で支える」── 保育園・祖父母・地域支援員の関わりがすべて愛着を補強する（Cooper 2009 南アフリカ RCT）。
- **佐々木 ◎**：「育てたように子は育つ」を励ましとして提供。自責ループからの解毒。
- **汐見 ○**：「共育て」── 保育士・行政との関係構築の言語化。
- **アドラー ○**：「課題の分離」が「すべて自分でやらねば」の負荷を下げる。
- **NVC △**：「自己共感」の入口は強力、ただし学習負荷を考慮。
- **モンテッソーリ △**：環境設計の時間的・経済的余裕を考えて部分採用。
- **ピクラー △**：理念は応援に値するが、シングルでの「自由運動の確保」（柵を立てた安全空間）はリソース要する。

### 3.4 ペルソナ D: 育休中の父親

- **Bowlby ◎**：**Madigan 2024 父親の感受性メタ分析**が最重要根拠 ──「父親も愛着対象として独立に効く」。父親育児の科学的正当化。
- **NVC ◎**：「妻のやり方とのズレ」を「ニーズの違い」として整理できる。夫婦間の対話技法として強力。
- **ピクラー ◎**：おむつ替え・着替え・授乳（哺乳瓶）の場面で **「抱き上げる前に一言」** が短時間で習得可能、効果が大きい。父親が乳児期から関係を作る具体ツール。
- **アドラー ○**：横の関係 ── 「子を従わせる父親像」を解体する。
- **佐々木 ○**：「過保護 OK」が父親の関わり方の指針に（「甘やかすな」式の祖父母世代の声への抵抗線）。
- **汐見 ○**：「共育て」── 夫婦間の共同設計の言語化。
- **モンテッソーリ △**：物理環境の設計は父親が得意な領域だが、教具至上主義に陥らないよう注意。

### 3.5 ペルソナ E: 祖父母同居

- **Bowlby ◎**：「複数愛着対象」── 祖父母も愛着対象として子の発達に効く（Madigan 2024）。世代間の役割分担の科学的根拠。
- **佐々木 ◎**：祖父母世代に読まれた古典でもある。**世代を超えて共通言語になる**。「過保護 OK」は祖父母世代の不安（甘やかしすぎでは？）を解毒する。
- **アドラー ◎**：「縦の関係から横の関係へ」── 祖父母 → 親 → 子の縦階層を相対化。共同体感覚（C+）は日本の家族文化と親和的。
- **汐見 ◎**：「共育て」── 祖父母も含めた共同養育の言語化。
- **NVC ○**：祖父母 vs 親の対立（しつけ・抱き癖・離乳食）を「ニーズの違い」として翻訳。ただし祖父母世代に NVC を強要しない。
- **モンテッソーリ △**：教具・環境設計は祖父母世代に説明コストが高い。「日常生活の練習」（手伝い参加）の部分だけ採用。
- **ピクラー △**：「立たせない」「歩かせない」は祖父母世代の「促す愛情」と衝突しやすい。慎重に。

### 3.6 ペルソナ F: ASD/ADHD 気質の子の親

- **Bowlby ◎**：愛着は発達特性と独立して育つ。「特性のある子だから愛着が育たない」は誤解 ── これを伝えることが最重要。
- **モンテッソーリ ◎**：**構造的環境・予測可能性・自己訂正教具** ── 発達特性のある子に最も効きやすい設計。「整えられた環境」が混乱を減らす。
- **アドラー ○**：「目的論」── 困った行動を「特性のせい」でなく「ニーズの表現」と読む視点。ただし発達特性は環境調整でなく医療的介入も必要、と区別する。
- **NVC ○**：感情語彙・ニーズリストは、感情表出に困難のある子の言語化を助ける。
- **ピクラー ○**：身体の自律的発達を尊重する姿勢が、感覚過敏のある子に合う。
- **佐々木 ○**：佐々木は **TEACCH（自閉症支援）を日本に紹介した人物**。発達特性への理解と「待つ」姿勢を統合した発信力がある。
- **汐見 △**：「放牧」が発達特性のある子には構造不足になりうる。「自由」と「構造」のバランスを慎重に。

### 3.7 ペルソナ G: ハイリスク家庭（DV経験・親自身のトラウマ）

- **Bowlby ◎**：**最重要だが慎重に扱う**。「世代間連鎖は決定でない」（Verhage 2018: リスク条件下では伝達が弱まる）「介入は早いほど効果的」（Bakermans 2003）「無秩序型 (D) は専門家相談が必須」（Carlson 1998, Granqvist 2017）── これらをセットで提示する。
- **佐々木 ◎**：「育てたように子は育つ」を **励まし** として再翻訳。自責ループに陥った親への「希望」のメッセージ。
- **汐見 ○**：「孤育て」批判 ── 個人の責任に閉じ込めない構造的視点。
- **アドラー △**：「課題の分離」「勇気づけ」は強力だが、トラウマ対応には **EMDR / トラウマフォーカスト CBT** など専門治療が優先される。アドラーだけで解決しようとしない。
- **NVC △**：「自己共感」は強力だが、トラウマ反応中は神経系の調整（ポリヴェーガル理論）が先。NVC の前にポリヴェーガル（Tier A）への接続。
- **モンテッソーリ △**：環境設計は有効、ただし「構造化が完璧でないと」式の自責を煽らない。
- **ピクラー △**：理念は応援だが、トラウマ反応のある親に「促さない」を伝えると「何もできない」自己評価に転じうる。

**G ペルソナへの全般注意**：
- 7 理論の **どれも単独では十分でない**。専門家（精神科・心療内科・カウンセラー・児童相談所）との併用が前提。
- ひだまりこそだち の note 記事は **「気づきのきっかけ」「専門家窓口の入口」** であって、治療ツールではない。
- 信田さよ子（Tier A の AC・共依存論）、ポリヴェーガル理論（Tier A の神経系調整）、Harvard CDC（ACEs・toxic stress 概念）と組み合わせる。

## 5. マトリクス利用上の注意

1. **「× 推奨しない」がないことの意味**：Tier S は **どのペルソナにも基本的に推奨可能** な理論群である。△ は「単独では使わない」「専門家併用」「部分採用」を意味する。
2. **ペルソナの単純化**：実際の親は複数ペルソナの要素を持つ（共働きのひとり親、ASD 気質の子を持つ祖父母同居家庭など）。マトリクスは入口として使い、最終的な推薦は組み合わせて判断する。
3. **「忙しい・余裕がない」軸の扱い**：すべてのペルソナで時間的・経済的余裕は異なる。マッチャーは別途「実装コスト」軸を持ち、短時間で実装可能な理論を優先する設計を検討する（v0.5 で追加予定）。
4. **第二子・第三子は別ペルソナ**：上の子の年齢、性別、関係性で大きく変わる。B ペルソナは第二子妊娠中だが、出産後・3 人目以降は別途設計が必要。
5. **多胎児・里親・養子縁組家庭**：本マトリクスは想定外。Phase B でペルソナ拡張予定。
6. **LGBTQ ファミリー**：「父親」「母親」役割の固定化を避ける設計を Phase B で追加する。
