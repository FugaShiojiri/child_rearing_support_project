## 1. Tier B の位置づけ ── 「古典の地層 + 現代の余白」

Tier S 7 理論が **ひだまりこそだち の知的バックボーン（土台）**、Tier A 11 理論が **その実装ツールキット（枝・葉）** だとすれば、Tier B 17 理論は **「**地下の地層**」と「**外周の余白**」** に相当する。地下には 20 世紀発達心理学を支えた **古典群**（ピアジェ / エリクソン / バンデューラ / スキナー / ガードナー / シュタイナー / フレーベル / Dewey / Brazelton / Elkind / Tools of the Mind の元になる Vygotsky 派生 / SDT）── これらは **「Tier S/A を読み込むための前提知識」** であり、知らないと現代の議論が立体的に見えない。外周には **2010 年代以降の現代余白**（Barrett 構成主義感情理論 / Galinsky 7 つのライフスキル / Payne Simplicity Parenting / Wojcicki TRICK / Bronfenbrenner 生態学的システムの再評価）── これらは **「Tier S/A に新しい角度を足す」**「**両論併記の素材**」「**マッチャーで親の問いに直接刺さる視点**」を担う。

Tier B の選定軸は次の三つ。

1. **Tier S / Tier A の前提となる古典、または現代的拡張** ── 単独で支持される実装思想ではなく、**「これを知らないと Tier S/A が立体的に見えない」**「**Tier S/A の限界点に現代から穴を開ける**」位置にある。
2. **0-6 歳の家庭・園・臨床・社会システムのいずれかに直接届く** ── 抽象論であっても、家庭の親に何らかの「**読み替え**」を提供する。
3. **エビデンス・実践知・思想のいずれかで一定の厚みを持つ** ── 厚みの種類は理論ごとに異なる（バンデューラはエビデンス強、シュタイナーは思想・実践知中心、Barrett は神経科学）。

Tier B 17 理論は、Tier S 7 + Tier A 11 = 18 理論の **「**周辺と地下を満たして、35 理論の立体図を完成させる役**」**。マッチャーの推薦アルゴリズムは **Tier B を第三推薦層** または **両論併記層** として扱う。

## 2. 各理論の中核思想（200-400 字要約）

### 2.1 ピアジェ 認知発達段階説 ── 「子は小さな科学者」

スイスの生物学者・心理学者 **Jean Piaget**（1896-1980）が、1923 年以降のジュネーブ大学での研究で築き上げた **20 世紀発達心理学の出発点**。中核概念は **「子は世界を観察し仮説を立て確かめる小さな科学者」**「**シェマ・同化・調節・均衡化**」「**4 段階説**（感覚運動期 0-2 / 前操作期 2-7 / 具体的操作期 7-11 / 形式的操作期 11+）」「**対象の永続性・保存の概念・自己中心性・アニミズム**」。中核命題は「**認知は教え込まれるのではなく、子が能動的に構成する**」── 構成主義の原典。0-6 歳の親には **前操作期** の理解が最重要：「**ジュースが少なくなった**」と泣くのは嘘ではなく **本気でそう見えている**。晩年に「**段階の年齢区切りは目安**」「**子の能力を過小評価していた**」（Carey / Baillargeon / Wynn ら現代発達心理）「**社会・文化・言語の役割を過小評価**」（Vygotsky）など多くの批判を受けたが、**「段階を見る枠」「答えを急がない」「先取りしない」** の3つは Tier S/A の発達観全体の通奏低音として今も生きている。

### 2.2 エリクソン 心理社会的発達 8 段階 ── 「人生は8つの課題の旅」

ドイツ出身・米国で活躍した精神分析家 **Erik Erikson**（1902-1994）が 1950 年 *Childhood and Society* で確立した **生涯発達理論**。中核は **8 段階の心理社会的危機**（基本的信頼 vs 不信 / 自律 vs 恥 / 自主性 vs 罪悪感 / 勤勉性 vs 劣等感 / アイデンティティ vs 役割混乱 / 親密性 vs 孤立 / 世代性 vs 停滞 / 統合 vs 絶望）と、それらが **後成的原理（epigenetic principle）** に従って順に問われる、という見方。「**アイデンティティ**」「**アイデンティティ・クライシス**」という現代の共通語彙を作った人。0-6 歳の親に関わるのは段階 1-3：**乳児期は信頼 / 幼児前半は自律 / 幼児後半は自主性**。動詞でいうと「**応える・許す・応援する**」。日本では **佐々木正美**（Tier S）が講演体で家庭に翻訳した形で深く浸透している。段階決定論への誤読 + ギリガンによる男性中心性批判 + 1950 年代米国の核家族前提への現代的再解釈、が要点。

### 2.3 Bronfenbrenner 生態学的システム理論 ── 「親だけのせいじゃない」

ロシア生まれ米国コーネル大学の発達心理学者 **Urie Bronfenbrenner**（1917-2005）が 1979 年 *The Ecology of Human Development* で確立した **社会システム発達観**。中核は **5 つの入れ子の環境システム** ── **マイクロ**（家庭・園・親戚）/ **メゾ**（マイクロ同士のつながり）/ **エクソ**（親の職場・自治体制度）/ **マクロ**（文化・社会通念）/ **クロノ**（時間軸の変化）。**「子の問題＝親（特に母親）の責任」という一点集中の見方を構造的に解きほぐす** のが最大の貢献。1965 年米国 **ヘッドスタート（Head Start）** プログラムの共同創設者として政策化にも携わり、「**子育ては個人ではなく社会の仕事**」を国家プログラムに翻訳した。晩年は **PPCT モデル**（Process-Person-Context-Time）に発展、子と環境の相互作用プロセスそのものを発達の駆動力に位置づける。日本の **「孤育て・ワンオペ」を構造的に解毒する** 理論として、ひだまりこそだち の社会的メッセージの根拠になる。

### 2.4 Dewey 経験主義教育 ── 「学ぶことは経験を再構成すること」

米国の哲学者 **John Dewey**（1859-1952）が、1916 年 *Democracy and Education*、1938 年 *Experience and Education* で確立した **20 世紀進歩主義教育の哲学的支柱**。中核命題は **「教育は経験の再構成である」**「**学校は生活そのもの**」「**Learning by doing**」「**民主主義は生き方（way of life）であり、教育の中で育つ**」。シカゴ大学附属実験学校（1896-1904）で **興味から立ち上がる主題（オキュペーション）・小さな民主共同体としての教室・教師は協働者** を実装した。**進歩主義教育（Progressive Education）** の理論的支柱として、**倉橋惣三**（Tier A）の誘導保育論、レッジョ・エミリア（Tier A）の **プロジェッタツィオーネ**、ハイスコープの **Plan-Do-Review**、IB-PYP・PBL（プロジェクト型学習）すべての源流。批判は「**伝統主義 vs 進歩主義**」の二項対立化のリスク + **「経験主義」の解釈の幅広さによる実装のばらつき**。家庭での借りどころは **「子の興味から始める / 経験を言葉で振り返る / 生活と学びを切り離さない」** の3点。

### 2.5 自己決定理論（SDT） ── 「3 欲求が満たされたとき内側からやる気が湧く」

米国ロチェスター大学の **Edward Deci**（1942-2022）と **Richard Ryan**（1953-）が、1970 年代の **内発的動機づけ研究** から出発し 1985 年に体系化した、**現代心理学で最も引用される動機づけ理論**。中核は **3 つの基本心理欲求** ── **自律性（autonomy）/ 有能感（competence）/ 関係性（relatedness）**。3 つが満たされる環境では、人は外から駆り立てなくても **内発的に** 動く。代表知見 **アンダーマイニング効果** ── 楽しんでいた活動に統制的な外的報酬を導入すると、報酬が止まった後に活動の頻度・質が下がる（Deci 1999 メタ分析）。動機づけは **「ある/ない」の二項でなく自律性の度合いによる連続体**（外的調整 → 取り入れ → 同一化 → 統合 → 内発）。「**ご褒美シール全否定**」ではなく「**統制的・期待される・有形・タスク完成型報酬が、もともと興味のある活動の内発動機を選択的に削る**」が正確な含意。日本でも教育・スポーツ・職場に広く浸透。**アドラー（Tier S）の「勇気づけ」、NVC（Tier S）の「ニーズの翻訳」、Growth Mindset（Tier A）の「過程賞賛」を、実証研究の言語で支える**。

### 2.6 シュタイナー（ヴァルドルフ）教育 ── 「0-7 歳は真似で育つ」

オーストリア出身の神秘思想家・哲学者 **Rudolf Steiner**（1861-1925）が、1919 年ドイツ・シュトゥットガルトの自由ヴァルドルフ学校創設で世界に広めた **代替教育の代表格**。中核は **7 年周期発達論**（0-7 歳は意志・真似 / 7-14 歳は感情・権威への信頼 / 14-21 歳は思考）と、**人智学（Anthroposophy）** に基づく独自の世界観。0-7 歳の実践原理は **「早期の知的詰め込みを避ける」「真似される存在として大人が在る」「物語・歌・繰り返しの儀式」「メディア回避」「自然素材・完成しすぎない玩具」**。独自の **オイリュトミー・ライアー・にじみ絵・フォルメン線描** を持つ。日本では「賢治の学校」「京田辺シュタイナー学校」など。**人智学の宗教的世界観・人種主義的記述問題・反ワクチン傾向との関連（ヴァルドルフ学校のはしか集団感染）** など、思想と教育実践を切り分けて受け取る必要がある。家庭での借りどころは **「生活のリズム」「メディアのゆるい運用」「自然素材」**。**Tier S モンテッソーリの「整えられた環境 + 自己構築」とは対比的に「真似される大人 + 生活のリズム」を強調**。

### 2.7 フレーベル 幼稚園（Kindergarten） ── 「世界初の幼稚園」

ドイツの教育者 **Friedrich Fröbel**（1782-1852）が 1837 年に **「Kindergarten（子どもの庭園）」** という名称と概念を世界で初めて創出した、**幼児教育の祖**。中核思想は **「子は自ら遊びを通じて学び、神性を表現する存在」**「**遊びは子どもの最高の発達表現**」、そして独自の教具 **「恩物（Gabe／Gifts）」と「作業（Beschäftigung／Occupations）」** の体系。**球・立方体・円柱**を組み合わせた木製教具（6 つの恩物の連続）は **形・数・関係性を子が手で構成する素材** として、現代モンテッソーリ教具・積み木遊び・幾何学的構成遊びの直接の祖先。**「Kindergarten」という言葉そのものが世界 100 か国以上で使われている** ことが彼の影響力の証拠。日本へは 1876 年に東京女子師範学校附属幼稚園が開設されて伝来、**倉橋惣三**（Tier A）が大正期に「フレーベル主義の硬直」を批判して **誘導保育論** へと発展させた経緯がある。批判は **(1) 神秘的・象徴的解釈の難解さ（恩物の哲学的意味の暗号化）、(2) 教具の使い方の硬直化（フレーベル主義の批判は倉橋から）**。家庭での借りどころは **「遊びを最高の学びとして尊重する」「木の積み木の系譜を辿る」**。

### 2.8 バンデューラ 社会的学習理論 / 自己効力感 ── 「子は見て真似て学ぶ」

カナダ生まれ米国スタンフォード大学の心理学者 **Albert Bandura**（1925-2021）が、1961 年 **ボボ人形実験**、1977 年 *Social Learning Theory*、1986 年 *Social Foundations of Thought and Action* で確立した **20 世紀心理学最大の引用数を持つ理論群**。中核は **(1) 観察学習** ── 人は他者を観察するだけで新しい行動を学習する（**ボボ人形実験**：大人が攻撃する映像を見た子は同じ攻撃を再現）、**(2) 代理強化** ── モデルが褒められる場面を見ると再現率が高く、罰される場面では低い、**(3) 相互決定論** ── 人（認知）/ 行動 / 環境の3要素が相互に影響、**(4) 自己効力感** ── 「自分はこの状況でこの行動ができる、という本人の信念」が実際の行動・粘り強さ・達成を強く予測。自己効力感は **4 つの源**（直接経験 / 代理経験 / 言語的説得 / 生理的状態）から育つ。幼児期の親への含意は **「言って聞かせる より、見せる方が強い」「親が大切にしたい姿を、まず親自身が体現する」「『できた』を小さく積む」**。**スキナーの行動主義に認知を再導入した転換点** であり、**成長マインドセット（Tier A）の上流**、PCIT / Triple P / Incredible Years など主要な親トレーニング・プログラムの理論基盤。

### 2.9 スキナー 行動主義（オペラント条件づけ） ── 「行動は強化と罰で形作られる」

米国ハーバード大学の心理学者 **B. F. Skinner**（1904-1990）が、1938 年 *The Behavior of Organisms* で確立した **20 世紀前半の心理学を支配した行動主義の頂点**。中核は **オペラント条件づけ** ── 行動の後に **正の強化（報酬）/ 負の強化（嫌悪刺激の除去）/ 正の罰（嫌悪刺激の付与）/ 負の罰（報酬の除去）** のいずれかが続くことで、行動の頻度が変わる、というモデル。**スキナー箱（オペラント箱）** での動物実験から、**強化スケジュール**（固定間隔 / 変動間隔 / 固定比率 / 変動比率）、**形成（shaping）**、**消去（extinction）** などの概念体系を打ち出した。教育・臨床応用は **プログラム学習（個別最適教育の祖）**、**応用行動分析（ABA）**、**トークン・エコノミー** など。ABA は自閉症療育で主流の介入法として現代でも広く使われる一方、**Ross Greene CPS（Tier A）の「報酬と罰はスキルを教えない」** との論争が今も続く。**(1) 子の内的状態（感情・思考・意味）を扱わない、(2) 動物モデルを人間に外挿する妥当性、(3) 倫理的問題（強化と罰の濫用は虐待につながりうる）** が継続的批判。ひだまりこそだち は **「シール表は補助輪としては有効、内発動機が立ち上がったら早めに外す」（SDT と整合）** の立場で部分採用。**Tier S アドラー の「賞罰否定」と Tier A CPS の「報酬と罰はスキルを教えない」が、スキナーへの対抗線**。

### 2.10 ガードナー 多重知能（MI）理論 ── 「知能は1つでなく少なくとも8つ」

米国ハーバード大学教育大学院 **Project Zero** の発達心理学者・教育学者 **Howard Gardner**（1943-）が、1983 年 *Frames of Mind: The Theory of Multiple Intelligences* で打ち出した **IQ 一元論への正面の異議**。**8 つの相対的に独立した知能** ── **言語的 / 論理数学的 / 空間的 / 身体運動的 / 音楽的 / 対人的 / 内省的 / 博物学的**（1983 年版は 7、1995-1999 年に博物学的を追加して 8 に）。9 番目候補として **実存的知能（8.5 番目）** を慎重に論じる。重要なのは、ガードナー自身が繰り返し「**MI は教育プログラムではなく視点（perspective）**」「**8 つの知能は協働して働く / 独立に伸ばせという主張ではない**」と明言していること。にもかかわらず日本の **「複合知能カリキュラム」「9つの知能教育」** などのプログラム化は本人の意図と乖離している、と批判される。家庭での借りどころは **「IQ・学校成績だけで子を測らない」「8 つのレンズで子の強みを観察する」「言語・論理数学に偏った評価軸を疑う」**。**Tier A レッジョ・エミリアの「子は 100 の言葉を持つ」と並走する、知能の多元化のレンズ**。

### 2.11 Brazelton タッチポイント ── 「発達は階段でなく螺旋」

米国の小児科医 **T. Berry Brazelton**（1918-2018）が、ハーバード大学医学部・ボストン小児病院での 50 年の臨床から築き上げた **発達小児科学の家庭翻訳版**。代表概念 **「タッチポイント（Touchpoints）」** は、**子の発達には予測可能な「踏み越え」の前後で一時的に退行・不安定化する時期がある** という見方 ── **新しいスキルを獲得する前に、それまでできていたことが一旦崩れる**（例：歩き始める前に夜泣きが復活、言葉が増える前に癇癪が増える）。**新生児行動評価尺度（NBAS）** で世界の新生児ケアを変えた人で、**生後すぐの赤ちゃんも「個性を持つ社会的存在」** として観察する視線を医療現場に広めた。**親への含意**: **(1) 退行は失敗ではなく次の段階の予兆、(2) 子は親に診断されるのでなく親と一緒に発達を観察するパートナー、(3) 小児科医・保育者・親の3者連携（タッチポイント・モデルの家族支援プログラムが米国で普及）**。**Tier S Bowlby と佐々木の応答性思想を、小児科臨床のエビデンスで補強する立場**。

### 2.12 Elkind 急かされる子（The Hurried Child） ── 「早期化批判の米国版」

米国タフツ大学の発達心理学者 **David Elkind**（1931-）が、1981 年 *The Hurried Child: Growing Up Too Fast Too Soon* で世界的に注目された **早期化・先取り教育への批判の古典**。中核命題は **「現代社会は子に大人の役割と責任を早く負わせすぎている」**「**子は『小さな大人』ではない**」「**ストレス・成功圧力・スケジュール過多が、子の精神的健康を蝕む**」。代表概念 **「想像上の観客（imaginary audience）」** と **「個人的寓話（personal fable）」** は思春期発達の自己中心性を捉えた古典概念。続編 *Miseducation: Preschoolers at Risk*（1987）で **「就学前児への早期教育の害」** を、*The Power of Play*（2007）で **「遊びの消失」** を警告。**汐見稔幸（Tier S）の早期化批判 + Payne Simplicity Parenting + Wojcicki TRICK と並走する「子のペースを守る系統」の米国側源流**。ひだまりこそだち の **「習い事至上主義・先取り教育に懐疑的」** スタンスの実証的・歴史的厚みを支える。批判は **(1) 1981 年の米国中流家庭が想定で、現代の多様な家族構造に翻訳が要る、(2) 「子は小さな大人ではない」の主張は現代発達心理（Carey ら）の「乳幼児の能力過小評価批判」とは別の論点**。

### 2.13 Galinsky 7 つのライフスキル ── 「実行機能の家庭翻訳版」

米国 **Families and Work Institute** の **Ellen Galinsky** が、2010 年 *Mind in the Making: The Seven Essential Life Skills Every Child Needs* で打ち出した **発達神経科学・実行機能研究の家庭翻訳版**。**7 つのスキル** ── **(1) Focus & Self-Control（集中と自己制御）/ (2) Perspective Taking（視点取得）/ (3) Communicating（コミュニケーション）/ (4) Making Connections（関連づけ）/ (5) Critical Thinking（批判的思考）/ (6) Taking on Challenges（挑戦する力）/ (7) Self-Directed, Engaged Learning（自己主導の学び）**。これらは **Adele Diamond 系列の実行機能（EF）研究**、**バンデューラの自己効力感**、**Dweck の成長マインドセット**、**Vygotsky の ZPD と Tools of the Mind**、**Theory of Mind 研究** を統合して家庭の親が **観察し育てるレンズ** として提示。Galinsky は **Harvard CDC（Center on the Developing Child）/ HighScope / Tools of the Mind / Mind in the Making（彼女自身の介入プログラム）** をつなぐ **ハブ人物**。**「学力でなくライフスキル」** という公的政策メッセージの米国側現代化担当。家庭での借りどころは **「7 つのスキルを観察するレンズ」「IQ 一元評価への対抗」「親自身もこれらのスキルを育て続ける生涯発達の発想」**。

### 2.14 Payne Simplicity Parenting ── 「親の最良の道具は『減らす』こと」

米国の教育者・家族カウンセラー **Kim John Payne** が、ヴァルドルフ教育の臨床経験と現代家族の観察から、2009 年 *Simplicity Parenting: Using the Extraordinary Power of Less to Raise Calmer, Happier, and More Secure Kids* で打ち出した **家庭環境の「減らす」設計論**。中核命題は **「現代の子どもは情報・玩具・スケジュール・大人の心配の過剰摂取で、軽い PTSD のような状態にある」**。実装は **4 つの簡素化** ── **(1) 環境（玩具・服・本を 3 分の 1 以下へ）/ (2) リズム（予測可能な日課・週課・季節リズム）/ (3) スケジュール（習い事・予定の絞り込み）/ (4) 情報のろ過（ニュース・大人の会話・親の心配からの保護）**。**シュタイナー教育（メディア回避・自然素材）+ Elkind の早期化批判 + 汐見の「放牧」** の家庭環境設計版。**ひだまりこそだち の「断捨離 / 暮らしを軽くする / 親の余白」と最も近い理論**。批判は **(1) 中流家庭の物的余裕が前提（貧困家庭への適用には別の議論が要る）、(2) 「軽い PTSD」の比喩は臨床用語との混同の危険、(3) 「テレビ全廃」など完全主義に流れるとシュタイナー教育と同様の親の消耗**。家庭での借りどころは **「玩具の数を意識する」「予定の余白を死守する」「親自身の心配の口数を減らす」**。

### 2.15 Barrett 構成主義感情理論 ── 「感情は反応でなく構成される予測」

米国ノースイースタン大学の心理学・神経科学者 **Lisa Feldman Barrett**（1963-）が、2017 年 *How Emotions Are Made: The Secret Life of the Brain* で打ち出した **現代の感情研究の最先端**。中核命題は **「感情は脳が世界に対する『反応』として生まれるのでなく、過去の経験と身体感覚から脳が能動的に『予測・構成』するもの」**（**Theory of Constructed Emotion**）。古典的な「**基本感情説**（Ekman の 6 つの基本感情）」を **「文化・言語・経験で構成される感情カテゴリー**」に置き換え、**「感情語彙が豊かなほど感情調整が上手い（emotional granularity）」**「**身体感覚（interoception）が感情の素材**」「**感情は脳の予測誤差最小化プロセスの一部**」を主張。家庭への含意は **「子に感情語彙を貸すことが、感情調整能力を育てる神経科学的根拠」**「**「ちゃんと感じなさい」でなく「これは寂しいかも、悔しいかも」と一緒に名づける**」。**Gottman 感情コーチング（Tier A）と Siegel ホールブレイン（Tier A）の神経科学的前提を 2010 年代の最先端で更新する立場**。批判は **(1) Ekman 学派からの「基本感情の生物学的根拠は否定できない」反論、(2) 構成主義の極論化リスク（感情は完全に構成物ではない）、(3) 神経科学の比喩を家庭の親が誤読する危険（Siegel の「右脳/左脳」と同じ罠）**。

### 2.16 Wojcicki TRICK ── 「Trust / Respect / Independence / Collaboration / Kindness」

米国カリフォルニア州 Palo Alto High School のジャーナリズム教師 **Esther Wojcicki** が、2019 年 *How to Raise Successful People* で打ち出した **子育ての 5 原則**。**TRICK** ── **Trust（信頼）/ Respect（尊重）/ Independence（独立）/ Collaboration（協働）/ Kindness（思いやり）**。自身の 3 人の娘（YouTube CEO Susan / 23andMe CEO Anne / UCSF 教授 Janet）の育て方を一般化した実践書で、世界 30 か国以上で翻訳された。**Baumrind の authoritative（高応答 + 高要求）の現代解説版** + **シリコンバレーの自律性重視文化** + **米国上層中流家庭の養育観**。家庭での借りどころは **「信頼を最初に渡す」「子と対等に話す」「子に責任を渡して引き上げる」**。批判は **(1) シリコンバレー上層中流の文脈バイアス、(2) 「成功（successful）」の定義が経済的・キャリア的に偏る、(3) Trust の名のもとに監視と評価が緩んで放任に滑るリスク（Baumrind の permissive への陥り）**。**Tier A Baumrind の「2 軸マップ」の補完として、家庭の親に届きやすい言語化**。

### 2.17 Tools of the Mind ── 「ごっこ遊びで実行機能を育てる」

米国コロラド州 **Elena Bodrova**（ヴィゴツキー学派のロシア出身研究者）と **Deborah Leong** が 1993 年に立ち上げた **就学前の実行機能介入カリキュラム**。土台は **ヴィゴツキー（Tier A）** の **「心の道具（mental tools）」** 概念 ── 人は道具を使って自然を変えるように、心の道具を使って自分の心を扱う。中核ツールは **(1) 計画的なごっこ遊び**（「あなたは医者、私は患者」と役とルールを決めて遊ぶことで、今の気持ちより決めた役のルールに従う練習を積む）、**(2) プライベートスピーチ（独り言）の尊重**（「次は手を洗うんだ」とつぶやくのは自己制御を育てる行為）、**(3) プレイ・プラン**（遊びの計画を絵で描いて貼る）、**(4) バディ・リーディング**（2人組で読み合う）。**Diamond et al. 2007 の Science 誌 RCT** で就学前児の実行機能・読解・語彙の改善が報告され、**実行機能介入研究の代表例** に。批判は **(1) 後続の Wilbur 2014 や Farran 2018 の追試で効果が再現されない事例、(2) 家庭での完全再現は不可能（保育者向け研修・教材中心）、(3) 「実行機能を伸ばす」を親が前のめりになると遊びがタスクになる**。家庭での借りどころは **「ごっこ遊びで子のシナリオに乗る」「独り言を遮らない」「順番カード / タイマーなど目に見える道具で衝動を抑える支え」**。

```
Brazelton │ Bronfenbrenner │ エリクソン │ シュタイナー │ Payne │ フレーベル │ ピアジェ │ ガードナー │ Galinsky │ Tools of the Mind │ バンデューラ │ Barrett │ SDT │ Dewey │ Elkind │ Wojcicki │ スキナー
```

- **乳児期から**: Brazelton（新生児から）/ Bronfenbrenner / エリクソン / Barrett
- **0-6 歳全域**: シュタイナー / Payne / フレーベル / ピアジェ / ガードナー
- **3-6 歳〜**: Galinsky / Tools of the Mind / バンデューラ / SDT
- **学齢期以降が本領**: Dewey / Elkind / Wojcicki / スキナー（ABA は乳幼児にも適用）

## 5. Tier B 17 理論の補完関係

### 5.1 古典発達理論の3本柱: ピアジェ + エリクソン + バンデューラ

- **ピアジェ**: 認知の発達段階を見る枠（個人主義）
- **エリクソン**: 心理社会的課題を見る枠（社会との接点）
- **バンデューラ**: 観察学習と自己効力感を見る枠（モデリングと自己信念）

3 つを並べることで「**0-6 歳の子の発達を 3 方向から立体的に見る**」レンズが立ち上がる。

### 5.2 学習理論の系譜: スキナー → バンデューラ → SDT

- **スキナー（1938）**: 行動主義の頂点 ── 強化と罰
- **バンデューラ（1961-1977）**: 観察学習 + 認知の再導入 ── 「強化なしで学べる」
- **SDT（1985）**: 内発動機 + 3 欲求 ── 「外発でなく内発、ご褒美の罠」

3 つを通じて、ひだまりこそだち の **「賞罰でなく勇気づけ / 過程の言語化 / 内発動機を守る」** が **20 世紀心理学の歴史的展開** の上に立っていることが見える。

### 5.3 社会システムの3層: Bronfenbrenner + Dewey + Elkind

- **Bronfenbrenner**: 5 層の生態学的システムで「親だけのせいじゃない」
- **Dewey**: 民主主義は生き方、教育は社会と切り離せない
- **Elkind**: 現代社会の早期化・成功圧力への警告

3 つを並べると、ひだまりこそだち の **「孤育てを構造的に解毒する」「教育を社会の文脈で見る」「早期化に抗う」** の社会的メッセージの根拠になる。

### 5.4 家庭環境設計の3つ: シュタイナー + Payne + Wojcicki

- **シュタイナー**: 生活のリズム + 自然素材 + メディア回避
- **Payne**: 玩具・予定・情報を減らす（「軽い PTSD」を解毒）
- **Wojcicki**: TRICK（信頼 / 尊重 / 独立 / 協働 / 思いやり）

3 つを並べると、ひだまりこそだち の **「暮らしを軽くする / 親の余白 / 信頼を最初に渡す」** が家庭環境設計として実装可能になる。

### 5.5 認知科学の最先端: Tools of the Mind + Galinsky + Barrett

- **Tools of the Mind**: ヴィゴツキーの「心の道具」を実行機能介入に
- **Galinsky**: 実行機能 + 自己効力感 + マインドセットを家庭の親へ
- **Barrett**: 感情は構成される予測 ── 感情語彙が感情調整を育てる

3 つを並べると、ひだまりこそだち の **「実行機能 / ライフスキル / 感情語彙」** が 2010 年代以降の認知科学・神経科学の最先端で支えられていることが見える。

### 5.6 早期化批判の3声: Elkind + Payne + 汐見（Tier S）

- **Elkind（1981）**: *The Hurried Child* ── 米国側の古典
- **Payne（2009）**: *Simplicity Parenting* ── 家庭環境設計版
- **汐見（Tier S）**: 「保育の本質は放牧」 ── 日本側現代

3 つを並べると、ひだまりこそだち の **「習い事至上主義に懐疑」** が **米国 40 年 + 日本現代** の系譜上にあることが示される。

### 5.7 推奨される組み合わせパターン（Tier S/A と Tier B）

## 6. Tier B の運用ルール（ひだまりこそだち 編集ガイド）

1. **Tier B 単独で記事を立てない、原則 Tier S/A と組み合わせる**。Tier B は「Tier S/A の前提知識・現代的拡張・両論併記の素材」として位置づけられている。
2. **古典発達理論（ピアジェ / エリクソン / バンデューラ）は「発達を見る枠の提供」として note シリーズに組み込む**。Tier S/A の議論の前提知識として、月齢比較の不安を解毒する記事の根拠に。
3. **スキナー / 行動主義は「両論併記」の形で扱う**。シール表・ABA は「補助輪としては有効、内発動機が立ち上がったら早めに外す」の SDT 統合版で。完全否定でも完全肯定でもない。
4. **シュタイナー・フレーベルは「保育観の整理」シリーズで使う**。家庭での全面再現を推奨しない。**シュタイナーの人智学・反ワクチン傾向は明示的に距離を取る**。
5. **Bronfenbrenner は「孤育て・ワンオペ」記事の理論的根拠**として最重要。社会的メッセージの土台。
6. **Elkind + Payne + Wojcicki は「暮らしを軽くする」「早期教育志向の解毒」シリーズの三本柱**。汐見と統合する。
7. **Barrett は「感情語彙を貸す」「感情調整」記事で Gottman / Siegel の補強として使う**。神経科学比喩の誤読に注意（Siegel と同様の罠）。
8. **Tools of the Mind / Galinsky は「実行機能 / ライフスキル」記事で使う**。発達特性のある子の親に届くテーマ。
9. **エビデンス強度の差異を明示**（バンデューラ / SDT / ピアジェ / Brazelton ＞ ガードナー / Elkind / Payne / Wojcicki / シュタイナー）。
10. **古典の年代と現代との文脈差を明示**（ピアジェ 1923 / エリクソン 1950 米国核家族前提 / シュタイナー 1919 など）。
11. **ハイリスク家庭への Tier B 適用は慎重に**。Tier S/A と同じく専門家窓口の併記が必須。

## 7. Tier S + Tier A + Tier B = 35 理論の通底メッセージ

35 理論すべてに通底する **共通メッセージ**:

1. **子は教えられて育つのではなく、応えられて育つ**
2. **完璧でなくていい、修復できればよい**
3. **「困った行動」は絆 or 発達 or ニーズ or スキルのサインと読み替える**
4. **賞罰・命令でなく対等な関係で関わる**
5. **母親一人で抱え込まない、複数の大人・地域・社会で支える**
6. **早期化・先取りより、今この子の発達段階に応える**
7. **親自身を勇気づける、「いい親」を降りる**
8. **暮らしを軽くする、減らすことが最大の道具**（Tier B から追加）
9. **学びは生活と切り離せない、経験の再構成として起きる**（Tier B から追加）

これらは Tier S 7 + Tier A 11 + Tier B 17 = 35 理論すべてに通底する **ひだまりこそだち の声の中核** を構成する。

## 8. マッチャーの三層推薦設計

[[docs/matcher/recommendation_v0]] のスコアリング関数で、3 つの Tier をどう使うか。

```
親プロファイル（6 軸スコア）
  ↓
[第一層] Tier S 推薦 ── 2-3 理論（土台）
  ↓
[第二層] Tier A 補完推薦 ── 1-2 理論（実装ツール、Tier S と整合）
  ↓
[第三層] Tier B 補強推薦 ── 1-2 理論（古典知識 / 現代余白 / 両論併記の素材）
  ↓
[整合チェック] 思想的に矛盾しないか
  ↓
[出力] 主軸 + 副軸 + 補強 + ペルソナ別の追加メッセージ
```

例: 親プロファイル {R+1.5, S+0.5, I-0.5, E-1.0, P-0.5, C+0.5}

- **第一層 Tier S**: Bowlby (R+2.0) + 佐々木 (R+2.0) + NVC (R+1.5, E-1.5)
- **第二層 Tier A**: Gottman + Siegel + ギノット（感情の三段ロケット）
- **第三層 Tier B**: Brazelton（小児科臨床で補強）+ Barrett（感情語彙）+ Bronfenbrenner（社会的支援）
