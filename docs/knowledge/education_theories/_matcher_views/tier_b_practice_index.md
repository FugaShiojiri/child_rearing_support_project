# Tier B 17理論 実践シーン横断インデックス

> 目的: 0-6 歳の典型的な家庭シーン 18 場面で、Tier B 17 理論がそれぞれ何を示唆するかを並列に並べる。
> 用途: note 記事執筆時の「17 のレンズで同じ場面を見る」フレーム、マッチャー結果で複数 Tier B 理論を提示する際の対比、Tier S / Tier A 実践シーン（→ [[tier_s_practice_index]] / [[tier_a_practice_index]]）の **第三層の補強** として並列に読む。
> 注意: Tier S / Tier A 18 場面と整合的な 18 場面構成（同番号 = 同シーン）。Tier B は「**古典の地層 + 現代の余白**」── Tier S/A が示す方向性に対し、**(1) 古典的根拠（ピアジェ・エリクソン・バンデューラ・スキナー・フレーベル）、(2) 現代的拡張（Barrett・Galinsky・Tools of the Mind・Wojcicki）、(3) 社会的視点（Bronfenbrenner・Dewey）、(4) 早期化批判（Elkind・Payne・シュタイナー）、(5) 動機づけ実証（SDT）、(6) 知能の多元化（ガードナー）、(7) 小児科臨床（Brazelton）** を加える。

## 2. 場面別 × 17 理論 横断比較

---

### シーン 1: 夜泣き・寝ぐずり（0-2 歳）

- **ピアジェ**: 感覚運動期 ── 言語以前なので認知発達のレンズは限定。「**対象の永続性**の獲得途上で『親がいない』ことが分からない」という読み。
- **エリクソン**: **基本的信頼 vs 不信** の代表シーン ──「夜泣きへの応答は信頼の土台」。佐々木と統合。
- **Bronfenbrenner**: 夜泣きを「親の頑張り不足」でなく「**社会的支援ネットワークの希薄化**」（ワンオペ・核家族化）として読む。「**夜中に交代できる人がいるか**」を構造的に問う。
- **Dewey**: 直接的処方は薄い。
- **SDT**: 「関係性のニーズ」── 子の関係性欲求への応答が中核。
- **シュタイナー**: 「**生活のリズム**」── 就寝前の儀式（同じ歌・同じ物語）の繰り返しで予測可能性を渡す。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: 直接的処方は薄い。**親自身が夜泣きへの対処を模範**として示している（子は親を観察している）。
- **スキナー**: 「**消去（extinction）」= Cry It Out** の根拠とされてきたが、現代の小児科・愛着研究では否定的（応答性が安定型を育てる）。**両論併記で慎重に**。
- **ガードナー**: 直接的処方は薄い。
- **Brazelton**: **タッチポイントの代表シーン** ── **新しいスキル獲得（歩く・話す）の前に夜泣きが復活** することがある、退行は失敗でなく予兆。
- **Elkind**: 「**スケジュール過多が子の睡眠を蝕む**」── 日中の予定が詰まりすぎていないか観察。
- **Galinsky**: 7 つのライフスキルのうち **「Focus & Self-Control」の発達途上** の表現として読む。
- **Payne Simplicity**: 「**減らす**」── 寝る前の刺激（テレビ・玩具）を減らす。
- **Barrett**: 「**身体感覚（interoception）の不安定**」── 夜泣きは感情でなく身体感覚（空腹・暑さ・寒さ・かゆみ）が起点であることが多い。
- **Wojcicki**: 直接的処方は薄い。
- **Tools of the Mind**: 直接的処方は薄い、0-2 歳には早すぎる。

**Tier B 共通メッセージ**: 0-2 歳の夜泣きは **対話・しつけのレイヤーではなく、応答・神経系・愛着・身体感覚のレイヤー**。Tier B は **Brazelton（タッチポイント）+ Bronfenbrenner（社会的支援）+ Payne（減らす）+ シュタイナー（リズム）+ エリクソン（信頼）** で Tier S の Bowlby / 佐々木 / ピクラー を厚く支える。

### シーン 2: 後追い・分離不安（0.5-2 歳）

- **ピアジェ**: **対象の永続性** の獲得途上 ──「親が見えないと存在しなくなる」感覚から、「**親は見えなくてもまた戻ってくる**」感覚への移行が後追いを起こす。
- **エリクソン**: **基本的信頼 vs 不信** の延長 ──「親が応えると分かっている」関係の証拠。
- **Bronfenbrenner**: メゾシステム（保育者 / 祖父母 / 近所）への移行期 ── 「複数の応答者」への移行は時間がかかる。
- **Dewey**: 直接的処方は薄い。
- **SDT**: 「関係性欲求」── 後追いは関係性が満たされている証拠。
- **シュタイナー**: 「生活のリズムが安定していると分離不安は軽くなる」。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: 親の **「安心して立ち去る」モデル** を見せる（不安な顔で立ち去ると子も不安になる）。
- **スキナー**: 「**負の罰**としての無視」は推奨しない、応答的な関わりを優先。
- **ガードナー**: 直接的処方は薄い。
- **Brazelton**: タッチポイントで、後追い・分離不安は **次の自立への踏み越え** の予兆として予期。
- **Elkind**: 「**早期保育の影響**」── ただし「保育園は愛着を壊さない」（Bowlby・佐々木）と整合させて慎重に。
- **Galinsky**: 「Perspective Taking」の前段階 ── 親の視点を持てるようになる過程の表現。
- **Payne**: 「**減らす**」── 別れの場面を簡素化（長い別れ・隠れて去るは推奨しない、Ainsworth と整合）。
- **Barrett**: 「**不安の身体感覚**」を一緒に名づける ──「胸がドキドキするね」。
- **Wojcicki**: TRICK の「Trust」── 子が「ママは戻ってくる」と信じられるよう、約束を守る。
- **Tools of the Mind**: 直接的処方は薄い。

**Tier B 共通メッセージ**: 後追いは **対象の永続性（ピアジェ）+ 基本的信頼（エリクソン）+ 関係性欲求（SDT）+ タッチポイント（Brazelton）** の重層的サイン。Tier S Bowlby + Ainsworth + 佐々木 と整合的に、**「育っている証拠」** として読む。

### シーン 3: 卒乳・哺乳瓶拒否（0.5-1.5 歳）

- **ピアジェ**: 感覚運動期の **シェマの調節** ── 「母乳のシェマ」から「コップ / スプーンのシェマ」への調節期。違和感（不均衡）を経て新しいシェマへ。
- **エリクソン**: 「**応える・許す・応援する**」のうち「**応える**」── 子のペースを待つ。
- **Bronfenbrenner**: 「**社会的圧力（祖父母・職場・WHO 指針）**」── 卒乳のタイミングを **マクロシステム** の文脈で読む。
- **Dewey**: 直接的処方は薄い。
- **SDT**: 「**自律性のニーズ**」── 子が自分で卒乳のタイミングを選べる感覚。
- **シュタイナー**: 「子のペースを尊重」── 早すぎる卒乳に否定的。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: 直接的処方は薄い。
- **スキナー**: 哺乳瓶の **置き換えとしての強化**（コップで飲んだら笑顔と声かけ）── ただし全否定でなく補助輪。
- **ガードナー**: 直接的処方は薄い。
- **Brazelton**: **「卒乳はタッチポイント」** ── 退行（一時的に母乳に戻りたがる）は予期される。
- **Elkind**: 「**社会的圧力で急かさない**」── 「○ か月までに卒乳」式の指針に縛られない。
- **Galinsky**: 直接的処方は薄い。
- **Payne**: 「**減らす**」── 卒乳ストレスを減らすために、他の予定を減らす。
- **Barrett**: 「飲みたい身体感覚」を一緒に名づける ──「**おっぱい欲しいんだね、安心したいね**」。
- **Wojcicki**: TRICK の「Trust」── 子のペースを信頼する。
- **Tools of the Mind**: 直接的処方は薄い。

### シーン 4: おむつ替えを嫌がる（0.5-2 歳）

- **ピアジェ**: 感覚運動期 ──「**自分の意思を持つ存在**」になってきた表現。
- **エリクソン**: **自律 vs 恥** の最初の表現 ──「自分でやる」「自分のタイミングで」の芽。
- **Bronfenbrenner**: 直接的処方は薄い。
- **Dewey**: 直接的処方は薄い。
- **SDT**: **自律性欲求** が中核 ──「**ここで替える？お部屋で替える？**」の選択肢。
- **シュタイナー**: 「生活のリズム」── 同じ時間・同じ場所で替えるリズム化。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: 親が **「替える際に楽しそうにしている」モデル** を示す。
- **スキナー**: 「**正の強化**」── 替えた後の「**さっぱりしたね**」「**気持ちいいね**」の応答が次回の協力を促す（補助輪）。
- **ガードナー**: 「**身体運動的知能**」── 替えるとき子に身体感覚を言語化（「足、伸ばして」）。
- **Brazelton**: タッチポイントで、おむつ替え拒否は **自律の踏み越え** の予兆。
- **Elkind**: 直接的処方は薄い。
- **Galinsky**: 「**Self-Control**」の発達段階の表現。
- **Payne**: 「**減らす**」── おむつ替えを儀式化せず流れ作業にしすぎない。
- **Barrett**: 「**かぶれの身体感覚 = 嫌な感じ**」を一緒に名づける。
- **Wojcicki**: TRICK の「Respect」── 子のタイミングを尊重する範囲で。
- **Tools of the Mind**: 「**手順カード**」（おむつ替えの絵カード）で予測可能性を渡す。

---

### シーン 5: 立たせる・歩かせる促し（0.5-1.5 歳）

- **ピアジェ**: 感覚運動期の **シェマの構成** ── 立つ・歩くは子が能動的に構成するスキル。先取りは効かない。
- **エリクソン**: **自律 vs 恥** の身体的表現 ── 「自分で」の最初の挑戦。
- **Bronfenbrenner**: 「**月齢比較の社会的圧力**」── マクロシステムから来る焦りを構造的に解毒。
- **Dewey**: 直接的処方は薄い。
- **SDT**: 「**有能感のニーズ**」── 「**できた感**」が次の挑戦を促す。
- **シュタイナー**: 「**子のペース**」── 早期の歩行訓練に否定的。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: 「親の **焦りの表情** が子に伝わる」── 親のメタモデリングへの注意。
- **スキナー**: 「**正の強化**」での歩行訓練は推奨しない（ピクラーの「促さない」と対立）。
- **ガードナー**: 「**身体運動的知能**」── 個別差を肯定するレンズ。
- **Brazelton**: **タッチポイントの代表シーン** ──「歩く前に夜泣きが再発」「歩く前に1週間動かない時期」など、退行が予期される。
- **Elkind**: **早期化批判の代表シーン** ──「**○ か月までに歩く**」の煽りを退ける。
- **Galinsky**: 直接的処方は薄い。
- **Payne**: 「**減らす**」── 「歩行器・専用おもちゃ」など強化アイテムを減らす。
- **Barrett**: 直接的処方は薄い。
- **Wojcicki**: TRICK の「Trust」── 子の発達を信頼して待つ。
- **Tools of the Mind**: 直接的処方は薄い。

**Tier B 共通メッセージ**: **Tier S ピクラーの「促さない」を、Tier B は Elkind（早期化批判）+ Brazelton（タッチポイント）+ ガードナー（身体運動的知能の個別差）+ Bronfenbrenner（月齢比較の社会的圧力）+ シュタイナー（子のペース）** で重層的に支える。

### シーン 6: イヤイヤ期の癇癪（1.5-3 歳）

- **ピアジェ**: **前操作期の自己中心性** ── 他者視点が取れない段階で「自分の意思」が強く出る。
- **エリクソン**: **自律 vs 恥** の代表シーン ── イヤイヤ期は **「自律性の芽の正常な発達」**。
- **Bronfenbrenner**: 「**家族・保育園・社会全体で対応**」── 親一人で抱え込まない。
- **Dewey**: 直接的処方は薄い。
- **SDT**: **自律性 + 関係性のニーズが両立しない** 場面 ──「自分で決めたい」と「親に応えてほしい」の葛藤。
- **シュタイナー**: 「**生活のリズム**」── 予測可能性が癇癪を減らす。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: 親自身の **怒りモデル** に注意 ── 子は癇癪への親の反応を観察。
- **スキナー**: 「**癇癪に反応すると強化される**」という古典的解釈は **CPS（Tier A）と対立** ──「**注目を引くため**」ではなく「**スキルの問題**」。両論併記。
- **ガードナー**: 「**内省的知能**」の発達途上 ── 自分の感情を理解できない段階。
- **Brazelton**: タッチポイントで、イヤイヤ期は **言葉の発達前の自律の表現** として予期。
- **Elkind**: 「**スケジュール過多 + 早期化**」が癇癪を増やす可能性。
- **Galinsky**: 7 つのライフスキルのうち **「Self-Control」の発達段階**。
- **Payne**: 「**減らす**」── 刺激・予定・選択肢の過剰が癇癪を増やす。
- **Barrett**: **感情語彙の代表シーン** ──「**腹が立ったんだね**」「**悲しいんだね**」と一緒に名づけることが感情調整能力を育てる神経科学的根拠。
- **Wojcicki**: TRICK の「Respect」── 癇癪を尊重しながら限界を設ける。
- **Tools of the Mind**: 「**プライベートスピーチ**」── 子の独り言「**もう、ぷんぷん**」を遮らない、自己制御の発達途上。

**Tier B 共通メッセージ**: **イヤイヤ期は「自律の芽 + 前操作期の自己中心性 + 感情語彙の発達途上 + 自己制御スキルの発達段階」の重層的サイン**。Tier S アドラー・NVC + Tier A Gottman・Siegel・ギノット に、**Tier B は Barrett（感情語彙の神経科学）+ エリクソン（自律 vs 恥）+ Payne（減らす）+ Galinsky（Self-Control）** で重層的に支える。

### シーン 7: ご飯を食べない・偏食（1.5-5 歳）

- **ピアジェ**: 前操作期の **アニミズム / 自己中心性** ──「ブロッコリーは怒ってる」など。
- **エリクソン**: **自律 vs 恥** の食事版 ──「自分で選ぶ」の表現。
- **Bronfenbrenner**: 「**親の食事観 = マクロシステムの社会通念**」── 「**残さず食べる**」が正解と決まっていない時代。
- **Dewey**: 「経験を通して学ぶ」── 食材体験を通して食の好みが形成される。
- **SDT**: **自律性のニーズ** ── 「**食べる/食べないは子の課題**」（アドラー由来）と整合。「**統制的な強要（食べないと○○）**」が内発動機を削る。
- **シュタイナー**: 「**生活のリズム**」── 同じ時間に食卓に着く、無理に食べさせない。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: 親が **「楽しそうに食べているモデル**」を見せる ── 強要より模範。
- **スキナー**: 「**食べたら強化**（褒める・シール）」── 補助輪として可、ただし長期的には内発動機を削る（SDT）。
- **ガードナー**: 「**身体運動的・博物学的知能**」── 食材を観察する遊び。
- **Brazelton**: 「**子の食欲は日々変動する**」── 短期の偏食を病的でなく発達の一部と読む。
- **Elkind**: 「**完璧な栄養への親の不安**」を社会的圧力として解毒。
- **Galinsky**: 「Taking on Challenges」── 新しい食材への挑戦。
- **Payne**: **「減らす」の代表シーン** ── 食卓に出すものを減らす、選択肢を絞る、デザート過剰を避ける。
- **Barrett**: 「**お腹いっぱい / 食べたい身体感覚**」を一緒に名づける ── 子の interoception 発達。
- **Wojcicki**: TRICK の「Trust」── 子の食欲を信頼する。
- **Tools of the Mind**: 「**食事の手順カード**」（食べる順番を絵で示す）。

**Tier B 共通メッセージ**: **Tier A CPS の Plan B + Tier B の SDT（自律性）+ Payne（減らす）+ Brazelton（食欲は変動する）** が重層的に効く。**「食べる/食べないは子の課題」（アドラー）に Tier B が実証研究と臨床知で厚みを加える**。

### シーン 8: お片付けしない（2-5 歳）

- **ピアジェ**: 前操作期 ──「**片付けの順序**」が抽象的すぎて操作できない。具体物（**ブロックの箱、絵本の棚**）を見せる。

- **エリクソン**: **自主性 vs 罪悪感** ──「もっと見たい」を尊重しつつ限界。
- **Bronfenbrenner**: **マクロシステム（メディア環境の社会的影響）+ エクソシステム（親の働き方とスクリーン時間の関係）**。
- **Dewey**: 「**経験を通した学び**」── 直接経験 vs メディア経験の質の違い。
- **SDT**: **自律性のニーズ** ──「**いつ止めるかを子と決める**」が中核。
- **シュタイナー**: **「メディア回避」の代表シーン** ── 0-7 歳はメディア回避が原則（ただし完全主義に陥らないゆるい運用を推奨）。
- **フレーベル**: 「**遊びは子の最高の発達表現**」── スクリーン以外の遊びを保障。
- **バンデューラ**: **「メディアからの代理強化・モデリング」が最も問題視されるシーン** ── 暴力的・性的・消費主義的なコンテンツの影響。
- **スキナー**: 「**スクリーン時間の強化スケジュール**」── ABA的に時間制限を設けるか、SDTの自律支援的に「**一緒に決める**」か。両論併記。
- **ガードナー**: 「**スクリーンが特定の知能を伸ばす**」と過剰主張しない。
- **Brazelton**: タッチポイントで、スクリーン依存は発達の踏み越え時期に増えやすい。
- **Elkind**: **「スクリーンが子のペースを乱す」** ── 早期化批判の現代版。
- **Galinsky**: 7 つのライフスキルのうち **「Focus & Self-Control」「Critical Thinking」** が育つ vs 削られる場面。
- **Payne**: **「減らす」の代表シーン** ── スクリーン時間を **絶対量で減らす**（時間制限）+ **質を選ぶ**（コンテンツ選別）。
- **Barrett**: 「**スクリーンが終わった後の身体感覚**」を一緒に名づける ──「**目がしょぼしょぼするね**」。
- **Wojcicki**: TRICK の「Trust + Collaboration」── 子と一緒にスクリーンルールを決める。
- **Tools of the Mind**: 「**タイマー・絵カード**」── スクリーン時間の視覚化。

**Tier B 共通メッセージ**: **Tier A CPS Plan B + ポジティブ・ディシプリン家族会議に、Tier B Payne（減らす）+ シュタイナー（メディア回避）+ バンデューラ（代理強化への注意）+ SDT（一緒に決める）+ Elkind（早期化批判）** が現代家庭の最も切実なシーンに対する補強。

### シーン 18: 子に手を上げてしまった（全年齢）

- **ピアジェ**: 直接的処方は薄い、**親自身の認知の発達**として読む。
- **エリクソン**: **「世代性 vs 停滞」** ── 親自身もライフサイクルの主人公、修復のプロセス。
- **Bronfenbrenner**: **「親一人で抱え込まない」の代表シーン** ── 親の余力低下を **エクソ・マクロの問題** として読む（夫婦関係・職場・地域）。「**親自身の応答者ネットワークが必要**」。
- **Dewey**: 「**経験を振り返って学ぶ**」── 親自身の経験。
- **SDT**: 「**親自身の 3 欲求が脅かされている**」── 親自身の自律性・有能感・関係性をまず満たす。
- **シュタイナー**: 「**真似される存在として大人が在る**」── 親自身の振る舞いが教育、修復もモデリング。
- **フレーベル**: 直接的処方は薄い。
- **バンデューラ**: **「親の修復モデルを子が観察する」** ── 「**さっきは怒りすぎた、ごめんね**」が代理強化として子に学ばれる。
- **スキナー**: **直接推奨しない** ── スキナーの枠組みは「**親の体罰は子に強化と罰を教える**」（バンデューラ系列の批判）。両論併記。
- **ガードナー**: 直接的処方は薄い。
- **Brazelton**: 「**親と子と医療者のパートナーシップ**」── 親自身も小児科医・カウンセラーに頼る。
- **Elkind**: **「親への成功圧力」を解毒** ── 「完璧な親」幻想からの脱却。
- **Galinsky**: 7 つのライフスキルは **親自身にも適用** ── 「親も生涯学習」。
- **Payne**: **「減らす」の代表シーン** ── 親の負荷（予定・情報・期待）を減らすことが、手を上げない最大の予防。
- **Barrett**: **「親自身の感情語彙を貸す」** ── 親の怒りを構成要素（疲労・空腹・孤独）に分解。
- **Wojcicki**: TRICK の「Kindness」── 自分にも親切に。
- **Tools of the Mind**: 「**親自身のプライベートスピーチ**」── 「**深呼吸、深呼吸**」と自分に言う。

**Tier B 共通メッセージ**: **Tier S 佐々木・Bowlby + Tier A Siegel（修復可能性）+ ポジティブ・ディシプリン（3 R's）+ Gottman（メタ感情）+ ギノット（自己観察）に、Tier B Bronfenbrenner（社会的支援・親の負荷の構造的解毒）+ Payne（減らす）+ エリクソン（生涯発達・修復可能）+ バンデューラ（修復モデル）+ Barrett（親自身の感情語彙）** が **「親を社会システムで支える」立体的視点** を加える。

ハイリスク家庭（DV / トラウマ）には専門家窓口の併記が必須（→ [[tier_b_persona_matrix]] §3.7）。

## 3. 横断パターン分析

### 3.1 Tier B が補強する 3 つの新しいレイヤー（Tier S/A の 4-5 ステップに加えて）

Tier S §3.1 の 4 ステップ + Tier A §3.1 の 5 ステップに対し、**Tier B は 3 つの新しいレイヤー**を加える:

1. **構造的に読む（Structural Reading）**: 親の問題を **エクソ・マクロの問題** として読み替える（Bronfenbrenner / Dewey）
2. **多元的に観察する（Multi-dimensional Observation）**: 単一評価軸でなく **8 つの知能 / 7 つのライフスキル** で観察する（ガードナー / Galinsky）
3. **減らす（Subtraction）**: 玩具・予定・情報・期待を **減らす** ことが最大の道具になる（Payne / シュタイナー / Elkind）

加えて、**(a) 発達段階を見る枠**（ピアジェ・エリクソン・Brazelton）、**(b) 動機づけ実証**（SDT・バンデューラ）、**(c) 神経科学の素材**（Barrett・Tools of the Mind）、**(d) 古典の権威**（フレーベル・シュタイナー）、**(e) 両論併記の素材**（スキナー）── 5 つの厚みも合わせ持つ。

## 4. note 記事化のヒント

### 4.1 「1 シーン × 35 レンズ」シリーズ（Tier S 7 + Tier A 11 + Tier B 17 = 35 レンズ）

Tier S 7 レンズ + Tier A 11 レンズに Tier B 17 レンズを足すと、各シーンを **35 レンズ** で見られる。読者は自分の感覚に近いレンズを選んで取り入れられる。**ひだまりこそだち の note の最大の差別化**。

### 4.2 「Tier B の 5 つの厚み」シリーズ

Tier B の **5 つの厚み** を中心に据えた記事群:

- **古典発達の地層**（ピアジェ / エリクソン / Brazelton）── 全シーンで月齢比較の不安を解毒
- **社会システムの視点**（Bronfenbrenner / Dewey）── シーン 1, 13, 17, 18 で親の自責解毒
- **環境設計の3本柱**（シュタイナー / フレーベル / Payne）── シーン 8, 14, 17, 18 で「減らす」「リズム」「自然」
- **動機づけ実証**（SDT / バンデューラ）── シーン 7, 9, 11, 14, 15 で内発動機の科学
- **早期化批判の3声**（Elkind / Payne / ピアジェ）── シーン 5, 14, 15, 17 で先取り解毒

### 4.3 「親を社会で支える」シリーズ

シーン 1, 13, 17, 18 を中核に、**Bronfenbrenner + エリクソン（世代性）+ Payne（減らす）+ Brazelton（小児科臨床）** で「**親の負荷を社会システムで解毒する**」記事を作る。**Tier S 佐々木の「育てたように子は育つ」を希望のメッセージに翻訳する記事の最重要源**。

### 4.4 「早期教育志向を再フレーム」シリーズ

シーン 5, 14, 15, 17 を中核に、**Elkind + Payne + SDT + ガードナー + Galinsky + Tools of the Mind + ピアジェ** の 7 理論で「**先取り vs 待つの二項対立を解く**」記事を作る。**Tier B が H ペルソナに最も力を発揮するシリーズ**。

### 4.5 「保育観の整理」シリーズ

シーン 11, 14 を中心に、**フレーベル + シュタイナー + Dewey + Tools of the Mind + ガードナー** で「**保育園・幼稚園選び**」記事を作る。Tier A レッジョ + Vygotsky + 倉橋と統合する 8 理論シリーズ。

### 4.6 「感情語彙を貸す」シリーズ

シーン 6, 12, 15, 18 を中心に、**Barrett + Tools of the Mind + Galinsky** で「**感情語彙の神経科学的根拠**」記事を作る。Tier A の Gottman + Siegel + ギノットと統合する。
