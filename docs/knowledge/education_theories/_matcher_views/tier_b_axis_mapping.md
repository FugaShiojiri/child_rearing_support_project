# Tier B 17理論 × マッチャー6軸 マッピング

> 目的: マッチャー（親×理論診断）の 6 軸（R応答性 / S構造性 / I主導権 / E評価観 / P早期化 / C関係性）で Tier B 17 理論をスコア化し、Tier S スコアマップ（→ [[tier_s_axis_mapping]]）・Tier A スコアマップ（→ [[tier_a_axis_mapping]]）と整合的に並べる。
> スコア範囲: **-2.0 〜 +2.0**（各軸の極性は [[docs/matcher/axes_v0]] を参照）
> 注意: スコアは「その理論が **どの軸でどちらの極に近い親に推奨されやすいか**」を示すものであり、**その軸でその理論が「正しい」とする評価ではない**。

## 1. 6 軸の極性（おさらい）

| 軸 | + 極 | - 極 |
|---|---|---|
| **R** 応答性 | R+ 高応答・察し | R− 自律探索を尊重 |
| **S** 構造性 | S+ 構造的・ルーティン | S− 流動的・自由 |
| **I** 主導権 | I+ 親主導・誘導 | I− 子主導・委ねる |
| **E** 評価観 | E+ 結果・能力 | E− 過程・工夫 |
| **P** 早期化 | P+ 早期投資・先取り | P− 発達待ち・ゆっくり |
| **C** 関係性 | C+ 共同体・つながり | C− 個別自立・境界 |

## 3. 各理論の軸別スコア + 理由

### 3.1 ピアジェ

- **R 応答性: +0.5**（やや R+）
  - 「子の今の段階の論理を尊重する」観察的応答性。
  - ただし NVC ほど「サインを読んで応える」を中核に置かない。認知の枠組み中心。
- **S 構造性: +0.5**（やや S+）
  - 4 段階説は構造的な発達の枠組みを提供。
  - ただし環境設計・ルーティンには踏み込まない。
- **I 主導権: 0.0**（中立）
  - 「教えるのでなく子が構成する」は子主導側だが、「観察し問い返す大人」は親の伴走も含む。
- **E 評価観: -1.0**（E−寄り）
  - 「結果でなく認知の発達プロセス」── 評価軸を結果から発達プロセスへ。
  - ただし過程賞賛の言語化は持たない。
- **P 早期化: -1.5**（強い P−）
  - **「アメリカの質問への有名な拒絶」** ── 「**どうすれば早く次の段階に行けるか**」と聞く米国人に「**それを急ぐ必要はない**」と返した。早期化を強く戒める。
- **C 関係性: 0.0**（中立）
  - 「個人主義的」批判の通り、社会的関係を中核に置かない。
  - Vygotsky と対比される。

### 3.2 エリクソン

- **R 応答性: +1.0**（R+寄り）
  - **「乳児期は信頼 ── 要求に応える」が中核**。
  - 「**応える・許す・応援する**」の動詞のうち、最初の「応える」が応答性そのもの。
- **S 構造性: +0.5**（やや S+）
  - 8 段階説は構造的だが、環境設計には踏み込まない。
- **I 主導権: -0.5**（やや I−）
  - 「**自分でやる**」の自律 / 「**やってみたい**」の自主性 を尊重 ── 子主導側。
  - ただし「課題が育つ環境を提供する」── 大人が完全に降りるのでもない。
- **E 評価観: -1.0**（E−寄り）
  - **「困った行動を発達課題の正常な表現と読み替える」** ── 結果評価でなく発達段階を読む。
- **P 早期化: -1.0**（P−寄り）
  - 「**段階を逃すと取り返せない**」とは言わない、生涯発達。
  - 早期決定論を退ける。
- **C 関係性: +0.5**（やや C+）
  - **「心理社会的」発達 ── 家族・地域・文化の影響を発達理論に取り込む**。
  - フロイト派の個人内力動から脱却した社会的視点。

### 3.3 Bronfenbrenner

- **R 応答性: +0.5**（やや R+）
  - マイクロシステムでの応答的関わりを重視。
  - ただし応答の言語化は持たない、構造的視点中心。
- **S 構造性: 0.0**（中立）
  - 5 層モデル自体は構造的だが、家庭の構造化を推奨しない。
- **I 主導権: 0.0**（中立）
  - 親が主導/子が主導という個人内軸を扱わない。
  - システム視点。
- **E 評価観: -0.5**（やや E−）
  - 結果評価でなく **「環境システムの中で育つ過程」** を見る。
- **P 早期化: -0.5**（やや P−）
  - 早期化論に直接踏み込まない。
- **C 関係性: +2.0**（最強の C+ ── Tier B 内で最強）
  - **5 層の入れ子環境システムそのものが C+ の極致**。
  - 「**親だけのせいじゃない、社会システムで育つ**」── ひだまりこそだち の社会的メッセージの根拠。
  - 佐々木（Tier S, C+1.5）/ レッジョ・倉橋（Tier A, C+1.5）と並ぶ C+ 最強の理論。

### 3.4 Dewey

- **R 応答性: +0.5**（やや R+）
  - 「子の興味から立ち上がる」── 興味への応答性。
  - ただし応答の言語化は持たない。
- **S 構造性: 0.0**（中立）
  - 「学校は生活そのもの」── 構造化を最小限に。
  - ただし「経験を振り返る」プロセスは構造的。
- **I 主導権: -0.5**（やや I−）
  - 「子の興味から始める」── 子主導側。
  - ただし「教師は協働者」── 親も伴走者として関わる。
- **E 評価観: -1.0**（E−寄り）
  - 「**Learning by doing**」── 結果でなく経験の質を価値づける。
- **P 早期化: -0.5**（やや P−）
  - 早期化に踏み込まないが、経験を急がない思想。
- **C 関係性: +1.0**（C+寄り）
  - 「**民主主義は生き方 / 学校は小さな民主共同体**」── 共同体軸が中核。

### 3.5 SDT（自己決定理論）

- **R 応答性: +1.0**（R+寄り）
  - **3 欲求のうち関係性 + 自律支援的フィードバック**で応答性を中核に。
  - Mouratidis 2010 の自律支援的ネガティブ・フィードバック実験。
- **S 構造性: 0.0**（中立）
  - 「構造（structure）」は有能感を支える環境として位置づけられるが、ルーティン化には踏み込まない。
- **I 主導権: -1.0**（I−寄り）
  - **「やる気を出させるのでなく、3欲求が満たされる場をつくる」** ── 親は伴走者。
  - 自律性支援が中核。
- **E 評価観: -1.5**（強い E−）
  - **アンダーマイニング効果**：統制的報酬が内発動機を削る。
  - 過程の言語化が中核（情報的フィードバック）。
- **P 早期化: -0.5**（やや P−）
  - 「3 欲求が満たされる場」── 急かさない発想。
- **C 関係性: +0.5**（やや C+）
  - 「関係性」が3欲求の1つ。
  - ただし社会システム視点までは踏み込まない。

### 3.6 シュタイナー

- **R 応答性: +0.5**（やや R+）
  - 「子の発達リズムに寄り添う」観察的応答性。
  - ただし「察し」を中核に置かない、生活のリズム中心。
- **S 構造性: +1.5**（強い S+）
  - **「生活のリズム」「季節の祝祭」「朝の歌・寝る前の物語」** ── 反復と儀式が中核。
  - モンテッソーリ（Tier S, S+1.5）と並ぶ S+ の極。
- **I 主導権: -0.5**（やや I−）
  - 「真似される存在として大人が在る」── 教え込まない。
  - ただし生活のリズムを大人が整える。
- **E 評価観: -1.0**（E−寄り）
  - 「**早期の知的詰め込みを避ける**」── 結果評価を退ける。
- **P 早期化: -2.0**（最強の P− ── Tier B 内で最強）
  - **「読み書き計算は 7 歳以降」** ── 早期化を最も強く退ける。
  - 汐見・ピクラー（Tier S, P-1.5）/ Elkind（Tier B, P-2.0）/ Payne（Tier B, P-1.5）と並ぶ P− 最強の理論。
- **C 関係性: +1.0**（C+寄り）
  - 「ヴァルドルフ学校は共同体」── 子・親・教師の共同体。
  - 季節の祝祭・自然との関係性。

### 3.7 フレーベル

- **R 応答性: +0.5**（やや R+）
  - 「子は遊びを通して自ら学ぶ」観察的応答性。
- **S 構造性: +1.0**（S+寄り）
  - **恩物の体系・作業の体系** ── 構造的な教具を持つ。
  - モンテッソーリの直接の祖先。
- **I 主導権: -0.5**（やや I−）
  - 「子は遊びの主人公」── 子主導。
  - ただし恩物の使い方は大人が示す。
- **E 評価観: -1.0**（E−寄り）
  - 「遊びは子の最高の発達表現」── 結果評価でなく遊びそのものを価値づける。
- **P 早期化: -0.5**（やや P−）
  - 早期化論を持たない、子のペースを尊重。
- **C 関係性: +0.5**（やや C+）
  - 「Kindergarten = 子どもの庭園」── 共同の場。

### 3.8 バンデューラ

- **R 応答性: +0.5**（やや R+）
  - 「子は親を見て真似る」── モデリングは観察的な関わり。
  - ただし「察し」を中核に置かない、認知中心。
- **S 構造性: +0.5**（やや S+）
  - 観察学習の4段階モデル（注意→保持→再生→動機づけ）が構造的。
  - PCIT / Triple P / Incredible Years などの構造化された介入の源流。
- **I 主導権: +0.5**（やや I+）
  - **Tier B 内で珍しい I+ 側** ── 「親が大切にしたい姿を体現する」「言語的説得」など、親の能動的関わりを推奨。
  - Tier A の Vygotsky と同じ I+ 側。
- **E 評価観: -0.5**（やや E−）
  - 自己効力感は **「できた感」の言語化** ── 過程承認に近い。
- **P 早期化: 0.0**（中立）
  - 早期化論を持たない。
- **C 関係性: +0.5**（やや C+）
  - 相互決定論：人・行動・環境の相互作用 ── 社会的視点。

### 3.9 スキナー

- **R 応答性: +0.5**（やや R+）
  - **行動主義の中の応答性** ── 子の行動に即座に強化を返す、というのは応答的。
  - ただし内的状態（感情・思考）を扱わないので、Tier S/A の応答性とは異質。
- **S 構造性: +1.5**（強い S+）
  - **強化スケジュール・トークン・エコノミー** ── 最も構造的な理論。
  - シュタイナー / モンテッソーリと並ぶ S+ 最強。
- **I 主導権: +1.5**（強い I+ ── Tier B 内で最強）
  - **強化と罰で子の行動を形成する** ── 親主導の極致。
  - **35 理論の中で最も I+ の極にある**（他の理論は I− 〜 中立に分布）。
- **E 評価観: +1.0**（E+ ── Tier B 内で最強）
  - **「行動の結果（強化・罰）で行動が決まる」** ── 結果評価そのもの。
  - **35 理論の中で唯一の明確な E+ 側**（成長マインドセット = E-2.0 の正反対）。
- **P 早期化: +0.5**（やや P+）
  - **プログラム学習・早期介入（ABA）** ── 早期からの行動形成を肯定。
- **C 関係性: -0.5**（やや C−）
  - 個人の行動形成中心、社会的関係は副次的。

### 3.10 ガードナー

- **R 応答性: 0.0**（中立）
  - 親の応答性に直接言及しない。
  - 「8 つの知能を観察する」レンズ中心。
- **S 構造性: 0.0**（中立）
  - 環境設計・ルーティンに踏み込まない、視点提供。
- **I 主導権: 0.0**（中立）
  - 親が主導/子が主導という軸を扱わない。
- **E 評価観: -1.0**（E−寄り）
  - **「IQ 一元評価への対抗 / 8 つの知能で見る」** ── 単一評価軸への抵抗。
- **P 早期化: -0.5**（やや P−）
  - 「**MI は教育プログラムではなく視点**」── 早期介入の根拠に使うのは誤読。
- **C 関係性: 0.0**（中立）
  - 個人内の知能配合プロファイル中心。

### 3.11 Brazelton

- **R 応答性: +1.5**（強い R+）
  - **新生児行動評価尺度（NBAS）** ── 生後すぐの赤ちゃんの個性を観察的に読む。
  - 「**親と一緒に発達を観察するパートナー**」── 観察的応答性。
- **S 構造性: +0.5**（やや S+）
  - **タッチポイント・モデル** ── 発達の予測可能な踏み越え時期を構造化。
- **I 主導権: -0.5**（やや I−）
  - 「親と子と医療者のパートナーシップ」── 親主導でも子主導でもない協働。
- **E 評価観: -0.5**（やや E−）
  - 「退行は失敗でなく次の段階の予兆」── 結果評価を退ける。
- **P 早期化: -1.0**（P−寄り）
  - 「子のペースで発達する」── 早期化を退ける。
- **C 関係性: +0.5**（やや C+）
  - 「小児科医・保育者・親の3者連携」── 社会的支援ネットワーク視点。

### 3.12 Elkind

- **R 応答性: +0.5**（やや R+）
  - 「子のペースを守る」── 観察的応答性。
- **S 構造性: -0.5**（やや S−）

## 8. 留意事項

1. **スコアは v0.1**: 実データ（100 ペルソナでの軸スコア分布）が出てから再キャリブレーション必要。
2. **スキナーの I+/S+/E+/P+ の偏り**: スキナーは 35 理論の中で **唯一明確な I+/E+/P+** の極を担う。マッチャーで親プロファイルが I+/E+/P+ の場合、スキナーが「両論併記」として推薦されるが、**ひだまりこそだち は「補助輪としては有効、内発動機が立ち上がったら早めに外す」の SDT 統合版** で扱う。
3. **Bronfenbrenner の C+2.0**: 35 理論の中で最強の C+。マッチャーで親プロファイルが C+1.5 以上の場合、Bronfenbrenner は **第一推薦に近い扱い** にする（社会的支援メッセージの根拠）。
4. **シュタイナー・Elkind の P-2.0**: 35 理論の中で最強の P−。早期化批判記事の中核として位置づける。
5. **Tier B は「Tier S/A と組み合わせる」前提**: Tier B 単独の距離計算は推奨しない。Tier S/A 推薦が決まった後の補強推薦として使う。
6. **エビデンス強度の差**: バンデューラ / SDT / ピアジェ / Brazelton（研究厚）vs ガードナー / Elkind / Payne / Wojcicki / シュタイナー / フレーベル（思想・実践知）── マッチャー結果画面で明示。
7. **文化差**: Tier B 17 理論の起源国は スイス1（ピアジェ）/ 米国12（エリクソン・Bronfenbrenner・Dewey・SDT・バンデューラ・スキナー・ガードナー・Brazelton・Elkind・Galinsky・Payne・Barrett・Wojcicki・Tools of the Mind の14理論）/ 独語圏3（シュタイナー・フレーベル）── 米国理論が圧倒的に多いため、Tier S 汐見・佐々木・倉橋（Tier A）と必ず組み合わせて文化バイアスを相殺する。
8. **年齢別の重み変動**: 乳児期では Brazelton + Bronfenbrenner + エリクソン + Barrett の重みが大きく、3-6 歳では SDT + バンデューラ + ピアジェ + ガードナー + Tools of the Mind + Galinsky が大きくなる。Phase B で年齢セグメント別に再計算予定。
9. **Tier S + Tier A + Tier B = 35 理論の総スコア = 35 × 6 軸 = 210 スコア**。マッチャー設計の最終的な参照表として、3 つの軸マップを統合的に参照する。
