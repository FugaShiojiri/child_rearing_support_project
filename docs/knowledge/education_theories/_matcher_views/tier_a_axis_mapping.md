# Tier A 11理論 × マッチャー6軸 マッピング

> 目的: マッチャー（親×理論診断）の 6 軸（R応答性 / S構造性 / I主導権 / E評価観 / P早期化 / C関係性）で Tier A 11 理論をスコア化し、Tier S スコアマップ（→ [[tier_s_axis_mapping]]）と整合的に並べる。
> スコア範囲: **-2.0 〜 +2.0**（各軸の極性は [[docs/matcher/axes_v0]] を参照）
> 注意: スコアは「その理論が **どの軸でどちらの極に近い親に推奨されやすいか**」を示すものであり、**その軸でその理論が「正しい」とする評価ではない**。

## 1. 6 軸の極性（おさらい）

| 軸 | + 極 | - 極 |
|---|---|---|
| **R** 応答性 | R+ 高応答・察し | R− 自律探索を尊重 |
| **S** 構造性 | S+ 構造的・ルーティン | S− 流動的・自由 |
| **I** 主導権 | I+ 親主導・誘導 | I− 子主導・委ねる |
| **E** 評価観 | E+ 結果・能力 | E− 過程・工夫 |
| **P** 早期化 | P+ 早期投資・先取り | P− 発達待ち・ゆっくり |
| **C** 関係性 | C+ 共同体・つながり | C− 個別自立・境界 |

## 3. 各理論の軸別スコア + 理由

### 3.1 ポジティブ・ディシプリン

- **R 応答性: +1.0**（R+寄り）
  - 「Connection before Correction」── 修正の前にまずつながる。
  - ただし NVC ほど「サインを読む」を中核に置かない。実装はカリキュラム的。
- **S 構造性: +0.5**（やや S+）
  - 「家族会議の 8 ステップ」「ルーティンチャート」「Wheel of Choice」など、**構造的ツール** を多数持つ。
  - ただし環境設計（モンテッソーリ的）には踏み込まない。
- **I 主導権: -1.0**（I−寄り）
  - 「子の声を聞く」「子と一緒に解決策を考える」が中核。
  - ただし「対等」── アドラー譲りで、完全に子に委ねるのでもない。
- **E 評価観: -1.5**（強い E−）
  - **アドラー直系の「勇気づけ vs 賞賛」を継承**。「ありがとう、助かった」（貢献承認）。
  - 「Mistakes Are Wonderful Opportunities to Learn」── 失敗を学びの素材として遇する。
- **P 早期化: -0.5**（やや P−）
  - 早期教育に踏み込まない。
  - 3 歳未満は「教えるのではなくつながる」と明示（Nelsen 自身の言）。
- **C 関係性: +1.0**（C+寄り）
  - **「家族会議」が中核ツール** ── 家族を共同体として位置づける。
  - アドラーの「共同体感覚」を継承。

### 3.2 ハイム・ギノット

- **R 応答性: +1.5**（R+寄り）
  - **「子の感情を翻訳して返す」が中核** ── 「保育園が嫌なんだね」。
  - 感情への敏感性は Tier A 内で Gottman / Siegel / Ainsworth に次ぐ位置。
- **S 構造性: 0.0**（中立）
  - 環境設計・ルーティンに言及しない。
  - 「言葉のスキル」が中核で、構造ツールはほぼ持たない。
- **I 主導権: -0.5**（やや I−）
  - 「子の感情を出発点に対話する」。
  - ただし「行動には限界を設ける」── 親が降りるのでもない。
- **E 評価観: -1.5**（強い E−）
  - **「人格批判ではなく行動を記述する」が中核**。「You are lazy」（人格断定）→「服が散らかっている」（観察）。
  - **「描写的賞賛」** が成長マインドセットの 30 年先取り。「上手！」→「赤と青を重ねたんだね」。
- **P 早期化: 0.0**（中立）
  - 年齢論に言及しない。
  - 3 歳以降の言語発達後が本領。
- **C 関係性: 0.0**（中立）
  - 個と関係性のバランス。
  - 文化バイアスが軽い（イスラエル出身・米国活動）。

### 3.3 CPS（Ross Greene）

- **R 応答性: +1.0**（R+寄り）
  - **Plan B の共感ステップが中核** ── 子の懸念を聞き取る。
  - ただし「解釈・説教 NG」「open-ended な問いと沈黙」── 過剰な察しでなく観察的応答性。
- **S 構造性: +1.0**（S+寄り）
  - **「Plan A / B / C」「Plan B の 3 ステップ」「ALSUP」** など、構造的な実装ツール群。
  - 「爆発の最中でなく穏やかな時間に話す」── 時間設計が構造的。
- **I 主導権: -0.5**（やや I−）
  - 「親が先に解決策を提案しない」── 子のアイデアから出てもらう。
  - ただし「大人の懸念を並べて置く」── 親が完全に降りるのでもない。
- **E 評価観: -1.0**（E−寄り）
  - **「Kids do well if they can」** ──「やる気の問題（人格評価）」でなく「スキルの問題」。
  - 結果評価でなくスキル獲得プロセスに焦点。
- **P 早期化: -0.5**（やや P−）
  - 早期教育に踏み込まない。
  - 「スキルは時間をかけて獲得される」── 焦らない発想。
- **C 関係性: +0.5**（やや C+）
  - 「共同問題解決」── 家族・教師・心理士がチームで子を支える。
  - ALSUP はチームで使う共通言語。

### 3.4 成長マインドセット（ドゥエック）

- **R 応答性: 0.0**（中立）
  - 親の応答性に直接言及しない。
  - 「親自身のマインドセット」が中核 ── 関係性の質ではない。
- **S 構造性: 0.0**（中立）
  - 環境設計・ルーティンに言及しない。
  - 「言葉の選び方」が中核。
- **I 主導権: 0.0**（中立）
  - 親が主導/子が主導という軸を扱わない。
  - 認知の枠組みの問題。
- **E 評価観: +2.0**（最強の E−側ではなく、「過程評価」へのシフトを最強に主張）
  - **理論全体が E 軸の理論**。「能力（人格）でなく過程を価値づける」。
  - ※スコア表記の注意: +2.0 は「**過程賞賛の主張の強さ**」を示す。マッチャー設計上、E軸はE−寄り = -2.0 と表記すべきだが、本表は **「軸として最も中核的な理論」** を強調するため絶対値で表記。後の表中では「**E -2.0**」と読み替える。
  - **再キャリブレーション**: E軸スコアを **-2.0** に修正（過程賞賛 = E− 強）。
- **P 早期化: 0.0**（中立）
  - 年齢論に言及しない。
  - 0 歳から使えるが、本領は 3 歳以降。
- **C 関係性: 0.0**（中立）
  - 個人主義的色彩（米国スタンフォード発）。
  - ただし「親の信念 → 子の信念」の関係的伝播は扱う。

**修正版スコア（Dweck 成長マインドセット）**: R 0.0 / S 0.0 / I 0.0 / **E -2.0** / P 0.0 / C 0.0

E 軸のみが強く突出する **「E 軸特化理論」** という位置づけ。

### 3.5 Vygotsky ZPD

- **R 応答性: +1.0**（R+寄り）
  - 「子の現在水準を観察して把握する」が ZPD ベースの関わりの起点。
  - 「**最小限の援助を渡し、できたら援助を引いていく**」── 観察ベースの応答性。
- **S 構造性: +0.5**（やや S+）
  - 「心理的道具（言語・記号・カレンダー・ToDo リスト）」が構造的。
  - Tools of the Mind の「プレイ・プラン」「バディ・リーディング」などツール多数。
- **I 主導権: +0.5**（やや I+）
  - **Tier S は全体的に I− 寄りだったが、Vygotsky は珍しく I+ 寄り**。
  - 「ZPD で大人が伴走する」── 大人の主導性が高い。
  - ただし「教える」のでなく「足場かけ」── 援助は引いていく。
- **E 評価観: -0.5**（やや E−）
  - 「IQ で測れる力でなく、関係性の中で立ち現れる力」── 静的評価を否定。
  - ただし過程賞賛の言語化は持たない。
- **P 早期化: 0.0**（中立）
  - 「敏感期」概念は持たない。
  - ZPD は **個別の現在水準** から始まるので、早期化とも遅延化とも独立。
- **C 関係性: +1.0**（C+寄り）
  - **「高次精神機能の社会的起源」** ── 精神は社会的関係から内化される。
  - 「私的言語 → 内言」── 社会的言語が思考になる。

### 3.6 レッジョ・エミリア

- **R 応答性: +0.5**（やや R+）
  - 「listening（子の世界に開かれる構え）」── 文字どおりの傾聴を超えた応答性。
  - ただし応答の言語化は持たない。
- **S 構造性: +0.5**（やや S+）
  - **「環境は第三の教師」「アトリエ」「ドキュメンテーション」** ── 環境設計は強い。
  - ただしモンテッソーリほどの教具体系は持たない。
- **I 主導権: -1.0**（I−寄り）
  - 「子の興味から立ち上がる progettazione」。
  - 大人は「答えを持つ専門家」でなく「共同探究者」。
- **E 評価観: -1.0**（E−寄り）
  - 「子の作品を上手・下手で判定しない」。
  - 「100 の言葉」── 多元的表現を肯定。
- **P 早期化: -0.5**（やや P−）
  - 「先取り」概念を持たない。
  - 子の興味のペースで進む。
- **C 関係性: +1.5**（強い C+）
  - **「子は政治的市民」「沈黙する子を作らない」** ── 戦後イタリアの市民運動由来。
  - 共同探究 + 地域社会 + ドキュメンテーション共有 ── 共同体軸を Tier A で最も強く担う。

### 3.7 倉橋惣三 誘導保育論

- **R 応答性: +0.5**（やや R+）
  - 「さながらの生活」── 子のそのままの姿を受け入れる。
  - 「育つを助ける心」── 観察的応答性。
- **S 構造性: -0.5**（やや S−）
  - **「保育の階梯」は構造的だが、環境設計には踏み込まない**。
  - 「日常そのものを大切にする」── 構造化を最小限に。
- **I 主導権: -1.0**（I−寄り）
  - 「自ら育つものを育たせようとする心」── 子主導。
  - ただし「誘導」「教導」── 親が完全に降りるのでもない。
- **E 評価観: -1.0**（E−寄り）
  - 「育ちつつある存在」── 結果評価でなくプロセス重視。
  - 「自己充実」を価値の中心に置く。
- **P 早期化: -1.0**（P−寄り）
  - **「自ら育つ」が中核** ── 早期化を強く拒む。
  - 大正自由教育運動 = 注入主義への反動として生まれた思想。
- **C 関係性: +1.5**（強い C+）
  - **戦後日本保育思想の源流** ── 日本の集団主義的家族文化と親和的。
  - 城戸幡太郎との論争で「個 vs 集団」の緊張を経た上での共同体観。

### 3.8 Gottman 感情コーチング

- **R 応答性: +2.0**（最強の R+ ── Bowlby・佐々木と並ぶ）
  - **「メタ感情哲学」「5 ステップ感情コーチング」** が中核。
  - 「子の感情に気づく」「親密の機会と捉える」── 応答性の最高水準。
- **S 構造性: +0.5**（やや S+）
  - 5 ステップは構造的。
  - TIK プログラム化で 6 セッション構造。
  - ただし日常リズム・環境設計には踏み込まない。
- **I 主導権: -0.5**（やや I−）
  - 「子の感情を出発点に対話」。
  - ただし「行動には限界を設ける」── 親が降りるのでもない。
- **E 評価観: -1.0**（E−寄り）
  - 「感情の正解 / 不正解」を作らない ──「感情は全部 OK」。
  - ただし過程賞賛の言語化は持たない。
- **P 早期化: -0.5**（やや P−）
  - 「子の発達に合わせる」── 早期化を煽らない。
  - 0 歳から使えるが、3 歳以降が本領。
- **C 関係性: +0.5**（やや C+）
  - 「夫婦間ミスマッチも扱う」── 家族システム視点を持つ。
  - ただし共同体・社会的支援ネットワークまでは踏み込まない。

### 3.9 Siegel ホールブレイン

- **R 応答性: +1.5**（強い R+）
  - **「Connect and Redirect」が中核** ── つながってから方向転換。
  - 「Name it to Tame it」── 感情への応答性。
- **S 構造性: +0.5**（やや S+）
  - 「12 戦略」「4 つの S」など構造化されたフレーム。
  - ただし環境設計・ルーティンには踏み込まない。
- **I 主導権: -0.5**（やや I−）
  - 「子の感情に体を寄せる」── 子起点。
  - ただし「Redirect」── 親が方向を示す要素もある。
- **E 評価観: -1.0**（E−寄り）
  - 「癇癪は『悪い子』でなく『脳が統合中』のサイン」── 行動を人格評価しない。
  - ただし過程賞賛の言語化は持たない。
- **P 早期化: -0.5**（やや P−）
  - 「前頭前野は 20 代半ばまで発達」── 早期化を強く拒む発達観。
  - 「自分でコントロールできないのは怠慢でなく発達的に当然」。
- **C 関係性: +0.5**（やや C+）
  - 「共同調整 → 自己調整」── 関係性の中で発達する観点。
  - ただし共同体・社会まで踏み込まない。

### 3.10 Ainsworth SSP

- **R 応答性: +2.0**（最強の R+ ── Bowlby・佐々木・Gottman と並ぶ）
  - **「敏感性・応答性・協調性・受容性」の 4 観点が中核**。
  - 「サインを読む → 適切に応じる」が安定型を育てる。
- **S 構造性: 0.0**（中立）
  - SSP は実験室手続きで、家庭の構造化を推奨しない。
- **I 主導権: -0.5**（やや I−）
  - 「子のシグナルに応じる」── 子起点。
- **E 評価観: -0.5**（やや E−）
  - タイプ分類を「優劣」「性格」と読まないことが中核メッセージ。
- **P 早期化: -0.5**（やや P−）
  - 早期介入研究の素地ではあるが、「先取り教育」とは別物。
- **C 関係性: +0.5**（やや C+）
  - 「再会場面」── 別れた後にどうつなぎ直すかが鍵。
  - 文化差（日本では回避型少・抵抗型多）── 文化バイアスへの感度を持つ。

### 3.11 Baumrind authoritative

- **R 応答性: +1.0**（R+寄り）
  - **「応答性 × 要求性」の 2 軸の片方を担う**。
  - 「温かく支持的な親子関係」が authoritative の前提。
- **S 構造性: +1.0**（S+寄り）
  - **「要求性」の側面** ── 期待・限界・一貫性を持つ。
  - ただし環境設計（モンテッソーリ的）には踏み込まない。
- **I 主導権: 0.0**（中立）
  - 「対話的だが、親が降りない」── 中央。
  - Tier A 11 理論の中で最も主導権が中立。
- **E 評価観: 0.0**（中立）
  - 評価観そのものに踏み込まない。
  - 「予測可能な結末」── 結果と過程の両方を扱う。
- **P 早期化: 0.0**（中立）
  - 早期化論に踏み込まない。
- **C 関係性: +0.5**（やや C+）
  - 家族システムを 2 軸でマップ化する視点。
  - ただし共同体・社会への踏み込みは薄い。

## 4. 軸ごとの理論分布（Tier A 11 理論）

各軸で、+ 極から - 極まで Tier A 11 理論を並べる。マッチャーが推薦するときの「軸 + 親プロファイル → 候補理論」の早見表。

### 4.1 R 軸（応答性）

```
R+ ←──────────────────────────────→ R−
[+2.0] Gottman ━━━━ Ainsworth [+2.0]
[+1.5] ギノット ━━━━ Siegel [+1.5]
[+1.0] ポジティブ・ディシプリン ━━━━ CPS ━━━━ Vygotsky ━━━━ Baumrind [+1.0]
[+0.5] レッジョ ━━━━ 倉橋 [+0.5]
[0.0]  成長マインドセット
```

**R+ 強の親**（察し・先回り）→ Gottman / Ainsworth / Siegel / ギノット
**R− 強の親**（待つ・観察）→ Tier A 内には強い R− は無し（Tier S のモンテッソーリ -0.5 が候補）

### 4.2 S 軸（構造性）

```
S+ ←──────────────────────────────→ S−
[+1.0] CPS ━━━━ Baumrind [+1.0]
[+0.5] ポジティブ・ディシプリン ━━━━ Vygotsky ━━━━ レッジョ ━━━━ Gottman ━━━━ Siegel [+0.5]
[0.0]  ギノット ━━━━ 成長マインドセット ━━━━ Ainsworth [0.0]
[-0.5] 倉橋 [-0.5]
```

**S+ 強の親**（ルーティン・予測可能性）→ CPS / Baumrind / ポジティブ・ディシプリン（家族会議の構造）
**S− 強の親**（流動的・柔軟）→ 倉橋（Tier A 内で唯一の S−）

### 4.3 I 軸（主導権）

```
I+ ←──────────────────────────────→ I−
[+0.5] Vygotsky [+0.5]
[0.0]  成長マインドセット ━━━━ Baumrind [0.0]
[-0.5] ギノット ━━━━ CPS ━━━━ Gottman ━━━━ Siegel ━━━━ Ainsworth [-0.5]
[-1.0] ポジティブ・ディシプリン ━━━━ レッジョ ━━━━ 倉橋 [-1.0]
```

**I+ 強の親**（誘導・先取り）→ Vygotsky（Tier A 内で唯一の I+ ── ZPD で大人が伴走する設計）
**I− 強の親**（委ねる）→ ポジティブ・ディシプリン / レッジョ / 倉橋

**重要**: Tier S（Bowlby -1.0、ピクラー -2.0、モンテッソーリ -1.5）と比べて、Tier A は **全体的に I− がマイルド**。これは Tier A が「**親が能動的に関わるツール群**」だからで、Tier S の「**待つ・観察する**」とは異なる方向性。

### 4.4 E 軸（評価観）

```
E+ ←──────────────────────────────→ E−
[0.0]  Baumrind [0.0]
[-0.5] Vygotsky ━━━━ Ainsworth [-0.5]
[-1.0] CPS ━━━━ レッジョ ━━━━ 倉橋 ━━━━ Gottman ━━━━ Siegel [-1.0]
[-1.5] ポジティブ・ディシプリン ━━━━ ギノット [-1.5]
[-2.0] 成長マインドセット [-2.0]
```

**E+ 強の親**（結果評価・賞賛）→ Tier A 内には無し（Baumrind の中立が最 + 寄り）
**E− 強の親**（過程評価）→ **成長マインドセット**（Tier A 内で最強）/ ポジティブ・ディシプリン / ギノット

**重要**: **成長マインドセットは E 軸特化理論**。R/S/I/P/C は中立で、E のみが -2.0。アドラー（Tier S、E -2.0）と並ぶ E 軸の二大理論。

### 4.5 P 軸（早期化）

```
P+ ←──────────────────────────────→ P−
[0.0]  ギノット ━━━━ 成長マインドセット ━━━━ Vygotsky ━━━━ Baumrind [0.0]
[-0.5] ポジティブ・ディシプリン ━━━━ CPS ━━━━ レッジョ ━━━━ Gottman ━━━━ Siegel ━━━━ Ainsworth [-0.5]
[-1.0] 倉橋 [-1.0]
```

**P+ 強の親**（早期投資・先取り）→ Tier A 内には無し（Tier S モンテッソーリ +0.5 が候補）
**P− 強の親**（発達待ち）→ 倉橋（Tier A 内で最強）

**重要**: Tier A は全体的に **P 軸で中立 ~ やや P−**。Tier S（汐見 -1.5、ピクラー -1.5、佐々木 -1.0）ほどの強い P− は持たない。これは Tier A が「**実装ツール**」だからで、年齢論を強く語らない。

### 4.6 C 軸（関係性）

```
C+ ←──────────────────────────────→ C−
[+1.5] レッジョ ━━━━ 倉橋 [+1.5]
[+1.0] ポジティブ・ディシプリン ━━━━ Vygotsky [+1.0]
[+0.5] CPS ━━━━ Gottman ━━━━ Siegel ━━━━ Ainsworth ━━━━ Baumrind [+0.5]
[0.0]  ギノット ━━━━ 成長マインドセット [0.0]
```

**C+ 強の親**（共同体・つながり）→ レッジョ / 倉橋 / ポジティブ・ディシプリン / Vygotsky
**C− 強の親**（個別自立・境界）→ Tier A 内には無し（Tier S モンテッソーリ -1.0 が候補）

## 6. 軸の相関に基づく親プロファイル類型と Tier A 推薦

Tier S の §5 で挙げた 6 つの親プロファイル類型に対する、**Tier A からの第二推薦** を示す。

### 6.1 「察し・つながり」型（R+ / C+ / E− / I−）

- **主軸（Tier S）**: 佐々木 + Bowlby
- **副軸（Tier S）**: アドラー + NVC
- **Tier A 第二推薦**: **Gottman + Siegel + ギノット**（感情の三段ロケット）
- 注意: Gottman の 5 ステップを「形式」に走らせず、Tier S の温度感を維持する

### 6.2 「環境・構造」型（S+ / I− / R−）

- **主軸（Tier S）**: モンテッソーリ
- **副軸（Tier S）**: ピクラー + Bowlby
- **Tier A 第二推薦**: **CPS（構造的実装）+ レッジョ（環境哲学）+ Vygotsky（ZPD）**
- 注意: Vygotsky は I+ 側なので、モンテッソーリの I− と組み合わせるときは「**ZPD は探求の足場であり、強制ではない**」と注釈

### 6.3 「自由・放牧」型（S− / I− / P−）

- **主軸（Tier S）**: 汐見
- **副軸（Tier S）**: ピクラー + 佐々木
- **Tier A 第二推薦**: **倉橋（汐見の源流）+ レッジョ（探究の自由）**
- 注意: 「放任」と紙一重 ── Tier S Bowlby + Tier A Ainsworth で応答性の歯止めをかける

### 6.4 「対等・勇気づけ」型（E− / I− / C 中立）

- **主軸（Tier S）**: アドラー
- **副軸（Tier S）**: NVC + Bowlby
- **Tier A 第二推薦**: **ポジティブ・ディシプリン（アドラー直系）+ ギノット + 成長マインドセット**
- 注意: ポジティブ・ディシプリンは家族会議など実装ツールを提供、成長マインドセットは E 軸の補強

### 6.5 「先取り・成果」型（P+ / I+ / E+ / S+）

- **主軸（Tier S）からの直接推薦は限定的**
- **Tier A 第二推薦**: **Vygotsky ZPD（I+ で対応可、ただし「先取り」と区別）+ 成長マインドセット（E+ → E− への入口）+ Baumrind authoritative（S+ への枠付け）**
- 注意: Tier C の早期教育系（ヨコミネ式・公文式・七田式）との両論併記、Bowlby + Gottman の土台を必ず併記

### 6.6 「ハイリスク・不安」型（R+ 強 / 親の自責が強い）

- **主軸（Tier S）**: 佐々木
- **副軸（Tier S）**: Bowlby（+ 専門家）
- **Tier A 第二推薦**: **Ainsworth（タイプは固定でない）+ Siegel（修復可能性）+ ポジティブ・ディシプリン（Mistakes are wonderful）**
- 注意: 専門家窓口の併記が必須、Tier A 単独で Plan B / 5 ステップに突入させない

## 7. 推薦アルゴリズムへの接続

[[docs/matcher/recommendation_v0]] のスコアリング関数で、Tier A スコアをどう使うか。

### 7.1 二層構造の推薦（Tier S 優先 + Tier A 補完）

親プロファイル（6 軸スコア）に対し、以下の順で推薦する:

1. **第一層 Tier S 推薦**: Tier S 7 理論から距離が近い 2-3 理論を提示
2. **第二層 Tier A 推薦**: Tier S 推薦と整合的な Tier A 理論を 1-2 提示
3. **整合チェック**: Tier A 推薦が Tier S 推薦と思想的に矛盾しないか（§3 の派生関係マップを参照）

例:
- 親プロファイル {R+1.5, S+0.5, I-0.5, E-1.0, P-0.5, C+0.5} の場合
- Tier S: Bowlby (R+2.0) + 佐々木 (R+2.0) + NVC (R+1.5, E-1.5)
- Tier A: **Gottman + Siegel + ギノット**（Tier S と整合する感情の三段ロケット）

### 7.2 Tier A 特化推薦パターン

特定の親ニーズで Tier A が主役になる場面:

- **「叱り方の言葉選び」を学びたい**: ギノット + 成長マインドセット + ポジティブ・ディシプリン
- **「子の癇癪・爆発」に対応したい**: Siegel + Gottman + CPS
- **「保育園選び・保育観の整理」**: レッジョ + Vygotsky + 倉橋
- **「愛着タイプを知りたい」**: Ainsworth + Bowlby（タイプ判定の危険を併記）
- **「しつけ哲学の整理」**: Baumrind + ポジティブ・ディシプリン + アドラー

## 8. 留意事項

1. **スコアは v0.1**: 実データ（100 ペルソナでの軸スコア分布）が出てから再キャリブレーション必要。
2. **成長マインドセットの E 軸特化**: R/S/I/P/C 中立で E のみ -2.0 は、マッチャーの距離計算で **「軸間の独立性を破る」** 可能性がある。E 軸の重み調整で扱う。
3. **Tier A は「Tier S と組み合わせる」前提**: Tier A 単独の距離計算は推奨しない。Tier S 推薦が決まった後の補完推薦として使う。
4. **エビデンス強度の差**: Gottman / Ainsworth / Baumrind / Vygotsky（研究厚）vs ポジティブ・ディシプリン / ギノット / レッジョ / 倉橋（実践知）── マッチャー結果画面で明示。
5. **文化差**: Tier A 11 理論のうち日本起源は倉橋のみ。米国 9 / 欧州 1 (Vygotsky) / 伊 1 (レッジョ)。**米国理論の比率が高い**ため、Tier S 汐見・佐々木と必ず組み合わせて文化バイアスを相殺する。
6. **年齢別の重み変動**: 0-1 歳では Ainsworth + Siegel + Gottman の重みが大きく、3-6 歳ではポジティブ・ディシプリン + ギノット + 成長マインドセット + CPS が大きくなる。Phase B で年齢セグメント別に再計算予定。
