# Tier S 7理論 統合レビュー

> 目的: ひだまりこそだち の知的バックボーン「Tier S」7理論（ボウルビィ / アドラー / NVC / モンテッソーリ / ピクラー / 汐見稔幸 / 佐々木正美）を、一枚絵で俯瞰する。
> 用途: マッチャー（親×理論診断）の理論バイアス把握、note 記事の理論的根拠の引き合い、ペルソナ別推薦の前提整理。
> 関連: [[tier_s_axis_mapping]]（6軸マッピング） / [[tier_s_persona_matrix]]（ペルソナ × 理論マトリクス） / [[tier_s_practice_index]]（実践シーン横断）

## 1. なぜこの 7 理論なのか

ひだまりこそだち が「親和性 ◎ 非常に高い」とした全理論のうち、**0-6 歳の家庭子育てに直接の翻訳可能性を持ち、現代日本の親が遭遇する困りごとに最短距離で接続できる** 理論として 7 つを Tier S に選定した。選定軸は次の三つ。

1. **0-6 歳のリアルな家庭シーンに対応するナラティブを持つ** ── 抽象論ではなく「夜泣き」「イヤイヤ期」「きょうだいゲンカ」「ごはん食べない」を扱える。
2. **「待つ・観察する・断言しない」のサービス基調と整合する** ── 早期成果や訓練を煽らない。
3. **海外 4 理論 + 日本 3 理論で文化的バイアスを相殺する** ── 西洋中産階級モデルだけに偏らないよう、日本の児童精神科医・保育学者・関係性理論を意図的に併置する。

7 理論は以下の通り（Bowlby は他理論の土台、Adler/NVC は関係性、Montessori/Pikler は環境、汐見/佐々木は日本の母語）。

## 2. 各理論の中核思想（300-500 字要約）

### 2.1 ボウルビィ アタッチメント理論 ── 「絆が探索の土台」

**世界は応えてくれる場所だ** という内的作業モデル (IWM) が、生まれてから 6 歳までの繰り返される応答的やりとりの中で子の中に形成される。これが将来の人間関係（友人・恋愛・職場・自分の子）の土台になる。中核概念は ①安全基地 ②内的作業モデル ③愛着行動システム ④ 4 類型（B/A/C/D）の 4 つで、Madigan 2024 のメタ分析は **父親の感受性も独立して効く** ことを示した。「3 歳までは母親が」は戦後日本独自の言説でボウルビィ自身の主張ではない。「敏感性 = 察し過剰」でもなく、サインを読んで応える力。Tronick 2007 の「3 分の 1 で十分」研究は、**完璧でなく修復可能であればよい** という現実的なメッセージ。父・祖父母・保育者など複数の愛着対象で支えるネットワーク発想は、ひだまりこそだち の「孤育ての解毒」テーマと直結する。**他の 6 理論すべての土台となる、最重要理論**。

### 2.2 アドラー心理学 ── 「縦の関係から横の関係へ」

人は他者とつながり貢献し所属したいという根源的欲求（共同体感覚）を持つ、という人間観から、**子を「未熟で教えられるべき存在」ではなく「対等な共同体の一員」として扱う** 関係観を導く。中核は ①共同体感覚 ②目的論 ③課題の分離 ④勇気づけ の 4 つ。「すごい」（評価・縦）ではなく「ありがとう、助かった」（貢献承認・横）、「えらいね」（上から）ではなく「やってみようと思ったんだね」（過程承認）。賞罰・命令・評価は縦、共感・尊敬・信頼・協力は横の関係。岸見一郎『嫌われる勇気』ブームで「課題の分離さえできれば楽になる」と単純化されたが、本質は「分離した上で協力する」── **分離 = 突き放しではない**。乳児期は Bowlby が土台、3 歳以降の関係性レイヤーで特に強力。日本での実践母体は野田俊作、岩井俊憲、ヒューマン・ギルド。

### 2.3 非暴力コミュニケーション (NVC) ── 「ジャッカル語をキリン語に翻訳する」

**すべての怒り・批判・暴力は、満たされていないニーズの悲劇的な表現である** という人間観のもと、対話の四要素 **OFNR（観察 → 感情 → ニーズ → 要求）** を提示する。子の「ご飯食べない！」を、わがまま（ジャッカル）ではなく「眠い・お腹いっぱい・自律したい」（ニーズ）と翻訳する。「ダメ！」と評価・命令する代わりに「おもちゃが床にある（観察）、私は焦ってる（感情）、リビングを片付けたい（ニーズ）、3 つだけ片付けてくれる？（要求）」と話す。ローゼンバーグ自身が晩年「Compassionate Communication」と改称したように、**形式 (OFNR) でなく姿勢 (intent) が本質**。「自己共感が先 → 相手への共感 → 正直な表現」の循環。日本の「察し文化」とは正面衝突しうるため、**察してもらうだけでなく言葉にも出す** 両立スタンスを取る。Adler と思想が共鳴し、Bowlby の敏感性概念とも接続する。

### 2.4 モンテッソーリ教育 ── 「Help me to do it myself」

子は **自己教育力 (auto-education)** ── 自分自身を発達させる内的プログラム ── を持って生まれる。大人の仕事は教えることではなく **「整えられた環境」を準備し、観察し、邪魔しないこと**。中核概念は ①自己教育力 ②敏感期（言語・秩序・運動・小さなもの・感覚・社会性、各 0-6 歳） ③整えられた環境 ④お仕事と集中現象 の 4 つ。「援助しすぎない援助者」が大人の理想像。Lillard & Else-Quest 2006 の Science 誌論文が代表的エビデンスだが、Marshall 2017 のレビューは「全体としての効果検証は乏しい」と慎重。注意点は **「教具を揃えなければ本物でない」式の商業化** と **「敏感期を逃すと取り戻せない」式の脅し**。家庭で再現可能なのは「日常生活の練習」領域（料理参加・着替え自立・決まった置き場所）。「家を子どもの家にする」のではなく「子のための一角を作る」が現実解。

### 2.5 ピクラー・アプローチ ── 「促さない・妨げない・尊厳ある世話」

ハンガリーの小児科医エミ・ピクラーが 1946 年、戦災孤児を養育するロッツィ乳児院で確立した 0-3 歳の関わり方。中核命題は **乳児は自分のペースで寝返り・座り・歩行を獲得する。大人が身体的に促す必要はない**。原則は ①自由な運動発達（うつ伏せ強制・歩行器・早すぎる座らせを避ける） ②尊厳ある世話（おむつ替え・着替え・授乳の時間こそが関係形成の中心、抱き上げる前に一言・応答を待つ） ③中断のない自由遊び ④観察ベースの関わり。「Pikler Triangle」など最低限の遊具と、仰向け・自由に動ける床面さえあればよい。マグダ・ガーバーが米国で「RIE / Educaring」として家庭向けに翻訳した（→ [[rie-gerber]]）。注意点は **「絶対に手を貸さない」と硬直化させない** こと。ピクラー本人は施設運営者であり、家庭の現実（ベビーカー・抱っこ紐・保育園）を否定する原典運用は避ける。Montessori と思想的近縁、Bowlby と相補（身体面 × 情緒面）。

### 2.6 汐見稔幸「子ども主体の保育」 ── 「保育の本質は放牧」

日本の保育学の第一人者（東京大学名誉教授、白梅学園大学元学長）。新保育所保育指針 (2017 改訂) の中核策定者の一人。**「保育の本質は放牧である」「子どもファースト」「保護者と保育者の共育て」** の三つが標語。子は内側に「やってみたい」を持って生まれる存在で、大人の仕事は **囲い込むのではなく、安全な範囲を確保した上で自由に動ける場を保証する** こと。「教えから学びへ」（2021 河出新書）では、知識を上から教える教育観から、子の生活と興味から学びが立ち上がる教育観への転換を説く。倉橋惣三の誘導保育、デューイの経験主義、Bank Street の発達相互作用論と思想的に同系列。**ひだまりこそだち の「指導でなく伴走」「共育て」というスタンスに最も近い日本の理論的母体**。Montessori/Pikler の「邪魔しない観察」の日本語訳としての性格も持ち、海外理論と日本の親をつなぐ橋渡し役。

### 2.7 佐々木正美「子どもへのまなざし」 ── 「過保護はあってよい、過干渉が問題」

新潟大学医学部卒の児童精神科医（1935-2017）。米国の自閉症支援プログラム TEACCH を日本に紹介した人物。1998 年刊『子どもへのまなざし』（福音館書店）は累計 100 万部超の子育て古典。中心思想は **エリクソンの発達段階論を日本の親に翻訳して届ける** こと ── 乳児期に育つのは基本的信頼、要求にていねいに応えてもらう体験から「世界は応えてくれる場所だ」という土台ができる。標語は ①過保護はあってよい、過干渉は問題 ②育てたように子は育つ（相田みつをから） ③ 待つ・信じる・応える。**「過保護 (子の要求に応える) と過干渉 (子が求めていないことを先回りする) の線引き」** は、戦後日本の「抱き癖」言説を解毒する力を持つ。Bowlby の応答性理論を日本語の温度感で語り直したもの。注意点は「育てたように子は育つ」が「すべて親のせい」と自責ループに転じる危険 ── 佐々木本人の真意は **「関わりを変えれば子も変わる、希望はある」** という励まし。

## 3. 7 理論の対立軸

7 理論は「子を尊重し、待ち、罰しない」という大方針では一致するが、内部に重要な対立軸を持つ。これを理解しないと、混ぜたときに矛盾するメッセージを出してしまう。

### 3.1 介入度（積極的に環境を組むか / 自然に任せるか）

```
高介入 ←──────────────────────────────→ 低介入
モンテッソーリ │ ピクラー │ Bowlby │ Adler/NVC │ 汐見 │ 佐々木
```

- **Montessori** は最も介入度が高い ── 教具・棚配置・大人の振る舞いまで設計する。
- **Pikler** は身体面では低介入（促さない）だが、世話の場面では高介入（一言ずつ声をかける）。
- **Bowlby/Adler/NVC** は関係性に介入するが、物理環境には言及しない。
- **汐見/佐々木** は最も低介入で、日常そのものを大切にする。

### 3.2 主導権（親が示すか / 子に委ねるか）

```
親主導 ←──────────────────────────────→ 子主導
（ほぼ全理論が中央〜子主導側）
Adler │ Bowlby │ NVC │ 佐々木 │ 汐見 │ Montessori │ Pikler
```

7 理論は全体として「子主導」寄りに分布している（だからこそ Tier S）。ただし **Adler は「対等」── 親が完全に降りるのでなく、横に並ぶ** という独特の立ち位置。**Pikler は最も子主導**（乳児に促しすらしない）。

### 3.3 年齢適用範囲

```
0歳 ─────────── 3歳 ─────────── 6歳 ─────────── 学齢期
Pikler │ 佐々木 │ Bowlby │ Montessori │ 汐見 │ Adler/NVC
```

- **Pikler** は 0-3 歳特化、6 歳以降は適用しにくい。
- **Bowlby** は乳幼児期中心だが、生涯にわたる愛着の理論。
- **Adler/NVC** は子の言語発達が一定進んでからのほうが効く（3 歳以降が中心）。
- **Montessori** は 0-18 歳の全段階を持つが、ひだまりこそだち の関心は 0-6 歳。
- **佐々木/汐見** は 0-6 歳全域。

### 3.4 文化背景

```
西洋（個別自立）    ───      日本（共同体）
Pikler │ Montessori │ NVC │ Bowlby │ Adler │ 汐見 │ 佐々木
```

- **Pikler/Montessori** は西洋中産階級の「個と境界」を前提とする。
- **NVC** は米国だが「ニーズの普遍性」を主張、文化的にはやや中立。
- **Adler** は欧州起源だが共同体感覚を中核に据える、文化的に折衷的。
- **Bowlby** は西洋起源だが Rothbaum 2000 等で日本研究と接続済み。
- **汐見/佐々木** は日本起源、日本の親の現実感覚に最も近い。

### 3.5 エビデンス強度

```
強 ←──────────────────────────────→ 弱
Bowlby │ Montessori │ Adler │ Pikler │ NVC │ 汐見/佐々木（実践知）
```

- **Bowlby** は最強（Madigan 2024 のメタ、Sroufe 2005 の 30 年追跡など）。
- **Montessori** は Science 誌の RCT があるが Marshall 2017 が慎重論を出す。
- **Adler** は近接領域（賞賛研究、しつけ研究）から間接的に支持される。
- **NVC** は大規模 RCT なし、パイロット研究中心。
- **汐見/佐々木** は実践知・臨床知であって、RCT エビデンスではない。

ひだまりこそだち は **エビデンス強度を誇張せず、実践知と区別して提示する** スタンスを取る。

## 4. 7 理論の補完関係

各理論は単独では穴を持つが、組み合わせると補完する。

### 4.1 基礎レイヤー: Bowlby（応答性・修復可能性）

すべての関わりの土台。**ここが崩れていると、他の 6 理論はどれも機能しない**。乳児期の応答性、世代間連鎖の解毒、修復可能性の哲学を提供する。Adler/NVC の「対等」「キリン語」も、Bowlby の安全基地が前提でないと表面的なテクニックに陥る。

### 4.2 環境レイヤー: Montessori + Pikler

物理環境と身体の扱いを担当。Montessori が「子サイズの家具・整理整頓・選択肢のある棚」を、Pikler が「促さない身体・尊厳ある世話・自由な動き」を提供する。**0-3 歳は Pikler、3-6 歳は Montessori** の重み付けが現実的。

### 4.3 関係性レイヤー: Adler + NVC

声かけと対話の質を担当。Adler が「横の関係・勇気づけ・課題の分離」という関係観を、NVC が「OFNR・感情とニーズの語彙」という具体的な対話技法を提供する。**Adler が方向感、NVC が実装** という関係。両者は思想的に強く共鳴する。

### 4.4 日本翻訳レイヤー: 汐見 + 佐々木

海外 5 理論を日本の親の生活感覚に翻訳する。汐見が「保育の本質は放牧」「共育て」で関係性の社会的側面を、佐々木が「過保護 OK / 過干渉 NG」で日々の判断基準を提供する。**この層が薄いと、海外理論がそのまま入って親を追い詰める**。

### 4.5 推奨される組み合わせパターン

| 場面 | 主軸 | 副軸 |
|---|---|---|
| 0-1 歳・夜泣き / 授乳 | Bowlby | Pikler / 佐々木 |
| 1-3 歳・イヤイヤ期 | Adler | NVC / Montessori |
| 0-3 歳・身体発達 | Pikler | Bowlby |
| 3-6 歳・きょうだいげんか | NVC | Adler |
| 3-6 歳・お手伝い / 自立 | Montessori | 汐見 |
| 親自身の自責 | 佐々木 | Bowlby |
| 保育園選び・共育て | 汐見 | Bowlby |
| ハイリスク家庭 | Bowlby（+ 専門家） | 佐々木 |

詳細は [[tier_s_practice_index]] と [[tier_s_persona_matrix]] を参照。

## 5. ひだまりこそだち の立ち位置（折衷的、特定流派に与しない）

### 5.1 基本姿勢

ひだまりこそだち は **特定の流派に「入信」しない**。Tier S の 7 理論は **「装備品の品揃え」** であって「教義」ではない。コンテンツ作成時は、その記事・その場面・その親に **最も役立つ理論を組み合わせて使う**。

### 5.2 折衷の原則

1. **基礎は Bowlby**：すべての記事は「安全基地・応答性・修復可能性」と矛盾しない。
2. **声かけは Adler + NVC**：「すごい」より「ありがとう」「やってみたんだね」、「ダメ」を OFNR で言い換える。
3. **環境は Montessori + Pikler**：子サイズ・整理・促さない。
4. **日本語の温度は 汐見 + 佐々木**：「過保護 OK」「放牧」「育てたように」の言葉を引き合いに出す。
5. **文化バイアスを併記**：西洋理論（Bowlby/Adler/NVC/Montessori/Pikler）を出すときは、必ず日本研究（Rothbaum 2000, Behrens 2016 など）の文化差注釈を添える。

### 5.3 与しない流派・読み方

- **「3 歳までは母親が」式の母性主義** ── Bowlby 自身の主張でなく、戦後日本独自の言説。明確に否定する。
- **「教具を揃えなければモンテッソーリでない」式の商業化** ── Montessori 原典からの逸脱。
- **「すべて勇気の問題」「課題の分離さえできれば楽」式のアドラー単純化** ── 岸見一郎ブーム以後の解釈に与しない。
- **「ジャッカル = 悪、キリン = 善」式の NVC 二元論** ── Rosenberg 晩年の Compassionate Communication への改称を尊重する。
- **「育てたように子は育つ → すべて親のせい」式の自責読み** ── 佐々木本人の真意（励まし）から外れる。
- **「敏感期を逃すと取り戻せない」式の脅し** ── 脳の可塑性研究からも誇張。

### 5.4 サービス名「ひだまりこそだち」との対応

- 「**陽だまり**」= **Bowlby** の安全基地、**佐々木** の温かいまなざし、**ポリヴェーガル** の腹側迷走神経（安心）
- 「**子育ち**」= **Montessori** の自己教育力、**Pikler** の自分のペース、**汐見** の放牧
- 「**子育て**」= **Adler** の横の関係、**NVC** のキリン語、**汐見** の共育て

7 理論は 3 つの語彙それぞれの背後にバランスよく分散しており、**ブランド名そのものが Tier S の縮図** になっている。

## 6. 横断的に通底するメッセージ

7 理論が共通して発しているメッセージを、ひだまりこそだち の声で要約すると次のようになる。

1. **子は教えられて育つのではなく、応えられて育つ**（Bowlby + Montessori + Pikler + 佐々木 + 汐見）
2. **完璧でなくていい、修復できればよい**（Bowlby Tronick + Adler + NVC + 佐々木）
3. **「困った行動」は絆 or 発達 or ニーズのサインと読み替える**（Bowlby + Adler + NVC + 佐々木）
4. **賞罰・命令でなく対等な関係で関わる**（Adler + NVC + Pikler + 汐見 + 佐々木）
5. **母親一人で抱え込まない。複数の大人・地域・社会で支える**（Bowlby + Adler + 汐見）
6. **早期化・先取りより、今この子の発達段階に応える**（Montessori 敏感期 + 佐々木 + 汐見）
7. **親自身を勇気づける。「いい親」を降りる**（Adler + NVC + 佐々木 + 信田、後者は Tier A）

## 7. Tier S の運用ルール（ひだまりこそだち 編集ガイド）

1. **note 記事の理論引き合いは原則 Tier S 7 理論から選ぶ**。Tier A 以下を引くときは、Tier S のどれかと組み合わせる。
2. **1 記事で複数の Tier S 理論を引くときは、対立軸（§3）を意識する**。組み合わせ方は §4 を参照。
3. **海外理論を引くときは必ず日本文化文脈の注釈**（佐々木 / 汐見 / Rothbaum 等）を添える。
4. **「絶対」「必ず」「正解」を避ける**。7 理論はすべて「正解の押し付け」を避ける哲学を共有しているため、ひだまりこそだち の語り口もそれに整合させる。
5. **エビデンス強度の差異を明示する**。Bowlby/Montessori（研究厚） vs NVC/汐見/佐々木（実践知）を混同しない。
6. **ハイリスク家庭（DV / トラウマ / 精神疾患併存）には Tier S を直接適用しない**。専門家窓口を必ず併記する（Bowlby controversies の警告に従う）。
