# RIE（アール・アイ・イー / Resources for Infant Educarers）

## 1. 一行サマリ
赤ちゃんは「お客様」ではなく「一人の人」。急がせず・邪魔せずに見守る関わり方。

## 2. 中核思想
RIE（Resources for Infant Educarers）は、1978年にハンガリー出身のマグダ・ガーバーが米ロサンゼルスで小児科医トム・フォレストと共同設立した、乳児（0〜2歳）への関わり方を体系化した思想です。彼女の師は[[pikler|ピクラー・アプローチ]]の創始者エミ・ピクラー。RIEは**ピクラーの考えを家庭で実践可能な形に翻訳した米国版**と位置づけられます。

ガーバーは「教える（educate）」と「世話する（care）」を分けずに「**Educaring（エデュケアリング）**」という造語を作りました。乳児の世話の時間（おむつ替え・授乳・着替え・お風呂）こそが、もっとも濃密な学びと関係形成の場である、という発想です。

中核にあるのは**尊重（Respect）**。「赤ちゃんを一人の人として、抱き上げる前に声をかけ、本人に直接語りかけ、応答を待つ」というシンプルな姿勢です。さらに、（1）赤ちゃんを**主体的な探究者**として信頼する、（2）**邪魔しない自由な遊び**の時間を保証する、（3）**観察**を中心に据える、（4）**明確で一貫した枠**を示す──といった原則が連なります。「早く立たせる」「もっと刺激を」と急かさず、赤ちゃん自身のペースを信じます。

## 3. 子どもの捉え方
生まれた瞬間から**有能な学び手**。「教えないと何もできない無力な存在」ではなく、自ら動き・探り・学ぶ主体として見ます。

## 4. 大人（親・保育者）の役割
**観察者**であり、**世話の時間にていねいに応答する人**。促す人ではなく、安全な環境を整えて見守る人。世話のときには「いまおむつを開けるね」「腕を上げてくれる？」と一言ずつ声をかけ、子どもを「世話される対象」ではなく「協力するパートナー」として扱います。

## 5. 環境・道具
- 体に対して**広すぎず狭すぎない**、安全に動き回れる空間。
- 機能が決まりすぎていない**シンプルな素材**（布・木のおもちゃ・カップなど）。
- 体を反らせない**仰向け**を基本姿勢に。バウンサーやベビーチェアに長時間入れない。
- 「Pikler Triangle（よじ登り三角）」など、子の自由な運動を支える遊具。

## 6. 0-6歳の実践イメージ
- シーン1: おむつ替えの前に「いまおむつ替えるよ」と声をかけ、赤ちゃんが目を合わせるのを少し待ってから抱き上げる。
- シーン2: 床に寝かせた赤ちゃんが布や木のカップで一人遊びしているとき、つい話しかけたくなるのを我慢して**そっと観察**。集中の時間を尊重する。
- シーン3: つかまり立ちをしたがる10か月の子に、立たせて支えるのではなく、自分で掴める高さの安定した台のある環境を用意する。

## 7. ひだまりこそだち との接点

**共感する点**
- **赤ちゃんを一人の人として扱う**という尊厳の出発点：「ものを言わない＝何も分からない」ではない、という前提が共有できる。
- 「**急がない・邪魔しない**」という関わり方：早期教育の煽りへの強力な対抗軸になる。
- 世話の時間そのものが関係形成という発想：[[attachment|アタッチメント]]と地続き。

**距離を置く点**
- 「**邪魔しない**」を厳格に運用すると、親が**話しかけることに罪悪感**を持ってしまう。RIEは「無言の育児」を勧めているわけではなく、**世話の時に直接語りかけること**を強く推奨している。沈黙の哲学ではない、という誤解に注意。
- 「バウンサー・抱っこ紐は使わない」と原典に忠実すぎると、現代日本の家事育児両立の現実と衝突する。

**取り入れたい要素**
- おむつ替え・着替えの**一言の声かけ**（「いま手を入れるね」）。
- 赤ちゃんが何かに集中しているときの「**話しかけずに見守る**」選択肢を持つ。
- うつ伏せ強制・歩行器・早すぎる座らせ──こうした「促し」を**急がない**視点。

## 8. 親が陥りがちな誤解
- **「抱っこは控えるべき」**：RIEは抱っこ自体を否定していない。「**むやみに抱き上げない**」と「抱っこしない」は別。応答する抱っこは尊重の一部。
- **「話しかけてはいけない」**：原則は逆で、世話の場面では**直接子に向かって語りかける**ことが推奨される。「邪魔しない」は遊びの集中時の話。
- **「ピクラーの教具を揃えないと始まらない」**：道具は副次的。**観察と尊重の態度**が本体。
