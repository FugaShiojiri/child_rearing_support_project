# ゴットマン感情コーチング ─ 実践シーン集（0-6歳）

各シーンは **「場面 → 親のメタ感情の自己観察 → 5ステップでの応答 → 注意点」** の4ブロック。家庭で疲れた親が **5ステップ全部を毎回やる必要はない** ── ゴットマン自身が「**3割の場面で coaching できれば子の発達には十分**」と述べているため、**今日は1ステップだけ** という姿勢で読んでください。

ゴットマンの **5ステップ**（再掲）：
1. **気づく**：子の感情に気づく
2. **機会と捉える**：親密と学びの機会と読み替える
3. **共感的に聴く**：解決を急がず、まず感情を受ける
4. **ラベリングを助ける**：感情に言葉を与える
5. **限界＋問題解決**：行動の限界を示し、次の解決を一緒に考える

ゴットマンの **4タイプの親**（再掲）：
- **Dismissing**：軽視・否認（「**そんなことで**」）
- **Disapproving**：不承認・叱責（「**いつまで泣いてるの**」）
- **Laissez-Faire**：放任・受容過剰（「**好きなだけ泣いて**」のみで終わる）
- **Emotion-Coaching**：感情 OK ＋ 行動限界（理想形）

---

## シーン1：積み木が崩れて泣き叫ぶ（5ステップの基本形）

**場面**：3歳、夢中で積み上げていた積み木が崩れて泣き叫び、残った積み木を投げ始める。

**親のメタ感情の自己観察**：「**こんなことで…**」と思いそうになる → これは Dismissing の信念。自分が子の時、悔しさを否定された経験があるかも、と一拍置く。

**5ステップでの応答**：
- ①気づく：「いま、怒り＋悲しみ＋悔しさ」
- ②機会と捉える：「**面倒**」でなく「**ここで一緒に感情を扱える**」
- ③共感：「**うわ、崩れちゃったね。それは悔しいよね**」
- ④ラベリング：「**「悔しい」って気持ち**。せっかく作ったのに、ね」
- ⑤限界＋解決：「**投げるのはダメ**（限界）。**もう一回作る？それともお休みする？**（次の選択）」

**注意点**：3歳には5ステップを全部はやらない。**「悔しいよね（共感）＋投げるのはダメ（限界）」だけで十分**。落ち着いてから「もう一回作る？」を提案する順番が大事。

## シーン2：「Dismissing → Coaching」への変換（最も頻度の高い置き換え）

**場面**：4歳、お友達におもちゃを取られて泣く。「**そんなことで泣かないの**」と言いそうになる。

**親のメタ感情の自己観察**：「**そんなことで**」は **Dismissing の典型台詞**。自分の親が同じ言葉を使ったかも。それを引き継いでいないか、と気づく。

**5ステップでの応答**：
- ×「**そんなことで泣かないの！**」（Dismissing）
- ○「**取られたんだね。悲しかった**」（③共感 ＋ ④ラベリング）
- ○「**どうしたい？**（⑤次の選択）」

**注意点**：「そんなことで」は **大人の物差し**。3歳にとって、おもちゃを取られることは **世界が崩れるレベルの出来事**。物差しを子の世界に合わせる。

## シーン3：「Disapproving → Coaching」への変換（怒りの感情を罰しない）

**場面**：5歳、弟に怒鳴って「**バカ！嫌い！**」と叫んだ。「**そんなこと言うなんていい子じゃないよ**」と返しそうになる。

**親のメタ感情の自己観察**：「**怒り＝悪い感情**」と思っていないか。自分は怒ってはいけないと育てられたか。子の怒りに、自分の怒りが触発されていないか。

**5ステップでの応答**：
- ×「**そんなこと言うなんてダメ！いい子じゃない！**」（Disapproving）
- ○「**怒ってるんだね。何があった？**」（③共感）
- ○「**怒っていいよ。怒るのは悪いことじゃない**」（④ラベリング、感情の許可）
- ○「**でも「バカ」「嫌い」って言われると弟は悲しい。「やめて」「あっち行って」って言える？**」（⑤限界＋代替案）

**注意点**：「**怒り**」と「**怒りの表現**」を分ける。**感情そのものは OK、表現方法に限界を設ける**。これがゴットマンの二段構造の核。

## シーン4：「Laissez-Faire からの脱却」（受容だけで終わらない）

**場面**：3歳、保育園で嫌なことがあって帰宅後ずっと泣いている。「**好きなだけ泣いていいよ**」と言って、横でスマホを見ている。

**親のメタ感情の自己観察**：「**受け入れることだけが大事**」と思い込んでいないか。「**何もしない受容**」は実は **放置** に近い。

**5ステップでの応答**：
- ×（「好きなだけ泣いていいよ」で終わって離れる：Laissez-Faire）
- ○「**好きなだけ泣いていいよ。ママ／パパはここに居るよ**」（③共感＋身体的同伴）
- ○（少し落ち着いたら）「**何があったの？**」（④ラベリング誘導）
- ○「**今度同じことがあったら、どうしたい？**」（⑤一緒に考える）

**注意点**：受容は **「同伴」とセット**。横に居ること、目を合わせること、必要なら触れること。子は **「感情を見てもらった」** ことで初めて次のステップに進める。

---

## シーン5：朝の登園拒否（感情とスケジュールの両立）

**場面**：4歳、月曜の朝、「**保育園行きたくない！**」と玄関で動かない。出勤時間が迫る。

**親のメタ感情の自己観察**：「**焦り**」と「**罪悪感**」が混ざる。**自分の焦りを子のせいにしていないか**、一拍置く。

**5ステップでの応答**：
- ×「**わがまま言わないで！早く！**」（Disapproving）
- ○「**行きたくないんだね**」（③共感）
- ○「**何かあった？それともなんとなく？**」（④原因のラベリング）
- ○「**行きたくない気持ちは本当のことだね**（感情 OK）。**でも今日は行く日**（行動の限界）。**車の中で続き話そう？それとも保育園着いたら先生にも言う？**」（⑤次の選択）

**注意点**：**感情を受け止めても、行動の選択は親が決めていい**。「気持ちを受け止める＝行かなくていい」ではない。これも Laissez-Faire 型との分岐点。

---

## シーン6：恐れの感情（怖い・不安）

**場面**：5歳、夜寝る時に「**お化けが怖い、一人で寝れない**」と泣く。「**お化けなんていないよ**」と返しそうになる。

**親のメタ感情の自己観察**：「**現実的にはお化けはいない**」という理性で説得しようとしていないか。**子にとって恐れは身体感覚として現実**。

**5ステップでの応答**：
- ×「**お化けなんていないでしょ、何回言ったらわかるの**」（Dismissing）
- ○「**怖いんだね**」（③共感）
- ○「**「怖い」って気持ち、ママも子供の時あったよ**」（④ラベリング＋親自身の経験を共有）
- ○「**じゃあ、ぬいぐるみと一緒に寝る？それとも電気を少しつけておく？**」（⑤一緒に対策）

**注意点**：**恐れを論理で消そうとしない**。「いない」と言われても消えないのが恐れ。**身体的な安心の手段**（電気・ぬいぐるみ・短時間の同伴）で対応する。ポリヴェーガル理論の **共同調整** とも重なる実践。

## シーン7：羨望・嫉妬の感情（複雑感情のラベリング）

**場面**：4歳、お友達が新しいおもちゃを持ってきた。家に帰ってから「**○○ちゃんずるい！**」と機嫌が悪い。

**親のメタ感情の自己観察**：「**そんなこと言うんじゃない**」（Disapproving）と返したくなる。**羨望は親自身も扱いにくい感情**だから。

**5ステップでの応答**：
- ×「**お友達が持ってるからってずるいなんて、いやしいこと言うんじゃない**」
- ○「**○○ちゃんの新しいおもちゃ、いいなって思ったんだね**」（③共感＋④ラベリング）
- ○「**「いいな」って気持ち、誰でもあるよ。それは「うらやましい」って気持ち**」（④複雑感情のラベル）
- ○「**でもお友達のものを取ったり、ずるいって本人に言うのはダメ**（限界）。**おうちで何して遊ぼうか？**」（⑤切り替え）

**注意点**：**羨望・嫉妬・気まずさ・誇り** など複雑感情に **正しい名前** を与えるのは、感情コーチングの中核。Lisa Feldman Barrett の **emotional granularity（感情の粒度）** 研究で、感情語彙が豊富な子・大人ほど **精神病理・身体症状が少ない** ことが示されている。

## シーン8：兄弟げんか（同時に2人の感情をコーチ）

**場面**：5歳と3歳、おもちゃの取り合いで両方泣いている。

**親のメタ感情の自己観察**：「**お兄ちゃんなんだから譲りなさい**」を言いたくなる → これは Ginott が警告した **役割の押し付け**。同時に **2人の感情を別々に扱う** 練習。

**5ステップでの応答**：
- ×「**お兄ちゃんなんだから貸してあげなさい！**」
- ○「**○○くん（兄）は、まだ使ってたのに取られて悲しいんだね**」（兄への③共感＋④ラベリング）
- ○「**△△ちゃん（弟）は、それで遊びたかったんだね**」（弟への③共感＋④ラベリング）
- ○「**取り合いはやめよう**（限界）。**どうしたら2人とも使えそう？**」（⑤一緒に考える）

**注意点**：兄弟げんかで親が **裁判官** になると、関係が固定化する。**両方の感情を独立に受ける** → **解決は子に返す**、が Gottman ＋ Faber&Mazlish 共通の発想。

## シーン9：失望・がっかり（結果が思う通りにならなかった時）

**場面**：5歳、保育園の発表会で歌を間違えた。帰宅後ずっと黙っている。

**親のメタ感情の自己観察**：「**そんなの気にしなくていいよ、上手だったよ**」と慰めたくなる → これは **感情の上書き**。Dismissing の柔らかい形。

**5ステップでの応答**：
- ×「**気にしなくていいよ、ちゃんとできてたよ**」
- ○「**ずっと静かだね。何か考えてる？**」（①気づく＋③共感）
- ○（子が話したら）「**そっか、間違えたのが悔しかったんだね。それは「がっかり」って気持ちかな**」（④ラベリング）
- ○「**ママ／パパも、大事な時に失敗して悔しかったことあるよ**」（同伴）
- ○「**次の発表会、どんなふうにしたい？**」（⑤未来への接続）

**注意点**：**慰めは早すぎると感情を消してしまう**。**まず感情を見届ける** → **それから前向きな話**、の順番。失望・がっかりは **複雑感情** で、子はまだ名前を持っていないことが多い。

## シーン10：親が爆発しそうな時（自己コーチング）

**場面**：1日中ワンオペ、夫が帰ってこない、子は泣き止まない。自分が泣きそうで、子に怒鳴りそう。

**親のメタ感情の自己観察**：これがゴットマン感情コーチングで **最も重要な瞬間**。「**親が自分の感情をどう扱うか**」を子は見ている（モデリング）。

**5ステップを「自分に」適用**：
- ①気づく：「**自分はいま、限界に近い**」
- ②機会と捉える：「**ここで自分の感情を扱う姿を子に見せられる**」
- ③共感（自己）：「**疲れた。当然だ**」
- ④ラベリング（自己）：「**これは「消耗」と「無力感」**」
- ⑤限界＋解決：「**子を傷つけないこと**（限界）。**3分だけソファで深呼吸する**（解決）」

**子への声かけ**：「**ママ／パパは今、すごく疲れてる。あなたのせいじゃないよ。3分だけソファに座らせて。終わったら戻ってくるね**」

**注意点**：これは「**子に親を励まさせる**」ではない。**「親も感情を持っている人」というモデルを見せる**。Eisenberg (2020) の **三要素モデル** のうち「**親のモデリング**」経路。

## シーン11：子のうそ（うそも感情の表現として読む）

**場面**：4歳、お菓子を勝手に食べたのに「**食べてない**」と言う。

**親のメタ感情の自己観察**：「**うそつき！**」と即座にラベルしたくなる → Disapproving の典型。**「うそ」の背後にある感情**（怒られたくない・恥ずかしい）を見落としていないか。

**5ステップでの応答**：
- ×「**うそつくな！正直に言いなさい！**」
- ○「**袋が開いてて、3つ減ってるね**」（事実の描写：ジノットと共通）
- ○「**食べたくなったんだね。怒られると思って言えなかった？**」（③感情の推測＋④ラベリング）
- ○「**食べる前に「食べたい」って言ってほしかったな**（限界）。**今度はそうしてみる？**」（⑤次の選択）

**注意点**：**「うそをついた」を人格断定しない**。「**怒られたくない**」「**恥ずかしい**」という感情を扱うと、うそをつかなくていい関係が育つ。ジノット・Faber&Mazlish と完全一致の実践。

## シーン12：「気持ちは OK、行動は限界」の完全形（噛みつき）

**場面**：2歳、おもちゃを取られて、お友達を噛んだ。

**親のメタ感情の自己観察**：「**他人を傷つけた**」という衝撃で、Disapproving モードに入りやすい。一拍置く。

**5ステップでの応答**：
- ×「**噛んじゃダメでしょ！悪い子！**」
- ○（まず身体的に止める：安全優先）「**噛むのはダメ**（限界）」
- ○「**取られたくなかったんだね、怒ったんだね**」（③共感＋④ラベリング）
- ○「**でも噛むのはダメ**（限界の再確認）。**お友達痛かったよ**（事実）」
- ○「**今度取られそうな時は、「ダメ！」って大きい声で言おう**」（⑤代替行動）

**注意点**：2歳には複雑な説明は届かない。**「翻訳1文 + 限界1文 + 代替1文」の3文構造**（ジノットと共通）。**身体的に止める** ことが最優先。言葉は止めた後で。

## まとめ：3割で十分という心構え

12シーン全部を毎回やる必要はありません。ゴットマン自身が **「親が3割の場面で coaching できれば、子の長期的な発達には十分」** と述べています（『Raising an Emotionally Intelligent Child』）。

ひだまりこそだち として推奨する **取り組み方の順序**：

1. **今週は「①気づく」だけ**：子の感情に気づくこと、それだけ。応答は今まで通りでいい。
2. **来週は「③共感」だけ追加**：「**○○なんだね**」を1日1回試す。
3. **慣れてきたら「④ラベリング」を追加**：複雑感情（悔しい・がっかり・羨望）に名前を貸す。
4. **最後に「⑤限界＋解決」**：「行動はダメ、でも気持ちは OK」のセット。

**5ステップを順番に体に入れる** ── これが TIK プログラムでもベースとなっている学び方です。1日1ステップ・1週間1ステップ・1ヶ月1ステップ、どれでも構いません。「**できなかった日**」も同じくらい大事 ── そこで自分を責めずに、**自分にも感情コーチング** を適用してください（シーン10）。
