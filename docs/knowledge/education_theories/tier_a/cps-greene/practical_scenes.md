# CPS ─ 実践シーン集（0-6歳）

各シーンは「**場面 → CPS的解釈（ラグドール／未解決問題） → Plan B の3ステップ（共感 → 大人の懸念 → 招待） → 注意点**」の4ブロック構成。家庭で疲れている親が、その場で1つだけ選べる形で書いています。**重要**：Plan B は **穏やかな時間に proactive に** 行うのが原則。爆発の最中はまず安全確保（Plan C で棚上げ）、対話は後日。

---

## シーン1：朝の着替え

**場面**：4歳。「早く着替えなさい！」で毎朝大泣き → 親も怒る → 遅刻、の繰り返し。

**CPS的解釈**：
- 未解決問題：「平日朝の保育園出発前の着替え」
- ラグドール候補：気持ちの切り替えスキル（遊びから次の活動へ）、時間感覚の未獲得、感覚過敏（服のタグ・素材）

**Plan B**：
- **共感**：（夜寝る前に）「最近、朝の着替えで何が嫌？」── 沈黙を恐れず待つ。
- **大人の懸念**：「ママは保育園に遅れちゃうのが心配なんだ」
- **招待**：「2人とも気持ちよく朝が過ごせる方法、何かない？」 → 子「パジャマで朝ごはん食べてから着替えたい」「タグのないTシャツがいい」

**注意点**：「早く！」（Plan A）を全否定しない。本当に時間がないときは Plan A も可。**前夜に話す** が肝心。

## シーン2：公園からの帰宅

**場面**：3歳。「帰るよ」で毎回床に寝転がって癇癪。「もう連れて行かない」と脅す自分が嫌。

**CPS的解釈**：
- 未解決問題：「公園から家に戻る移行」
- ラグドール候補：移行スキル、予測の未獲得、楽しい活動を中断する欲求不満耐性

**Plan B**：
- **共感**：（次の日の朝に）「昨日、公園から帰るとき泣いてたね、何が嫌だった？」
- **大人の懸念**：「ママは時間になっても帰れないと夕飯の準備ができなくて困るんだ」
- **招待**：「どうしたら、2人とも気持ちよく帰れる？」 → 子「滑り台あと3回って言ってほしい」「タイマー鳴らしてほしい」

**注意点**：癇癪の最中に「Plan B やろう」は無理。爆発の最中は **抱きしめて待つ**（Plan C 棚上げ）→ 落ち着いた後日に共感ステップ。

## シーン3：歯磨き拒否

**場面**：2歳。歯磨きを毎晩拒否。押さえつけて磨いて、互いに泣く。

**CPS的解釈**：
- 未解決問題：「夜の歯磨き」
- ラグドール候補：感覚過敏（口腔内）、自分のペースを保つスキル、見通しの未獲得

**Plan B**（2歳でも観察できる）：
- **共感**：日中「歯磨きのとき、何が嫌？」── 言葉が出にくければ親が候補を出す。「歯ブラシの感触？水の味？仰向けが嫌？」
- **大人の懸念**：「虫歯になると痛いから心配なんだ」
- **招待**：「どんな歯磨きならできそう？」 → 子「自分でやる」「お風呂で立って磨く」

**注意点**：安全に関わる場面（虫歯リスクが高い）は **Plan A を併用** することもある。「自分で磨く → 親が仕上げ」の二段構えが現実解。

## シーン4：きょうだいゲンカ（おもちゃ）

**場面**：5歳と3歳。同じおもちゃの取り合いで毎日衝突。「お姉ちゃんでしょ、貸してあげなさい」が常套句に。

**CPS的解釈**：
- 未解決問題：「人気のおもちゃ1個に2人が同時にアクセスしたい」
- ラグドール候補：交渉スキル、待つスキル、欲求不満耐性、心の理論（相手の視点）

**Plan B**：
- **共感**：（喧嘩の数時間後に）「○○ちゃんと△△ちゃん、車のおもちゃで毎日もめてるね。何が嫌？」── 別々に聞いてもいい。
- **大人の懸念**：「2人が叩き合うのを見てるのがママは辛いんだ」
- **招待**：「2人がもめないで遊べる方法ない？」 → 子たち「タイマーで交代」「もう1個買ってもらう」「曜日で分ける」

**注意点**：「お姉ちゃんなんだから」（縦の関係）は CPS 的にも アドラー的にも NG。**両者を対等な交渉相手として扱う**。

## シーン5：食事を食べない／偏食

**場面**：3歳。トマト・ピーマンを食べない。「一口だけ！」と懇願する自分が嫌。

**CPS的解釈**：
- 未解決問題：「特定の野菜を食卓に出されること」
- ラグドール候補：感覚処理（食感・味覚）、見通しのなさ（食べたことがない＝予測できない＝不安）

**Plan B**：
- **共感**：（食事の場面でなく別の日に）「最近トマト残してるね、何が嫌？」 → 「ぐにゃっとしてて嫌」
- **大人の懸念**：「ママは野菜の栄養が偏らないか心配なんだ」
- **招待**：「どんなトマトなら食べられそう？」 → 「焼いたトマトならOK」「ミニトマトの皮なしなら」

**注意点**：「食べる量は子の課題」（Ellyn Satter の分業）と組み合わせる。Plan B は **食材の出し方** の交渉で、食べる量の強制ではない。

## シーン6：お風呂を嫌がる

**場面**：2歳。「お風呂入るよ」で号泣。

**CPS的解釈**：
- 未解決問題：「日中の遊びを中断してお風呂に行くこと」
- ラグドール候補：移行スキル、感覚過敏（水温・髪を洗うときの目に入る水）、見通しの未獲得

**Plan B**：
- **共感**：別の時間に「お風呂で何が嫌？」 → 言葉が出なければ親が観察を述べる。「シャワー怖いみたいだね」
- **大人の懸念**：「ママは体が清潔じゃないと肌が荒れちゃうから心配」
- **招待**：「どんなお風呂ならOK？」 → 「シャワーじゃなくて湯船」「おもちゃ持って入る」「目に水入らないように顔は別で拭く」

**注意点**：感覚過敏は **本当の身体反応** で、わがままではない。「我慢して入って」は Plan A の限界。

## シーン7：登園拒否（4歳）

**場面**：4歳。「保育園行きたくない」が3週間続く。理由を聞いても「わからない」「行きたくない」のみ。

**CPS的解釈**：
- 未解決問題：「平日朝の保育園登園」
- ラグドール候補：気持ちを言葉にするスキル、不安の処理スキル、特定の友達／先生／活動との関係性

**Plan B**：
- **共感**：（保育園と関係ない時間に）「最近、保育園行きたくないって言ってるね、何が嫌？」── 答えが出ないなら「行く前」「お昼」「お昼寝」「帰り」と時間で切って聞く。沈黙OK。
- **大人の懸念**：「無理に行かせるのも、休ませ続けるのも、ママは迷ってるんだ」
- **招待**：「どうしたら少しでも気持ちよく行ける？」 → 「お昼寝のとき隣の先生が嫌」「給食のピーマンが嫌」のような具体が出てくる。

**注意点**：3週間以上続く場合は **保育園・医療と連携**。CPS だけで抱え込まない。「行かせる／休ませる」の二者択一に追い込まれないために、保育園との Plan B（環境調整）も並行する。

## シーン8：寝かしつけが長引く

**場面**：5歳。寝室に入って30分以上「眠れない」「水飲みたい」「もう一冊」が続く。

**CPS的解釈**：
- 未解決問題：「就寝までの30分」
- ラグドール候補：睡眠への移行スキル、不安（暗闇・分離）、ルーチン化の未獲得

**Plan B**：
- **共感**：（昼間に）「夜、寝るときに『もう一冊』『水飲みたい』って言うね。何が起きてる？」 → 「真っ暗が怖い」「ママと離れるのが嫌」
- **大人の懸念**：「ママは寝る時間が遅くなると、自分の時間が取れなくて疲れちゃうんだ（自己開示）」
- **招待**：「どうしたら2人とも納得できる就寝ルーチンになる？」 → 「水は枕元に最初から置く」「常夜灯つける」「絵本2冊までと決める」

**注意点**：親の **自己開示**（私メッセージ）は CPS にとっても重要。「ママだって人間で、疲れてる」を伝えていい。

---

## シーン9：友達への乱暴

**場面**：3歳。保育園で友達を叩く。先生からも報告。家でも下の子を叩く。

**CPS的解釈**：
- 未解決問題：「自分の思い通りにならない場面（友達との交渉）」
- ラグドール候補：感情を言葉にするスキル、待つスキル、相手の視点に立つスキル（心の理論）、衝動制御

**Plan B**：
- **共感**：（叩いた直後でなく、落ち着いた後で）「○○ちゃんを叩いたとき、どんな気持ちだった？」 → 「使いたかったのに貸してくれなかった」
- **大人の懸念**：「叩かれた子は痛いし、○○ちゃんも『悪い子』って言われたら悲しいでしょ。ママもそれが心配」
- **招待**：「叩く代わりに、どうしたら自分の気持ち伝えられる？」 → 「『貸して』って言う」「先生呼ぶ」「離れる」

**注意点**：「叩いてはダメ」（Plan A／境界線）は **言って良い**。CPS は境界線を否定しない。「**境界線 + Plan B**」が両輪。叩く行為は止め、その後で共同問題解決。

## シーン10：イヤイヤ期の床ふせ（2歳）

**場面**：2歳。スーパーで「これ買って」が通らず床に寝転んで号泣。

**CPS的解釈**：
- 未解決問題：「お店で欲しいものを買ってもらえないこと」
- ラグドール候補：欲求不満耐性、感情調節、見通しのなさ（買い物 = 楽しい場所だと期待）

**Plan B**（2歳には言葉のキャッチボールが難しいので、**親が観察を述べる版**）：
- **共感**：「これ欲しかったんだね（観察）。買ってもらえなくて悲しいね（感情の名づけ）」
- **大人の懸念**：「ママは今日はパンとお肉だけ買いに来たんだ」
- **招待**（2歳版）：「今日は買わないけど、お家に帰ったら絵本読もうか／○曜日にまた来ようか」── 2歳には「招待」より「**代替提示**」が現実的。

**注意点**：2歳には完全な Plan B は難しい。「**Plan B 的姿勢**（共感＋自分の事情を伝える）」だけでも違う。Plan C（買い物に連れて行かない、別の人が見る）も並行で。

## シーン11：習い事を行きたがらない

**場面**：5歳。体操教室を「行きたくない」と毎週ぐずる。

**CPS的解釈**：
- 未解決問題：「週末の体操教室」
- ラグドール候補：特定スキルの困難（前転ができない等の劣等感）、特定の先生との関係、移行スキル

**Plan B**：
- **共感**：「体操、行きたくないって言ってるね。何が嫌？」 → 「○○ができないのが恥ずかしい」「△△先生が怖い」
- **大人の懸念**：「ママは続けたら楽しくなるかもって思ってたけど、嫌なら考え直したい」
- **招待**：「どうしたい？やめる？別の場所に変える？月2回にする？」

**注意点**：「やめる」も選択肢。CPS は **どんな解決策が出るかは決めつけない**。親が密かに「続けてほしい」と思っていても、招待ステップでは中立に出す。

## シーン12：「ママじゃないとイヤ」

**場面**：3歳。お風呂・寝かしつけ・食事すべて「ママじゃないとイヤ」。父親が落ち込んでいる。

**CPS的解釈**：
- 未解決問題：「父親が世話をする場面」
- ラグドール候補：分離への耐性、信頼関係の構築（父親との関わり時間が少ない）、移行スキル

**Plan B**（親同士でやる Plan B）：
- **共感**：「パパとお風呂入るの、何が嫌？」 → 「パパは目に水入れるから」「パパは絵本早すぎる」── 具体が出る。
- **大人の懸念**：「ママもずっと1人で全部やるのは疲れてるんだ。パパにも頼りたい」
- **招待**：「パパと一緒だと、どうやれば気持ちよくできる？」 → 「ママが先に体洗って、湯船はパパと」「絵本はママの真似してゆっくり読んで」

**注意点**：父親側の「Plan B 的姿勢」も必要。父親が「自分のやり方」に固執すると、子の懸念に応えられない。**親も Plan B の対象**（グリーンの「大人にも当てはまる」原則）。

## シーン13：宿題／ワークが進まない（年長）

**場面**：6歳。「字を書く練習」を毎日嫌がる。「やらないと小学校で困る」と言ってしまう自分が嫌。

**CPS的解釈**：
- 未解決問題：「字の練習ワーク」
- ラグドール候補：書字スキルそのもの、集中の持続、座位の維持、完璧主義（汚く書くのが嫌）

**Plan B**：
- **共感**：「字の練習、何が嫌？」 → 「うまく書けないと嫌」「長くて疲れる」
- **大人の懸念**：「ママは小学校で困らないようにと思ってたけど、嫌々やるのが心配」
- **招待**：「どうやったらできそう？」 → 「1日1文字でいい」「ホワイトボードに大きく書きたい」「鉛筆じゃなくてクレヨンがいい」

**注意点**：「小学校で困る」は **親の不安投影**。Plan B で子が選んだ方法が「1日1文字」でも、それは子のスキルに合ったペース。**親の予定通りでないことを許容できるか** が試される。

## シーン14：「ダメ」を言ったときの爆発

**場面**：4歳。テレビを「もう終わりね」と言うと毎回爆発。

**CPS的解釈**：
- 未解決問題：「テレビ視聴の終了」
- ラグドール候補：移行スキル、欲求不満耐性、見通しの未獲得（突然終わるのが嫌）

**Plan B**：
- **共感**：別の時間に「テレビ終わるとき、何が嫌？」 → 「途中で終わるのが嫌」「次の話が気になる」
- **大人の懸念**：「ママはテレビ見すぎると目に悪いし、夕飯の準備が進まなくて困る」
- **招待**：「どうやって終わったら2人とも納得できる？」 → 「キリのいいところまで」「タイマー鳴ったら自分で消す」「次の話の最初だけ見て止める」

**注意点**：**「次のキリのいいところ」は子のペース** で。親の都合（夕飯の時間）は **大人の懸念** ステップで素直に伝える。

## シーン15：親自身が爆発した翌日

**場面**：親が前日子を強く叱ってしまった。子は普通に振る舞っているが、親が罪悪感を抱えている。

**CPS的解釈（親に適用）**：
- 未解決問題：「親自身の感情コントロール」
- ラグドール候補（親の）：疲労時の感情調節、自分の限界を予測するスキル、休息を取るスキル

**親が子にする Plan B**：
- **共感**：「昨日ママが怒ったとき、どんな気持ちだった？」 → 「怖かった」「悲しかった」
- **大人の懸念（自己開示）**：「ママは疲れていて怒鳴ってしまった。ごめんね」
- **招待**：「ママがまたイライラしそうなとき、どうしてほしい？」 → 「『ママ深呼吸して』って言う」「離れる」

**注意点**：CPS は **修復可能性（rupture and repair）** を前提とする。完璧に Plan B できる親はいない。**失敗 → 修復 → 学ぶ** のサイクルを子に見せること自体が、子のスキル育成になる。

## 補足：「いつ Plan B を使えないか」

- **爆発の最中**（神経系がオフライン）→ まず安全確保（Plan C）、後日 Plan B。
- **安全に関わる場面**（道路飛び出し、刃物、暴力中）→ Plan A で即時停止。
- **親が疲労困憊**（夜間・病気時・複数のストレッサー重複）→ Plan C で棚上げ。Plan B は別日に。
- **対話が成立しない年齢／状態**（言語前、強い不安発作中）→ Plan B 的姿勢（共感の名づけ）だけで十分。
