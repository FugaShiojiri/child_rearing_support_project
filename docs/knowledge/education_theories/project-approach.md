# プロジェクト・アプローチ（Project Approach / カッツ＆チャード）

## 1. 一行サマリ
子どもの「**なんで？**」を**数日〜数週間かけて掘り下げる**学び方です。

## 2. 中核思想
プロジェクト・アプローチは、1989年に米国の幼児教育者**リリアン・カッツ**（イリノイ大学名誉教授・米国乳幼児教育学会元会長）と**シルビア・チャード**（カナダ・アルバータ大学教授）が著書『Engaging Children's Minds: The Project Approach』で体系化した実践です。レッジョ・エミリアの探究的な保育に強く影響を受けつつ、英語圏の幼児教育・小学校で実装しやすい形に「翻訳」されたものと位置づけられます。

中心にあるのは「**プロジェクト**」── 子どもが興味を持ったテーマ（「うちの近くの郵便屋さん」「水ってどこから来るの？」など）を、数日から数週間かけて深く調べる活動です。やり方は3つの段階に整理されています。

- **第1段階：はじまり** ── 子どもが何を知っていて、何を不思議に思っているか出し合う。
- **第2段階：調べる** ── 現場見学・インタビュー・実験・絵や工作で表現。
- **第3段階：まとめる** ── 学んだことを誰かに伝える（展示・劇・本づくり）。

「ワークシートをこなす学び」の対極にある、**問いから始まる学び**です。幼児期版のPBL（プロジェクト型学習）と呼ばれることもあります。

## 3. 子どもの捉え方
有能な探究者。「子どもは小さい大人」ではなく、独自の理論で世界を仮説検証している**研究者**として扱います。

## 4. 大人（親・保育者）の役割
**問いを一緒に立て・記録し・つなぐ**人。答えを教える人ではなく、子どもの問いを真剣に受け取って、必要なリソース（見学先・本・道具）を一緒に探す協力者です。

## 5. 環境・道具
特別な教具はいりません。**現場（フィールド）**そのもの・**素材**（紙・粘土・カメラ）・**記録**（写真・子どもの言葉のメモ＝ドキュメンテーション）が中心です。プロジェクトが進むほど、教室の壁が「学びの軌跡」で埋まっていきます。

## 6. 0-6歳の実践イメージ
- シーン1: 「アリってどこに住んでるの？」がきっかけで、庭で観察→絵を描く→図鑑で調べる→アリの巣の模型を作る、を1週間ほどかけて。
- シーン2: 「水道の水はどこから？」を発端に、蛇口を分解した写真を撮り、給水塔を見にいく散歩を計画する。
- シーン3: 「パン屋さんはどうやってパンを作る？」をテーマに、地域のパン屋さんに見学を依頼。家でも粉から生地をこねてみる。

## 7. ひだまりこそだち との接点

**共感する点**
- 「子どもの問い」を出発点にする姿勢：「待つ・観察」の原則と地続き。
- レッジョの理念を**実装可能な形**に翻訳した点：日本の家庭に取り入れやすい。
- 結果（成果物）より**過程の記録（ドキュメンテーション）**を重視：成長マインドセットと響き合う。

**距離を置く点**
- 本来は集団保育のフレームで、家庭で「プロジェクトをやらせる」と親主導の知育になりやすい。
- 「テーマを決めて1週間掘り下げる」は親の段取り力に依存。**人手介入最小化**の方針と直接ぶつかる場面がある。

**取り入れたい要素**
- 子どもの「なんで？」を**消費せずに数日寝かせる**態度。
- 写真・子どもの言葉のメモを**ゆるく残す習慣**（成長記録の副産物）。
- 「正解」を急がず、「一緒に調べてみよう」と返す言葉づかい。

## 8. 親が陥りがちな誤解
- **「プロジェクトをやらせる」**：親が題材・期間・成果物を決めると、子どもの問いではなく親の宿題になる。
- **「成果物を作らせなきゃ」**：展示や発表は副産物。**問いを大事にした時間そのもの**が中心。
- **「興味が続かない子はダメ」**：3〜4歳では数日で興味が変わるのが普通。**興味が冷めたら自然に閉じる**のも実践のうち。
