# フィンランド就学前教育（EsiOpetus／エシオペトゥス／Esiopetus）

## 1. 一行サマリ
6歳児の1年だけ、遊びを通して小学校に橋を架ける。

## 2. 中核思想

フィンランドの **EsiOpetus（エシオペトゥス／就学前教育）** は、義務教育（7歳から始まる基礎学校）の前年にあたる **6歳児対象の1年間** のカリキュラム。1996年に「National Core Curriculum for Pre-primary Education」として国家カリキュラム化され、2015年に **義務化** された。費用は無料、給食も交通費も国が負担する。

中核にあるのは「遊びが学び（learning through play）」という哲学。1日約4時間、ワークシートや読み書きドリルでなく、**遊び・対話・グループ活動・自然体験** を通して、社会性・言語・数の感覚・運動・自己表現を育む。学力テスト・宿題・成績評価は基本的に存在しない。

親の日常感覚に翻訳すると、「6歳の1年間は学校の予習ではなく、安心して遊び尽くす最後の年」。日本の幼稚園年長クラスの位置にあたるが、「就学準備＝ひらがな・足し算ドリル」とは正反対の発想で組まれている。

## 3. 子どもの捉え方

子どもは **「能動的な主体であり、グループの一員」** として捉えられる（フィンランド国家教育庁・ECEC概要より）。「固有の価値、成長の権利、意見表現の権利」を持つ存在であり、教師は子どもを「未完成な大人予備軍」ではなく **いま完全に子どもである存在** として尊重する。年齢で「できるはず／まだ無理」を測ることを避け、個別の発達ペースを前提に置く。

## 4. 大人（親・保育者）の役割

EsiOpetus の教師は **修士号取得者** が標準で、専門性が極めて高い。役割は：

- 子どもの興味と強みを起点に学習環境をデザインする
- 遊びを「単なる暇つぶし」ではなく学習として組み立てる
- 各児童の個別教育計画を **年1回以上、保護者と共に評価** する
- 親を「共同の計画者・実行者・評価者」として迎える

親に置き換えると、「先生に丸投げ」でも「家庭で学校の予習」でもなく、**先生と一緒にこの子をどう支えるかを話す共同体メンバー** という位置づけ。

## 5. 環境・道具

教室は遊び・読み聞かせ・運動・アートが混在できる柔らかな空間で、屋外（森・公園）への外出が日常的。特別な教具よりも、**自然・物語・人との対話** が中心の道具。1クラスあたりの子どもの人数は日本より少なく（おおむね教師1人に対し7-13人程度）、目が行き届く設計になっている。

## 6. 0-6歳の実践イメージ

- **シーン1**：朝、外気温が氷点下でも雪の中で外遊び。「寒さで歩かない」ではなく、適切な防寒で外に出ることが当たり前。日本の都市部でも、雨でも公園に行ってみる、というアレンジが可能。
- **シーン2**：6歳児が「お店ごっこ」をする。値段を書く、お金を数える、お客さんと話す──算数・読み書き・社会性が遊びの中に自然に溶け込む。プリント学習ではなくロールプレイで「就学準備」が進む。
- **シーン3**：絵本を読んだ後、「あなたなら主人公にどう声をかける？」と先生が問う。正解を当てる時間ではなく、自分の言葉で考えを表す時間。

## 7. ひだまりこそだち との接点

**共感する点**
- 「遊びこそが学び」という発想は、ひだまりこそだち の「待つ」「観察」スタンスと地続き
- 学力テスト・成績評価なしで、子どもを **横並びで測らない** 文化
- 親を「指導される対象」ではなく「共同の計画者」として位置づける
- 屋外・自然との接続を重視する（[[forest-kindergarten]] と通底）

**距離を置く点**
- 教師1人あたりの子ども数、教師の修士号、無料給食、男女平等な育休制度──**社会構造ごと違うシステムであり、家庭単位だけで真似できない部分が大きい**。
- 近年（2015年以降）PISA順位が下落傾向にあり、「フィンランド＝世界一」という10-15年前の物語のまま語ると現状とずれる。

**取り入れたい要素**
- 6歳の1年間を「就学準備の詰め込み期」ではなく「遊び尽くす最後の年」として味わう発想
- プリントやドリルでなく、ごっこ遊び・お買い物・料理の手伝いで数・文字・社会性を扱う
- 子どもとの会話で「正解を当てる」より「あなたはどう思う？」を増やす

## 8. 親が陥りがちな誤解

**誤解1：「フィンランド神話」──フィンランドの真似をすれば子どもが伸びる**
フィンランドの教育成果は、教師養成（修士号）・社会福祉・男女平等な育児休業・低い経済格差・人口規模（約550万人）など、**社会全体の土台** に支えられている。家庭での声かけだけを真似て同じ結果を期待するのは無理がある。「あの国を真似る」のではなく、**自分の家庭で何が応用できるか** に絞って考えるのが現実的。

**誤解2：「フィンランドは何も教えないから子どもがのびのび育つ」**
「遊びが学び」は無計画な放任ではない。**国家カリキュラム（National Core Curriculum for Pre-primary Education）** が存在し、教師が個別教育計画を立て、保護者と年1回以上評価する。緻密な専門性に支えられた「遊び」であり、「ほったらかし」とは違う。

**誤解3：「6歳になるまで文字や数を見せない方がよい」**
EsiOpetus は文字・数を **禁止** しているのではなく、**ドリルで強制せず、遊びの中で出会わせる** スタンス。子どもが「読みたい・書きたい」と言ったら応える。「○歳までは見せない」ルールを家庭で硬く運用すると逆に窮屈になる。
