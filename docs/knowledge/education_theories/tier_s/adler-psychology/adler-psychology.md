# アドラー心理学（あどらーしんりがく／Individual Psychology / Adlerian Psychology）

## 1. 一行サマリ
親は「上に立って評価する人」ではなく、「横にいて勇気づける人」── 子どもを **対等な共同体の一員** として扱うことから始まる関わり方です。

## 2. 中核思想

アルフレッド・アドラー（1870-1937、オーストリアの精神科医）が創始した **個人心理学（Individual Psychology）** は、フロイト派の精神分析と袂を分かち、人間を「過去に縛られた存在」ではなく **「未来に向かって目的を持って動く存在」** として捉え直した心理学です。子育てに翻訳すると、次の4つが中核概念になります。

第一に **共同体感覚（Gemeinschaftsgefühl／social interest）**。人は他者とつながり、貢献し、所属したいという根源的な欲求を持つ。子どももまた、家族・園・地域という共同体の一員として「役に立っている」「ここに居場所がある」と感じることで安定する。アドラーはこの感覚を「精神的健康のバロメータ」と呼びました。

第二に **目的論（teleology）**。「なぜそうしたのか（原因）」より「何のためにそうしているのか（目的）」を見る。子どもの困った行動を「お腹が空いていたから」「眠かったから」と原因で片付ける前に、「注目してほしい／力を示したい／仕返ししたい／無気力で諦めている」── ドライカース（Dreikurs）が整理した **誤った行動の4つの目的** で読み解く視点です。

第三に **課題の分離（separation of tasks）**。「最終的にその結果を引き受けるのは誰か？」を基準に、誰の課題かを区別する。宿題の結果を引き受けるのは子ども、子どもの将来を不安に思うのは親。親が子の課題に踏み込みすぎると、子は自分の人生の主人公になれない。だからといって突き放すのではなく、**「あなたを信頼している。困ったら相談に来てね」と伝えて待つ** のが基本姿勢です。

第四に **勇気づけ（encouragement）**。これがアドラー心理学の中核実践。「褒める（praise）」とは違い、評価者の立場から見下ろさず、横に並んで「あなたはあなたのままで価値がある」と伝える関わり。「すごいね（評価）」より「ありがとう、助かったよ（貢献の承認）」、「えらいね（上から）」より「やってみようと思ったんだね（過程の承認）」。

これら4つを貫くのが **「縦の関係から横の関係へ」** という関係観の転換です。賞罰・命令・評価は縦の関係。共感・尊敬・信頼・協力は横の関係。アドラーは「人間の悩みはすべて対人関係の悩みである」と言い、その対人関係を **対等に組み直す** ことで人は楽になれる、と説きました。

## 3. 子どもの捉え方

子どもは「未熟で教えられるべき存在」ではなく、**「共同体の一員として、すでに貢献できる対等な人間」** として捉えます。

アドラーは「子どもは皆、優越への努力（striving for superiority）を持つ」と言いました。これは他者を打ち負かしたい欲求ではなく、「いまの自分より一歩前に進みたい」という生命の根源的な動き。同時に「劣等感（feelings of inferiority）」も誰もが持っており、これは病ではなく、成長の原動力。問題は「劣等感」そのものではなく、それが **「劣等コンプレックス」（言い訳の道具）** に変質することにあります。

ドライカースが整理した「**誤った行動の4つの目的**」は実践でとくに有用です：
- (1) **注目を引きたい** — 「ここに居ていいんだ」と確認したい
- (2) **権力闘争** — 「自分にも力がある」と示したい
- (3) **仕返し** — 「傷ついた、傷つけ返したい」
- (4) **無気力の誇示** — 「どうせ無理だから、もう試さない」

子どもの「困った行動」は、共同体の中で **「居場所」を取り戻そうとする誤った方法** だと読み替える。罰や叱責で抑え込むのではなく、共同体感覚を満たす別の経路を提示するのが大人の役割です。

## 4. 大人（親・保育者）の役割

アドラー心理学における大人の役割は、**「縦の関係をやめ、横の関係で接する」** こと。具体的には次の5つに分解されます。

1. **勇気づける人**：失敗を責めず、挑戦そのもの・過程・貢献を承認する。「結果がどうあれ、あなたの存在を歓迎している」を伝える。
2. **課題を分離する人**：「これは誰の課題か？」を都度問い、子の課題には介入しない（ただし孤立させず、相談される余地は残す）。
3. **共感で聴く人**：解決策を急がず、まず「そう感じたんだね」と相手の地平に降りる。
4. **民主的な家族会議の主催者**：家族の決め事を、子も含めた全員で話し合う場を作る（Family Meeting）。
5. **自分自身を勇気づける人**：「いい親でなければ」という縦の自己評価をやめ、不完全な自分を受け入れる（自己受容）。子の前で完璧を演じない。

アドラー派の標語の一つに「**目立たないこと（unobtrusiveness）**」があります。賞罰や指示で目立つ親ではなく、横にいて必要なときに声をかける大人。教える人というより、**「一緒に生きる共同体の先輩」** という立ち位置です。

## 5. 環境・道具

アドラー心理学は「特別な教具」を持ちませんが、**「対話のための場」** を重視します。代表的なのは：

- **家族会議（Family Meeting / Klassenrat）**：週1回、家族全員で議題を出し合い対等に話し合う場。子も親も「議題提案者」として対等。
- **クラス会議（Class Meeting）**：園・学校で同様の場をもつ。Jane Nelsen の Positive Discipline では中核実践。
- **感謝の時間**：「今日ありがとうと言いたいこと」を共有する習慣。共同体感覚を日々耕す。
- **選択肢の提示**：命令ではなく「Aにする？Bにする？」と尊重と限界を同時に示す。

物理環境としては、**子どもの目線で世界が見える・触れる・自分で完結できる** 配置が推奨されます（モンテッソーリと近接）。

## 6. 0-6歳の実践イメージ

子どもの年齢が小さくても、「対等」「勇気づけ」「目的を見る」は応用できます。

- **シーン1（1-2歳・イヤイヤ期）**：「自分で！」と叫んで靴下を投げる。
  → 力で従わせず、選択を渡す。「赤い靴下にする？ 青いの？」「自分で履く？ ママと一緒？」。「イヤ」は権力闘争ではなく **自律の芽** と読む。

- **シーン2（2-3歳・お手伝い）**：トマトを洗う・テーブルを拭くなど「貢献」できる場を作る。
  → 「ありがとう、助かったよ」と感謝を伝える（「えらいね」ではなく）。共同体への貢献感が勇気の土台になる。

- **シーン3（3-4歳・きょうだいゲンカ）**：おもちゃの取り合い。
  → ジャッジ役にならない。「どうしたら2人とも気持ちよくなれそう？」と、解決を子に渡す。介入は最小限。

- **シーン4（4-5歳・できないことへの反応）**：「もうやらない！」と投げ出す。
  → 「ここまでやってみたんだね（過程の承認）」「できないと感じてるんだね（共感）」「またやりたくなったら教えてね（信頼）」。叱咤せず、無気力の目的を読む。

- **シーン5（5-6歳・友達トラブル）**：園で「〇〇ちゃんに意地悪された」と泣いて帰る。
  → 解決策をすぐ提示せず、まず聴く。「悲しかったね」「どうしたい？」。問題解決は子の課題、共感は親の役割と分ける。

## 7. ひだまりこそだち との接点

**共感する点**
- 「親が頑張りすぎない」「完璧でなくていい」と一致する **自己受容** の発想。
- 賞罰・体罰によらない関わりという土台。
- 「子どもを信じて待つ」スタンス（課題の分離）。
- 「親も一人の人間」── 縦に立たない親像。
- 「ありがとう」を起点にする貢献文化。

**距離を置く点**
- **岸見一郎流の単純化リスク**：『嫌われる勇気』ブーム以後、「すべては勇気の問題」「課題の分離さえできれば楽になる」と単純化されて流通している。実際の子育てはそれだけでは整理しきれない（発達段階・愛着・神経系の要因が併在する）。
- **「ほめない」を機械的に守る誤解**：「褒めてはいけない」と覚えて、子どもへの感情的な反応を全部止めると、かえって冷たくなる。本質は「上から評価しない」であって「無反応」ではない。
- **「課題の分離」の放任化**：「これは子の課題」と境界を引きすぎ、結果として子が孤立する。アドラーは「分離した上で協力する」と説いており、「分離＝突き放し」ではない。

**取り入れたい要素**
- 「勇気づけ」を **「ありがとう」「助かった」「やってみたんだね」** という日常語に翻訳して提供する。
- 「目的を見る」レンズを、保護者が子の行動を理解する補助線として渡す（罪悪感の解毒剤になる）。
- 「親自身が縦の関係を降りる」── 親が自分を勇気づける視点を、コミュニティで共有する。
- 「家族会議」のミニ版（週1回5分でいい）を、シンプルなツールとして提案する。

## 8. 親が陥りがちな誤解

- **誤解1：「ほめない＝放置」**
  → アドラーは「評価する立場から見下ろさない」と言っているのであって、「何も反応するな」とは言っていません。「ありがとう」「あなたがそう決めたんだね」「やってみたんだね」── 反応の **質** を変えるのが本旨です。

- **誤解2：「課題の分離＝放任」**
  → 「これは子の課題だから関わらない」と境界を引きすぎると、子は「親に見捨てられた」と感じます。アドラーは「課題を分けた上で、求められたら援助する」と説きました。**「あなたを信頼している、困ったら相談してね」と伝えて待つ** が正解で、「勝手にしろ」ではありません。

- **誤解3：「勇気づければ全部解決する」**
  → 0-2歳の睡眠・授乳・愛着など、勇気づけ以前の生理的・愛着的な土台が機能していなければ、どんな言葉も届きません。アドラー心理学は **3歳以降の関係性レイヤー** に特に有効で、乳児期は Bowlby のアタッチメント理論を土台に据えるのが妥当です。

- **誤解4：「縦の関係はすべて悪」**
  → 子の命に関わる場面（道路に飛び出す等）は、横の関係を一旦置いて即座に制止します。「対等」は「無制限」ではなく、**安全とコミュニティのルール** という限界の中での対等です。

- **誤解5：「勇気づけ＝大げさに励ます」**
  → 「すごい！えらい！がんばれ！」を勇気づけと勘違いするケース。これは Brummelman 2014 の「**inflated praise（誇張賞賛）**」で、自尊心の低い子どもにはむしろ重荷になります（[[research/D1_voice/brummelman-2014-inflated-praise]]）。勇気づけは静かで等身大の言葉のほうが届きます。
