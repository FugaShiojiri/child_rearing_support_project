# B.F. スキナー ─ 実践シーン集（0-6歳）

各シーンは **「場面 → スキナー的解釈 → 具体的言葉かけ／行動 → 注意点（controversies含む）」** の4ブロック。家庭で疲れた親が **「いまこの行動は、何によって強化／罰されているか」** を読むレンズとして使えるよう、最小単位で書いています。

スキナーの三大原則：
- **A**: 行動は **その結果** で形作られる ── 「**いま何が強化／消去になっているか**」を読む
- **B**: **強化のタイミング** は **直後** が肝心 ── 遅延した強化は効きにくい
- **C**: **罰** より **強化** を優先 ── 罰は副作用が多い／いきなり完璧を求めず **シェイピング** で段階的に

ただし、スキナーの枠組みは **動機づけの質** と **関係性の温度** を扱えない。各シーンの「注意点」で SDT ([[sdt]])・CPS ([[cps-greene]])・愛着 ([[bowlby-attachment]]) との緊張関係を併記します。

---

## シーン1：自分で靴を履いた瞬間に声をかける（強化のタイミング、3歳）

**場面**：3歳児が玄関で、もたもたしながら自分で靴を履いた。

**スキナー的解釈**：これは **強化のチャンス**。「**自分で履く**」という行動が起きた **直後** に、親が肯定的な注目を返すと、この行動は次回以降増える。逆に、「**早くして**」と急かしたり、無反応で外に出ると、行動は強化されない。**強化は数秒以内** が原則。

**具体的言葉かけ／行動**：
- ○「**自分で履けたね**」（行動の直後に、行動の事実を描写：Ginott の **行動の描写** とも整合）
- ○ 親が笑顔を向ける、目線を合わせる（**注目という社会的強化** は、おやつより強い場合が多い）
- ×「**今日は遅いね**」（行動の **負の側面** に注目すると、せっかくの強化機会が消える）
- × 夜になって「**今日靴自分で履けたね**」（遅延強化は弱い）

**注意点**：「**褒めて伸ばす**」は SDT 的には **過剰賞賛** や **統制的フィードバック** に滑る危険がある。「**えらい**」「**すごい**」より、**行動を描写する**（Ginott、[[ginott]]）方が、内発動機を削りにくい。

## シーン2：かんしゃくに反応するとかんしゃくが増える（消去・計画的無視、2歳）

**場面**：2歳児がスーパーで「**お菓子買って！**」とかんしゃく。親が「**ダメ**」と言い続けると激しくなり、最終的に折れて買ってしまう。

**スキナー的解釈**：これは **間欠強化** の典型。「**かんしゃくしたら 10回に1回は買ってもらえる**」が学習されると、**部分強化** の消去抵抗（消えにくさ）が働き、かんしゃくは **強固に維持** される。一方、親が **一貫して反応しない** ＋ **落ち着いたら関わる** を続けると、徐々に消去される。

**具体的言葉かけ／行動**：
- ×「**ダメ → 折れる → 買う**」（最悪のパターン。間欠強化で固定化）
- ○ 安全が確保できる場面で **一時的に反応しない**（計画的無視）
- ○ 落ち着いたら「**さっき辛かったね、お話ししよう**」（関係の修復）
- ○ 事前ルール「**今日はお菓子コーナーは見るだけ**」を **店に入る前** に確認（プリマック原理 ＋ 事前合意）

**注意点**：「**計画的無視**」は誤用されやすい。**乳児（0-1歳）には使わない**、**愛着の文脈を損なわない**、**安全を確認する**、**落ち着いたら必ず関わる** ── がセット。CPS（[[cps-greene]]）は「**かんしゃくは can't（できない）の表出**」と読み、**穏やかな時間に proactive に話す** Plan B を提案する。両者は補完的に使える。

## シーン3：歯磨きを嫌がって泣くと親がやめる（負の強化の罠、3歳）

**場面**：3歳児が歯磨きを嫌がって激しく泣く。親が根負けして「**じゃあ今日はもういいよ**」とやめる。

**スキナー的解釈**：これは **子の側に負の強化** が成立した瞬間。「**泣く → 嫌な歯磨きが消える**」が学習され、次回からも泣けばやめてもらえると学ぶ。**親の「楽になりたい」気持ち** が子の問題行動を強化してしまう典型例。

**具体的言葉かけ／行動**：
- ×「**泣いたらやめる**」（負の強化が成立）
- ○ シェイピングで段階的に：「**口の中に入れただけえらい**」→「**1本磨けたね**」→「**全部磨けた**」
- ○ **強化を厚く**：「**○○ちゃん、ピカピカになったね**」「**鏡で見てみよう**」
- ○ 歯磨き後に **好きな絵本** を読む（プリマック：好まれない行動の後に好まれる行動を置く）

**注意点**：「**やめてあげる優しさ**」が **長期的には子を苦しめる** ことがある、というのがスキナーの含意。ただし、**子の感覚過敏** や **発達特性** で本当に痛い・耐えられない場合は、CPS の「**can't の問題**」として扱い、無理強いせず歯科医に相談する判断が必要。

## シーン4：偏食をシェイピングで攻略（漸次接近、3歳）

**場面**：3歳児が緑黄色野菜を一切食べない。「**食べなさい**」と強要すると吐き出し、食卓が戦場になる。

**スキナー的解釈**：「**全部食べる**」を一気に求めるのは、シェイピングの原則に反する。**今できる行動** から始めて、段階的にハードルを上げる。**「皿の上にあるのを許容する → 触る → 口に近づける → 一口 → 二口」** という階段を、各段階で十分強化しながら登る。

**具体的言葉かけ／行動**：
- ×「**全部食べないとデザートなし**」（罰：副作用が大きい）
- ○ 段階1「**今日はお皿に乗ってるね**」（許容しただけ強化）
- ○ 段階2「**お野菜に触れたね**」
- ○ 段階3「**一口食べてみる？**」「**おっ、食べたね**」
- ○ 各段階で **何日もかける**（無理に進めない）

**注意点**：偏食には **感覚過敏**（自閉症スペクトラム）、**口腔機能**、**鉄欠乏** などスキナー枠組みで扱えない要因がある。**シェイピングで進まない場合は専門家**（言語聴覚士・小児科医）に相談。「**食べないのは行動の問題**」と決めつけない。

## シーン5：嘘を強く叱ると「ばれない嘘」が育つ（罰の副作用、5歳）

**場面**：5歳児がコップを割った。「**割ってない**」と嘘をつく。親が強く叱る。次回からは嘘がより巧妙になる。

**スキナー的解釈**：**罰は行動を「ばれない方向」に進化させる** ことがある。「**正直に言うと叱られる → 嘘の方が安全**」が学習されると、嘘が強化される。罰よりも、**正直に話した時の強化** を厚くする方が、長期的に「正直さ」を育てる。

**具体的言葉かけ／行動**：
- ×「**嘘をつくな！**」（強い罰：嘘の巧妙化を招く）
- ○「**割れちゃったね。教えてくれてありがとう。一緒に片付けよう**」（正直に話した時の強化を厚く）
- ○ そもそも「**ばれたら罰**」のシナリオを作らない。「**割れた**」事実への対処を一緒に行う
- ○ 子が嘘をついたら「**本当のこと教えてくれたら助かるな**」と **正直の機会** を残す

**注意点**：これは Adler ([[adler-psychology]]) の「**勇気づけ**」、Ginott ([[ginott]]) の「**行動の描写**」、CPS ([[cps-greene]]) の「**問題を一緒に解く**」と完全に整合する。**罰の代わりに何を置くか** という設計が、現代しつけ理論の中心問題。

## シーン6：シール表は早めに外す（トークンエコノミーの設計、4歳）

**場面**：4歳児に、片付け・歯磨き・着替えで毎日シールを貼り、10個貯まったらおもちゃ、というシール表を導入。最初は喜んでやっていたが、3ヶ月後「**シールないならやらない**」と言うように。

**スキナー的解釈**：トークンエコノミーは **強固な強化システム** で、最初は機能する。しかし、**SDT のアンダーマイニング効果** ── 統制的な外的報酬が、もともと内発動機があった活動の動機を削る ── が長期的に発動する。**「外発で動かす」と「内発が育つ」が両立しにくい**。

**具体的言葉かけ／行動**：
- 設計1：シール表は **最初の習慣形成の補助輪** として導入（2-4週間）
- 設計2：行動が定着し始めたら **早めにシールを外す**（「**もうシール卒業しようか、自分でできるね**」）
- 設計3：シール撤去後は **言語的強化** に切り替え（「**自分で片付けたね**」）
- ×「**シール表を半年・1年続ける**」（内発動機を削る）

**注意点**：これは **スキナーと SDT を両方知っている**ことで初めてできる設計。スキナーだけだと「**シール表は効くからずっと続けよう**」、SDT だけだと「**シール表は絶対ダメ**」になりがち。**両者を補完的に** 使うのが現代の標準。

## シーン7：自閉症療育で ABA を考える時の構え（ABA倫理、3-6歳）

**場面**：3歳児に自閉症スペクトラムの診断。療育施設で ABA（応用行動分析）を勧められる。親はネット検索で「**ABA は虐待だ**」という当事者の声を読んで戸惑う。

**スキナー的解釈**：ABA はスキナーの理論を直接応用した療育法で、**70年以上の研究蓄積** がある。一方、**伝統的 Lovaas 法**（1960-80年代の厳格 ABA）は、自閉症成人の当事者運動から「**神経定型者に合わせるための同化的訓練であり、トラウマを引き起こす**」と批判されている。一方、**現代的 NDBI**（Naturalistic Developmental Behavioral Intervention、ESDM など）は **遊び中心・子主導・子の興味を活用** する形で、伝統的 ABA とは大きく異なる。

**具体的言葉かけ／行動**：
- ○ 施設に「**伝統的 ABA か、NDBI か、どちらに近いですか？**」と聞く
- ○ 「**子の意思を尊重するか、子のサインで休憩するか**」のような **子の主体性** に関する方針を確認
- ○ 自閉症成人の当事者の声（ASAN: Autistic Self Advocacy Network 等）も読む
- ○「**この方法でうちの子が苦しんでないか**」を **観察し続ける**（強化されているはずなのに、子の表情が硬くなる、夜泣きが増える、退行する等は危険信号）

**注意点**：「**ABA は絶対善／絶対悪**」のどちらでもない。**どの ABA か、誰が、どんな関係性のなかで使うか** で全く別物になる。日本の親に紹介するときは、**論争の存在を伝える** のが誠実。CPS ([[cps-greene]]) は ABA への代替・補完として位置づけられることもある。

## 補足：スキナーの「効く」と SDT の「育つ」を両立する

スキナーの強化／罰／消去は、**短期の行動修正には強い**。SDT ([[sdt]]) の自律性／有能感／関係性は、**長期の内発動機の育成に強い**。両者は **タイムスケールが違う** ── 両立できる。

| 局面 | スキナー（短期） | SDT（長期） |
|---|---|---|
| かんしゃくが頻発 | 一貫した反応・消去 | 子の感情を受け止める・関係性 |
| 偏食 | シェイピング・段階的強化 | 食事を楽しい場にする・自律性 |
| 歯磨き嫌い | 段階的強化・プリマック | なぜ大事かを子の言葉で理解 |
| 嘘 | 正直の強化、罰の最小化 | 関係性の温度・安心して言える環境 |

CPS ([[cps-greene]]) はさらに「**この子のスキルが足りていない部分はどこか**」を見るレンズを加える。**スキナー × SDT × CPS** の3つを場面ごとに切り替える設計が、現代の親トレーニングの到達点です。
