# B.F. スキナー ─ 行動主義／オペラント条件づけ／ABA の理論的基盤

## 1. 一行サマリ

**「**行動は、その結果によって形作られる**」── 褒められた行動は増え、無視された行動は消える。** 20世紀心理学を支配し、21世紀の **PCIT・ABA・ペアレント・トレーニング** など現代しつけ介入の **理論的基盤** を作った、米国のもっとも論争的な心理学者。

## 2. 中核思想

バラス・フレデリック・スキナー（B.F. Skinner, 1904-1990）は、米ペンシルベニア州サスケハナで生まれ、ハミルトン・カレッジで英文学を学んだ後、作家を志して挫折、25歳でハーバード大学心理学科に入学、博士号取得後はミネソタ大学・インディアナ大学を経て、1948年から生涯ハーバード大学で研究を続けました。20世紀前半に支配的だった **行動主義** ── ワトソン、パブロフ以来「**観察可能な行動だけを科学の対象にする**」立場 ── の中で、スキナーは **オペラント条件づけ（operant conditioning）** という独自の枠組みを打ち立てます。

パブロフの **古典的条件づけ**（ベルの音と餌を結びつけ、ベルだけで犬がよだれを出す）が **反射的・受動的** な学習を扱うのに対し、スキナーの **オペラント条件づけ** は **自発的・能動的** な行動を扱う ── **行動が環境にどう作用し、どんな結果が返ってきたか** で、その行動の頻度が変わる、という枠組みです。**スキナー箱**（鳩・ラットを使った実験装置）での膨大な実験から、以下の4要素モデルが体系化されました：

- **正の強化（positive reinforcement）**：行動の後に **好ましいもの** が出現 → 行動が増える（例：片付けたら褒められる → 片付けが増える）
- **負の強化（negative reinforcement）**：行動の後に **嫌なもの** が消失 → 行動が増える（例：シートベルトを締めると警告音が止まる → 締める行動が増える）
- **正の罰（positive punishment）**：行動の後に **嫌なもの** が出現 → 行動が減る（例：触ったら叱られる → 触らなくなる）
- **負の罰（negative punishment）**：行動の後に **好ましいもの** が消失 → 行動が減る（例：暴れたらおもちゃが取り上げられる → 暴れなくなる）
- **消去（extinction）**：強化を完全に取り去る → 行動が徐々に消える（例：かんしゃくに反応しない → かんしゃくが減る）
- **シェイピング（shaping、漸次接近法）**：目標行動に近い行動から段階的に強化していく → 複雑な行動を段階的に形成
- **強化スケジュール**：連続強化 vs 部分強化（変動比率／変動間隔）。**部分強化** の方が消去抵抗が強い ── ギャンブルや SNS の通知設計の理論的源流

スキナーの最も論争的な著作 *Beyond Freedom and Dignity*（1971）では、「**自由意志は錯覚であり、すべての行動は環境随伴性によって形作られる**」とまで主張、後年の人文学・哲学・宗教界から強烈な反発を受けます。一方で、彼の枠組みは **応用行動分析（Applied Behavior Analysis, ABA）** として、特に **自閉症療育**、**PCIT（Parent-Child Interaction Therapy）**、**Triple P**、**Incredible Years**、**SST（Social Skills Training）**、**学校現場のトークンエコノミー** など、現代の主要な介入プログラムの **直接の理論的基盤** になっています。

幼児期の親にとってのスキナーの含意は、4つに集約されます。**(1) 子の行動は「その結果」で決まっている、(2) 望ましい行動の「直後」に良い結果を返す、(3) 望ましくない行動への「過剰反応」が逆に強化することがある、(4) 罰よりも強化の方が長期的に有効**。── 「**叱るより、できた瞬間を見逃さず褒める**」というよく聞く育児アドバイスは、すべてスキナーの理論の応用です。

## 3. 子どもの捉え方

子は **「環境との随伴性で行動を組み立てる学習体」**。スキナーは、子の内面（思考・感情・動機）よりも **行動とその結果** に焦点を当てます。「**なぜそうするのか**」より「**何が起きた結果その行動が増えた／減ったのか**」を見る視点。

これは現代的にはやや極端な見方であり、バンデューラ ([[bandura]]) が認知（観察・解釈）を再導入し、デシ＆ライアン ([[sdt]]) が内発動機を中心に据え、ロス・グリーン ([[cps-greene]]) が「**スキルの問題**」として再定義する ── というかたちで、スキナーの **行動還元主義** は徐々に補正されてきました。

それでも、**「いまこの子の行動を、何が強化／罰しているか」** を読むレンズは、現代の親トレーニング・ペアレント・コーチングで **最も即効性のある分析ツール** であり続けています。「**かんしゃくしたら親が反応する → かんしゃくが強化される**」という分析は、シンプルで強力。子を **責める** のでなく **環境随伴性を変える** という発想は、スキナーが残した最大の家庭への贈り物です。

## 4. 大人（親・保育者）の役割

**「環境設計者」かつ「結果のタイミング管理者」**。スキナーの含意は4つです。

**(1) 望ましい行動を「捕まえて」強化する**：「**できた瞬間**」を見逃さず、直後に注目／言葉／触れ合いを返す。**遅延した強化は効きにくい**（行動の直後数秒が肝心）。「**今日は片付けえらかったね**」（夜の振り返り）より「**いま自分で片付けたね**」（その瞬間）の方が強化として強い。

**(2) 望ましくない行動への「過剰反応」を点検する**：かんしゃく・泣き・甘え・ふざけ ── 親が **強い反応**（叱る・なだめる・取引する）を返すと、それ自体が **注目という強化** になり、行動が増えることがある。「**消去**」（無視）を意図的に使う場面もある ── ただし安全と感情への配慮とセット。

**(3) 罰より強化を優先**：罰は **短期的な抑制** には効くが、(a) 行動の **回避** だけ学習し、代わりの行動が育たない、(b) 罰する人への **恐怖・回避** が学習される、(c) 罰の場面を「**ばれなければOK**」と読み替える ── という副作用がある。**「ダメな行動を罰する」より「望ましい行動を強化する」**。

**(4) シェイピングを使う**：いきなり完璧な行動を求めず、**今できる行動 → 少し進んだ行動 → 完成形** と段階的に強化する。歯磨きを嫌がる子に「**全部磨かせる**」を求めず「**ブラシを口に入れただけえらい**」から始める。

## 5. 環境・道具（家庭・園）

スキナーの枠組みは、家庭で具体的に使える **シンプルな道具** を提供します：

- **トークンエコノミー**（シール表、ポイント表）：望ましい行動にトークン（シール・スタンプ）を出し、貯まると報酬と交換。**ただし SDT の「アンダーマイニング効果」** との緊張関係に注意（後述）
- **タイムアウト**（厳密には negative punishment）：望ましくない行動の直後に、**注目・好刺激から離す** 時間を作る。0-3歳には推奨されないが、3-6歳で短時間（年齢×1分目安）に限定して使う技法
- **計画的無視（planned ignoring）**：かんしゃく等の **注目獲得行動** への意図的無反応。安全が確保された場面で
- **行動契約**：「○○したら○○できる」という事前のルール明示（**プリマック原理**：好きな行動の前に好まれない行動を置く）
- **PCIT（Parent-Child Interaction Therapy）**：スキナーの理論を直接応用した親トレーニング。米国で2-7歳の問題行動への **エビデンスベース介入** として確立。日本でも臨床導入が進む

家庭で借りられるのは、**(1) 望ましい行動の「直後」に肯定を返す習慣**、**(2) 望ましくない行動への過剰反応を一度立ち止まって点検する習慣**、**(3) 罰よりも強化を先に使う構え**、**(4) シェイピングで段階的にハードルを上げる発想** ── という設計図です。

## 6. 0-6歳の実践イメージ

- **シーン1（強化のタイミング、3歳）**：子が自分で靴を履いた **瞬間** に「**自分で履けたね**」と言う ── 遅延した「夜の褒め」より強い。
- **シーン2（消去、2歳）**：かんしゃくで欲しいものを取ろうとする。親が反応するとかんしゃくが増える。安全が確保されたら **一時的に反応しない** + 落ち着いた後に対話。
- **シーン3（負の強化の罠、4歳）**：歯磨きを嫌がって泣くと親が止める → 泣けば止まると学習。負の強化が成立してしまう。
- **シーン4（シェイピング、3歳）**：偏食の子に「**全部食べる**」を求めず「**口に近づけたらえらい → 一口 → 二口**」と段階的に。
- **シーン5（罰の副作用、5歳）**：嘘をついたので強く叱る → 嘘をやめるのでなく **ばれない嘘の技術** が育つ。代わりに「正直に話した時の強化」を厚くする。

## 7. ひだまりこそだち との接点

**共感する点**
- **「行動の直後に何が起きたか」を分析するレンズ** は、原因不明の問題行動を **構造的に** 解決する第一歩。「**この子は意地悪な子だ**」というラベルでなく、「**この行動を強化しているものは何か**」という問いに転換する効用は大きい。
- **シェイピング（段階的接近）** は、ひだまりこそだち の「**スモールステップ**」「**子のペースを尊重する**」基調と整合する。「**いきなり完璧を求めない**」発想の理論的根拠。
- **正の強化 > 罰** という基本原則は、佐々木正美 ([[sasaki-masami]]) の「**信頼で育てる**」、ポジティブ・ディシプリン ([[positive-discipline]])、Adler ([[adler-psychology]]) の「**勇気づけ**」、Ginott ([[ginott]]) の「**行動の描写**」── すべてと整合する基層。
- **PCIT** は日本でも導入が進む **エビデンスベース** の親トレーニングで、ひだまりこそだち が紹介する **「困った行動」介入** のなかで最も研究蓄積が厚い選択肢の1つ。

**距離を置く点（controversies）**
- **ロス・グリーン (CPS) からの強力な批判** ── グリーン ([[cps-greene]]) は「**Kids do well if they can**」を掲げ、「**報酬と罰は、スキルを教えない**」と ABA／トークンエコノミー／タイムアウト を強く批判。困った行動を **やる気の問題** でなく **スキルの問題** と捉え直す。両者は **補完的に使える局面が多い** が、極端な ABA 適用には注意。
- **SDT（自己決定理論）との対立** ── デシ＆ライアン ([[sdt]]) の **アンダーマイニング効果** は、もともと興味のある活動に **統制的な外的報酬** を与えると、報酬撤去後に **内発動機が削られる** ことを示した。「**シール表で動かす**」のは、**最初の習慣形成の補助輪** としては機能しても、**早めに外さないと内発動機を蝕む**。スキナーの「**強化すれば行動は増える**」は、**長期の内発動機の話を扱えない**。
- **「人間性軽視」批判** ── スキナーは「**自由意志は錯覚**」と論じ、人文学・哲学・宗教界から強烈な反発を受けた。子を **環境随伴性で説明可能な反応体** として扱う構えは、**主体性・尊厳・関係性** を軽視する危険を内包する。Rogers の人間性心理学、現代の SDT、CPS、NVC ([[nvc]]) は、いずれも行動主義への **応答** として生まれた。
- **自閉症 ABA の倫理論争** ── ABA は自閉症療育の **第一選択** として米国で広く普及したが、近年は **当事者運動**（自閉症成人による批判）が「**ABA は神経定型者に合わせるための同化的訓練であり、トラウマを引き起こす**」と告発。**Lovaas 法**（伝統的・厳格 ABA）と **現代的・自然主義 ABA**（NDBI: Naturalistic Developmental Behavioral Intervention）の区別、倫理的配慮、当事者の声を聞く構えが必要。日本の親に ABA を紹介するときは **この論争の存在を伝える** のが誠実。
- **トークンエコノミーの濫用** ── シール表・ポイント表は、家庭で気軽に使われるが、(a) 当初は楽しい活動も **報酬目当て** に変質する、(b) 報酬を撤去すると **行動も消える**、(c) 兄弟比較・公平性問題が起きやすい、(d) 親自身が「**操作している**」罪悪感を持つことがある ── という副作用がある。SDT の知見と組み合わせて **慎重に使う／早めに外す** 設計が必要。
- **内発動機の軽視** ── スキナー枠組みでは「**なぜそれを楽しいと感じるか**」という質問が扱えない。デシ＆ライアン以降の動機づけ研究は、外発と内発を区別し、**外発の中にも質の差**（外的調整 → 取り入れ → 同一化 → 統合）があるとした。スキナーの枠組みは「**動かす**」ことには強いが「**好きになる**」ことには弱い。
- **計画的無視・タイムアウトの誤用** ── 「**泣いても無視しなさい**」が **愛着** ([[bowlby-attachment]]) を損なう懸念。**安全と感情への配慮なしの計画的無視** は、子に「**自分は重要でない**」というメッセージを送りうる。**乳児（0-1歳）のかんしゃくに計画的無視を使わない** は現代の合意。
