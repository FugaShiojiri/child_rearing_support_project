# フランスの子どもは夜泣きをしない パリ発「子育て」の秘密

## 一行サマリ
パリ在住の米国人ジャーナリストが体験を交えて描いた、フランス式育児観察記です。

## 書誌情報
- 著者: Pamela Druckerman（パメラ・ドラッカーマン、米国のジャーナリスト、ウォール・ストリート・ジャーナル記者）
- 原著: *Bringing Up Bébé* (Penguin Press, 2012)
- 邦訳: 鹿田昌美 訳『フランスの子どもは夜泣きをしない』集英社、2014年
- ISBN: 978-4-08-789004-4
- 原著言語: 英語

## 中核思想（自分の言葉で要約）
著者はパリ在住の米国人ジャーナリスト。子育てしているうちに「**フランスの子は癇癪を起こさず、レストランで静かに食事し、夜は通して寝る**」ことに気づき、その背景を観察したエッセイ。「**フランス式しつけ**」の特徴として：

1. **赤ちゃんの夜泣き対応**：泣いてもすぐ抱き上げず、数分待つ（「**pause**」）。乳児にも自分で再入眠する機会を与える。
2. **食事のしつけ**：4回の決まった食事時間（10時頃に「**ル・グテ（軽食）**」のみ）。間食しない。
3. **「**Non**」を躊躇しない**：明確な枠を示し、子の要求に折れない。
4. **大人の時間を確保**：親には親の人生があり、それを子に見せる。

家庭への翻訳: 「**子の主体性を尊重する**」と「**大人が枠を示す**」は両立するという発想。「**子は順応する力を持っている**」という前提で、過保護でも放任でもない関わり方の例示。

## 著者紹介
パメラ・ドラッカーマンはWSJの元記者。パリに移住しジャーナリストとして活動するなか、子育てを通じて文化比較に関心を持ち本書を執筆。世界的ベストセラーに。

## ひだまりこそだち接点
- **想定保護者**: 夜泣き・食事しつけに悩む保護者、「日本の育児はしんどい」と感じている保護者、海外文化に関心のある保護者
- **関連理論**: [[self-determination-theory]]
- **我々の立場**: 距離を置く（参考）。「**子の力を信じる**」「**大人にも自分の時間が必要**」という基本姿勢は同意。一方で、本書はジャーナリストの観察記であり、「**フランス式が優れている**」という単純化はステレオタイプの強化につながる。具体的提案（「**Cry-it-out（泣かせる睡眠訓練）**」など）は科学的エビデンスが分かれており、保護者の判断を要する。

## 推奨度と注意
- **推奨度**: C（参考のみ）
- **注意**: 「**フランス式pause**」は実質的に**Cry-it-out（CIO）法**であり、効果（[[research/D2_sleep/hiscock-2002-rct-behavioural-sleep-intervention-maternal-mood]]）と論争（[[research/D2_sleep/middlemiss-2011-asynchrony-cortisol-cry-it-out]]）の両方を知る必要がある。「**フランス＝正解／日本＝不正解**」という二項対立に陥らないこと。**統計データではなくエッセイ**なので、「**こういう文化もある**」という相対化材料として読む。
