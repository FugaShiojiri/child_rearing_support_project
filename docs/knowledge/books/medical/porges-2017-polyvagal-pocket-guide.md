# ポリヴェーガル理論入門 心身に変革をおこす「安全」と「絆」

## 一行サマリ
「**まず安心、それから学び**」── 自律神経の働きから親子関係を読み解く、ポージェスによる入門書です。

## 中核思想（自分の言葉で要約）
ポージェスは1994年に「**ポリヴェーガル理論（多重迷走神経理論）**」を提唱した神経科学者。本書は彼自身による一般向け入門書で、心理臨床家・支援者を主な読者として書かれています。

中心理論：自律神経系は従来の「交感／副交感」の2階層ではなく、3つの状態を持つ──(1) **腹側迷走神経系**（安心モード、社会的関わり）、(2) **交感神経系**（闘争／逃走モード）、(3) **背側迷走神経系**（凍りつき／シャットダウン）。子の癇癪・パニック・固まる・甘えてくるは、しつけで変わる前に「**神経系の状態**」の問題。**安心スイッチが入っていないと学べないし、言うことも聞けない**。

家庭への翻訳: 子の癇癪は「**いま神経系が交感に落ちている**」状態であり、論理で説得しても届かない。まず安心を回復させる（声・表情・抱っこ・移動）、それから話す。親自身も「**腹側**」状態でいることが、子の安心の出発点。

## 著者紹介
スティーブン・ポージェスはインディアナ大学・ノースカロライナ大学を経てキンゼイ研究所所属の神経科学者。ポリヴェーガル理論は心理臨床・トラウマ治療の現場で広く活用される一方、神経解剖学の主流からは批判もあり、議論が継続中。

## ひだまりこそだち接点
- **想定保護者**: 心理臨床家・支援者、トラウマインフォームドケアに関心のある保育者・保護者、子の癇癪に困っている保護者
- **関連理論**: [[polyvagal]], [[bowlby-attachment]], [[harvard-cdc-framework]]
- **我々の立場**: 同意（モデルとして）。「**まず安心、それから学び**」「**叱る前に共同調整**」というメッセージは、ひだまりこそだちと完全に一致。一方、ポリヴェーガル理論は「**確立した科学**」ではなく「**臨床的に有用な比喩・モデル**」と理解する誠実さが必要。

## 推奨度と注意
- **推奨度**: B（条件付き）
- **注意**: ポリヴェーガル理論は心理臨床では広く活用されているが、神経解剖学・主流神経科学からは「**dorsal vagal の役割の説明にエビデンスが弱い**」等の批判が継続中。「**ポリヴェーガル的に正しい子育て**」のような教義化は避け、「**比喩として有用なモデル**」として扱う。本書は心理臨床家向けに書かれており、一般保護者には専門用語が多いため、家庭向けにはひだまりこそだち側で噛み砕いて紹介する。
