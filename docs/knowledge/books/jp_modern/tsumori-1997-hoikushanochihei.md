# 保育者の地平

## 一行サマリ
お茶大附属幼稚園での実践と愛育養護学校長としての日々を、現象学的なまなざしで綴った日本保育思想の到達点です。

## 書誌情報
- 著者: 津守真（つもり まこと、1926-2018、日本の保育学者・心理学者、お茶の水女子大学名誉教授）
- 出版: ミネルヴァ書房、1997年
- ISBN: 978-4-623-02784-2
- 副題: 私的体験から普遍に向けて
- 原著言語: 日本語

## 中核思想（自分の言葉で要約）
津守真は、倉橋惣三の直系の後継者として、お茶の水女子大学附属幼稚園主事を経て、晩年は愛育養護学校（重度障害児教育）の校長を務めた人物。本書は60代から70代にかけての実践と思索を、「**保育者として子と共にいることの意味**」という主題のもとに編んだ随想兼論集です。

津守の中心概念は「**出会い**」と「**応答**」、そして「**省察（リフレクション）**」。子と保育者の関係は、計画やカリキュラムで設計しきれるものではなく、その日その時の**一回的な出会い**として立ち上がる。保育者は子の発した些細な動き・声・まなざしに「**応答する身体**」として居る。そして1日が終わったあとに「**今日、自分はどう居たか**」を省察する──この三角形が保育者の仕事の核心だと津守は説きます。

特に重要なのは、津守が**重度障害児との関わり**を通じて辿り着いた地平です。言葉のない子、応答が見えにくい子と居続けるとき、保育者は「**子から何かを引き出そうとする構え**」を一度ほどき、ただ**そこに居る**ことの意味を発見する。健常児に対しても、本質は同じ──「教えこむ」「育てる」「導く」という能動の言葉の手前に、「**共に居る**」という受動的・関係的な働きがある。

倉橋の「**育ての心**」を、戦後の臨床心理学・現象学（メルロ＝ポンティ等）と接続して**深化**させた書として読める。家庭への翻訳: 親が「何をしてあげるか」より「**どう居るか**」を考える。子と一緒の時間の質は、何をしたかではなく、その時間に親がどんな身体・心で居たかで決まる、という視座。

## 著者紹介
津守真は東京帝国大学卒、お茶の水女子大学で発達心理学・幼児教育学を講じ、附属幼稚園主事を長年務めた。1983年から1995年まで愛育養護学校校長として重度障害児教育に従事し、その実践記録が本書および続編の核をなす。倉橋惣三 → 津守真 → 高杉自子 という日本保育学の正統な系譜の中心人物。

## ひだまりこそだち接点
- **想定保護者**: 「何をしてあげるか」より「どう居るか」を考えたい保護者、障害児支援・インクルーシブな関わりに関心のある保護者、保育者・教師
- **関連理論**: [[kurahashi-sozo]], [[bank-street]], [[pikler]]
- **我々の立場**: 全面的に同意。ひだまりこそだちの「**居る**」「**応答する**」という核を、日本保育学の系譜の中で最も成熟した形で言語化した書。倉橋の『育ての心』が**思想の出発点**だとすれば、津守の本書は**現代的な到達点**。共に書籍棚の中核に置く。

## 推奨度と注意
- **推奨度**: A
- **注意**: 文体は柔らかいが、現象学・臨床心理学の素養があると深く読める一方、思想書の読み慣れがないとやや難解。一般保護者向けというよりは、**保育者・教育研究者・思想に関心のある保護者向け**。実証研究の本ではなく、**実践と省察の記録**として読む。続編に『保育の体験と思索』（大日本図書、1980年）、『子どもの世界をどうみるか』（NHKブックス、1987年）があり、合わせて読むと理解が深まる。
