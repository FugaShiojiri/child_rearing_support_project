# 子どものための精神医学

## 一行サマリ
**「子どもの精神的困難を、関係性・発達・社会の文脈で理解する」**──日本の児童精神医学の包括的概説書として、現代の臨床・教育・福祉に橋を架ける一冊です。

## 書誌情報
- 著者: 滝川一廣（たきかわ かずひろ、1947-、児童精神科医、学習院大学名誉教授、元 子どもの虹情報研修センター長）
- 出版: 医学書院、2017年4月
- ISBN: 978-4-260-03037-3
- 原著言語: 日本語

## 中核思想（自分の言葉で要約）
滝川一廣は、東京大学医学部卒、東京都立梅ヶ丘病院などを経て、児童精神科臨床と児童虐待対応の現場で長年活動してきた児童精神科医です。本書は、児童虐待・発達障害・不登校など現代的課題を含めた **児童精神医学の包括的概説書** として書かれ、医学書院から刊行された600頁超の大著で、児童精神医学領域の標準的教科書として広く参照されています。

中核命題は **「子どもの精神的困難は、生物学的素因・発達のあり方・関係性・社会的環境の交叉点で生じる」**。滝川は **「病気か否か」の二分法を退け**、子どもの状態を **発達と関係性の文脈で連続的に理解する** 視座を一貫して取ります。具体的には：

1. **「精神発達」を縦糸に置く**：本書の前半は精神発達論にあてられ、ピアジェ・エリクソン・ボウルビィ・ヴィゴツキーらの古典を統合しながら、「**認識発達**」と「**関係発達**」の二軸で子の心の成り立ちを記述する。著者独自の発達図式は、後続の臨床家・教育者にとっての参照枠になっている。
2. **「精神医学的問題」を発達の連続体として扱う**：発達障害、不登校、神経症的な不適応、虐待・トラウマの後遺、思春期の精神病性体験など、個別の症候群を扱う際にも、「**発達のどの線がどう滞っているか**」「**関係の中で何が起きているか**」を問う姿勢が貫かれる。
3. **診断は「区分」ではなく「理解の補助線」**：DSM/ICD的な操作的診断の有用性を認めつつ、それを **絶対視せず**、目の前の子の生きづらさを理解する補助線として用いる立場。
4. **支援は「治療」より「育ち直し」**：症状除去ではなく、子・家族・場の **発達の再起動** を目指す視点。家族・学校・施設・地域がチームで支える「**多重的支援**」を強調する。

家庭への含意（家族向け実用書ではないが、本書から滲み出てくる視座）：
1. **子の困難は「親のしつけの失敗」でも「子の性格の問題」でもなく、関係性と発達の中で生じる**。誰の責任、ではなく「**どう関わりを組み立て直すか**」が問い。
2. **専門機関に相談することは「親が失格である」証ではなく、関係性を整え直すための社会資源の活用**。
3. **「うちの子は普通か」という問いより、「うちの子は今どの発達課題に取り組んでいるか」「どこで滞りやすいか」という問いのほうが、関わりを開く**。

家庭への翻訳: 本書は専門書だが、保育園・学校・支援機関で「**なぜこの子はこうなのか**」を考える支援職が一人いるだけで、家庭が救われる場面は多い。保護者自身が読み通すには重いが、**信頼できる支援者がこの枠組みを持っているか** は、家族の安心に直結する。

## 著者紹介
滝川一廣は、東京大学医学部卒（1972）、東京都立梅ヶ丘病院、川崎市中央児童相談所、子どもの虹情報研修センター長などを歴任。日本の児童虐待対応の体制整備、児童精神医学の臨床と教育の両面で中心的役割を果たしてきた。主著に *新版 子どものための精神医学*（医学書院、2017、本書）、*学校に行く意味・休む意味*（日本図書センター、2012）、*「こころ」の本質とは何か*（ちくま新書、2004）、共著・編著多数。

## ひだまりこそだち接点
- **想定保護者**: 子の状態が気になる保護者で「医学的に何かあるのか、それとも個性か」を悩んでいる人、児童精神科・発達障害者支援センターに相談する前後で **枠組み** を持ちたい保護者、保育・教育・福祉の現場で家族と関わる支援職
- **関連理論**: [[bowlby-attachment]]（関係発達の基盤）、[[sasaki-masami]]（同じ児童精神科医として、より一般向けに翻訳した語り口）、[[harvard-cdc-framework]]（生物・心理・社会の統合枠組み）、[[erikson]]（発達段階論の系譜）、[[theory-of-mind]]（認識発達）
- **我々の立場**: 同意。滝川の **「区分ではなく連続体」「症状除去ではなく育ち直し」「親の責任ではなく関係性の組み直し**」 という臨床姿勢は、ひだまりこそだちが採用する基本軸と一致する。保護者向けには重すぎるが、**サービスの編集者・運営者が拠って立つ底本** として価値が高い。佐々木正美が「親への語り」だとすれば、滝川は「**支援職への臨床思考の言語化**」を担う仕事。

## 推奨度と注意（controversies）
- **推奨度**: A（強推奨、ただし支援職・編集者向け／一般保護者には条件付き）
- **【最重要】医療助言ではない旨の明記**: 本書は児童精神医学の概説書であり、特定の症状の **自己診断・自己治療のためのものではない**。気になる症状（極端な情動の不安定、長期の不登校、自傷、摂食障害、神経発達症の疑い等）がある場合は、児童精神科、小児神経科、地域の子ども家庭支援センター、児童相談所、発達障害者支援センターなどへ。個別の診断・治療・支援計画は必ず専門職と一緒に行うこと。
- **専門書としての読み方**: 600頁超の概説書で、医学・心理・福祉の基礎的素養があると読みやすい。一般保護者向けには、まず佐々木正美『子どもへのまなざし』（[[books/jp_modern/sasaki-1998-kodomohenomanazashi]]）等の一般向け入門書を経由してから、関心領域だけ滝川に進む、という二段読みが現実的。
- **診断概念への姿勢**: 滝川はDSM/ICDの操作的診断を **絶対視せず**、補助線として用いる立場をとる。一方、現場では「**診断名がついて初めて支援が届く**」現実もあり、診断軽視に読まれない注意が要る。本書の趣旨は「**診断を超えて子を理解する**」ことであり、「**診断不要**」ではない。
- **「育ち直し」概念の取り扱い**: 「育ち直し」は希望のメッセージとして響く一方、家族・支援者の **長期的コミット** を前提とする概念で、「**気軽にできる**」ものではない。安易に「**愛情で取り戻せる**」と読み替えないこと。
- **発達障害の章の取り扱い**: 本書は発達障害をスペクトラム的・連続体的に扱うが、これは特性の **否認** ではない。特性が日常生活に支障を生じている場合、専門機関での評価・支援は **早いほうがよい**（→ [[books/jp_modern/sugiyama-2007-hattatsu-shogai-no-kodomotachi]]）。
