# 子どもの世界をどうみるか

## 一行サマリ
子どもの行為のひとつひとつを「**意味のある世界づくり**」として読み解く眼差し──津守真が示した、保育者・親のための **観察の哲学** です。

## 書誌情報
- 著者: 津守真（つもり まこと、1926-2018、日本の保育学者・心理学者、お茶の水女子大学名誉教授、愛育養護学校元校長）
- 出版: 日本放送出版協会（NHKブックス523）、1987年
- ISBN: 978-4-14-001522-3
- 副題: 行為とその意味
- 原著言語: 日本語

## 中核思想（自分の言葉で要約）
津守真の代表作の一つで、新書サイズながら **「子どもの行為をどう読むか」という主題を、日本保育学の到達点として体系化した一冊**。後年の『保育者の地平』（1997）と並ぶ、津守思想のコアです。

中心概念は「**行為の意味**」── 子どもが砂を握る・水をこぼす・棚から物を出して並べる、といった大人から見れば「いたずら」「無意味」に見える行為が、子にとっては **世界を理解しようとする探究そのもの** であるという視座。津守は、お茶の水女子大学附属幼稚園での観察記録、そして愛育養護学校で出会った重度障害のある子どもたちの行為を題材に、「**子の行為には、その子なりの文脈と意味がある**」ということを、現象学的なまなざしで繰り返し示します。

中心メッセージは三つ。**(1)** 子の行為を「**正しい/間違い**」「**できる/できない**」で評価する前に、**その行為が子にとってどんな意味を持つか** を観る。**(2)** 観察者（保育者・親）自身もまた、子との関係のなかで **応答する身体** として存在しており、観察は中立ではなく **関係的な行為**。**(3)** 子の世界は、言葉で説明できる範囲よりはるかに広い。観察者の役割は、解釈で閉じてしまうことではなく「**まだ分からない**」を抱え続けることでもある。

家庭への翻訳: 子の「**いたずら**」「**こだわり**」「**わけのわからない遊び**」を、まず **意味を持った行為** として見てみる。「やめさせる」「直す」前に、「**この子はいま、何を発見しているのか**」と問うてみる。──この一拍の余白が、親子の関係を変える、というのが津守の核心。

## 著者紹介
津守真は東京帝国大学卒、お茶の水女子大学で発達心理学・幼児教育学を講じ、附属幼稚園主事を長年務めた。1983-1995年に愛育養護学校校長として重度障害児教育に従事。本書はその両方の経験を背景に、新書というアクセシブルな形で「**観察の哲学**」を提示した代表作。倉橋惣三 → 津守真 → 高杉自子という日本保育学の正統な系譜の中心人物。

## ひだまりこそだち接点
- **想定保護者**: 子の「**わけのわからない行動**」に困っている保護者、観察と省察の姿勢を学びたい保育者・親、障害児・発達特性のある子の家族
- **関連理論**: [[kurahashi-sozo]], [[bank-street]], [[pikler]], [[reggio-emilia]]（行為の意味を読むという視座で共鳴）
- **我々の立場**: 全面的に同意。ひだまりこそだちの「**待つ・観る・応える**」という編集軸を、**保護者にも届く言葉と分量** で書き切った稀少な書。『保育者の地平』が思想の到達点であるのに対し、本書は **入口** として置く。レッジョ・エミリアの「**100の言葉**」（[[reggio-emilia]]）と同じ場所を、日本の文脈で語っている。

## 推奨度と注意
- **推奨度**: A
- **注意**: NHKブックスのため『保育者の地平』より読みやすいが、それでも **エビデンスベースの育児書ではなく観察の哲学書**。具体的なハウツーや月齢別マニュアルを期待すると裏切られる。「**子と一緒の時間を、もう一段深く味わいたい**」保護者にこそ届く本。1987年刊行のため装丁・流通は古書中心となり、入手はやや困難（NDL・大型図書館・古書市場で確実）。続編・関連書として『保育の体験と思索』(1980)、『保育者の地平』(1997)、『子ども学のはじまり』(2003) が並ぶ。
