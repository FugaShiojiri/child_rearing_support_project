# 幼稚園真諦

## 一行サマリ
「さながらの生活」から始める誘導保育──日本の児童中心主義の原典です。

## 書誌情報
- 著者: 倉橋惣三（くらはし そうぞう、1882-1955、日本の幼児教育学者）
- 出版: 東洋図書（初版 1934年）／フレーベル館（戦後復刊・新版多数）
- ISBN: 978-4-577-80000-3（フレーベル館 新版）
- 原著言語: 日本語

## 中核思想（自分の言葉で要約）
倉橋は、当時日本に輸入されていた「フレーベル恩物（決まった教具を順番に使わせる）」の形式化を批判し、子どもの**生活そのもの**から始める保育を提唱しました。中心概念は4つの動き：

1. **さながらの生活**：子が園に来たそのままの姿・興味を起点にする。
2. **自己充実**：子が自分の力で遊び込み、満たされる時間を確保する。
3. **充実指導**：充実が深まるよう、大人がさりげなく環境を整える。
4. **誘導**：自己充実を、より広い経験へとそっと誘い出す。

「**自ら育つものを育たせようとする心**」── これが姉妹編『育ての心』の核です。子は「育てる対象」である前に「**育ちつつある存在**」であり、大人は「育つを助ける」役に徹する。

家庭への翻訳: 「教えなければ」「指導しなければ」と先回りせず、子のいま夢中になっていることに環境を寄せる。「待つ」と「放任」は違う──大人は見ていて、必要なときに環境を少し整える。

## 著者紹介
倉橋惣三は東京女子高等師範学校（現お茶の水女子大学）附属幼稚園主事を長年務め、戦前から戦後の日本幼児教育を方向づけた。「日本のフレーベル」と呼ばれるが、実態はフレーベル主義の形式化を批判して独自の理論を立てた。デューイ思想の日本への翻訳者の一人でもある。

## ひだまりこそだち接点
- **想定保護者**: 子ども主体の保育園・幼稚園を選びたい保護者、子育ての日本的源流を知りたい保護者
- **関連理論**: [[kurahashi-sozo]], [[dewey-experience]], [[bank-street]]
- **我々の立場**: 全面的に同意（思想として）。ひだまりこそだちの「待つ」「観察」「断言しない」3原則の日本における直接の源流。一方で、戦前～昭和初期の**母性ロマンチシズム**（「母親が一日中そばにいるべき」式の規範）は時代制約として括弧に入れ、思想の核だけを現代に翻訳して使う立場を取る。

## 推奨度と注意
- **推奨度**: B（条件付き／思想の出典として）
- **注意**: 1930-50年代の保育者向け講義をまとめた書で、文体が古く家庭育児書としては読みづらい。専業主婦・母性中心の家族観が前提のため、現代の共働き・多様な家族形態への適用には注釈が必要。一方で「**自己充実→充実指導→誘導**」というシークエンスは、現代の保育者・保護者にも十分通じる枠組み。
