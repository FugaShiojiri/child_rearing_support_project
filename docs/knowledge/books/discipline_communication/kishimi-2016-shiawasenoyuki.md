# 幸せになる勇気 ─ 自己啓発の源流「アドラー」の教えII

## 一行サマリ
「ほめてはいけない、叱ってもいけない」── 教育論・恋愛論にフォーカスした『嫌われる勇気』続編で、子育てに最も直接接続する一冊です。

## 書誌情報
- 著者: 岸見一郎（きしみいちろう、1956-、京都府立医科大学非常勤講師、アドラー心理学カウンセラー）／古賀史健（こがふみたけ、1973-、ライター）
- 出版: ダイヤモンド社、2016年2月
- ISBN: 978-4-478-06611-9
- 原著言語: 日本語（韓国・台湾でも前作同様ベストセラー）

## 中核思想（自分の言葉で要約）
本書は『嫌われる勇気』（2013）の続編で、再び哲人と青年の対話形式。前作から3年経って教師になった青年が「アドラー心理学は教育現場で通用しない」と哲人に挑む、という設定で **教育論・愛の議論** に踏み込みます。前作が「個人の生き方」中心だったのに対し、本書は **教育者・親の役割** が明示的にテーマ化されている点で、子育て・保育文脈での参照価値が高い一冊。

中心メッセージは4つ：(1) **「ほめてはいけない、叱ってもいけない」**＝賞罰はどちらも「縦の関係」、子の自立を奪う。代わりに **勇気づけ（横の関係での承認）** を行う、(2) **教育の目標は「自立」**＝子を尊敬・信頼することから始め、最終的に「自分の力で生きていける」状態へ導く、(3) **「課題の分離」から「共同体感覚」へ**＝分離は出発点で、最終的には「他者を仲間と見る」共同体感覚に至る、(4) **「愛」は技術である**＝愛は受身の感情ではなく、能動的な「実践課題」として扱う。

子育て・保育への翻訳: 「**ほめないってどういうこと？**」と問われたときの教科書的参照源。「**評価＝縦から見下ろす言葉（えらいね、すごいね）**」と「**勇気づけ＝横から並ぶ言葉（ありがとう、助かった、やってみたんだね）**」の区別を、対話形式で平易に説明。前作で誤読された「課題の分離」を **「共同体感覚に至るための入口」** として位置づけ直した点が、子育て文脈では特に重要。

家庭への翻訳: 「**ほめる／叱る**」が反射的に出る瞬間に、「**自分はいま縦に立っているか？**」を点検する補助線。0-2歳ではまず安全と愛着が優先、3歳以降でこの言葉の使い分けを意識する、というのが現実的な運用。

## 著者紹介
前作と同じ岸見一郎・古賀史健コンビ。岸見は本書執筆中に心臓疾患で入院し、退院後に古賀との対話を再開して完成させたという経緯がある（あとがき）。日本アドラー心理学会の野田俊作系の正統的解釈を背景に持つが、教育論パートは岸見の独自展開も含まれる。

## ひだまりこそだち接点
- **想定保護者**: 「ほめてはいけない」の意味を正確に知りたい保護者、『嫌われる勇気』の次の一冊を探す保護者、保育者・教育者
- **関連理論**: [[adler-psychology]]（教育論パートが直接接続）、[[conscious-discipline]]（賞罰批判で重なる）、[[nvc]]（評価でなく観察と感情を伝える点で並行）
- **我々の立場**: 子育て・保育文脈では **前作より本書を優先推薦**。「賞罰の否定」「教育の目標は自立」というメッセージは、ひだまりこそだちが伝えたい子育て観と一致。ただし前作と同じく、単純化・スローガン化のリスクは強い。

## 推奨度と注意
- **推奨度**: A（強推奨／ただし条件付き）
- **重要な注意（controversies）**: 前作と同様、岸見流のアドラー解釈には **学術派から批判** がある。
  1. **「ほめてはいけない」の機械化**: 本書の最大の誤読リスク。自然な感情表現（「うわー、できたね！」）まで抑制し、結果として **無反応な親** になる事例が多数発生。アドラー本来の意図は「**評価者の立場から見下ろさない**」であって「**感情表現の禁止**」ではない。割合の問題として「ありがとう」を増やす、という現実的運用が必要。
  2. **「教育の目標は自立」の早期化リスク**: 0-2歳の乳児期は **愛着と依存が先**。本書のメッセージを乳児期に適用すると、過早な自立要求になる危険。Bowlby のアタッチメント理論を土台に、3歳以降のレイヤーで本書を使うのが妥当。
  3. **「賞罰の否定」の家庭間摩擦**: 祖父母世代・配偶者との価値観衝突を生みやすい。「一貫していなければ意味がない」と完璧主義に陥る親への配慮が必要。
  4. **アドラー研究者からの異論**: 「岸見解釈は思弁的、アドラー原典との乖離あり」という批判は本書にも該当する。特に本書終盤の「愛」「結婚」論はアドラー原典より岸見の哲学的展開色が強い。
  5. **エビデンスの問題**: 思想・哲学であり、RCT・メタ分析の蓄積は限定的。「効くと証明された」とは言わない。

詳細は [[education_theories/tier_s/adler-psychology/controversies]] を参照。コンテンツで本書を扱う際は「ほめない≠無反応」「自立は3歳以降のレイヤー」「思想であってRCTではない」の3点を必ず併記する。
