# 嫌われる勇気 ─ 自己啓発の源流「アドラー」の教え

## 一行サマリ
「すべての悩みは対人関係の悩み」── 哲人と青年の対話形式でアドラー心理学を語る、世界500万部のメガベストセラーです。

## 書誌情報
- 著者: 岸見一郎（きしみいちろう、1956-、京都府立医科大学非常勤講師、日本アドラー心理学会認定カウンセラー）／古賀史健（こがふみたけ、1973-、ライター）
- 出版: ダイヤモンド社、2013年12月
- ISBN: 978-4-478-02581-9
- 原著言語: 日本語（その後20以上の言語に翻訳、韓国・台湾・中国でも大ベストセラー）

## 中核思想（自分の言葉で要約）
本書は、青年と哲人（アドラー派カウンセラー）の対話形式で **アドラー心理学（個人心理学）** の主要概念を解説する思想入門書です。著者の岸見一郎は1980年代から日本アドラー心理学会で研鑽を積んだアドラー研究者で、本書はそれまでマイナーだったアドラー心理学を日本社会に広く知らしめた功績がある一冊。

中心メッセージは5つ：(1) **目的論**＝過去のトラウマでなく「いま何のために」を見る、(2) **すべての悩みは対人関係**＝個人内部の問題でなく関係の問題、(3) **課題の分離**＝「最終的に結果を引き受けるのは誰か」で誰の課題か区別する、(4) **承認欲求の否定**＝他者の評価で生きると不自由、自分で価値を決めよ、(5) **共同体感覚＋他者貢献**＝「私は誰かの役に立っている」が幸福の鍵。

子育てへの接続点は限定的（本書は子育て書ではない）ですが、「**課題の分離**」「**ほめてはいけない／叱ってもいけない**」「**横の関係**」というフレーズは、その後の日本の子育て言説に強く影響しました。「子どもの宿題は子の課題」「ほめるのは縦の関係、勇気づけが横の関係」という整理は、続編『幸せになる勇気』でより明示的に展開されます。

家庭への翻訳: 「**いい親でなければ**」という縦の自己評価を降り、子と対等な関係を組み直すための **思想的補助線**。ただし「**これだけで子育てが変わる**」と期待するのは過剰。

## 著者紹介
岸見一郎は京都大学大学院で西洋古代哲学を学んだ哲学者で、1989年に日本アドラー心理学会の野田俊作に師事。アドラー著作の翻訳（アルテ社）を多数手がけ、アカデミックな読解の正確さで知られる。古賀史健は構成・対話形式を担当し、難解な思想を一般読者に届ける編集力で本書を成立させた。

## ひだまりこそだち接点
- **想定保護者**: 「アドラーって何？」と聞く保護者への第一推薦書、「いい親」プレッシャーから降りたい保護者、自己啓発書として読書習慣がある保護者
- **関連理論**: [[adler-psychology]]（本書はそのまま入口）、[[nobuta-sayoko]]（「親を許さなくていい」「課題の分離」は親自身のメンタルケアと接続）、[[nvc]]（共感的傾聴の姿勢で重なる）
- **我々の立場**: 入口として **条件付きで推薦**。アドラーを知る最初の一冊として有用だが、ひだまりこそだちでは「**これだけで子育てが変わる**」とは絶対に言わない。続編『幸せになる勇気』のほうが教育・子育てに直接踏み込んでいるため、子育て目的なら続編優先という案内も併用する。

## 推奨度と注意
- **推奨度**: A（強推奨／ただし条件付き）
- **重要な注意（controversies）**: 本書のアドラー解釈は、**学術派アドラー研究者から複数の批判** がある。
  1. **岸見流の単純化**: 「すべては勇気の問題」「課題を分離すれば楽になる」というキャッチフレーズ化により、構造的問題（貧困・差別・DV・発達特性・産後うつ）まで個人の心の問題に還元される自己責任論的読解が広がった。
  2. **「課題の分離」の誤用**: 「子の課題に立ち入らない」が「放任」「無関心」と混同されやすい。アドラー本来の意図は「分離した上で信頼関係の中で協力する」であり、突き放しではない。
  3. **「ほめてはいけない」の機械化**: 自然な感情表現まで抑制してしまう保護者が増え、結果として「無反応な親」になる誤用。
  4. **アドラー研究者からの異論**: 国際アドラー会（NASAP系）の研究者の中には「岸見解釈は思弁的でアドラー原典と乖離がある」という指摘もある。
  5. **エビデンスの問題**: アドラー心理学は思想・哲学的側面が強く、CBTやPCITのような大規模RCT・メタ分析の蓄積は限定的。「エビデンスベースド」とは言わない。

詳細は [[education_theories/tier_s/adler-psychology/controversies]] を参照。コンテンツで本書を扱う際は **必ず** 「分離≠放任」「ほめない≠無反応」「思想であってRCTではない」の3点を併記する。
