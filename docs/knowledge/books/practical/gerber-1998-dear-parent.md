# Dear Parent: Caring for Infants With Respect

## 一行サマリ
赤ちゃんを「**一人の人**」として尊重する──RIE（Resources for Infant Educarers）の創始者マグダ・ガーバー自身による、思想と実践の原典です。

## 書誌情報
- 著者: Magda Gerber（マグダ・ガーバー、1910-2007、ハンガリー出身、米国RIE創始者）
- 原著: *Dear Parent: Caring for Infants With Respect* (RIE, 1998／第2版 2002)
- ISBN: 978-1-892560-06-3
- 原著言語: 英語（ガーバーの英語）
- 邦訳: 未邦訳（2026-05時点）。日本では汐見稔幸らによる紹介、RIE Japan による紹介記事、雑誌『**こどものとも**』『**保育**』系の翻訳記事を経由して断片的に流通。

## 中核思想（自分の言葉で要約）
マグダ・ガーバーは、ハンガリーのエミ・ピクラー（[[pikler]]）の弟子で、第二次大戦後に米国へ移住。1978年、ロサンゼルスで小児科医トム・フォレストと共同で **RIE（Resources for Infant Educarers）** を設立しました。本書は、彼女が長年にわたって書きためた親向けエッセイ・講演録を編集した、**RIEの思想と実践の原典** です。

中核命題は **"Treat infants as people, not objects"**（乳児を「もの」ではなく「人」として扱う）。彼女が造語した **"Educaring"**（Educate + Caring）は、「**世話する時間と教育する時間を分けない**」という発想。授乳・おむつ替え・着替え・お風呂──こうした **日常の世話の時間こそが、最も濃密な学びと関係形成の場** であると考えます。

実務の柱：
1. **声をかけてから触れる**：「**今おむつを開けるね**」「**腕を上げてくれる？**」──赤ちゃんに向かって直接、これから何をするかを伝える。赤ちゃんは「世話される対象」ではなく「**協力するパートナー**」。
2. **応答を待つ**：声をかけたあと、赤ちゃんの反応を **数秒待つ**。この間が「対話」を生む。
3. **邪魔しない自由な遊び（uninterrupted play）**：赤ちゃんが一人で何かに集中しているとき、声をかけず・教えず・促さず、**そっと観察する**。
4. **自然な運動発達を信じる**：座らせる・立たせる・歩かせる、を急がない。赤ちゃんは **自分で次の段階に進む**（ピクラーの自由運動発達論を継承）。
5. **観察（observation）を基本にする**：「**この子は今何をしているか、何に惹かれているか**」を、解釈・評価せずに見る。

家庭への翻訳: 「**早く・もっと・たくさん**」が支配的な現代育児への、最も静かな逆張り。「**急がない・邪魔しない・尊重する**」という三原則を、新生児期から実装する。

## 著者紹介
マグダ・ガーバーは、ブダペストのピクラー研究所で学び、ピクラー本人と長年共同研究。1957年に米国へ移住し、UCLAなどで講師を務めた後、1978年にRIEを設立。生涯にわたって親・保育者向けの教育に従事し、米国の乳児保育思想に大きな影響を与えた。本書 *Dear Parent* (1998) と *Your Self-Confident Baby* (Wiley, 1998、共著: Allison Johnson) が代表作。

## ひだまりこそだち接点
- **想定保護者**: 新生児期・乳児期（0-2歳）の保護者、「**早く立たせたい**」「**もっと刺激を**」と焦っている保護者、第一子で「**正解**」を求めて検索している保護者、保育者
- **関連理論**: [[rie-gerber]], [[pikler]], [[attachment]]
- **我々の立場**: 強く同意。「**赤ちゃんを一人の人として扱う**」という出発点は、ひだまりこそだちの「**子育ち**」哲学そのもの。「**おむつ替えの声かけ**」「**応答を待つ**」「**邪魔しない**」は、ワンオペでも・時間がなくても・初心者でも、明日から実装できる最も実践的な技法。

## 推奨度と注意
- **推奨度**: A（強推奨／RIE系のNo.1原典として）
- **注意**: (1) 邦訳がないため、日本の保護者には直接届けにくい。サービスとしては、本書の核となる「**5つの実務の柱**」を日本語の短い記事・動画に翻訳して届けるのが現実的。(2) ガーバーの文体は穏やかだが、原理主義的に運用すると「**バウンサー・抱っこ紐・スマホ授乳は全部ダメ**」になりがちで、現代日本のワンオペ・共働き家庭の現実と衝突する。「**全部やる**」ではなく「**世話の時間に一言声をかける**」だけでも本書の核は実装できる、と保護者に伝える距離感が必要。(3) 「**邪魔しない**」が「**話しかけない**」と誤解されやすい。RIEは **世話の時には積極的に語りかける** ことを推奨しており、「**沈黙の哲学**」ではない（→ [[rie-gerber]] §「親が陥りがちな誤解」参照）。
