# 「叱らない」しつけ 子どもがグングン成長する親になる本

## 一行サマリ
元小学校教師が、現場経験から「**叱らない**」の具体的な技を語った国内ベストセラーです。

## 書誌情報
- 著者: 親野智可等（おやの ちから、1958-、元小学校教師、教育評論家）
- 出版: PHP研究所、2006年
- ISBN: 4-569-65270-0
- 原著言語: 日本語

## 中核思想（自分の言葉で要約）
親野智可等は、公立小学校で23年間教鞭を執った元教師。退職後はメルマガ・著作・講演を通じて子育てアドバイスを発信し、保護者層に高い支持を得ている。本書は彼の代表作の一つで、「**叱らない**」を抽象論ではなく**現場で見た具体例**で語る構成。

中心メッセージ：(1) 子は「**叱られて変わる**」より「**認められて伸びる**」、(2) 子の困った行動の多くは**発達段階上の自然な姿**で、叱る対象ではない、(3) 「**叱る**」は親自身の感情の問題であることが多く、子の問題ではない、(4) 「**叱らない**」は「**何も言わない**」ではなく、「**事実を伝える・選択肢を示す・一緒に考える**」。

家庭への翻訳: 「**早く片付けなさい！**」→「**おもちゃ、戻す時間だよ。どっちから片付ける？**」のような具体的言い換え集として読みやすい。「叱るとどうなるか」の現場エピソードが豊富で、自分の感情を整える視点を提供します。

## 著者紹介
親野智可等は静岡県の公立小学校教師を23年務め、退職後は教育評論家として執筆・講演活動を展開。メルマガ「**親力で決まる子供の将来**」は20年以上続く長寿コラム。書籍多数。

## ひだまりこそだち接点
- **想定保護者**: 「叱り過ぎてしまう」と悩む保護者、入学準備期で「**しつけ**」が気になる保護者
- **関連理論**: [[positive-discipline]], [[conscious-discipline]], [[nvc]]
- **我々の立場**: 部分同意。「**叱らない**」「**認める**」「**待つ**」という核は、ひだまりこそだちの姿勢と一致。「**現場の具体例**」が豊富で実用的。一方、「**親野メソッド**」として運用すると「**叱ってしまった自分はダメな親**」という新たな自責を生む懸念があり、補助線が必要。

## 推奨度と注意
- **推奨度**: B（条件付き）
- **注意**: 学校教師の視点で書かれているため、「**しつけ＝学校で困らない子に育てる**」というフレームが強い。家庭の関わりを「**教育成果**」で測る読み方に陥らないこと。「**叱らない**」が「**親が我慢する**」になると共倒れになるため、「**親の感情を整えるためにどうするか**」を同時に考える必要あり（本書はその視点が弱い）。
