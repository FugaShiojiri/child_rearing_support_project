# 親子のベッドシェアリング：良い面・悪い面・エビデンスの重み

## 200-500字要約
本論文は、親子のベッドシェアリング（bed-sharing）に関する研究を系統的にレビューし、その「良い面」「悪い面」「エビデンスの質」を整理した総説です。著者らは、ベッドシェアリングが（1）母乳育児の維持・期間延長、（2）母子の睡眠中の生理的同期、（3）夜間応答性の高さ、と関連することを多くの研究が示す一方で、（4）SIDS および乳児窒息のリスク増加と関連する研究も同様に存在することを整理しています。研究では、SIDS リスクは「ベッドシェアリングそのもの」よりも、**親の喫煙・飲酒・薬物使用、ソファでの添い寝、早産児・低出生体重児、月齢 3 か月未満** といった具体的因子に強く依存することが繰り返し報告されてきました。著者らは、現存するエビデンスは方法論的に多様で（観察研究中心、自己報告ベース、文化差の交絡）、「ベッドシェアリングは良い／悪い」という二項対立を支える質の高いエビデンスは限られていると結論しています。家族の文化・授乳形態・リスク因子に応じた個別判断が必要であり、画一的な推奨は実証的根拠が弱いとされています。

## キーフィンディング（3-5項目）
- 知見1: ベッドシェアリングは母乳育児の維持・延長と一貫して関連する。
- 知見2: 母子の睡眠中の生理的同期・夜間応答性の高さも報告されている。
- 知見3: SIDS および乳児窒息のリスク増加と関連する研究も同様に存在し、無視できない。
- 知見4: SIDS リスクは喫煙・飲酒・薬物・ソファ・早産児・3 か月未満などの**具体的因子に強く依存**する。
- 知見5: 現存エビデンスの方法論的限界（観察研究中心・自己報告・文化交絡）から、画一的な賛否判定は困難。

## ひだまりこそだち への示唆（医療助言を避ける記述）
- **スタンス**: 本論文は共寝の賛否両論を最もバランスよく扱う系統的レビューです。日本のように添い寝が一般的な文化圏でも、リスク因子（喫煙・飲酒・寝具・ソファ）は変動するため、「文化的に普通だから安全」と単純化しない論調に使えます。
- マッチャーでの使い方: 「添い寝の是非で迷っている」マッチで、リスク因子の具体的内訳と授乳の利点を**両論併記**するクッションに使う。CEO 目視前提、`clinical_advice_safe: false`。
- note 記事化のフック: 「添い寝の『良い面・悪い面』──研究をフェアに読むと何が言えるか」。McKenna 2007 と本論文を並べた両論記事。
- 親への翻訳: 「研究では、添い寝には授乳が続きやすいという利点と、状況によっては窒息リスクが上がるという両方の側面が報告されています。重要なのは『添い寝するかしないか』より、寝具・喫煙・飲酒・ソファでの添い寝の回避など具体的な環境因子です」。

## 関連理論との関係
- [[bowlby-attachment]] / [[ainsworth-strange-situation]]: 共寝は近接性の最大形態だが、本論文は「共寝＝愛着安定」と単純化することにも慎重。愛着スタイルとの関連は別研究で必要。

## 留保・批判
- **個別判断は専門医に**: 添い寝の安全性は寝具・両親の飲酒・喫煙・乳児の早産・低出生体重などの個別要因に依存します。具体的な就寝環境の判断は、必ず小児科医・公衆衛生機関のガイドライン（厚生労働省、AAP 等）を参照してください。
- 観察研究の限界: ランダム化が事実上不可能な領域で、観察研究と自己報告に依存。
- 文化交絡: 欧米サンプル中心で、ベッドシェアリングが「規範的逸脱」とみなされる文化と「規範的標準」とみなされる文化の交絡が制御困難。
- 反証・対立: McKenna 2007 はより積極的に共寝の進化的・生物学的意義を擁護する立場。本論文はそれを参照しつつもより慎重。
