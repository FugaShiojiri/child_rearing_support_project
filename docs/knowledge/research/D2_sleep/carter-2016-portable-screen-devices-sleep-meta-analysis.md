# 携帯型スクリーンデバイスのアクセス／使用と睡眠アウトカムとの関連：系統的レビューとメタ分析

## 200-500字要約
本論文は、携帯型スクリーンデバイス（スマートフォン・タブレット等）の使用または寝室でのアクセスと、6-19 歳の学齢期児童・思春期の睡眠アウトカムの関連を、20 研究（合計約 125,198 名、平均年齢 14.5 歳、男児 50.1%）のメタ分析として統合した研究です。研究では、就寝時の携帯デバイス使用が以下と有意に関連することが報告されました: **睡眠時間の不足（OR 2.17, 95% CI 1.42-3.32）、睡眠の質の低下（OR 1.46, 1.14-1.88）、日中の過剰な眠気（OR 2.72, 1.32-5.61）**。さらに、**就寝時にデバイスを使用していなくても、寝室にデバイスがあるだけ（access）で同様のアウトカムが認められた**: 睡眠不足（OR 1.79）、睡眠質低下（OR 1.53）、日中眠気（OR 2.27）。研究では、この知見は、寝室のデバイスがいわば「常時オン」の睡眠妨害要因として機能している可能性を示唆するものと報告されました。著者らは、教師・医療従事者・親が連携してデバイスの寝室アクセスを最小化するアプローチが必要であり、睡眠衛生への影響を評価する更なる研究が必要と結論しています。

## キーフィンディング（3-5項目）
- 知見1: 就寝時の携帯デバイス使用は睡眠時間不足と関連（OR 2.17）。
- 知見2: 同様に睡眠の質低下（OR 1.46）、日中眠気（OR 2.72）と関連。
- 知見3: **使用していなくても寝室にデバイスがあるだけ** で、睡眠不足（OR 1.79）・質低下（OR 1.53）・日中眠気（OR 2.27）と関連。
- 知見4: 効果量はデバイス使用群より若干小さいが、アクセスのみでも有意な関連が認められた。
- 知見5: 著者らは寝室からのデバイス除去を含む統合的アプローチを提言。

## ひだまりこそだち への示唆（医療助言を避ける記述）
- **スタンス**: 学齢期のスクリーンと睡眠を扱う際の量的根拠。「スマホを使わなくても、寝室にあるだけで睡眠が悪化する」という直感に反する所見が note 記事化のフックとして強い。
- マッチャーでの使い方: 「小学生の寝つきが悪い・朝起きられない」マッチで、寝室のデバイス環境を確認する促しに使う。CEO 目視前提、`clinical_advice_safe: false`。
- note 記事化のフック: 「使ってなくてもダメ？──子どもの寝室のスマホ・タブレット問題」。**実践助言の参照値として使いやすい**。
- 親への翻訳: 「研究では、寝る前にスマホやタブレットを使うことだけでなく、**寝室に置いてあるだけで** 子どもの睡眠時間が短くなり、日中の眠気が増えることが報告されています。寝室をデバイスフリーにすることが効果的な対策の一つです」。

## 関連理論との関係
- [[harvard-cdc-framework]]: 安定した睡眠は発達の基盤的健康指標として位置づけられる。
- [[executive-function]]: 睡眠不足は実行機能低下と関連し、デバイスの寝室アクセスがその上流要因となりうる。

## 留保・批判
- **個別判断は専門医に**: 重度の不眠・概日リズム障害・思春期の自殺念慮を伴う睡眠問題などは、小児精神科・睡眠専門医による評価が必要です。
- 観察研究の限界: 対象研究の多くが横断研究で、因果方向（デバイス → 睡眠悪化 vs. 睡眠が悪いからデバイスに依存）を完全に分離できない。
- 異質性: I² 値が複数の解析で 50-90% と高く、研究間のばらつきが大きい。
- 文化差: 欧米中心のサンプル。日本の児童・生徒のデバイス使用パターン（保護者の管理様式・寝室文化）との適合度は別途検討が必要。
- 対象年齢: 6-19 歳が対象で、未就学児（0-5 歳）は本論文の対象外（Janssen 2019 を参照）。
