# 「Skype Me!」社会的応答性のあるやりとりは2歳児の言語学習を助ける（Roseberry et al., 2014）

## 200-500字要約
Roseberry、Hirsh-Pasek、Golinkoff（Temple大）による、**ビデオ通話が乳幼児の学習に有効か** を実験的に検証した重要研究（*Child Development*、被引用501）。

**背景**: 「ビデオ欠損（video deficit）」現象 — 2歳未満は録画されたビデオから新規言語・行動を学習しにくい。一方、対面では同じ内容を容易に学習する。社会的応答性（social contingency）が学習の鍵か？

**実験設計**: 24-30か月児 **N=36** を3条件にランダム割付:
1. **対面条件**: 実験者が部屋にいて、新規動詞（例: blicking）を教える
2. **ビデオ通話条件**: Skypeで実験者が同じ手順で教える（子の反応に応答的）
3. **録画ビデオ条件**: 同じ実験者が同じ内容を教える録画を視聴（応答なし）

**測定**: テスト場面で、教わった動詞の意味を理解しているか（指差し選択課題）。

**結果**:
- **対面条件 と ビデオ通話条件で同等の学習** （新規動詞の理解率高）
- **録画ビデオ条件では学習なし**（chance levelのみ）
- 違いを生んだのは **「子のサインに応答する社会的応答性」** であり、画面か対面かではない

**結論**: ビデオ通話のように **応答的なやりとりがあれば、2歳児は2D画面からも学習できる**。AAPが18か月未満で「ビデオ通話を唯一の例外」とする根拠。

**含意**: 「スクリーン＝悪」という単純化を退ける。**重要なのは社会的相互作用の有無**。録画ビデオ・受動視聴は学習に資さず、応答性のある使い方なら同年代でも有用。

## キーフィンディング（3-5項目）
- 24-30か月児は **ビデオ通話** からも対面と同等に新規語彙を学習可能
- **録画ビデオ** からは学習しない（video deficit現象を再確認）
- 違いを作るのは **「社会的応答性（social contingency）」** であり画面の有無ではない
- AAPの「18か月未満はビデオ通話を例外として」勧告の実証的根拠
- 「スクリーンタイム」を一律で論じる無意味さを示唆

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「祖父母とのビデオ通話は乳児にも見せていい？」相談 → 「**ビデオ通話は録画動画と異なり社会的応答性があるため、2歳児でも学習可能。むしろ推奨される使い方**」
- note記事化のフック: 「ビデオ通話なら乳児も学べる：スクリーン悪論への科学的反論」「祖父母とのSkypeが孫の言葉を育てる」
- 親への翻訳: 「**親戚との顔出し通話は積極的に**。録画動画より対話があるビデオ通話の方が脳が育つ」
- サービス設計示唆: コロナ後の遠距離家族向けに「**ビデオ通話の質を高める5つのコツ**」（呼びかけ・待つ・共同注視・繰り返し・感情の言語化）を提供可能

## 留保・批判
- **N=36と小サンプル**、効果量推定には限界
- 24-30か月児のみで、より低年齢（6-12か月）への一般化は別途検証必要
- 米国中産階級、英語ネイティブ、単発の実験室実験
- 実生活でのビデオ通話は実験条件ほど構造化されない（注意散漫・通信遅延等）
- 「学習可能」≠「他の活動より優れている」（対面遊び・本読みとの比較は別問題）
- 通信品質・画面サイズ・音声遅延などの実用的問題は扱われない
