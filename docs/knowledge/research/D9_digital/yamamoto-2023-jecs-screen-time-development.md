# 1-3歳児のスクリーンタイムと発達：JECS 大規模研究（Yamamoto et al., 2023 / 日本研究）

## 200-500字要約
本研究は、**山本翠（千葉大）と JECS Group** による、**1-3歳のテレビ/DVD スクリーンタイムと発達の双方向関係** を検証した **JAMA Pediatrics 掲載** の大規模縦断研究。**N=57,980** という極めて大きなサンプル（JECS：日本全国15地域連携）。**方法**：1歳・2歳・3歳の3時点で、(1) テレビ/DVD 視聴時間、(2) ASQ-3（Ages and Stages Questionnaire 3rd edition）による発達スクリーニング を測定。**Random Intercept Cross-Lagged Panel Model** で双方向効果を厳密に検証（時間不変な個人差を統制）。**結果**：(1) **スクリーンタイム → 発達低下** の効果が確認（1歳時のスクリーン増加 → 2歳時の発達スコア低下 β=-0.05; 2歳→3歳 β=-0.08）、(2) **逆方向（発達 → スクリーン）** ── コミュニケーション領域で発達スコア低下 → 次年度のスクリーン増加（1歳→2歳 γ=-0.03; 2歳→3歳 γ=-0.06）。著者らは「**1歳時からのテレビ/DVD 視聴増加が後の発達に負の影響を及ぼす。逆に発達遅延（特にコミュニケーション）が次年度のスクリーン増加を招く悪循環も存在**」と結論。Madigan 2019（カナダ）の結果を日本で再現・拡張した重要な研究。

## キーフィンディング（3-5項目）
- N=57,980 JECS データ、1-3歳の3時点縦断
- **テレビ/DVD スクリーン増加 → 次年度の発達スコア低下**（β=-0.05〜-0.08）
- 効果は **2歳→3歳でより強く**（累積効果の示唆）
- **コミュニケーション領域では双方向性**：発達遅延 → 次年度のスクリーン増加
- Madigan 2019 / Takahashi 2023 と整合する **頑健な実証**
- 政策含意：「**家族のメディア管理への支援と、スクリーンに頼りやすい親への社会的支援**」

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「テレビをつけてないと家事ができない、罪悪感がある」相談 → 「JECS データではスクリーンタイムと発達の関連は確認されたが、効果サイズは中程度。完全に避けるより『家族のメディア管理』『親のサポート』が鍵」
- note記事化のフック: 「58000人の日本人乳幼児が教えてくれた、スクリーンタイムと発達の関係 ── そして悪循環の正体」「『スクリーンが悪い』ではなく『親が孤立しているからスクリーンに頼る』というメカニズム」
- 親への翻訳: 「テレビ・DVD と発達の関連は日本データでも確認されている。でも『悪循環』── 発達がゆっくりだとスクリーンに頼る、というのも同時に起きる。親一人で抱えず、社会的支援を求めることが解決の入口」
- ひだまりこそだち事業への示唆: **「スクリーンに頼りやすい親のための社会的支援」** ── 著者らの結論そのまま事業価値。「孤立する親の代替として機能するコミュニティ」の科学的根拠

## 留保・批判
- **テレビ/DVD のみ測定**：タブレット・スマホ・YouTube は別形態
- **母親自己報告**：客観的測定（device log）ではない
- **発達指標は ASQ-3 親評価**：診断ではなくスクリーニング
- **効果サイズは中程度**（β=-0.05〜-0.08）：個人レベルでは小さい
- **JECS は妊娠期からの大規模調査**：結果の一般化は日本中心
- ASD 児は除外：ASD 関連は Kushima 2022 を参照
- それでも、cross-lagged panel model による **方向性の厳密検証** で因果方向のヒントを得た点で価値大
