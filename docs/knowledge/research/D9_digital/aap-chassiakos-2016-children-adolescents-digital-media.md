# AAP「子ども・青少年とデジタルメディア」テクニカルレポート（Chassiakos et al., 2016）

## 200-500字要約
米国小児科学会（AAP）の **Council on Communications and Media** による、**学齢児・青少年（5-18歳）のデジタルメディア使用** に関する公式テクニカルレポート（被引用1,289）。0-5歳向けpolicy声明（peds.2016-2591）の **根拠論文集としての姉妹文書**。

主要トピック:
- **メディア使用実態**: 米国8-12歳は1日4-6時間、13-18歳は9時間以上のスクリーン使用
- **健康影響**: 肥満（広告・座位行動）、睡眠（ブルーライト・覚醒）、視力（近視増加）
- **学習・認知**: media multitasking（メディア同時並行）の学習・記憶への悪影響
- **メンタルヘルス**: SNS使用と抑うつ・不安・自己肯定感低下の関連、「Facebook depression」現象
- **社会性**: cyberbullying（被害者の20%以上）、sexting、online predator
- **ポジティブ面**: 教育的活用、健康情報アクセス、社会的支援、創造性表現の場
- **prosocial media**: ポジティブな内容のメディアは向社会的行動を促進

**家族メディアプラン（Family Media Plan）** の提唱: 一律ガイドラインではなく、家族で話し合って **個別ルール** を作る。HealthyChildren.orgでツール提供。

医療者へは: 親への発達段階別アドバイス、red flag（依存症状）の識別、開放的な対話を推奨。

## キーフィンディング（3-5項目）
- 米国の学齢児はメディア使用が極めて多い（8-12歳で4-6時間、13-18歳で9時間以上）
- スクリーン使用は **肥満・睡眠・視力** への悪影響、**学習・記憶への干渉（media multitasking）** が示される
- SNSは **抑うつ・cyberbullying・sexting** のリスクと同時に、**社会的支援・創造性** のポジティブ面も持つ
- **Family Media Plan**（家族で個別ルールを作る）が現代の現実的アプローチ
- 一律「禁止」より **質・タイミング・関係性** に注目した家族別のアプローチが重要

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「小学生のスマホ使用はどうすれば？」相談 → 「**一律ルールより家族で話し合い、Family Media Planを作る。寝室・食事中は外す、コンテンツの質に注目を**」
- note記事化のフック: 「子のスマホ問題、AAPが示す現実的解」「メディアマルチタスキングが学習を蝕む理由」
- 親への翻訳: 「**完全禁止は逆効果、対話で家族ルール作りが現代的解**。良い面も悪い面もある」
- サービス設計示唆: **家族メディアプラン作成支援ツール**（時間・場所・内容の3軸で個別化）、学齢期の親向けコンテンツの根拠資料

## 関連理論との関係
- [[harvard-cdc-framework]]: 学齢期の Serve & Return も継続的に重要
- [[executive-function]]: media multitasking は EF を消耗
- [[bowlby-attachment]]: 親子の対話チャネルとしてのSNSの両義性

## 留保・批判
- 2016年時点の声明で、TikTok普及（2018-）・コロナ禍以降のオンライン化は反映されない
- 米国家庭・学校環境前提（LINE中心の日本との差異）
- 「メディア使用時間と健康指標の関連」の因果は依然議論あり（Orben & Przybylski 2019）
- cyberbullying統計は文化差大（日本の閉鎖型・関係性いじめは別の様相）
- 「健康影響」を強調しすぎると親の不安・罪悪感を煽る側面も
