# テクノフェレンス：親のスマホ気散漫と子の問題行動（McDaniel & Radesky, 2017）

## 200-500字要約
McDaniel（Penn State）とRadesky（Michigan、AAPテクニカルレポート共著者）による、**親自身のテクノロジー使用** （technoference = technology + interference）と **子の問題行動** の関連を検証した代表論文（*Child Development*、被引用546）。

**N=170組** の親子（子5歳未満）のオンライン調査。**Technology Device Interference Scale** で親がテクノロジー（スマホ・タブレット・TV・PC）に気を取られて子との時間を中断する頻度を測定。子の **外在化問題（癇癪・反抗）・内在化問題（引っ込み思案・不安）** との関連を検討。

**主要発見**:
- 親のtechnoferenceが多いほど、子の **外在化問題行動**（癇癪、反抗、過活動）が多い
- 子の **内在化問題**（不安・引っ込み思案）も増加
- 経路モデルでは: **親のtechnoference → 親のストレス感増加 → 子の問題行動増加** の媒介経路
- 母親のtechnoferenceは父親より子の問題行動と強く関連（母親が主要養育者の場合）
- 効果量は小〜中程度（β = .15〜.25）

**理論的根拠**: **Still-Face Paradigm（無表情パラダイム）** との接続 — 親が子のサインに応答せず無表情でいると、乳児は数十秒で苦痛を示し回避行動を取る（Tronick 1978）。スマホに没頭する親は子から見れば「断続的なstill-face」状態。

**Bowlbyのアタッチメント理論** との接続: 親の応答性（sensitivity）が中断されることで、子の安全基地機能が損なわれる。

実践的含意: 子のスクリーンタイムを規制する前に、**親自身がスマホを置く時間** を作ることが重要。

## キーフィンディング（3-5項目）
- 親のtechnoferenceは子の外在化・内在化問題行動と関連
- 経路: 親のスマホ気散漫 → 親ストレス感 → 子の問題行動
- 「**断続的なstill-face**」が乳幼児にストレスを与える可能性
- 母親のtechnoferenceは父親より子の問題行動と強く関連（主要養育者効果）
- 「子のスクリーン規制」より「**親自身のスマホ使用見直し**」が先

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「子の癇癪・反抗が増えた、何が原因？」相談 → 「**親自身のスマホ使用も振り返ってみては。technoference研究では親のスマホ気散漫と子の問題行動に有意な関連**」
- note記事化のフック: 「**親のスマホが子に与える影響**：『見えない無視』が癇癪を増やす」「Still-Face実験から見える、スマホ中の親に子が感じていること」
- 親への翻訳: 「**子のスクリーンを叱る前に、自分のスマホ時間を振り返る勇気**。1日数回、スマホを置く時間を作るだけで変わる」
- サービス設計示唆: 「**親の no-phone time**」を提案するコンテンツ（食事中・就寝前・遊び時間）。罪悪感ではなく **習慣形成** アプローチ

## 関連理論との関係
- [[bowlby-attachment]]: 親の応答性（sensitivity）が断続的に中断される現象
- [[harvard-cdc-framework]]: Serve & Return が成立しない瞬間が増えることの累積効果
- [[sasaki-masami]]: 「待つ・信じる・応える」の「応える」が損なわれる現代的脅威

## 留保・批判
- 横断研究で因果関係未確定（**親メンタル不調 → スマホ依存 → 子問題行動** の逆方向も可能）
- 自己報告で測定誤差大（親は自分のスマホ使用を過小評価しがち）
- N=170と中規模、オンラインサンプルで自己選択バイアス
- 効果量は小〜中で、生活への絶対的影響は議論あり
- 「スマホ＝悪」と単純化される危険（緊急時連絡・育児情報検索・親のメンタル支援等のポジティブ面）
- **親の罪悪感を煽る危険** — 親もスマホで休息・支援を得る必要があり、バランスが重要
