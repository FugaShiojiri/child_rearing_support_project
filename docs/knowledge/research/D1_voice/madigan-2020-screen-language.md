# 子のスクリーン使用と言語スキルの関連：系統的レビューとメタ分析（Madigan ら, 2020）

## 200-500字要約
0-12歳の言語発達と **スクリーン使用** の関連を扱った42研究（合計18,905名）を統合した系統的レビューとメタ分析。 **量的スクリーン使用**（時間が長いほど）は言語発達と **負の関連**（プールされた相関 r=-0.14）、**質的スクリーン使用**（教育的内容＋親と一緒に視聴）は **正の関連**（r=0.13）。さらに **視聴開始年齢が早いほど** 言語発達への負の影響が大きい。ただし効果量は小〜中程度で、 **時間量より「何を、誰と、いつから」が重要**。著者らは「displacement hypothesis」(スクリーン視聴が親子相互作用や能動的遊びを置き換えることで間接的に言語発達を阻害する)を支持。 **2歳未満では一人視聴を回避** し、年齢相応の教育コンテンツを **親と共同視聴** することを推奨。Phase A0 の Madigan 2019（応答性メタ）と対をなす、スクリーン側からの応答性侵食の実証。

## キーフィンディング（3-5項目）
- スクリーン使用 **時間量** は言語発達と弱い負の関連（r=-0.14）
- **教育的コンテンツ＋共同視聴** は逆に弱い正の関連（r=0.13）
- **開始年齢が早いほど** 言語への悪影響が大きい
- 機序: **置換仮説**（スクリーンが対面相互作用・能動遊びを置き換える）
- 効果量は小〜中。「スクリーン悪」ではなく「親子相互作用が失われるとき悪」

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「YouTubeで覚えた言葉が多い、これでいいの？」「家事中にEテレ見せちゃう」相談への現実的回答
- note記事化のフック: 「スクリーン時間より大事な3つの問い：何を／誰と／いつから」「『一人視聴』と『一緒に見る』では真逆の効果」
- 親への翻訳: 「短時間でも親が横で実況・問いかけしながら見る」「2歳未満は一人視聴を避ける」「禁止ではなく『誰と・どう見るか』を設計」

## 関連理論との関係
- [[harvard-cdc-framework]]: Serve-and-return がスクリーンによって中断されるリスクの実証
- [[vygotsky]]: 共有的活動なしの記号は学習に結びつきにくい

## 留保・批判
- 観察研究中心で因果は確定不可（言語遅延児ほどスクリーン視聴が長い逆方向の可能性）
- 効果量は小〜中。スクリーン削減だけで劇的に言語が伸びるとは言えない
- 質的測定の差（教育的か娯楽か、共同視聴の定義）が研究間で異なる
- 日本での適用: 日本は **Eテレ（NHK）の教育的コンテンツ** が独自に発達。共同視聴が前提のコンテンツも多く、米国の一般的TVと同列に扱えない可能性
- 反証研究との関係: Phase A0 の Madigan 2019 応答性メタの「親側の応答性」が CDS の鍵だが、スクリーンはこの応答性を **時間的に置換** することで間接的に害をなす（直接害ではない）
