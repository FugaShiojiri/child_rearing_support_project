# コミュニケーション手がかりは12ヶ月児の単語学習を促進する（Tsuji, Mazuka ら, 2019）

## 200-500字要約
**辻晶（つじ しょう、当時 RIKEN BSI / Max Planck）** と **馬塚れい子** が、フランスの Alejandrina Cristià と共同で行った日本人12ヶ月児73名の実験研究。 **動画画面のみ** で新奇な単語を提示し、 **(a) コミュニケーション的手がかりあり**（カメラ目線で語りかけ・名前を呼ぶ "ostensive signals"）と **(b) 手がかりなし**（淡々と提示）を比較。主な所見：(1) **生身の人間の対面相手がいなくても**、画面の中の話者が **カメラに視線を向け・赤ちゃんの名前を呼びかけ・IDS調で話す** と、12ヶ月児は単語と物の対応を学習、(2) コミュニケーション的手がかりなしの場合、学習は起きないか弱い、(3) これは「赤ちゃんは画面から学べない」というMadigan系メタ分析の **修正条件** ：「学べないのではなく、ostensive signals がないと学べない」、(4) 結論：画面を使うなら **アイコンタクト・名前呼び・IDS** が組み込まれていることが必須条件。本研究は **「画面＝悪」と一律に判断する単純化** を学術的に修正し、 **画面コンテンツの "質" を判別する基準** を提供する。日本の親が直面する「動画教材は使っていい？」への精密な回答。

## キーフィンディング（3-5項目）
- 画面内の話者でも **カメラ目線・名前呼び・IDS** があれば12ヶ月児は単語を学習
- コミュニケーション的手がかりが **ない** 場合は学習が起きない／弱い
- "Video deficit" は絶対ではなく、 **画面コンテンツの設計次第**
- 学習を支える鍵は **ostensive signals**（相手が自分に向けている合図）
- 日本人サンプルでも欧米と同様のパターン

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「動画教材使ってもいい？」「いないいないばあは見せてる、効果ある？」相談への精密回答
- note記事化のフック: 「画面は悪じゃない、 "話しかけ方" が悪い時だけ：理研の研究」「動画教材を選ぶ3つの基準：目線・名前・赤ちゃん言葉」
- 親への翻訳: 「カメラ目線で語りかけ、名前を呼ぶ動画は学習効果あり」「BGM＋ナレーション型は効果薄い」「親が一緒に見て応答するのが理想だが、 ostensive 動画なら単独でも一定の効果」「『いないいないばあ』『おかあさんといっしょ』はこの条件を満たす」

## 関連理論との関係
- [[harvard-cdc-framework]]: serve and return の "デジタル版" の可能性
- [[bowlby-attachment]]: ostensive signals は応答性の signaling
- [[tomasello-1986-joint-attention]]: 共有された注意が学習の核——画面でも擬似的に成立しうる

## 留保・批判
- 短期実験での即時学習、長期的な語彙獲得には別途検証必要
- "Madigan 2020" メタ分析（画面と言語発達の負の関係）を否定するものではなく、 **条件付き** で補強
- 過剰な画面利用一般を肯定するものではない、ostensive signals がある質の高い少量利用が前提
- 親との対面より画面が優れている、とは主張しない
- 日本のテレビ番組すべてがこの条件を満たすわけではない（広告・刺激過多のものは別）
