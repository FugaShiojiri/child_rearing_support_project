# 親トレーニングと子の言語発達：系統的レビューとメタ分析（Roberts ほか, 2019）

## 200-500字要約
本研究は、**親が言語介入の実施者となる介入の効果** を系統的レビューとメタ分析で検証しました。5歳未満の子を対象に、親トレーニングを含むRCT/非ランダム臨床試験を ERIC・PsycINFO 等から検索。除外基準として「親が主な実施者でない」「N<10」「言語アウトカムの報告なし」を設定しました。結果、親トレーニング介入は子の **言語・コミュニケーション・社会的コミュニケーション** において有意な改善効果を示しました。観察的研究の Madigan 2019 と合わせて、「敏感な応答性は介入で増やせ、増やせば子の言語が伸びる」という因果的連鎖を補強します。具体的介入手法には dialogic reading、応答性訓練、PCIT、Hanen Program などが含まれ、いずれも親が「聞き手」と「拡張者」として機能することを共通の核としています。

## キーフィンディング（3-5項目)
- 親トレーニング介入は子の言語発達に **有意な正の効果** を示す（介入可能性のエビデンス）
- 言語アウトカムだけでなく **コミュニケーション・社会的コミュニケーション** にも波及
- 親が「主実施者」であることが効果の前提（短期セラピストモデルではない）
- 介入の核は「子の発信を待ち、拾い、拡張する」応答性スキルの体系化

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「言葉が遅い」「2歳児の発語が少ない」相談で、**親トレーニング系プログラム（公的サービス含む）** へのつなぎを提案する根拠
- note記事化のフック: 「親が変わると2-3ヶ月で子の発語は変わる——研究が示す『応答訓練』の効果」「ダイアロジック・リーディング（対話読み）の3ステップ」
- 親への翻訳（実用フレーズ）: 「絵本を読む時、最後まで読まず『これ何だろう？』と問い返す」「子が言葉にしない時は3秒待つ」「子の片言を文として返す（『ブーブー』→『青いブーブーが走ってるね』）」

## 関連理論との関係
- [[vygotsky]]: 親が ZPD（最近接発達領域）の足場となる scaffolding を介入で訓練できる実証
- [[harvard-cdc-framework]]: Serve-and-return を「教えられるスキル」として体系化
- [[bowlby-attachment]]: 応答性訓練は愛着とも双方向に作用

## 留保・批判
- サンプルの限界: 多くが言語発達遅滞・低SESリスク群が対象。典型発達児では効果量が小さい可能性
- 出版バイアス: 介入効果のプール研究では一般的問題
- 文化的翻訳: 介入プログラム（Hanen 等）は北米中心。日本の母子保健の文脈での適応性は要検証
- 親の心理的負担: 「親が訓練を受けるべき」というメッセージが、特に育児不安の親には逆効果になるリスク（伝え方の工夫が必要）
