# 「ただ綺麗じゃなくて、信じられないくらい綺麗！」：誇張賞賛が自尊心の低い子どもに与える悪影響（Brummelman ほか, 2014）

## 200-500字要約
本研究は、西洋社会で広く行われる「誇張賞賛（inflated praise）」——例: 「すごく綺麗な絵だね！」のように形容詞を強める褒め方——が子どもに与える影響を3つの研究で検証しました。実験（研究1）と自然観察（研究2）から、大人は **自尊心の低い子どもにこそ誇張賞賛を与えがち** であることが分かりました。しかし研究3の実験では、誇張賞賛は **自尊心の低い子どもの『挑戦したい』気持ちを下げ**、自尊心の高い子どもには逆に挑戦意欲を高めることが示されました。誇張賞賛は「これからもこの高い基準を満たし続けよ」というメッセージとなり、自尊心の低い子には重荷になるためと解釈されます。「自尊心を上げよう」と意図された誇張賞賛が、皮肉にも最も支援が必要な子の学びの機会を奪う可能性を示唆します。

## キーフィンディング（3-5項目）
- 大人は自尊心が低い子に対してこそ「誇張賞賛」を与えがち（善意の介入）
- 誇張賞賛は **自尊心の低い子の挑戦行動を減少** させる（負の効果）
- 同じ誇張賞賛が、自尊心の高い子には挑戦行動を増やす（交互作用）
- メカニズム仮説: 誇張は「高水準維持の義務」として解釈され、失敗リスクを避ける動機が高まる

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「とにかく褒めて伸ばす」相談に対し、子の自己評価レベル＆過程フォーカスを問う分岐を作る
- note記事化のフック: 「『すっごく上手！』が子を萎縮させる時——褒め方の引き算」「自己評価が低い子ほど、シンプルな褒めが効く」
- 親への翻訳（実用フレーズ）: 「『信じられないくらい綺麗』ではなく『この色の重ね方、よく見つけたね』」「形容詞を盛らず、具体的に観察したことを返す」

## 関連理論との関係
- [[self-determination-theory]]: 賞賛は自律性と有能感を支えうるが、評価的賞賛は外的統制になりうる
- [[conscious-discipline]]: 評価より「気づき・描写」の言語化を重視する点と整合
- [[nvc]]: 評価（judgment）より観察（observation）を伝える原則と一致

## 留保・批判
- サンプルの限界: オランダの児童中心、小学生年齢。乳幼児期や日本児童での再現未確認
- 反証研究: **Verkoeijen ほか（2018, Collabra）** が研究3のデータを多重再解析し、外れ値の扱い次第で交互作用効果が消える可能性を示した。効果の頑健性に留保あり
- 日本文化との差: 日本は元来「褒めない文化」が強く、誇張賞賛の自然頻度は低い可能性。日本の親に伝える際は「褒めない⇄誇張賞賛」の極端往復ではなく「具体的描写」を中央値として推奨
