# Chicago School Readiness Project の10-11年追跡RCT（Watts ほか, 2018）

## 200-500字要約
**Chicago School Readiness Project (CSRP)**は、シカゴ市内の高暴力・高犯罪地域における Head Start センターの質を **保育者への情緒・行動管理コーチング**で強化する介入RCT（元プログラム 602名）。本論文はその**10-11年後（青年期）まで追跡**したフォローアップ報告。介入直後には「子どもの行動問題減少」「実行機能向上」「学業成績向上」が報告されていた。**10年後の追跡結果：(1) 学校成績にポジティブな効果は残るが、推定値の精度（信頼区間）が広く統計的有意は条件次第、(2) 行動問題への長期効果は確認されず、(3) 感情刺激への感受性が介入群で高まっていた**。Perry/Abecedarian ほど鮮明な長期効果ではなく、**「現代の Head Start ベースの介入では、強い長期効果を出すのは難しい」**ことを示す重要なミックス結果論文。

## キーフィンディング（3-5項目）
- 介入群で青年期の学校成績に positive 効果あり（ただし精度低、共変量依存）
- **長期の行動問題への効果は確認されず**（短期効果が消失）
- 介入群は感情刺激への感受性が**高まっている**（解釈困難な所見）
- Perry/Abecedarian のような鮮明な長期効果は再現せず
- 「Head Start を強化した介入は、より新しいコホートでも短期効果あり、長期効果は混在」

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「Perry の効果はもう古くて関係ない？」相談 → 「2000年代の Head Start で追試すると、短期効果はあるが Perry ほどの長期効果が出ない、というのが現在の実証状況」
- note記事化のフック: 「Perry幼児教育の効果は『再現』しているか？──CSRPの10年後」「Head Start は失敗だったのか、それとも変えていけば効くのか」
- 親への翻訳: 「『60年代の有名な早期介入研究』を現代に応用する時、効果サイズは過大評価しない方がよい。短期効果はあるが、長期効果は『環境次第』」

## 留保・批判
- 追跡時点で測定指標が変わる：学校成績は青年期、行動問題は前後で測定法異なる
- N=602 は中規模、サブグループ分析で検出力低下
- 「感情刺激への感受性が高い」の解釈分岐：脆弱性か、共感力向上か
- Perryと比較する際、介入の強度（CSRPは Head Start 強化、Perry は集中介入）が違う
- シカゴ高暴力地域：環境の継続的ストレスが介入効果を侵食している可能性
