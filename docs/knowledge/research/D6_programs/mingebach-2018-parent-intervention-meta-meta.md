# 親訓練介入の効果メタメタ分析（Mingebach ほか, 2018）

## 200-500字要約
親訓練介入（Triple P・Incredible Years・PCIT・Parent Management Training等）が子どもの**外在化行動問題（externalizing behavior：攻撃・反抗・癇癪等）**にもたらす効果を、**26件の既存メタ分析を統合したメタメタ分析**で評価。エビデンス階層では最上位の証拠力。**結果：全体効果サイズ SMD = 0.46（中等度）、親報告 SMD = 0.51、観察データ SMD = 0.62**。**フォローアップ期間でも効果は安定**（SMD = 0.45）し、Wilson 2012 系の「効果は短期のみ」批判には反論する。**親訓練（行動学的アプローチ）は子どもの行動問題改善に確立されたエビデンスベース介入**と結論。ただし**メタ分析間の重複（同じ原研究が複数メタに含まれる）の補正後の数値**であり、heterogeneity も大きい。

## キーフィンディング（3-5項目）
- **親訓練介入の全体効果サイズ SMD = 0.46**（中等度、確立された）
- 親報告で SMD = 0.51、観察データで SMD = 0.62（より客観的指標で効果大）
- **フォローアップ時点でも SMD = 0.45 と安定**（効果消失しない）
- 26のメタ分析を統合した最上位のエビデンス
- メタ分析間で「同じ原研究」が複数含まれる重複問題を統計的に補正

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「親訓練プログラムは本当に効くの？」相談 → 「26メタ分析の総合で『中等度の効果あり、追跡でも維持』。エビデンスは確立されている。日本でも導入価値あり」
- note記事化のフック: 「結論：親学級は『中等度に効く』──26メタ分析を統合した最新エビデンス」「Triple P・IY・PCITで何が違う？でも『どれかを学ぶ』ことの効果は確立」
- 親への翻訳: 「『親学級は意味あるか』への学術的回答は『中等度に効く、しかも持続する』。完璧でなくても、参加することに意義あり」

## 留保・批判
- メタ分析間の重複統計補正：完全には除去できない
- 外在化行動以外（情緒障害・自閉スペクトラム症・ADHD）への効果は別途評価
- 「親訓練」のカテゴリーが広く、行動学的・関係性的・愛着ベース等の質的差が平均化される
- 文化差を統合：日本サンプルが少数派
- van Aar 2016 との結論の差は「追跡期間の選択」「効果サイズの計算法」の違いに起因
