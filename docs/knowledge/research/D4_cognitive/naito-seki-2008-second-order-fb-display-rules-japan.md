# Second-Order False Belief and Display Rules in Japanese Children (Naito & Seki, 2008)

## 要約
**内藤美加 (Mika Naito, 上越教育大学)**, **関由起子** による、日本児4-8歳の **二次的誤信念 (second-order false belief)** 理解と **表示規則 (display rules)** 推論の関係を検証した発達研究。Developmental Science 掲載、被引用 59 回。

研究背景:
- 二次的誤信念 = 「彼女は彼が誤信念を持っていると信じている」のような **入れ子の心的状態**。通常6-7歳で獲得。
- 表示規則 = 「本当の感情と表に出す感情を分ける」社会的規範 (例: もらったプレゼントが気に入らなくても笑顔を見せる)。日本文化で重要。
- 認知的ToM (二次的誤信念) と情緒的社会理解 (表示規則) は **統合的に発達** するのか?

研究設計:
- 対象: 日本児4-8歳
- 課題:
  - 一次・二次的誤信念課題
  - 表示規則課題 (向社会的 prosocial: 相手を傷つけない / 自己呈示 self-presentational: 自分の体面を保つ)
  - 子どもに「なぜ本当の感情を隠すのか」を説明させ、**正当化の質** を分析

主要結果:
- 6-8歳で表示規則を理解 (二次的誤信念とほぼ同時)。
- 年齢が上がるほど、**「社会的圧力」による正当化が減り**、**「相手の視点に立った動機」による正当化が増える**。
- 8歳になって初めて、**二次的誤信念と表示規則は両タイプとも関連** を示す。
- 認知的ToMと情緒的社会理解は、初期は別々に発達するが、児童期に **統合** されていく。

意義:
- 日本児における「本音と建前」「察し」の文化的価値が、心的状態理解の発達と並行することを示す重要研究。
- 「日本人は感情を隠す」という固定観念が、**子の認知発達と接続** して理解できる。

## 子育て支援プロジェクトへの示唆
- 「相手を傷つけないために本当の気持ちを隠す」は **6-8歳以降の発達課題**。それ以前に「気を遣いなさい」と求めるのは発達的に無理。
- **ひだまりこそだち** で「気持ちを言葉にする」 vs 「気持ちを隠す」のバランスを語る際の発達根拠。学童期前は **本音重視**、学童期から **配慮を学習** という段階論。
- 内藤美加は Ruffman, Perner らとの共著で兄姉ToM効果 (1998) を打ち出した、日本ToM研究の代表的人物。
