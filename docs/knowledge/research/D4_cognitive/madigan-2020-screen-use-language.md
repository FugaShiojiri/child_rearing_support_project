# 子どものスクリーン使用と言語スキルの関連：メタ分析（Madigan ほか, 2020）

## 200-500字要約
本研究は、12歳以下の子どもにおけるスクリーン使用と言語スキルの関連を、42研究・延べ約1万9千人のデータで統合分析した JAMA Pediatrics 掲載のメタ分析です。「量・質・開始年齢」の3つの軸で結果が大きく異なりました。**量**については、スクリーン視聴時間が長いほど（r=-0.14）、また背景TV（ながら視聴環境）が多いほど（r=-0.19）、言語スキルが低い関連が認められました。一方で**質**については、教育プログラム視聴（r=+0.13）と共視聴（co-viewing、r=+0.16）が言語スキル向上と関連していました。さらに**開始年齢**は遅いほど言語スキルが高い関連（r=+0.17）が見られました。著者らは「視聴時間を制限する」「質の高い番組を選ぶ」「可能な限り親が一緒に視る」という小児科学会の推奨を支持する結果と結論しています。

## キーフィンディング（3-5項目）
- スクリーン時間が長い → 言語スキル低い（r=-0.14、小さいが有意）
- 背景TVの多さ → 言語スキル低い（r=-0.19、最も大きい負の関連）
- 教育プログラム視聴 → 言語スキル高い（r=+0.13）
- 親との共視聴（co-viewing） → 言語スキル高い（r=+0.16）
- 開始年齢が遅い → 言語スキル高い（r=+0.17）

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「YouTubeばかり見せてしまう」「言葉が遅い」相談 → 「量を見直す」「ながら視聴をやめる」「親が隣で一言コメントする」の3点をエビデンス付きで提示
- note記事化のフック: 「『スクリーン＝悪』を超える育児：3つの変数で全く違う」「ながらTVが一番危ない理由」「『共視聴』が育てる言葉のチカラ」
- 親への翻訳: 「動画を見せること自体より、『背景でつけっぱなし』『親が隣にいない』が言語発達には影響する。短く・選んで・一緒に見る、が現実解」

## 関連理論との関係
- [[harvard-cdc-framework]]: 「serve-and-return」を妨げる背景TV、促進する共視聴という対比でCDC枠組みと整合
- [[bronfenbrenner-ecological]]: マイクロシステム（親子相互作用）が中間変数として効くというモデルと一致
- [[research/D1_voice/madigan-2019-parenting-behavior-child-language]]: 同著者の親子相互作用メタと連結、共視聴メカニズムの説明に使える

## 留保・批判
- 相関研究中心: 因果方向の特定は困難（言語が苦手だからスクリーンに頼る、の逆方向も否定できない）
- 効果サイズは小～中程度: 「スクリーンが言語発達の主因」とは言えない
- 日本文化との差: 日本では教育系コンテンツ（おかあさんといっしょ等）の質が比較的高い可能性。「日本のテレビ番組はこのメタの平均より良いかも」という解釈の余地あり
- 「動画→言葉が遅れる」は誇張危険: 背景TVと能動的視聴は別。親メッセージとしてはここを慎重に伝える
