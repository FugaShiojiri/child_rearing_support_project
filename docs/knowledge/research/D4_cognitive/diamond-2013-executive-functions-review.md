# Executive Functions (Diamond, 2013)

## 要約
実行機能 (Executive Functions, EFs) に関する包括的レビュー論文。EFsは「アイデアを心の中で操作する」「行動の前に考える」「予期しない新規課題に対応する」「誘惑に抵抗する」「集中を維持する」といった能力を可能にする中核的認知機能と定義される。

著者は EFs の中核3要素を以下のように整理:
1. **抑制 (Inhibition)** ── 反応抑制(=自己制御、誘惑・衝動的反応の抑制) と 干渉制御(=選択的注意、認知的抑制)
2. **ワーキングメモリ (Working Memory)** ── 情報の保持と操作
3. **認知的柔軟性 (Cognitive Flexibility)** ── 視点切替、創造的思考、状況変化への適応

EFsの発達経過、流動性知能・自己調節・実行注意・努力的制御との関係性、ストレス・睡眠不足・孤独・運動不足が EFs を低下させること、EFsが訓練可能であり多様な介入手法が試みられていることを論じる。

## 子育て支援プロジェクトへの示唆
- **ひだまりこそだち**コンテンツで「実行機能」を解説する際の最重要レビュー。
- 「子どもの自己制御は身体と社会的健康に依存する」という主張は、保護者向けに「睡眠・運動・孤立回避が認知発達を支える」という統合メッセージを正当化する。
- 介入による訓練可能性は、家庭での実践 (ごっこ遊び、規則的ルーティン等) の根拠となる。
