# Shared Picture Book Reading Interventions for Child Language Development (Dowdall et al., 2019)

## 要約
就学前児童の言語発達を促す**共有絵本読み (shared picture book reading) 介入**の系統的レビューおよびメタ分析。対象児童は1-6歳、PRISMA準拠で実施。

主要結果:
- **表出言語 (expressive language)**: d = 0.41 (小〜中程度の効果)
- **受容言語 (receptive language)**: d = 0.26 (小程度の効果)
- **養育者の絵本共有スキル**: d = 1.01 (大効果)
- **介入用量による効果の調節**: 用量が低い介入は最小限の影響しかなく、十分な実施回数・期間が必要
- 子の年齢・養育者の教育水準は子のアウトカムに影響しなかった

著者らは「絵本共有介入は子の言語発達を加速・強化する有望性が確認された」と結論する。ただし用量効果が重要であり、単発的な絵本配布より継続的なスキル指導+実践のセットが効果を生む。

## 子育て支援プロジェクトへの示唆
- **ひだまりこそだち**で「絵本の読み聞かせ」コンテンツを設計する際、「親のスキル」が中央変数であることを伝える根拠。
- 「養育者教育レベルに関係なく効果が出る」のは、低所得層・教育機会の少ない保護者にも有効なメッセージ。
- 「用量効果あり」 ── 単発イベントより継続プログラム (週次のお話会、毎晩の読み聞かせ習慣化) を推奨する根拠。
- 既収集の Mol & Bus 2011 (D1) を**メタ分析として補完**する位置づけ (Mol & Bus は語彙、本研究は表出/受容言語と養育者スキルへの効果を分離)。
