# 児童虐待予防介入の効果的要素：メタ分析（van der Put et al., 2017）

## 200-500字要約
本論文は、児童虐待予防・介入プログラム121件の独立研究（N=39,044）を統合し、**どの要素が虐待リスクを下げるか**を検証したメタ分析です。予防的介入の効果量はd=0.26、治療的介入はd=0.36と中程度〜中強度。効果が高い要素は、(1) **短期（0-6か月）介入**、(2) **親の自己効力感を高めることに焦点**、(3) **専門職のみが提供**（混合提供は効果薄）、(4) フォローアップ期間が長いほど効果増（"sleeper effect" の示唆）。介入タイプ別では、認知行動療法（CBT）、家庭訪問、親トレーニング、家族ベース／マルチシステミック、薬物依存治療を組み合わせた介入が有効でした。
本研究の重要な含意は「**何でも詰め込めば良いのではなく、親の自信を高めるシンプルな短期介入**が最も費用対効果が高い」という点で、ひだまりこそだちのような個人事業主が運営する小規模介入の科学的正当性を示します。

## キーフィンディング（3-5項目）
- 親の **自己効力感（self-confidence）** を高める要素が最も効果的
- 短期介入（0-6か月）が長期介入と同等以上の効果
- 専門職のみによる提供が混合提供（ボランティア併用）より効果が高い
- CBT・家庭訪問・親トレーニングが有効プログラムタイプ
- フォローアップ期間が長いほど効果増（"sleeper effect" の可能性）

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「自分の育児が不安」「子どもにきつく当たってしまう」相談 → 「親の自己効力感を高める短期サポートが最も効く。長期講座より、頼れる場所と即効性のあるテクニック」と提示
- note記事化のフック: 「『良い親』になろうとしすぎない：121研究が示した『短く・自信を育てる』介入の科学」
- 親への翻訳: 「自分を責めるより、『これならできる』を1つ増やすだけで虐待リスクは下がる」
- サービス設計示唆: 個人事業主モデルとして「短期・専門職提供・自己効力感focus」は科学的に正当化される。長期講座より単発相談+継続フォローが理にかなう

## 関連理論との関係

- [[bowlby-attachment]]: Bakermans の "less is more" 短期介入研究と同方向の発見
- [[bronfenbrenner-ecological]]: 家庭訪問が家族環境（マイクロシステム）への介入として効果

## 留保・批判
- 効果量は中程度。劇的な効果は期待できない
- 「専門職のみ」効果はサンプル選択バイアスの可能性あり
- 介入要素は重複・組合せで効果。要素分離の解釈に注意
- 日本文脈での「専門職」の定義（保健師・心理士・産婦人科医）は欧米と異なる
- メカニズム（なぜ自己効力感が効くか）は未解明
