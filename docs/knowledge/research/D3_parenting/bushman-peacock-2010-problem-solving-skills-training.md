# 「問題解決スキル教育は効くのか？」（Bushman & Peacock, 2010）

## 200-500字要約
本論文は、行動問題を持つ子ども32名の親を対象に、**「親トレーニング単独」 vs 「親トレーニング＋問題解決スキル訓練」** をRCTで比較した実証研究です。問題解決スキル訓練は、Greene の Collaborative Problem Solving（CPS）と同系列の「**子ども自身が問題解決ステップを学ぶ**」アプローチで、(1) 問題の言語化、(2) 解決案の生成、(3) 案の評価、(4) 実行と振り返り、を含みます。
結果、問題解決スキル群の子どもは、(1) **親報告の社会的スキル改善**、(2) **親観察の社会的スキル改善**、(3) **子ども自身の自己報告での社会的スキル改善** が、非指示的群より有意に大きかった。親観察の問題行動も改善が大きかった一方、親報告の問題行動と親ストレスでは群間差なし。
本研究は、Greene の Collaborative Problem Solving が直接RCTで検証された数少ない研究の1つで、「**ルールで縛る・罰する** 」アプローチに対し「**子どもに問題解決を一緒に教える**」アプローチが補強として有効であることを示しました。サンプルサイズは小さいが、CPS的アプローチのエビデンスとして援用可能です。

## キーフィンディング（3-5項目）
- 親トレーニング＋問題解決スキル訓練の方が、社会的スキル改善が大きい
- 子ども自身の自己報告でも効果を確認（複数情報源）
- 親観察の問題行動も改善
- 親報告の問題行動と親ストレスでは群間差なし（限界）
- Greene の CPS アプローチ系列の RCT エビデンス（数少ない直接検証）

## ひだまりこそだち への示唆
- マッチャーでの使い方: 「叱っても聞かない、何度言っても同じ」相談 → 「叱る代わりに『一緒に解決策を考える』アプローチが、社会的スキルを伸ばす。子どもに『考える機会』を渡す」と提示
- note記事化のフック: 「『叱る』より『一緒に考える』：CPS的アプローチの科学」「Greene 流『一緒に解決』が子どもに育てる力」
- 親への翻訳: 「子どもに『なぜダメか自分で考えさせる』だけでも社会的スキルが伸びる。命令型より協同型」
- サービス設計示唆: マッチャーで親に「具体的な問題解決ステップ」を翻訳して渡すコンテンツが正当化される

## 留保・批判
- サンプルサイズ32名と小規模、効果量の精度に限界
- 単一施設・米国データ。一般化に注意
- 親ストレスと親報告問題行動で群間差なし（実装の難しさを示唆）
- 「非指示的群」と「問題解決訓練群」の介入差は厳密に統制できているか要確認
- CPS そのもののRCTではなく、類似アプローチの間接エビデンス
- 効果の長期持続は未検証（6週フォローのみ）
