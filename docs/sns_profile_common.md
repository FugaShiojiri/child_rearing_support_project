## 設計メモ（執筆判断の背景）

### 各プラットフォームの役割と書き分け方針

| 媒体 | 文字数枠 | 役割 | 書き分けの軸 |
|---|---|---|---|
| X (Twitter) | 160字以内 | テキスト中心・流れが速い | 「誰に・何を・どこで」を1秒で読み切れる導線重視。陽だまりメタファーを1回 |
| Instagram | 150字以内 | ビジュアル前提（プロフ画像と組合せ） | サービスの価値＋人間味。縁側メタファーで「ふらりと」誘導 |
| Threads | 150字以内 | 会話型・親近感 | 「うちはこんな日」の対話への招待。芽吹くメタファーで未来感 |
| note | 上限なし | 配信主軸 | ブランド人格を最も濃く表現（ロング版マニフェスト含む） |

## ブランドトーン基準（全媒体共通）

- やさしく、断言しない、親を急かさない、子の個性を尊重する
- 動詞は「教える／育てる」を避け、「育む・芽吹く・そっと寄り添う・日々を重ねる」を優先
- 「絶対」「必ず」「○歳までに」NG
- 陽だまり・縁側・午後の光のメタファーは各プラットフォーム1〜2回程度に抑える
- 誘導は「note でつぶやいています／毎日 1 つ／よかったら覗いてください」のような柔らかい文体

---

## 字数計測条件

- Python `len()` 相当（改行除く、句読点・全角記号「｜」「『』」「〜」を1字としてカウント、半角英数字も1字）
- 各プラットフォームの公式上限：X 160字 / Instagram 150字 / Threads 150字
- 掲載前に実機での見え方（改行・絵文字置換含む）を再確認すること

## リンク戦略

| 媒体 | 推奨設置場所 | 備考 |
|---|---|---|
| X | プロフィール内「ウェブサイト」欄 + 固定ポスト | 本文では URL を入れず字数を温存 |
| Instagram | プロフィール下「ウェブサイト」欄 | Linktree 等は当面不要、リンクは1本に絞る |
| Threads | プロフィール内「リンクを追加」 | 外部リンク導線が弱いため、初動スレッド本文で自然に貼る |
| note | プロフィール内 SNS リンク欄 | X / Instagram / Threads のハンドルを設定済 |

## プロフィール画像の方向性（CEO自作前提）

### キービジュアル要素

- 陽だまりの暖色（はちみつ色〜淡いオレンジ〜柔らかいクリーム）をベースに
- 縁側 or 窓辺の光の入り方を抽象化した幾何形（円・楕円・直線）
- 文字を入れる場合は「ひだまりこそだち」または「ひ」一文字を、明朝系の柔らかい和文書体で

### やらない方向性（NOT-do）

- 人物写真・実子の顔出し → プライバシー方針と矛盾
- 子供向けキャラクター・イラスト → 「親が主役」のブランドと矛盾
- 強い原色・コントラスト → トーンと矛盾
- 「○歳までに」「天才」「先取り」等のテキスト → 誇大表現NG

### 作成ツール

- Canva 無料プラン または Figma 無料プラン
- Claude Code 以外の有料 SaaS 不採用方針と整合

### サイズ

- 3 媒体とも正方形（円形クロップ対応）
- 最小辺 512px 以上の PNG を1枚作り、3 媒体で共通利用すると運用が楽

## 扱わない領域（CEO決裁 2026-05-15）

| 領域 | 扱い | 理由 |
|---|---|---|
| **胎教（出生前知育・「モーツァルトで賢くなる」式の効果保証的言説）** | **扱わない（明文化）** | 非エビデンス的・商業的言説が支配的。本ブランドの「断言しない・煽らない・根拠主義」と正面衝突し、足を踏み入れると差別化どころか信頼を毀損する |
| 科学的に言える準備期（周産期）テーマ：周産期の親メンタルヘルス／アタッチメント準備／産後の関わりの土台 | **保留**（需要駆動・[[project-pending-decisions]]）。新規大規模収集は解禁しない。扱う場合も既存ナレッジ＋公的機関の一般的合意の範囲に限定し、医療境界フック（気になれば専門医/かかりつけ/自治体相談窓口）必須 | 科学的根拠があればブランド適合。ただし activation 優先・収集凍結方針を崩さない |

> 判断トリガ: Form v1.2 回収後、妊娠中/妊活セグメントの待機リスト登録が一定数（目安: 当セグメントで任意メアド登録が母数の15%以上 or 実数で意味あるボリューム）に達したら、既存ナレッジ範囲で**試験記事1本のみ**を CEO 再決裁。未達なら着手しない。新規論文/書籍の収集は将来も解禁しない。

## 媒体間の表現重複チェック

- 3 媒体で完全に同一の文を使い回さず、メタファー（陽だまり／縁側／午後の光）と動詞（そっと届ける／つぶやく／少しずつ・芽吹く）を変えて、SNS横断で読者が見たときの単調感を回避
- 共通要素（「0〜6歳」「毎日のお題」「親への声かけ」「こそだち」造語）は3媒体で揃え、ブランド一貫性を担保
- 「0〜6歳」は **コンテンツ主戦場の宣言**であり、リード受け入れ範囲を排他しない（妊娠中/妊活など準備期層は Form/待機リストで受ける）。プロフィール文面では準備期に言及しない（CEO決裁 2026-05-15・胎教恒久不採用／保留#7と整合）
