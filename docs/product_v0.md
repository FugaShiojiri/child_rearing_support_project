## 1行サマリー

**就学準備が気になる年少〜年長の親が、毎晩寝る前の10分にLINEで届く『今日のお題1つ＋親の声かけ台本』で、親子の対話を通じて学びの土台を作れる、月¥980 のサービス。**

## 商品コンセプト

### 何を売るのか（価値の単位）

中核となる「価値の単位」は **「親への声かけ台本（スクリプト）」** である。

- 売っているのは「子のドリル」ではなく、**「親が今夜10分、子にどう声をかければ良いかの完璧な台本」**。
- 1日に届くもの: **(a) 今日のお題1つ（30秒で読めるカード）／(b) 親への声かけ例3パターン／(c) 子が答えに詰まった時の助け舟2つ／(d) 翌朝の「振り返り一言」テンプレ**。
- これを「**1日1ナッジ（nudge）**」と呼ぶ。

### なぜそれを選んだか（他案との比較）

| 候補 | 価値の単位 | 不採用理由 |
|---|---|---|
| ドリル/問題集 | 子の手元の課題 | 既存（ちゃれんじ・スマイルゼミ）と差別化不能、紙/タブレット必須化 |
| 動画コンテンツ | 受動視聴 | YouTube無料に勝てない、視聴時間=価値ではない |
| コミュニティ | 親同士の交流 | モデレーション工数青天井、個人運営非互換 |
| AIチャット相談 | 都度Q&A | 利用頻度が読めず継続率が出にくい |
| **親への声かけ台本（採用）** | 親の「今夜何を言えばいいか」が解決される | ペルソナBの一次不安（「ちゃんと教えてあげられない罪悪感」）に直撃。ドリルでなく"親の自信"を売る。 |

**戦略の核**: 子を賢くするプロダクトではなく、**親を「ちゃんと教えてあげられている自分」にするプロダクト**。これがYouTube・こどもちゃれんじ・スマイルゼミの誰もカバーしていない隙間。

## 課金形態

### 採用案

**月額サブスクリプション ¥980 / 月（年額¥9,800 = 約2ヶ月無料）**

- 加えて **「最初の7日間 無料体験」**（クレカ事前登録あり / なしの2パターンを Phase 2 で A/B）。
- 単発買い切り・従量課金は不採用（毎日の習慣化に対し料金体験が逆行する）。

## 配信形態とコア体験

### 配信チャネルの選定理由

**主チャネル: LINE 公式アカウント（Messaging API）／補助: 軽量Web（履歴・親アカウント設定）**

| チャネル | 採用 | 理由 |
|---|---|---|
| **LINE Bot** | ◎ | 日本のママ層普及率＞95%、プッシュ通知の開封率が高い、認証/決済の摩擦が少ない、ベネッセ等も新規窓口に活用実績あり |
| **軽量Web（履歴閲覧・設定）** | ○ | 過去30日のお題を見返す導線、課金管理。Stripe連携。Bot 単体だと「履歴を辿る体験」が弱いので補完 |
| 専用アプリ | × | iOS/Android ストア審査・更新・通知設計コスト過大、個人開発NG |
| メール | × | 開封率低、ママ層の到達性弱 |
| 動画 | × | 制作コスト×差別化弱 |
| PDF | × | ダウンロード/印刷の摩擦、習慣化と相性悪 |

### 1日のユーザー体験フロー（コア体験）

**ゴールデンタイム: 平日 19:30（夕食後〜お風呂前）／週末 9:30（朝の余裕時間）**

| 時刻 | 何が届く | 親のアクション | 所要 |
|---|---|---|---|
| 17:30 | LINE プッシュ「今夜のお題、届きました」（プレビュー1行） | 既読のみ | 5秒 |
| 19:30 | 親が能動的にLINEを開く → カード形式で「今日のお題1つ＋声かけ台本」 | 子の前で読む準備 | 1分 |
| 19:31〜19:40 | 子と対話（台本通り） | 声かけ、聞き返し、ほめる | 約8分 |
| 19:40 | LINEで「終わったらタップ」→ 完了スタンプ＋ご褒美一言（親向け） | タップ | 5秒 |
| 翌朝 7:30 | 「昨夜のフィードバック1行」「今日子に言うべき振り返り一言」 | 軽く声をかけるだけ | 30秒 |

**1日合計: 親の認知負荷 約10分 / うち子と向き合う時間 約8分**。既存のこどもちゃれんじ「1日約10分」と同水準。

## コンテンツ設計

### 1日のコンテンツ単位

```
[今日のお題] ひらがな「し」を探そう
  - 部屋の中で「し」がつくものを3つ見つける

[親への声かけ台本]
  1. 開始時: 「ねぇ、今日はね、おうちの中で『し』がつくものを探してみたいんだけど、ママ/パパと一緒にやってくれる？」
  2. 詰まった時: 「足元、見てごらん？○○ちゃんの足にあるよ」（ヒント: したじき・しーつ）
  3. 終了時: 「3つも見つけられたね、明日もまたやろうね」

[助け舟（子が興味を示さない場合）]
  - 代替プラン: 絵本の中から「し」を3つ探す
  - 撤退判断: 5分やって嫌がったら今日は終了でOK（罪悪感を持たない）

[翌朝の振り返り一言]
  - 「昨日見つけた『し』の○○、まだ覚えてる？」
```

### 1週間のリズム

| 曜日 | テーマ | 形式 |
|---|---|---|
| 月 | ひらがな・カタカナ（文字） | 探し物・指差し |
| 火 | 数（量・順序） | 数える・分ける |
| 水 | 生活マナー・あいさつ | ロールプレイ |
| 木 | お絵描き・工作（手指） | 5分制作 |
| 金 | 絵本・物語（読解の芽） | 親が読み聞かせ＋質問1つ |
| 土 | 自然・季節（外で体験） | お出かけ連動 |
| 日 | 「今週ふりかえり」 | 子をほめる週次レター（親向け） |

### 1ヶ月のリズム

- 第1週: 新トピック導入
- 第2週: 反復・深掘り
- 第3週: 応用・組み合わせ
- 第4週: 月次レポート「今月の○○ちゃんの成長」（**継続のフック**）

### AI生成 vs 人手監修の役割分担

| 項目 | 担当 | 工数 |
|---|---|---|
| お題テンプレ生成（年齢×テーマ×曜日のマトリクス） | AI（Claude API）＋ プロンプトライブラリ | 月10時間 |
| 声かけ台本の文面生成 | AI生成 | 月8時間 |
| 監修（児童発達・幼児教育の観点） | **業務委託の保育士/幼稚園教諭1名（月8時間=¥3万）** | 月8時間 |
| 月次レポート文面（個別性あり） | AI（テンプレ＋子のニックネーム差し込み） | 自動 |
| カスタマーサポート（FAQ・LINE返信） | 自動応答＋週2回手動巡回 | 週2時間 |

**個人運営での月間総工数想定: 約30時間（コンテンツ+CS+監修管理）**。

## オンボーディング

### 課金前7日間で何を体験させるか

**「7日でリズムが体に入る」をゴールに、Day1〜Day7 で意図的に体験密度を傾斜する。**

| Day | 配信内容 | 狙い |
|---|---|---|
| Day 0 (登録直後) | LINE友だち追加 → 「お子さんの月齢・名前・興味」3問アンケート（30秒） | パーソナライズの土台、心理的コミット |
| Day 1 | 「初回お題：いちばん簡単な成功体験」＋ 親の声かけ台本 | **初日に必ず成功させる**（解約防止の鉄則） |
| Day 2 | 「Day1 どうでした？」LINEで簡単フィードバック収集 | 双方向感 |
| Day 3 | 中難度のお題＋「子の反応はこうなることが多いです」予習文 | 期待値調整 |
| Day 4-5 | 通常運転（曜日テーマ通り） | リズム体感 |
| Day 6 | 「あと1日で7日間体験が終わります」＋ これまでの記録ダイジェスト | 喪失回避バイアス |
| Day 7 | 「今後も続けますか？」課金導線＋ 1ヶ月¥980/初月限定¥0 | コンバート |

**意図**: 課金転換のキモは「7日間で生活リズムに組み込まれているか」。組み込まれていれば¥980の解約より「習慣を失う痛み」が勝つ。

## 解約防止

### 3ヶ月目解約集中への対策（4つ）

> 教育サブスクは「3ヶ月で成果が見えない」と解約される（健康食品サブスクの先行知見）。本プロダクトは**「成果ではなく習慣を売る」**戦略で、3ヶ月目に「習慣化済みである自己認識」を作る。

1. **【月次成長レポート（第4週金曜配信）】**
   - 「今月のお題達成数 / 子が見せた成長エピソード3つ / 来月のテーマ予告」をLINE+Webで配信。
   - 「数字で成長が見える」体験を意図的に作る。ロードマップv0.1のリスク#1緩和策と一致。

2. **【3ヶ月目に「殿堂入りエピソード」を配信】**
   - 90日目に「○○ちゃんが見せてくれた今シーズンのベスト3エピソード」を保護者の同意ベースで美しいカード化。
   - 解約しようとした瞬間に「これは取っておきたい」と思わせる感情フック。

3. **【ペースダウン機能（"おやすみモード"）】**
   - 解約導線の手前に「忙しいので週3配信に下げる」選択肢。¥980 → ¥580 のライトプランに自動ダウンセル。
   - **解約vs休止の選択肢を増やす**ことで、完全離脱を減らす。

4. **【90日目特典: 入学準備チェックリスト】**
   - 「3ヶ月続けた人だけがもらえる、年長児向け『就学準備70項目チェックリスト』PDF」。
   - 行動経済学的「サンクコスト＋ご褒美」設計。

## ペルソナA（0-2歳）向けの差分

### 同じ基本構造で、何だけ変えるか

| 要素 | ペルソナB（3-6歳） | ペルソナA（0-2歳）差分 |
|---|---|---|
| 価格 | ¥980/月 | **¥1,480/月**（孤立解消＋専門家監修プレミアム） |
| 配信時刻 | 19:30（夕食後） | **13:30（昼寝中）／22:00（寝かしつけ後）** の2回 |
| お題の中身 | 子と一緒にやるアクティビティ | **「今日の発達観察ポイント1つ」＋「離乳食/遊び案1つ」** |
| 声かけ台本 | 子に対する台本 | **「自分（親）への声かけ」＝「今のあなたはこれで大丈夫」の安心メッセージ** |
| 監修者 | 幼稚園教諭・保育士 | **小児科医監修・公認心理師の月次コラム追加** |
| 週次レポート | 子の成長 | **「ママの今週の頑張り」レポート（孤立解消の核）** |
| 緊急時導線 | なし | 「気になる発達」相談先一覧（医療領域には踏み込まない） |

**基本構造（LINE Bot＋1日1ナッジ＋週次レポート）は共通。差分はコンテンツ内容と監修体制のみ。**運用負荷の急増を避ける。

## 競合との差別化

### 比較マトリクス

| 軸 | こどもちゃれんじ | スマイルゼミ幼児 | ワンダーボックス | **本プロダクト** |
|---|---|---|---|---|
| 月額 | ¥3,000台 | ¥3,000台＋タブレット¥1万超 | ¥3,700〜 | **¥980** |
| 物の郵送 | あり（付録山積み） | タブレット | アプリ＋年4回トイ | **なし** |
| 親の役割 | 子に渡せばOK | 子に渡せばOK | 子に渡せばOK | **親が主役（声かけ台本）** |
| 子の能動性 | 教材で誘導 | タブレットで自走 | アプリで自走 | **親子対話で形成** |
| 売っているもの | 子のコンテンツ | 子の学習進度 | 子のSTEAM体験 | **親の自信と親子の対話時間** |

### NOT-do（あえてやらないこと）

1. **物理玩具/教材の郵送をしない** — 物流ゼロで個人運営可能を死守
2. **専用アプリを作らない** — LINE＋軽量Webで配信完結
3. **子のスキル「テスト」をしない** — 数値化は親へのレポート止まり。子に成績をつけない
4. **総合カリキュラムにしない** — 「就学準備の親子対話」に絞り、英語/プログラミング/運動には踏み込まない
5. **24時間チャット相談（人力）をしない** — AI回答＋週次まとめのみ

## 開発・運用の現実性

### 個人開発で月¥30万まで成立する根拠

**前提**: 月¥980 × 306人 = ¥299,880（ロードマップA案）

| 項目 | 月額コスト | 備考 |
|---|---|---|
| LINE Messaging API | ¥0〜5,000 | 月5,000通までフリー、それ以降従量。306人×30日=9,180通でも¥1万未満 |
| Claude API（コンテンツ生成） | ¥5,000〜10,000 | 月のお題テンプレ生成＋個別差し込み |
| Stripe決済手数料 | 約¥9,000 | 売上の3.6% |
| サーバ（Cloudflare Workers / Vercel） | ¥0〜3,000 | 軽量Web＋Bot Webhook |
| 監修者業務委託（保育士1名） | ¥30,000 | 月8時間 |
| ドメイン/その他 | ¥2,000 | |
| **合計コスト** | **約¥50,000〜60,000** | |
| **粗利** | **約¥24万〜25万** | 月¥30万目標時 |

→ **¥30万売上時の粗利は約24万**。ロードマップの「粗利30万」を厳密に達成するには **¥980×383人** または **年額¥9,800へのアップセル含む** が必要。**v0.2 で再計算予定**。

### 生産負荷の試算

- **コンテンツ生産**: 年齢帯×7曜日テーマ×4週パターン= 1セット完成すれば**最低3ヶ月は使い回し可能**（個人記憶力的に同一お題は許容）。AI生成で初回ライブラリ200個を1ヶ月で構築可能。
- **CS負荷**: 306人 × 月1問い合わせ想定= 300件。半数はFAQで自動回答、残150件を週2回バッチ処理（週3時間以内）。
- **監修**: 月8時間で「新規20お題のレビュー＋NGワード/不適切表現チェック」。

**結論: 個人運営で月30時間以内に収まる設計。** ロードマップ Phase 4 で人手追加せず到達可能。
