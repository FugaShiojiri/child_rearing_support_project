# Phase2 提案骨子 v1 ── 最速で母数を積む（C）×コメント接点（B）

> **【2026-06-09 CEO決裁・最速加速版】** オーナーの「6/10から一気に・できる最速で加速」を**正面から受諾**。慎重ペースの旧v0（隔週・逐次・収益化凍結継続）を上書きする。
> ただし「最速」＝無秩序な一括放出ではない（在庫を一度に撒くと数日で埋もれ発見性が積み上がらない）。**最速＝「高頻度の継続供給で母数を最短で積む」**と定義する。

## 0. なぜ加速に倒せるか（根拠）

- Phase1真因＝**リーチ絶対量の不足**（発見性は実証＝ビュー36→113・スキ0→19）。**速く多く出す＝発見性Cと同方向**。逆張りではない。
- **在庫が潤沢**：連載04-07（4本完成）＋Threads物語2本＋絵本リールv2完成＋量産システム。弾はある。
- **制作はmain（Claude）負担・オーナーは公開ボタン＋目視のみ**。量↑でもオーナー手作業はほぼ横ばい（最速時で約1.5h/週・週上限8〜10h内）。
- 「動ける≠動かす」は**CEOがオーナーの過剰意欲を抑える歯止め**であって、オーナー自身が最速を望む局面の抑制ではない＝今回は加速側に倒す正当性が高い。
- Phase1判定純度は6/10で終了→「判定を汚さないため在庫を出さない」制約は**消滅**。3チャネル同時起動を縛る理由がなくなる。

旧v0の「隔週・①→②→③逐次」を破棄し、**3チャネル同時起動＋note週2本**。発見性を殺さないため「同日全部出し」はせず、露出を分散して各投稿に山を作り、相互にプロフィール導線で送客。

## 2. C：チャネル再設計（主軸・最速）

中核仮説：発見性は動く（実証済み）。**母数を3〜5倍に積めば深層転換（コメント・重い反応）が観測域に入る**。最速版では：
- **note週2本＋3チャネル同時**で母数を最短で積む。
- note内発見性の深掘り（タグ/タイトル最適化・他者マガジン収録を狙う・将来は自前マガジン）。
- 在庫チャネル（絵本リール・Threads物語）を**即並走起動**（判定純度の縛りが6/10で消えるため）。

## 3. B：軽量定性＝コメント接点（Cに併走）

- **T070（誠実コメント接触）をBの中核手段に正式格上げ**（効果＋継続可能を実証済み・低コスト再現可能）。週手作業バジェットに正式枠取り（実時間は次週次で実測補正）。
- Form固執をやめ、**noteコメント・スキした人の観察・DM起点**の軽量定性へ。記事末尾の問いかけ・コメント返し文化で「向こうから声が出る」導線。

## 4. 収益化（加速プランv0.1）── 準備は即解凍・発射の引き金だけ死守

最速意向を受け、旧v0「6/10は解凍しない」を**「準備トラック即解凍」へ変更**：
- **第一弾有料記事（候補B・1シーン×3理論版・¥500目処）の本書きを6/11着手**（mainが担当・オーナー工数ゼロ）。**銀行口座登録をW1中に**。**6/30に弾装填完了状態**。
- **実発射トリガー＝「連載相当の継続供給＋note FW20人＋能動的読者反応1本以上」は死守・緩めない**。これは人の反応速度＝時間律速で、最速でも前倒しできない物理。ここを緩めると「売れない原因が品質か露出か」切り分け不能になり加速の判断材料を壊す。**装填は最速・発射の引き金だけ慎重に**。

## 5. KPI（最速版・6/10朝に実数充填）

- **主KPI＝note総ビュー/インプレッション（北極星）**。目標＝直近の**3〜5倍**（※6/10朝の最新値で具体数を確定）。
- **副KPI＝転換観測**（スキ・コメント・保存・FW・プロフィール遷移）。
- **重い反応（Form相当）はKPIから外しランク格下げ**（観測はするが達成基準にしない）。
- Goゲートは2段＝「リーチ3〜5倍（C成功）」＋「軽い反応→深い反応の転換が観測域に入ったか」。

## 6. 守る歯止め（最小3点・これ以外は全部アクセル）

1. **無料制約**：有料SaaSは Claude Code のみ。全施策ゼロ円。
2. **ブランド品質＝CEO目視**：量産でトーンを薄めない。各note公開前のオーナー目視＋Threads物語は誠実性チェック通過が条件。**量を増やしても1本もトーンを崩さない**。3本連続でトーン劣化をCEOが検知したら**該当チャネルだけ**即ペースダウン（全体は止めない）。
3. **燃え尽き監視**：オーナーの健康・本業・家庭が最優先。**3週連続で手作業が週上限を超えたら自動で低頻度に戻す**（main監視→CEOエスカレ）。
