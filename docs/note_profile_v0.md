## 設計メモ（執筆判断の背景）

### ブランドの確定情報

- **サービス名**: ひだまりこそだち
- **語源**:
  - 「ひだまり」=「日溜まり」= 陽の当たる温かい場所
  - 「こそだち」=「子育ち（子が自ら育つ）」＋「子育て（親が育てる）」の合成造語
- **思想**: 温かい陽だまりのような場所で、親子が自分のペースで育つ。育てる側と育つ側を切り分けず、双方が並んで日々を重ねる。
- **メタファー資源**: 陽だまり・縁側・午後の光・芽吹き・実り・季節・親子・並んで座る
- **対象年齢**: 0〜6歳（ペルソナA：0〜2歳／ペルソナB：3〜6歳の両方をカバー）

### トーン基準

- やさしく、断言しない、親を急かさない、子の個性を尊重する。
- 動詞は **「教える／育てる」より「育む・芽吹く・そっと寄り添う・日々を重ねる」** を優先。
- 「絶対」「必ず」「○歳までに」といった誇大表現は使わない。
- 陽だまり・縁側・午後の光のメタファーはロング版で **2〜3回まで** に抑え、押しつけがましくしない。
- 「こそだち＝子育ち＋子育て」の合成造語の説明をミドル／ロング版で必ず含める。サービス名は和文で読みやすい表記（カタカナ・英字混在を避ける）。

### 信頼性の担保

- 公的資料（文部科学省・こども家庭庁）の引用＋運営者目視確認（5層ガードレール）を、ロング版でのみ明示。
- 運営者は保育士ではなく「同じ立場の親」であることを開示し、専門家ぶらない姿勢を表明。

### note プロフィール慣行

- 「誰が」「何を」「なぜ」「何が読めるか」を短く伝える構成が読者に届きやすい（[note編集部のガイド](https://note.com/notemag/n/n13e84ca441b1)、[しぶや「すてきなnoteのプロフィール」の書き方](https://note.com/setoshohei/n/n62de93c08420) を参照）。
- 信頼感を上げるため、テーマ（誰に・何を）を最初の1文で明示。

## バージョンC: ロング（マニフェスト的長文・600〜800字目安）

> 字数: **798字**（句読点・全角記号含む／改行除く／Python `len()` で実測）

```
はじめまして。ひだまりこそだち、というちいさなメディアを運営しています。

「ひだまり」は、陽の当たる温かい場所のこと。「こそだち」は、子が自ら育つ「子育ち」と、親が育てる「子育て」を重ねた合成造語です。育てる側と育つ側を切り分けず、親子が並んで座る縁側のような場所で、それぞれのペースで日々を重ねていく。そんな関係を言葉にしたくて、この名前にしました。

ここでは、0〜6歳のお子さんと過ごす方に向けて、毎日のお題と、その場で使える「親への声かけ」を1日ひとつお届けします。お子さんへの教材ではなく、声をかける側の親が主役のメディアです。「何かをやらせなきゃ」と思う前に、まず私たち自身がひと呼吸おける。そんな午後の光のような余白を、ちいさく置いておきたいと思っています。

大切にしていることが、いくつかあります。ひとつめは、ものを増やさないこと。届くのは10分ほどで読み終わる短い文章だけで、教材も玩具もお送りしません。ふたつめは、断言しないこと。「絶対」「必ず」「○歳までに」といった言い方は使わず、「こういう声のかけ方もある」「うまく芽吹かない日もある」という余白を残します。みっつめは、専門家ぶらないこと。運営者は保育士ではなく、同じように悩みながら子と過ごしている一人の親です。寄り添う以上の立場には立ちません。

一方で、内容の信頼性は丁寧に担保します。文部科学省・こども家庭庁などの公的資料を引用しながらお題を組み立て、AIで素案を生成したあと、運営者がすべての記事を配信前に目で確かめています。プロンプト設計・公的資料引用・読者からの声・運営者の目視確認・コミュニティでの検証。この5層のガードレールで、誇大な表現や踏み込みすぎた言葉が混ざらないよう気をつけています。

正解を渡す場所にはしないつもりです。陽だまりに腰をおろすように、ご自身のペースでふらりと立ち寄っていただけたらうれしいです。
```
