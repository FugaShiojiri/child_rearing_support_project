## 設計メモ（執筆判断の背景）

- **ブランドトーン**: やさしく・断言しない・親と子を対等に語る。「教える」「育てる」の動詞を避け、「共に過ごす／気づく／育つ」を優先。
- **核となるメッセージ**: 「育てるのではなく、共に育つ」。サービス名「こそだち」は「子育ち（子が自ら育つ）」と「子育て（親が育てる）」の合成造語であることを必要に応じて明かす。
- **対象**: 0〜6歳児の保護者（暫定優先は3〜6歳）。プロフィール上では「未就学の子と過ごす方」と柔らかく表現。
- **差別化**: 親を主役にする／物を増やさない／10分で完結。
- **信頼性**: 公的資料（文科省・こども家庭庁）に基づく＋CEO目視確認。
- **避ける表現**: 「絶対」「必ず」「〇歳までに〇〇できないと」「専門家として教えます」。CEOは保育士ではなく、共に学ぶ親の立場。
- **note プロフィール慣行**: 「誰が」「何を」「なぜ」「何が読めるか」を短く伝える構成が読者に届きやすい（[note編集部のガイド](https://note.com/notemag/n/n13e84ca441b1)を参考）。

```
ここでは、今日その場で試せる10分ほどのお題、就学に向けて気になることへの寄り添い、保護者どうしの小さな気づきを共有していきます。情報を増やすより、ひとつ呼吸を整えるような言葉を置いていけたらと思っています。
```

## バージョンC: ロング（マニフェスト的長文・600〜800字目安）

> 字数: **717字**（句読点含む・改行除く／Python `len()` で実測）

```
はじめまして。「こそだち」というサービスを運営しています。

「こそだち」は、「子育ち（子が自ら育つ）」と「子育て（親が育てる）」を重ねた造語です。育てる側／育てられる側に分けず、「共に育つ」関係を言葉にしたくて、この名前にしました。

このアカウントでは、0〜6歳のお子さんと過ごす方に向けて、毎日のお題と、その場で使える「親への声かけ台本」を1日1つお届けします。お子さんへの教材ではなく、お父さん・お母さんが主役のサービスです。「何かをやらせなきゃ」と思う前に、声をかける側の私たちが、すこしほっとできるように。

大切にしていることが、いくつかあります。

ひとつめは、物を増やさないこと。届くのは10分ほどで読み終わる短い文章だけで、教材も玩具もお送りしません。ふたつめは、断言しないこと。「絶対」「必ず」「○歳までに」といった言い方は使わず、「こういう声のかけ方もある」「うまくいかない日もある」という余白を残します。みっつめは、専門家ぶらないこと。運営者は保育士ではなく、同じように悩みながら子と過ごしている一人の親です。寄り添う以上の立場には立ちません。

一方で、内容の信頼性は丁寧に担保します。文部科学省・こども家庭庁などの公的資料を引用しながらお題を組み立て、AIで素案を生成したあと、運営者がすべての記事を配信前に目で確かめています。5層のガードレールと呼んでいるこの仕組みで、誇大な表現や踏み込みすぎた言葉が混ざらないように気をつけています。

正解を渡す場所にはしないつもりです。今日の小さな気づきを、ことばにして並べておく場所。よかったら、ご自身のペースで覗いてみてください。子どもといっしょに、私たちもまだ育っている途中です。
```
