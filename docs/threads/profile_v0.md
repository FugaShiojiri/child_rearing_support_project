## プロフィール本文（コピペ用）

```
ひだまりこそだち｜0〜6歳の子と過ごす方へ、午後の光のような話を少しずつ。毎日のお題と『親への声かけ』をnoteに1日ひとつ。「うちはこんな日でした」もお気軽にどうぞ。それぞれのペースで芽吹いていけたらと思いながら、一緒に日々を重ねていく場所です。
```

## 最初のスレッド案

```
はじめまして。
「ひだまりこそだち」をはじめます。

0〜6歳の子と過ごす方へ、毎日のお題と『親への声かけ』を、noteに1日ひとつ並べていく予定です。

何かをやらせる前に、声をかける側の私たちが、ひと呼吸おけるような言葉を置いておきたくて。

「うちはこんな日でした」もお気軽に。
```

> 補足: Threads は会話型なので、初投稿は「自己紹介＋返信を促す一文」で締める。返信が来たら丁寧に拾い、ブランドトーン（断言しない・急かさない）を初動から徹底する。

## Threads 自己レビュー

| 観点 | 結果 |
|---|---|
| 「教える／育てる」動詞の回避 | OK（不使用） |
| 「育む／芽吹く／そっと寄り添う／日々を重ねる」の活用 | 「芽吹く」「日々を重ねる」採用 |
| 子の個性・ペースを尊重 | 「それぞれのペースで芽吹いていけたら」 |
| ターゲット明示（0〜6歳の保護者） | あり（冒頭） |
| 「こそだち」合成造語の説明 | なし（字数優先・対話の入り口を確保） |
| サービス価値（毎日のお題＋親への声かけ）明示 | あり |
| note 誘導の柔らかさ | 「お気軽にどうぞ」 |
| メタファー使用回数 | 2回（午後の光／芽吹く）※短文内なので許容範囲 |
| 媒体特性への適応 | 会話型・最初のスレッドで自己紹介を補完 |
