## プロフィール本文（コピペ用）

```
ひだまりこそだち｜0〜6歳の子と過ごす方のためのちいさなメディアです。毎日のお題と『親への声かけ』を1日ひとつ、noteでつぶやいています。「こそだち」は子育ち＋子育てを重ねた造語。縁側にふらりと寄るような気持ちで、それぞれのペースで日々を重ねていけたら。
```

---

## ハイライト名候補

- **お題**: 今週・今月のお題ピックアップ
- **声かけ**: 親への声かけ台本の抜粋カード
- **お庭**: 運営の裏側・季節の風景
- **季節**: 今月のテーマ・行事・自然のうつろい
- **始まりの記録**: サービス立ち上げの軌跡・自己紹介・運営者の想い
- **縁側**: 読者からの声・コメントピックアップ（設置は読者数が増えてから）
- **note**: メンバーシップ案内・最新記事リンク集

> 立ち上げ時は **「始まりの記録／お題／声かけ／季節／note」の5本** から開始するのが運用負荷的に現実的。ハイライトは6つを上限目安に。

## Instagram 自己レビュー

| 観点 | 結果 |
|---|---|
| 「教える／育てる」動詞の回避 | OK（不使用） |
| 「育む／芽吹く／そっと寄り添う／日々を重ねる」の活用 | 「日々を重ねる」採用 |
| 子の個性・ペースを尊重 | 「それぞれのペースで」 |
| ターゲット明示（0〜6歳の保護者） | あり（冒頭） |
| 「こそだち」合成造語の説明 | あり（簡潔） |
| サービス価値（毎日のお題＋親への声かけ）明示 | あり |
| note 誘導の柔らかさ | 「縁側にふらりと寄るような気持ちで」 |
| メタファー使用回数 | 1回（縁側） |
| 媒体特性への適応 | ビジュアル前提・ハイライトで補完 |
