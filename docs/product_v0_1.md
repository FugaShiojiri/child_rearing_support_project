## コンテンツ品質担保メカニズム（新章）

### 人手監修なしでどう品質を守るか

v0 で計上していた業務委託保育士¥30,000/月を不採用としたため、以下の **5層ガードレール** で代替する。

#### Layer 1: プロンプト設計（事前防御）

- **「禁止事項リスト」を Claude API システムプロンプトに固定埋め込み**
  - 医療判断（発達遅延の診断的言及）禁止
  - 体罰・恫喝を肯定する声かけ禁止
  - ジェンダー固定観念を強化する表現禁止（「男の子だから」「女の子なんだから」）
  - アレルギー・誤嚥リスクのある食材を断定的に推奨しない
- **「年齢相応性チェック」をプロンプト内で自己検証させる**
  - 3-6歳には「ひらがな・数・生活マナー」、0-2歳には「観察・声かけ・生活リズム」のスコープに自動限定

#### Layer 2: 公開教材・公的資料の引用ベース生成

人手監修の代わりに **公的機関の公開資料を一次ソースに固定** する：

- 文部科学省「幼稚園教育要領」「保育所保育指針」
- こども家庭庁 公開資料
- 厚労省「乳幼児栄養調査」「保育所におけるアレルギー対応ガイドライン」
- 日本小児科学会 こどもの予防接種・発達情報
- 公益財団法人 母子衛生研究会（赤ちゃん＆子育てインフォ）

→ お題テンプレ生成時に Claude へ「この公開資料の範囲内で逸脱せず生成」と指示。**「○○省ガイドライン準拠」表記をプロダクトに明示**してエビデンス感を演出。

#### Layer 3: ユーザーフィードバックループ（リアルタイム検知）

- 各お題配信後の **「役立った／違和感あり」2択ボタン** を LINE Bot に設置
- 「違和感あり」が10%超のお題は**自動的にライブラリから引退**しレビュー対象に
- 月1回、引退お題を CEO 自身が30分でレビューし、プロンプト調整に反映

#### Layer 4: 月次セルフレビュー（CEO自身）

- 月初に **過去30日の配信お題を CEO 自身が30-60分で抜き取りレビュー**
- レビュー観点: 危険／誤情報／表現問題／差別的表現
- 監修者を外注で持つコストの代わりに、CEO の月1時間で品質保証する

#### Layer 5: コミュニティ検閲（オフ会で出てくる声を吸収）

- 四半期オフ会で「最近のお題で違和感あったもの」を雑談として吸い上げ
- リアルな声は note 記事化→ さらに改善ループに戻す

#### コスト・工数

| 項目 | 工数 | 金額 |
|---|---|---|
| Layer 1-2: プロンプト設計（初期構築） | 一度きり20時間 | ¥0 |
| Layer 3: フィードバック収集 | 自動 | ¥0 |
| Layer 4: 月次セルフレビュー | 月1時間 | ¥0 |
| Layer 5: オフ会での聞き取り | オフ会に内包 | ¥0 |
| **合計** | **月1時間程度** | **¥0** |

→ v0 の¥30,000/月 が **¥0** に。粗利が月¥30,000向上。

#### 残存リスクと開示戦略

- 残存リスク: AI生成のため**100%の品質保証は不可能**
- 緩和策: プロダクトに「**本サービスは AI が公的ガイドラインを参照して生成しており、医療・発達の専門判断には代替しません。気になる症状は専門機関へ**」を明示
- このリスク開示自体が「誠実なプロダクト」のブランディング材料になる

## note の役割設計（新章）

### 位置づけ：集客の入口（メイン） × 解約防止の出口（サブ） × アップセル（マネタイズ）

#### 1. 集客の入口（最重要）

- **目的**: SEO とソーシャル拡散で月数万〜10万 PV を獲得し、LP への送客
- **コンテンツ方針**: 「ペルソナB の検索行動」に直撃する記事を **月8本ペース** で配信
  - 「ひらがな いつから 教える」「年長 就学準備 何する」「こどもちゃれんじ 解約 後悔」
  - 「3歳 言うこと聞かない 声かけ」「子ども 集中力 5歳」
- **記事構造**: 1本につき1悩み、3,000-5,000字、**末尾に LINE Bot 登録 CTA**
- **note は SEO で Google のドメイン評価を借りられる**ため、独自ブログ立ち上げより立ち上がりが早い
- 業界データ: 育児カテゴリのメンバーシップ売上トップ10のうち7人が **1年以内に参入した新規クリエイター**[(note公式)](https://prtimes.jp/main/html/rd/p/000000360.000017890.html)

#### 2. 解約防止の出口（中間目的）

- 有料会員には **note 過去記事の全アーカイブを LINE Bot 経由で検索可能** にする（自社プロダクトとの統合）
- 「note の過去記事ストックが資産」→ 解約すると失う感を演出

#### 3. 有料記事・メンバーシップ（補助収益）

- **月1-2本の有料単発記事（¥500）**: 季節特集（夏休みの過ごし方／入学準備チェックリスト）
- **note メンバーシップは v0.2 で再検討**（コアサブスクとカニバるリスクあり、まずは無料記事＋単発有料記事で運用）
- note 月額相場: **500〜1,500円が主流**[(note収益化ガイド)](https://www.canva.com/ja_jp/learn/how-to-monetize-note/)

#### 4. 工数試算

| 項目 | 工数 | 出力 |
|---|---|---|
| 記事執筆（Claude API ドラフト＋ CEO 編集） | 1本2-3時間 × 月8本 = 月20時間 | 8本／月 |
| SEOキーワード調査 | 月2時間 | 月次計画 |
| 有料記事執筆 | 月4時間 | 1-2本／月 |
| **合計** | **月26時間** | コンテンツ＋集客資産 |

→ v0 で計上していた「Instagram/X 育児アカ運用」の工数（推定週5-7時間 = 月20-28時間）を **note 中心に置き換え**。総工数は変わらず、ストック型資産に振り向ける。

#### 5. 収益貢献の見立て

- **集客貢献**: 月10万 PV × LP CVR 1% = LP登録 1,000人／月（中期目標）
- **直接収益**: 単発有料記事¥500 × 月50本売上 = **¥25,000／月**（軌道乗後）
- **メイン用途は集客**、直接収益は副次的に位置づけ

## オフ会・イベント設計（新章）

### 頻度・規模・参加費・運営フロー・収益貢献

#### 基本方針

- **頻度**: **四半期1回（年4回）** で開始。負荷を見て月次へ昇格判断
- **規模**: 1回 **10-20名**（親のみ、または親子参加可）
- **形式**: **少人数の対話型ミートアップ**（カフェ貸切・コワーキング・公共施設の和室など）
- **参加費**:
  - **会員 ¥2,000／回**（茶菓子代＋会場代を実費負担）
  - **非会員 ¥3,500／回**（会員になる体験差を作る）
- **エリア展開**: Phase 1 は**東京＋愛知の年4回ずつ**（ペルソナA首都圏／ペルソナB愛知）。Phase 2 で大阪・福岡を追加判断

#### 運営負荷（個人運営の現実性）

- 月平均 **2-3時間／月**（告知・準備・当日・レポート）
- 四半期に1回の集中投下なので、平時の負担は軽い
- **CEO がファシリ役を直接やる** ことで、ユーザーの生の声を仕入れる場として最大活用

#### 真の目的（解約防止フック）

- 「次のオフ会、3ヶ月後だから続けよう」という **継続のアンカー**
- リアルで会った人は **解約しにくくなる**（行動経済学のコミットメント効果）
- 月次レポートよりも遥かに強い心理的フック

#### NOT-do（オフ会で意図的にやらないこと）

1. **大規模イベント化しない**（30名超は CEO 一人では仕切れない）
2. **物販・教材販売をしない**（個人運営の物流リスク）
3. **講演型にしない**（対話型に固定。CEO は黒子）
4. **オンライン併催しない**（オフラインの希少価値を毀損）
