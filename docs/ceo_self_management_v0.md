## 使い方

1. 本テンプレートをコピーまたはそのまま編集し、**空欄（`___`）を埋める**。
2. **推奨デフォルト値** が併記されている箇所は、特に異論がなければそのまま採用してよい。
3. 配偶者と関連項目（特に第3節・第7節）を会話し、合意する。
4. 全項目を埋め終えたら、最後の **署名欄** に氏名と日付を記入する。
5. 本ドキュメントは **月1回（月次振り返り時）** に開き、運用が乖離していないか自己点検する。
6. 重大な前提変更（本業の変化・家族構成の変化・健康悪化等）があれば、再合意のうえ v0.1 として更新する。

## 0. 大前提（事業と自分の関係性）

このプロジェクトは **CEO 個人事業として月¥30万粗利を目指す副業** であり、以下を最上位の前提とする。

- **健康・家庭・本業 > 事業**。優先順位を逆転させない。
- **最初の6ヶ月は収益¥0を想定**（Phase 1〜2はゼロ収益、Phase 3で月¥3〜15万、Phase 4で月¥15〜30万のロードマップ）。
- **撤退は失敗ではない**。撤退条件（第6節）に該当したら速やかに休止または撤退する。

## 2. 本業との並行ルール

### 2-1. 副業規程の確認状況

- [ ] 本業の就業規則を確認した（副業可否の条項）: 確認日 ___
- [ ] 副業の事前申請の要否を確認した: 申請必要 / 申請不要（いずれかに○）
- [ ] 申請が必要な場合、申請を提出した: 提出日 ___ ／ 承認日 ___
- [ ] 競業避止義務に抵触しないか確認した（本業が教育・IT業界の場合は特に注意）: 確認結果 ___

**推奨デフォルト**: 上記4点はすべて **Phase 1 着手の前提条件** として完了させる。1つでも未確認なら Phase 1 を着手しない。

### 2-2. 業務時間外の取り扱い

- 本業の **業務時間中は事業作業を一切行わない**（休憩時間含む）。Slack/メール/Issue対応も不可。
- 本業の **業務用端末・アカウント・回線は事業に使用しない**。
- 本業の機密情報・顧客情報を事業に流用しない。
- 例外: ___（通常は「なし」）

### 2-3. 利益相反回避ルール

- 本業の顧客・取引先に対して、本事業のサービスを直接営業しない。
- 本業の同僚を本事業の有料顧客にしない（無料モニターは可、ただし業務時間外）。
- 本業の取引先と競合関係になった場合、即座に CEO 自身で判断し、必要なら事業側を撤退する。
- その他、本業に確認すべきグレーゾーンが発生した場合: ___（推奨: **本業の上長または人事に相談**）

## 3. 家庭との両立合意（配偶者）

> このセクションは **配偶者と一緒に読み、口頭で合意したうえで** 署名する。

### 3-1. 配偶者との合意項目

- [ ] **月の投下時間上限を共有**: 通常月 ___ 時間／繁忙月 ___ 時間／絶対上限 ___ 時間
  - 推奨デフォルト: 40h／50h／60h
- [ ] **期待しない収益タイムラインを共有**:
  - 最初6ヶ月（Phase 1〜2）: **収益¥0想定**
  - 7〜9ヶ月目（Phase 3）: 月¥3〜15万
  - 10〜12ヶ月目（Phase 4）: 月¥15〜30万
  - **「半年は1円も入らない可能性が高い」ことに配偶者が納得している**: はい / いいえ
- [ ] **家族イベント優先のルール**:
  - 子どもの行事（保育園・幼稚園・学校）は事業より優先: 同意 / 異議
  - 家族の体調不良時は事業作業を停止: 同意 / 異議
  - 家族旅行・帰省中は事業作業を行わない（緊急対応のみ可）: 同意 / 異議
  - 推奨デフォルト: すべて「同意」
- [ ] **家事・育児の分担に与える影響を共有**:
  - 事業時間中に配偶者が増える負担: ___（具体的に記載、例: 平日朝の保育園送り）
  - その補填方法: ___（例: 週末の家事を CEO が多めに引き受ける）
- [ ] **月次の進捗共有**:
  - 月1回、配偶者に進捗と今月の感触を5〜10分で共有する: 同意 / 異議
  - 共有タイミング: ___（推奨: **毎月第1日曜の夜**）

### 3-2. 配偶者の停止指示権（第7節と連動）

- 配偶者は CEO に対し、以下のいずれかが発生した場合、**事業の一時停止を指示する権限** を持つ。
  - CEO の健康が著しく悪化した（睡眠不足・体重急減・気分の落ち込み等）
  - 家族との時間が著しく削られている（子どもとの時間が週末まったく取れない等）
  - 本業のパフォーマンスが目に見えて落ちている
- 配偶者が停止を指示したら、CEO は **24時間以内に最低1週間の事業停止を実施** する。

## 4. 燃え尽き防止

### 4-1. 連続稼働の上限

- [ ] **連続稼働日数の上限**: 最大 ___ 日連続まで（推奨: **6日連続まで。週1日は完全オフ**）
- [ ] **連続ピーク週の上限**: 週15時間ペースは最大 ___ 週連続まで（推奨: **2週連続まで。3週目は必ず週10h以下に戻す**）
- [ ] **3週連続で目標未達なら強制1週間休暇**（pre_phase1_decisions 7-4 と整合）

### 4-2. 必須休養日

- [ ] **週次の完全オフ日**: ___ 曜日（推奨: **日曜**）
  - 完全オフ = Slack/GitHub/Claude Code を開かない、事業のことを考えない
- [ ] **月次の完全オフ日**: 月 ___ 日（推奨: **毎月最終日曜＋もう1日、計2日**）
- [ ] **四半期に1回、3連休をとる**: 同意 / 異議（推奨: 同意）

### 4-3. 月次振り返り

- [ ] **毎月 ___ 日に30分の振り返りを実施**（推奨: **毎月末の日曜夜、または翌月第1日曜の朝**）
- 振り返り項目（最低限）:
  1. 今月の投下時間 vs 上限
  2. 今月の主要KPI達成状況
  3. 燃え尽きシグナルの自己チェック（睡眠・気分・体調）
  4. 来月の継続/調整/休止判断
  5. 配偶者・第三者（4-4）と共有すべき内容の整理

### 4-4. 孤独防止（メンター／友人共有）

- [ ] **月1回、進捗を雑談共有する相手を1名以上指定**:
  - 候補1（必須）: ___（関係: ___ ／ 例: 大学時代の友人）
  - 候補2（任意）: ___（関係: ___ ／ 例: 元職場のメンター）
- 推奨デフォルト: **配偶者以外の友人またはメンターを1名。事業の細部より「最近どう？」レベルの雑談で十分**。
- 共有頻度: ___（推奨: **月1回・30分程度・対面 or オンライン**）

## 5. 健康・身体メンテ

### 5-1. 最低ライン（事業のKPIとして扱う）

| 項目 | 記入欄 | 推奨デフォルト | 計測方法 |
|---|---|---|---|
| 睡眠時間 | ___ 時間／日（最低） | **7時間／日** | スマートウォッチ or 自己申告 |
| 運動 | ___ 回／週 | **週3回**（1回30分以上の有酸素 or 筋トレ） | カレンダー記録 |
| 朝食 | ___ 回／週 | **週5回以上** | 自己申告 |
| アルコール | ___ 日／週（休肝日） | **週2日以上の休肝日** | 自己申告 |
| 健康診断 | ___ 回／年 | **年1回（本業の定期健診を活用）** | 受診記録 |

### 5-2. 健康崩壊時の停止権限

以下のいずれかが発生したら、CEO は **本人または配偶者の判断で事業を即時停止** できる（=やる）。

- 睡眠時間が **2週連続で平均6時間未満**
- 体重が **1ヶ月で3kg以上の減少（意図しない）**
- 健康診断で **要再検査・要治療** の判定
- メンタル不調を **自覚 or 配偶者から指摘** された
- 本業のパフォーマンスが **目に見えて低下** した

停止期間: 最低 ___ 週間（推奨: **最低2週間、状況により1ヶ月以上**）

## 6. 撤退・休止トリガー

> 以下の条件に該当したら、**感情を介在させず機械的に** 該当アクションを発動する。

| # | トリガー条件 | 自動発動アクション | 出典 |
|---|---|---|---|
| 6-1 | CEO の月投下時間が **60h超** が **3ヶ月連続** | **強制休止（最低1ヶ月）** | pre_phase1_decisions 6-4(4) |
| 6-2 | Phase 1 終了時に **LP登録 < 25件** | ピボット検討 or 撤退判断 | pre_phase1_decisions 6-4(1) |
| 6-3 | Phase 2 終了時に **β10名中 有料転換 < 3名** | ピボット検討 or 撤退判断 | pre_phase1_decisions 6-4(2) |
| 6-4 | Phase 3 終了時に **有料 < 50人** | ピボット検討 or 撤退判断 | pre_phase1_decisions 6-4(3) |
| 6-5 | **主要KPI未達が2フェーズ連続** | 撤退判断 | pre_phase1_decisions 6-4(5) |
| 6-6 | 健康崩壊シグナル（第5-2節）に該当 | 即時停止（最低2週間） | 本ドキュメント 5-2 |
| 6-7 | 配偶者が停止を指示（第3-2節） | 24時間以内に最低1週間停止 | 本ドキュメント 3-2 |
| 6-8 | 第三者承認者（第7節）が停止を指示 | 24時間以内に最低1週間停止 | 本ドキュメント 7 |
| 6-9 | 本業の就業規則違反・利益相反が顕在化 | 即時停止・整理 | 本ドキュメント 2-3 |

### 6-1. トリガー作動時のチェックリスト

トリガーが作動したら、以下を **必ず** 実行する:

- [ ] 配偶者に状況を共有する（24時間以内）
- [ ] 第三者承認者（第7節）に状況を共有する（48時間以内）
- [ ] 進行中の対顧客コミットメント（β契約・配信予約等）を整理する
- [ ] 休止/撤退期間中の連絡窓口を顧客に告知する（該当する場合）
- [ ] 月次振り返りで「なぜ作動したか」を1ページで記録する

## 7. 第三者承認権

> 配偶者以外に、**事業の停止指示権** を持つ信頼できる1名を指名する。
> 客観性を担保するため、できるだけ事業領域から独立した人物を選ぶ。

### 7-1. 第三者承認者の指名

- 氏名: ___
- 関係: ___（例: 大学時代の友人／元職場の先輩／メンター）
- 連絡手段: ___（例: LINE・電話）
- 推奨デフォルト: **配偶者以外で、事業の内容を雑談レベルで共有している月1相手（第4-4節と兼任可）**

### 7-2. 承認者の権限

- CEO の状態（健康・家庭・本業）に懸念を感じた場合、CEO に対して **事業の一時停止を指示** できる。
- 承認者が停止を指示したら、CEO は **24時間以内に最低1週間の事業停止を実施** する。
- 承認者の判断は **CEO 本人の異議によって覆らない**（このルールが本セクションの本質）。

### 7-3. 承認者への事前共有事項

- [ ] 本ドキュメント全体を承認者に共有した: 共有日 ___
- [ ] 承認者が停止指示権を引き受けることに同意した: 同意日 ___
- [ ] 月1回の雑談共有（第4-4節）の場で運用する旨を合意した: 同意日 ___
