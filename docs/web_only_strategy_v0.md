# ひだまりこそだち web完結戦略 v0（CEO決裁 2026-05-28）

> 本書は **オーナーが web完結で集客・コミュニティ形成を実現するための施策選定** を確定した CEO 決裁文書。
> 旧 `sns_strategy_v0.md`「コミュニティはオフライン中心」原則（[[project-operations-philosophy]] 旧原則3）は 2026-05-28 に **撤回・書き換え**（オーナーに知人/地域ネットワークが存在しないことが判明＝設計の前提誤りはCEO責任として引き受け済・[[project-distribution-reality]]）。
> 本書を **当面（Phase1 残期間 + Phase2 設計）の web集客の正** とする。

---

## 結論（30秒で読める）

1. **施策は 2 本に厳選・即発火**：(c) note他クリエイター誠実接触（週10件）／(b) note タグ・タイトル最適化（既存3本＋新規1本）
2. **不採用5本（明示）**：X押し込み強化／X育児ハッシュタグ参戦／Threads前倒し／note創作大賞応募／ランキング系まとめコンテンツ
3. **週バジェット**：A手作業7.2h（要監視・上限ギリギリ・1週試して再調整）
4. **「他クリエイター接触」が心理的に営業的と感じたら即撤回**（手段は手段・原則ではない）

---

## 1. 施策選定の判断軸

| 軸 | 基準 |
|---|---|
| ① 週7h以内 | オーナー総稼働バジェット内に収まるか |
| ② 人手最小 | 反復作業の自動化・委譲が効くか／オーナー手作業を増やさないか |
| ③ 学びが得られる | 真因切り分けや次フェーズ設計に資するデータが取れるか |
| ④ ブランド非権威 | 「正解はひとつではない」「断定しない」「親バッシングなし」と整合 |

---

## 2. 採用施策（2本のみ・即発火）

### 【採用1】(c) note他クリエイターへの "誠実な" 相互発見性アクション

| 項目 | 内容 |
|---|---|
| 内容 | 育児・教育・発達系の note 記事に対し、**読んだ上で具体的なスキ＋意味のあるコメント**（営業文ゼロ・自記事誘導禁止） |
| 量 | **週10件のみ**（1日1-2件・1件15分×10＝週2.5h） |
| 担当 | オーナー（読む・コメント書く） |
| 学べること | どんな記事に反応が来るか・どんな層がいるか・自記事へどう流入するか。**真因C（コンテンツ品質）の再評価データも同時に取れる** |
| 採用理由 | note 内エコシステムは「スキ・コメント返し」文化が強く、web完結で発見性を作る最も自然な手段。ブランド非権威と整合（権威性ではなく誠実性で関係を作る） |
| **要監視（撤回トリガー）** | オーナーが「営業的で嫌」と感じたら **即撤回**。1週やって週次レビューで実時間を測り、超過したら週7件に削る |

### 【採用2】(b) note 内タグ・タイトル最適化

| 項目 | 内容 |
|---|---|
| 内容 | 既存3記事のタグを「#子育て #エッセイ #育児」等 note内検索ボリュームの大きい一般タグに差し替え＋タイトルを「読みたくなる形」に微改修（権威性ではなく "問い" の形）。次の1本は最初から最適化して投稿 |
| 量 | **週1.5h**（既存3本改修1h＋新規1本反映0.5h）・**単発作業**（1回やれば恒久効果） |
| 担当 | メインClaude（タグ候補・タイトル案を下書き）→ オーナー（目視承認＋note 反映） |
| 学べること | タグ変更前後の流入差＝note検索SEOの効きが定量化できる |
| 採用理由 | note 24ビュー/10日 = 自然流入が「少しは」効いている証拠。タグ最適化は1回の作業で恒久効果。Bowlby記事の流入を倍にできれば、それだけで信号が変わる |

## 6. 期待効果と判定基準

### 期待効果（過剰期待しない）
- note 全体ビュー：36 → **目標 80〜120**（2〜3倍）。タグ改修＋他クリエイター回遊で達成見込み。
- note スキ：0 → **目標 3〜5**（誠実コメント返しからの自然反応）。
- Form 回答：0 → **目標 2〜5件**（リーチ倍化に応じた小規模上昇を期待・G1=20件には届かない前提）。

### 判定基準（6/4 週次レビュー）
- **継続条件**：施策時間が週7h以内に収まる ＋ note ビューが倍以上に伸びる ＋ オーナー心理負担が許容範囲
- **調整条件**：時間超過 → 他クリエイター接触を週10→7件に削減
- **撤回条件**：オーナーが「営業的で嫌」と感じる ／ ビューが伸びない ／ 心理負担が大きい
  → Phase2 設計選択肢の C/B/D いずれかに切り替え
