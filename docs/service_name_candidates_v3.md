## 🎯 最終確定（2026-05-13）

**サービス名: ひだまりこそだち**

- **語源**:
  - 「ひだまり」=「日溜まり」= 陽の当たる温かい場所
  - 「こそだち」=「子育ち（子が自ら育つ）」＋「子育て（親が育てる）」の合成造語
- **思想**: 温かい陽だまりのような場所で、親子が自分のペースで育つ
- **採用プロセス**: CEO 推奨1位「こそだち花畑」を含む v3 5案を提示し、CEO（ユーザー本人）が候補4「ひだまりこそだち」を選定
- **採用理由（CEO選定）**:
  - 「ひだまり」の温かさ・安心感が、Hagmii Garden が伝えたかった「育む場所」感より直接的に伝わる
  - 「こそだち（子育ち＋子育て）」は当初発案の思想を継承
  - 縁側・午後の光のメタファーが日本人保護者に親和性が高い
  - ひらがな7文字、覚えやすい

以下、v3 ブレスト経緯は **検討記録として保持**。

## 経緯と要件

### なぜ v3 が必要になったか

v2 で確定した **「Hagmii Garden（ハグミー・ガーデン）」** について、フル表記 `Hagmii Garden` は WebSearch で未検出だったが、口頭で必ず発生する **略称・呼称「ハグミー／hugme／HUGME／hugmo／はぐみ」音** が以下の既存ブランドと衝突することが判明：

| 衝突先 | 領域 | 影響度 |
|---|---|---|
| カトージ **hugme** ベビーカー | 育児ど真ん中（玩具・育児用品） | 高 |
| 一条工務店 **HUGme** 住宅商品 | 住宅・マス認知 | 中（領域違いだが認知量大） |
| **ハグミー・ナーサリー** / **Hug Me International School** | 保育園 | 高（直接領域） |
| **はぐみ（HUGME）** 保育支援システム | 保育 ICT | **致命的（直接競合）** |
| Gakken **hugmo** 保育 ICT | 保育 ICT | **致命的（直接競合）** |
| 鹿屋市 **かのやはぐめも** 子育てアプリ | 自治体子育てアプリ | 中（音類似） |

→ フル表記運用しても「ハグミーさん？」「はぐみのこと？」と毎回混同される構造。**フル表記でも略称でも逃げ場がない**ため、命名を白紙に戻して再ブレストする。

### v3 の新要件（ユーザー確定）

1. **多少長くてもよい**（7〜15文字程度を許容）
2. **略称が無くてもよい**（フル表記運用 OK）
3. **「ハグミー」「hugme」「HUGME」「hugmo」「はぐみ」音と被らないこと**
4. **「こどもちゃれんじ」「スマイルゼミ」「ワンダーボックス」等の有名競合と紛らわしくないこと**
5. **「育む場所」感を維持**（庭・場所・空間・育成環境・季節感）
6. **0〜6歳の両ペルソナを自然に包含**
7. **note アカウント・SNS ハンドルとして成立する**

### 注意：v1 既存5案との関係

v1 候補（ことだち／こえかけ／そだちのたね／はじめのいっぽ／おやとこ）はいずれも「**育む場所**」感が弱く（"行為" や "関係" が主軸）、v3 要件 5 を満たさないため再採用しない。ただし「ことだち」は推奨2位として併記する選択肢としてはあり得る。

## CEO 推奨1案

### **こそだち花畑（こそだちはなばたけ）**

**ユーザーへの説明文（200字以内）：**

Hagmii Garden の「庭」を「花畑」に置換した案を最推奨します。「ハグミー」音を完全回避しつつ、**育む場所の比喩・季節感・成長サイクル・0〜6歳の発達多様性**（いろんな花がいろんなペースで咲く）をすべて保持します。WebSearch で同名サービス未検出、混同リスクは v2 比で劇的に低下します。フル表記運用前提（略称不要）の方針にも合致します。

### 採用根拠の補強

1. **称呼衝突リスク**：v2 で致命的だった「はぐみ／hugmo」保育 ICT 系との混同が完全に消滅
2. **ブランド連続性**：v2 採用時の世界観（庭＝育成環境）を「花畑」で継承可能。コンテンツ展開（季節の花、芽吹き、収穫）も無改変で流用可
3. **両ペルソナ訴求**：ペルソナ A の「うちの子のペース大丈夫？」への回答 = 「花はそれぞれ違うペースで咲く」、ペルソナ B の「就学準備で焦らせたくない」への回答 = 「育つ場を整えれば自然に咲く」
4. **note 適合**：マガジン名「こそだち花畑」、メンバーシップ名「花畑メンバー」、季節特集「○月の花畑だより」など展開容易

### リスクと緩和策

- **長さ（8 文字）**：略称運用は不要とのユーザー方針で問題なし。SNS ハンドル `kosodachi-hanabatake` は 19 文字でやや長いが許容範囲
- **「こそだち」音と「こそだて」の関係**：「子育て（こそだて）」ではなく「子育ち（こそだち）」を意図的に使う旨をブランドストーリーで明示（"親が育てる" ではなく "子が自ら育つ場" という思想転換）
