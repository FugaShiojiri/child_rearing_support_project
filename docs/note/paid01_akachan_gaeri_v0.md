# 赤ちゃん返りに、どう向き合う？ — 「甘え」を3つの考え方で読み解く

下の子が生まれてから、上の子が急に甘えるようになった。抱っこ、抱っこ、と。自分でできていた着替えまで「やって」と言う。

正直、「もう赤ちゃんじゃないでしょ」と言いそうになる。下の子のお世話で手いっぱいなのに、上の子まで赤ちゃんに戻られたら、こっちが泣きたくなる。

これ、いわゆる「赤ちゃん返り」です。きょうだいが増えた家庭の多くが通る道で、決してあなたの育て方のせいではありません。

でも、しんどいですよね。「甘やかしていいの？」「突き放した方が自立するんじゃ？」と迷う。叱ってしまって、あとで落ち込む。

この記事では、その「赤ちゃん返り」というひとつの場面を、**3人の専門家の考え方**で読み解いてみます。

- なぜ起きるのか（ボウルビィ「安全基地」）
- どこまで受け止めていいのか（佐々木正美「甘えさせる」と「甘やかす」の違い）
- 明日から具体的に何をすればいいのか（アドラー「勇気づけ」）

ひとつの出来事も、見る角度を変えると、関わり方がふっと楽になります。「困った行動」が「意味のあるサイン」に見えてくる。読み終わるころには、今夜の「抱っこ」への返事が、少し変わっているかもしれません。

## 視点①　なぜ起きるのか — ボウルビィの「安全基地」

イギリスの精神科医ボウルビィは、子どもにとって親は「**安全基地**」だと考えました。

子どもは不安になると、親のもとへ戻ってくる。抱っこされたり、そばにいたりして安心を補給する。そして心が満たされると、また自分から離れて、世界を探検しに出ていく。**安心して戻れる場所があるからこそ、安心して離れられる。**これが安全基地の考え方です。

ここで下の子が生まれると、何が起きるか。

上の子にとっては、自分の「安全基地」だった親の関心が、突然もう一人にも向けられる。**基地が奪われるかもしれない、という不安**です。だから上の子は、抱っこをせがんだり、できることをわざと「できない」と言ったりして、**基地がまだ自分のものか、確かめにくる。**

つまり赤ちゃん返りは、わがままでも、後退でもありません。**「ぼく（わたし）の安全基地は、まだここにある？」という確認の行動**なんです。

だとすると、対応の方向性は見えてきます。突き放すと「基地が無くなった」という不安が増して、確認行動はもっと激しくなる。逆に、**求められたぶん受け止めてあげると、「基地はちゃんとある」と安心が満ちて、また自分から離れて遊ぶようになる。**

冒頭の「求められるだけ抱いてみたら、数週間で自分からまた遊びにいくようになった」というのは、まさにこれです。安心が満ちたから、探検に戻れた。

## 視点②　どこまで受け止めていいのか — 佐々木正美「甘えさせる」と「甘やかす」

とはいえ、ここで多くの親がブレーキを踏みます。「受け止めすぎたら、甘やかしになるんじゃないか」。

日本の児童精神科医・佐々木正美さんは、この不安に対してとても大事な区別をしています。**「甘えさせる」と「甘やかす」は、まったく別物だ**、と。

- **甘えさせる** … 子どもの**情緒的な欲求**に応えること。抱っこして、見て、そばにいて、という「心」の要求に応える。これは子どもの心の土台をつくり、**むしろ自立を促す**。
- **甘やかす** … 子どもが**自分でできること・やるべきこと**を親が代わりにやってしまう。物でご機嫌をとる。先回りして口を出しすぎる（過干渉）。これは自立を妨げる。

赤ちゃん返りの「抱っこして」「やって」は、ほとんどが**情緒的な欲求＝甘えさせていい側**です。物をねだっているわけでも、サボりたいわけでもない。「ぼくも見てほしい」という心の声だからです。

佐々木さんの有名な言葉に「**過保護を恐れるな、過干渉を恐れよ**」というものがあります。たっぷり甘えさせること（過保護的に見える関わり）はむしろ子どもを安定させる。本当に避けたいのは、子どもの気持ちを無視して大人の都合で動かす過干渉のほうだ、という意味です。

**十分に甘えた子は、ちゃんと甘えを卒業していく。**だから「受け止めること」に、罪悪感を持たなくていいんです。

## 視点③　明日から何をするか — アドラーの「勇気づけ」

最後に、具体的な関わり方を、アドラー心理学の視点から。

アドラーは、人の行動には必ず「**目的**」があると考えました。赤ちゃん返りという行動の目的を一言でいえば、**「下の子に移ってしまった注目と、自分の居場所（所属感）を取り戻したい」**。

ここがポイントです。子どもが「注目」と「居場所」を**問題行動（ぐずる・赤ちゃんぶる）で得ようとしている**なら、それを**いい形で先に満たしてあげればいい**。アドラーはこれを「**勇気づけ**」と呼びます。

明日からできる、具体的な5つ：

1. **先回りして、先に抱く。** ぐずってから対応すると「ぐずれば抱いてもらえる」と学習します。そうではなく、何も起きていないタイミングで、こちらから「ぎゅー」する。安心を**前払い**するイメージです。
2. **下の子のお世話を「手伝って」と頼る。** 「オムツ持ってきてくれる？」「見ててくれる？」。手伝えたら「助かった、ありがとう」。これで上の子は「自分はこの家に必要だ」という所属感を、いい形で得られます。
3. **「お兄ちゃん（お姉ちゃん）なんだから」を、いったん封印する。** これは我慢を強いる言葉です。年上だからと甘えを禁じるより、今は甘えを受ける時期だと割り切る。
4. **1日数分でいいので、二人きりの時間をつくる。** 量より「あなただけの時間がある」という事実が効きます。下の子が寝た後の5分の絵本でも十分。
5. **親自身が「甘え＝悪じゃない」と知っておく。** これが一番効くかもしれません。罪悪感なく受け止められると、こちらの表情がやわらぐ。その安心感は、ちゃんと子どもに伝わります。

## おわりに

赤ちゃん返りは、いつか終わります。安心が満ちれば、子どもは自分からまた離れていく。「甘え」は、満たされると卒業していくものだからです。

そして、こうやって悩んでいること自体が、あなたがちゃんと向き合っている証拠です。完璧な親である必要はありません。**親も、子と一緒に、少しずつ育っていく。**今日の抱っこ一つが、その一歩です。
