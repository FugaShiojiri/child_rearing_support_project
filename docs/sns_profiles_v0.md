## 設計メモ（執筆判断の背景）

### 各プラットフォームの役割と書き分け方針

| 媒体 | 文字数枠 | 役割 | 書き分けの軸 |
|---|---|---|---|
| X (Twitter) | 160字以内 | テキスト中心・流れが速い | 「誰に・何を・どこで」を1秒で読み切れる導線重視。陽だまりメタファーを1回 |
| Instagram | 150字以内 | ビジュアル前提（プロフ画像と組合せ） | サービスの価値＋人間味。縁側メタファーで「ふらりと」誘導 |
| Threads | 150字以内 | 会話型・親近感 | 「うちはこんな日」の対話への招待。芽吹くメタファーで未来感 |

### トーン基準（note プロフィール v0 と統一）

- やさしく、断言しない、親を急かさない、子の個性を尊重する。
- 動詞は「教える／育てる」を避け、「育む・芽吹く・そっと寄り添う・日々を重ねる」を優先。
- 「絶対」「必ず」「○歳までに」NG。
- 陽だまり・縁側・午後の光のメタファーは各プラットフォーム1回程度に抑える。
- 誘導は「note でつぶやいています／毎日 1 つ／よかったら覗いてください」のような柔らかい文体。

### 字数計測条件

- Python `len()` 相当（改行除く、句読点・全角記号「｜」「『』」「〜」を1字としてカウント、半角英数字も1字）。
- 各プラットフォームの公式上限：X 160字 / Instagram 150字 / Threads 150字。掲載前に実機での見え方（改行・絵文字置換含む）を再確認すること。

## X (Twitter) プロフィール

> 字数: **141字**（改行除く・実測）／上限160字
> 目標枠: 140-160字 → 範囲内

```
ひだまりこそだち｜0〜6歳の子と過ごす方へ、毎日のお題と、その場で使える『親への声かけ』をnoteに1日ひとつそっと届けています。「こそだち」は子育ち＋子育てを重ねた合成造語。陽だまりのような場所で、親子それぞれのペースで日々を重ねていけたらうれしいです。よかったら覗いてください。
```

### ハッシュタグ案

- 常設候補（プロフィール下部・固定ポスト・通常ポストで使い回し）
  - `#ひだまりこそだち`（ブランドタグ・最重要）
  - `#子育て` `#育児`（汎用・到達優先）
  - `#0歳 #1歳 #2歳 #3歳 #4歳 #5歳 #6歳`（年齢タグはポスト内容に合わせ1-2個）
  - `#就学準備`（ペルソナB訴求）
  - `#声かけ` `#親への声かけ`（プロダクト独自タグ）
  - `#noteで毎日`（誘導タグ）

### 固定ツイート案（任意）

```
0〜6歳の子と過ごす方へ。

毎日のお題と、その場で使える『親への声かけ』を、noteに1日ひとつそっと並べています。

「何かをやらせなきゃ」の前に、声をかける側の私たちが、ひと呼吸おける場所になれたら。

▼note（ひだまりこそだち）
https://note.com/<username>

#ひだまりこそだち
```

> 補足: 固定ポストは「何ができるか・どこで読めるか」を補い、プロフィール本文では削った note リンクへの動線を担う。

## Instagram プロフィール

> 字数: **128字**（改行除く・実測）／上限150字
> 目標枠: 120-150字 → 範囲内

```
ひだまりこそだち｜0〜6歳の子と過ごす方のためのちいさなメディアです。毎日のお題と『親への声かけ』を1日ひとつ、noteでつぶやいています。「こそだち」は子育ち＋子育てを重ねた造語。縁側にふらりと寄るような気持ちで、それぞれのペースで日々を重ねていけたら。
```

### ハイライト名候補

- お題（今週・今月のお題ピックアップ）
- 声かけ（親への声かけ台本の抜粋カード）
- お庭（運営の裏側・季節の風景）
- 季節（今月のテーマ・行事・自然のうつろい）
- 始まりの記録（サービス立ち上げの軌跡・自己紹介・運営者の想い）
- 縁側（読者からの声・コメントピックアップ／設置は読者数が増えてから）
- note（メンバーシップ案内・最新記事リンク集）

> 補足: ハイライトは6つを上限目安に。立ち上げ時は「始まりの記録／お題／声かけ／季節／note」の5本から開始するのが運用負荷的に現実的。

## Threads プロフィール

> 字数: **124字**（改行除く・実測）／上限150字
> 目標枠: 120-150字 → 範囲内

```
ひだまりこそだち｜0〜6歳の子と過ごす方へ、午後の光のような話を少しずつ。毎日のお題と『親への声かけ』をnoteに1日ひとつ。「うちはこんな日でした」もお気軽にどうぞ。それぞれのペースで芽吹いていけたらと思いながら、一緒に日々を重ねていく場所です。
```

### 最初のスレッド案（任意）

```
はじめまして。
「ひだまりこそだち」をはじめます。

0〜6歳の子と過ごす方へ、毎日のお題と『親への声かけ』を、noteに1日ひとつ並べていく予定です。

何かをやらせる前に、声をかける側の私たちが、ひと呼吸おけるような言葉を置いておきたくて。

「うちはこんな日でした」もお気軽に。
```

> 補足: Threads は会話型なので、初投稿は「自己紹介＋返信を促す一文」で締める。返信が来たら丁寧に拾い、ブランドトーン（断言しない・急かさない）を初動から徹底する。

## 共通事項

### リンク（note URL）の貼り方

| 媒体 | 推奨設置場所 | 備考 |
|---|---|---|
| X | プロフィール内「ウェブサイト」欄に note URL を設定。プロフィール本文では URL を入れず固定ポストで誘導 | プロフィール本文の字数を温存。固定ポスト内に `https://note.com/<username>` をフルで記載 |
| Instagram | プロフィール下「ウェブサイト」欄に note URL（Linktree 等は当面不要、リンクは1本に絞る） | リンク先のヒーロー記事は note プロフィール（マガジン Top）に固定 |
| Threads | プロフィール内「リンクを追加」で note URL を設定。本文では削る | Threads は外部リンクのクリック導線が弱いため、初動のスレッドに自然な文脈で note URL を埋める |

> 共通方針: 独自ドメインを購入しないため、すべて `https://note.com/<username>` を正規リンクとする（`docs/product_v0_2.md` §3-5 と整合）。

### プロフィール画像の方向性提案（CEO自作前提）

- **キービジュアル要素**:
  - 陽だまりの暖色（はちみつ色〜淡いオレンジ〜柔らかいクリーム）をベースに
  - 縁側 or 窓辺の光の入り方を抽象化した幾何形（円・楕円・直線）
  - 文字を入れる場合は「ひだまりこそだち」または「ひ」一文字を、明朝系の柔らかい和文書体で
- **やらない方向性（NOT-do）**:
  - 人物写真・実子の顔出し → プライバシー方針と矛盾
  - 子供向けキャラクター・イラスト → 「親が主役」のブランドと矛盾
  - 強い原色・コントラスト → トーンと矛盾
  - 「○歳までに」「天才」「先取り」等のテキスト → 誇大表現NG
- **作成ツール候補**: Canva 無料プラン / Figma 無料プラン（v0.2 の「Claude Code 以外有料 SaaS 不採用」と整合）
- **サイズ**: 3 媒体とも正方形（円形クロップ対応）。最小辺 512px 以上の PNG を1枚作り、3 媒体で共通利用すると運用が楽。

## 各SNS自己レビュー

### ブランドトーン整合性チェック

| 観点 | X | Instagram | Threads |
|---|---|---|---|
| 「教える／育てる」動詞の回避 | OK（不使用） | OK（不使用） | OK（不使用） |
| 「育む／芽吹く／そっと寄り添う／日々を重ねる」の活用 | 「そっと届ける」「日々を重ねる」採用 | 「日々を重ねる」採用 | 「芽吹く」「日々を重ねる」採用 |
| 子の個性・ペースを尊重 | 「親子それぞれのペースで」 | 「それぞれのペースで」 | 「それぞれのペースで芽吹いていけたら」 |
| ターゲット明示（0〜6歳の保護者） | あり（冒頭） | あり（冒頭） | あり（冒頭） |
| 「こそだち」合成造語の説明 | あり（簡潔） | あり（簡潔） | なし（字数優先・対話の入り口を確保） |
| サービス価値（毎日のお題＋親への声かけ）明示 | あり | あり | あり |
| note 誘導の柔らかさ | 「よかったら覗いてください」 | 「縁側にふらりと寄るような気持ちで」 | 「お気軽にどうぞ」 |
| メタファー使用回数（過剰でないか） | 1回（陽だまり） | 1回（縁側） | 2回（午後の光／芽吹く）※短文内なので許容範囲 |
| 媒体特性への適応 | 1秒で読める導線・固定ポストで補完 | ビジュアル前提・ハイライトで補完 | 会話型・最初のスレッドで自己紹介を補完 |

### 誇大表現NGワードチェック

| NG カテゴリ | 検査ワード | X | IG | Threads |
|---|---|---|---|---|
| 断定 | 絶対／必ず／確実に | 不使用 | 不使用 | 不使用 |
| 期限 | ○歳までに／いつまでに／タイムリミット | 不使用 | 不使用 | 不使用 |
| 能力誇示 | 天才／賢い／IQ／先取り／差をつける | 不使用 | 不使用 | 不使用 |
| 不安煽り | できないと／遅れる／手遅れ／後悔 | 不使用 | 不使用 | 不使用 |
| 医療領域 | 発達障害／診断／治療 | 不使用 | 不使用 | 不使用 |
| 保証 | 効果保証／返金保証／結果が出る | 不使用 | 不使用 | 不使用 |

→ 3 媒体すべて誇大表現・不安煽り・医療判断への踏み込みなし。`docs/product_v0_2.md` §4 の 5 層ガードレール Layer 1（プロンプト設計）と整合。

### 媒体間の表現の重複チェック

- 3 媒体で完全に同一の文を使い回さず、それぞれメタファー（陽だまり／縁側／午後の光）と動詞（そっと届ける／つぶやく／少しずつ・芽吹く）を変えて、SNS横断で読者が見たときの単調感を回避。
- 共通要素（「0〜6歳」「毎日のお題」「親への声かけ」「こそだち」造語）は3媒体で揃え、ブランド一貫性を担保。
