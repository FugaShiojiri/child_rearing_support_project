# Phase 1 インタビュー Form 設計 v0（ひだまりこそだち β版 利用意向アンケート）

> **Form タイトル（公開時）**: 「ひだまりこそだち β版 利用意向アンケート 〜親子で育む毎日について教えてください〜」
> **サービス名**: ひだまりこそだち — 「ひだまり（陽の当たる温かい場所）＋こそだち（子育ち＋子育て）」

> ステータス: ドラフト（実装前レビュー要）
> 配信形式: Google Form（無料、ユーザー決定の課金不可方針と整合）
> 想定回答時間: **5分以内**（離脱率最小化を最優先）
> 想定回答数: **30〜50件**（ペルソナA・B 各15〜25件）
> 検証対象: H1（A の ¥1,480 支払い意欲）／H2（B の ¥980 支払い意欲）／H3（A vs B の CVR・継続率優位）／H4（NOT-do 選好）＋ コンセプト受容性（声かけ台本 vs ドリル型サブスク）

> 作成日: 2026-05-13

```

  │   ├─ 妊娠中 / 7歳以上 / 子なし → [終了画面: 対象外お礼]
  │   ├─ 0〜2歳 を選択 ──────→ [セクション2] → [セクション3A] → [セクション4] → [5] → [6] → [7]
  │   └─ 3〜6歳 を選択 ──────→ [セクション2] → [セクション3B] → [セクション4] → [5] → [6] → [7]
  │       （きょうだいで両方該当 → 上の子の年齢で振り分け、両方答えたい人向けに最後に "もう片方も回答する" リンクを表示）
  │
[セクション2: 子育ての現状・困りごと（共通・2問）]
  │
[セクション3A: 0-2歳ペルソナA向け（4問）]  または  [セクション3B: 3-6歳ペルソナB向け（4問）]
  │
[セクション4: コンセプト受容性（共通・コンセプト説明150字＋3問）]
  │
[セクション5: 課金意向（共通・年齢帯別に¥980 or ¥1,480 を出し分け・2問）]
  │

  │
```

**実装メモ（Google Form 機能との整合）**:

- 必須項目はセクション1のQ1.1（年齢帯）とセクション5の課金意向2問のみ。他はすべて任意
- 進捗バー表示ON（離脱抑制）

## 集計・分析方針

### 仮説判定マトリクス

| 仮説 | 判定に使う質問 | 合格ライン（暫定） |
|---|---|---|
| **H1** 0-2歳ママは ¥1,480 を払う | Q5A.1（「たぶん払う」以上の比率）／Q5A.2（¥1,480まで以上を選んだ比率） | Q5A.1 で4以上が **回答者の30%以上**／Q5A.2 で ¥1,480以上が **20%以上** |
| **H2** 3-6歳ママは ¥980 を払う | Q5B.1／Q5B.2 | Q5B.1 で4以上が **回答者の35%以上**／Q5B.2 で ¥980以上が **30%以上** |
| **H3** A vs B の CVR 優位 | Q5A.1 vs Q5B.1 の「4以上」比率差／Q4.1 の平均値差 | 比率差5pt以上、または平均値差0.3以上 |
| **H4** NOT-do が選好理由として成立 | Q6.1／Q6.2（4または5を選んだ比率） | **両方で4以上が50%以上** |
| **コンセプト受容性** 声かけ台本 vs ドリル | Q4.2（4または5の比率） | 4以上が **40%以上** で「声かけ台本仮説」採用継続 |
| **AI＋目視の信頼担保** | Q4.3 | 4以上が **50%以上**、1〜2が **20%以下** |

### 副次分析（クロス集計）

- Q2.2（過去解約サービス）× Q4.1（コンセプト魅力度）: 「こどもちゃれんじ解約者」のコンセプト受容度を抽出（v0.2 の差別化仮説の検証）
- Q3A.4 / Q3B.4（現在の月支出）× Q5の価格意向: 既に育児費を払っている層の価格弾力性
- Q4.2（声かけ台本選好）× Q5（課金意向）: 「声かけ台本」を強く好む層の課金意向が高いか
- 年齢帯（Q1.1）× 課金意向: 0-1歳 / 2歳 / 3-4歳 / 5-6歳 の4区分でのCVR差（v0.2 の3セグメント設計の妥当性検証）

### サンプルサイズ目標と回収上の留意

- ペルソナA（0-2歳）: **15〜25件**
- ペルソナB（3-6歳）: **15〜25件**
- 合計: **30〜50件**（pre_phase1_decisions.md の Go/No-Go 基準: 「LP登録50件」「課金意向あり15件以上」と整合）
- 回答時間は実測（Google Form の "セッション時間" 機能 or 自動計測ツール）で 5分以内を確認。超過する場合は任意項目を更に削る
- 同一人物の複数回答は Google アカウント認証ON、または Cookie 制御で抑制

- Google Form 制約: 条件分岐は「セクションへの移動」のみ。質問単位の出し分けは不可のため、価格出し分けは **セクションを2つ用意して分岐** で実装
- A/B ペルソナの **両方を1つのFormで賄う構成** とし、回答者が混乱しないよう冒頭文に「お子さまの年齢に応じて表示される質問が変わります」と明記
- 回答データは Google Sheets にエクスポート → 配信ライブラリ（product_v0.2 セクション1-3）とは別シートで管理
