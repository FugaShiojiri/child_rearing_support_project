## 案A: 太陽の下の親子家族（v1 更新版・推奨）

**コンセプト**: 陽だまりの下で親子3人が一緒に育つ / Sun + Family of sprouts

中央上の太陽（はちみつ色）が「ひだまり」。地面の上に3株の植物が並ぶ：
- **両側に背の高い双葉（ふたば）2株** = 2人の親（保護者）の象徴
- **真ん中に背の低い一ッ葉 1株** = 子（親に見守られながら自分のペースで育つ）

「親子一緒に陽だまりの下で育っていく」家族の世界観を直接的に表現。

- **強み**: 親と子の関係性が一目で伝わる、ブランド理念「子と親が共に育つ」と完全整合
- **弱み**: 構図がやや具体的なので、抽象性を求める場合は案C が良い
- **推奨用途**: SNS アイコン（X / Instagram / Threads / note）全般

---

## 案B: 縁側の午後

**コンセプト**: 縁側に差し込む午後の光 / Engawa with afternoon light

横長の地平線=縁側、その上に低い位置の太陽、手前に二株の小さな芽。「並んで座る」「日々を重ねる」の世界観をより情景的に表現。

- **強み**: 物語性があり、note の世界観と直結。アイキャッチに転用しやすい
- **弱み**: 情報量が多くアイコン小サイズだと見えづらい
- **推奨用途**: note アイキャッチ、Web ヘッダー

---

## 案C: 「ひ」モノグラム

**コンセプト**: ひらがな「ひ」を抽象造形にして、左の点を太陽、右下の払いに葉/芽を配置

- **強み**: 最も抽象的で独自性が高い、小サイズでも視認可能
- **弱み**: 「ひ」とすぐに認識されない可能性
- **推奨用途**: favicon、CEO の名刺等の小サイズ用途

## 使い方

### ブラウザでプレビュー
```bash
# Linux/WSL の場合
xdg-open assets/logo/mark_v0_a_sun_sprout.svg

# Mac の場合
open assets/logo/mark_v0_a_sun_sprout.svg

# Windows の場合（WSL）
explorer.exe assets/logo/mark_v0_a_sun_sprout.svg
```

### PNG に変換（SNS アップロード用）

#### 方法1: ブラウザ + スクリーンショット（最速・無料）
1. SVG ファイルをブラウザで開く
2. ズームで好みのサイズに調整
3. スクリーンショット → 保存

#### 方法2: Inkscape（無料・本格的）
1. https://inkscape.org/ からダウンロード（無料）
2. SVG を開く
3. File → Export → PNG → サイズ指定（推奨 512x512 以上）

#### 方法3: オンライン変換（無料）
- https://cloudconvert.com/svg-to-png （無料、登録不要、複数同時変換可）
- https://www.zamzar.com/convert/svg-to-png/

### ChatGPT に画像生成依頼する場合

ChatGPT (DALL-E) でプロフィール画像を作る際、本ロゴを参考画像として渡しつつ、以下のプロンプトテンプレが使えます：

```
[添付: 本ロゴ SVG]

このロゴの世界観で、SNSプロフィール画像を作ってください。
- ブランド: ひだまりこそだち（子育て支援サービス）
- 雰囲気: 温かい・柔らかい・断言しない・親と子を急かさない
- 必須要素: はちみつ色の太陽、親と子の2つの新芽
- 避けるもの: 人物写真、子供のキャラクター、強い原色、誇大なテキスト
- カラー: #FFC857（太陽）、#7AA77A・#A4C293（葉）、#FFFAF0（背景）
- 用途: SNS（円形クロップ前提）、最小辺 512px 以上
- フォーマット: シンプル、和の優しさ、午後の陽だまり
```

## 編集したい場合

- **Inkscape**（無料・Windows/Mac/Linux）: SVG を直接編集
- **Figma**（無料・Web）: SVG を import して編集
- **Canva**（無料・Web）: 「アップロード」から SVG 配置、テキスト追加

色の変更は SVG ファイルを直接テキストエディタで開き、`fill="#FFC857"` のような部分を書き換えるだけでも可能です。
